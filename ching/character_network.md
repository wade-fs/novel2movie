# character_network.md
# 人物關係網與政治互動管理

> 文件狀態：初版，持續校訂中  
> 適用範圍：清末至現代，1840年至暫定2020年  
> 核心用途：管理歷史人物之間的關係、政治立場、組織歸屬、利益衝突與合作變化，確保人物塑造符合歷史脈絡，並維持跨卷敘事的一致性。

---

## 一、文件目的

《天下易主》以人物推動歷史敘事，但不把歷史簡化成少數英雄的意志，也不以勝敗或道德評價直接決定人物的重要性。

人物關係網的目的，是理解：

1. 人物為何合作、競爭、妥協或決裂。
2. 個人選擇如何受到制度、組織、利益與資訊限制。
3. 同一人物在不同時期為何可能改變立場。
4. 名義上的上下級關係，是否等同於實際的權力控制。
5. 地方勢力、中央政府、軍隊、政黨、商業網絡與普通人之間如何互相影響。
6. 歷史人物如何透過不同制度與政治環境，影響後續世代。

本文件不只是人物名單，而是整個小說專案的**人物關係資料庫規範**。

## 二、人物分級

全系列統一採用一級、二級、三級人物分類，不以正派、反派或歷史勝敗作為分級標準。

### 2.1 一級人物：跨卷核心人物

一級人物通常具備下列一項或多項特徵：

- 直接影響重大歷史轉折。
- 跨越多個重要事件或政治階段。
- 其選擇能呈現制度、利益與歷史條件之間的衝突。
- 與多條人物線存在持續互動。
- 能連結中央政治、地方社會與普通人的生活。

例如，清末至民國初年的核心人物可包括曾國藩、李鴻章、慈禧太后、孫中山、袁世凱；民國至1949年的核心人物可包括蔣中正、毛澤東，以及其他對國家與地方秩序具有重大影響的人物。

上述名單僅為初步候選，最終分級應依各卷的敘事任務決定。

### 2.2 二級人物：關鍵互動人物

二級人物可能不是全系列主軸，但對特定政治轉折、組織運作或人物選擇不可或缺。

常見類型包括：

- 政治人物的同僚、競爭者與幕僚。
- 地方軍政首長、外交官、官僚與組織領導人。
- 重要的思想家、新聞工作者、商人、教育者與社會運動者。
- 連接不同地區、階層或政治組織的人物。

二級人物不可只作為一級人物的陪襯。其立場、利益與行動必須有自己的邏輯。

### 2.3 三級人物：局部事件與社會生活人物

三級人物的作用，是讓歷史進入具體生活。

可能包括：

- 地方官吏、基層軍人、教師、學生與商販。
- 難民、農民、工人、家庭成員與地方社會代表。
- 在特定事件中留下記錄的見證者。
- 為小說連接不同地點、階層與歷史事件而創作的虛構人物。

三級人物可以是虛構角色，但其生活條件、行動能力與可獲得的資訊，必須符合當時的歷史環境。

## 三、關係類型與記錄方式

人物之間不能只標記「認識」「朋友」「敵人」等籠統關係。每條重要關係都應標明其性質、時間範圍與證據依據。

### 3.1 關係分類

| 關係類型 | 定義 | 校核重點 |
|---|---|---|
| 親屬 | 血緣、婚姻、收養及姻親關係 | 親屬關係是否有可靠史料支持 |
| 師承 | 師生、思想傳承、軍政培訓 | 是否為正式師承，或僅有思想影響 |
| 上下級 | 官職、軍階、組織職務上的隸屬 | 名義職位與實際指揮權是否一致 |
| 政治合作 | 共同推動政策、政變、改革或革命 | 合作目標是否一致，合作何時開始或結束 |
| 組織隸屬 | 同一政黨、軍隊、政府或社會組織 | 加入、退出、被開除或組織改組的時間 |
| 利益聯盟 | 基於共同利益形成的暫時合作 | 利益是否改變，是否存在隱藏衝突 |
| 政治競爭 | 爭奪職位、政策主導權或組織控制權 | 競爭的具體目標與制度背景 |
| 軍事對抗 | 直接交戰或指揮敵對力量 | 不可把軍事對抗直接等同私人仇恨 |
| 思想分歧 | 對國家、制度、革命或改革有不同主張 | 不同主張是否隨時間改變 |
| 外交關係 | 談判、承認、條約、交涉與外交衝突 | 正式外交關係與私人接觸分開記錄 |
| 社會網絡 | 商業、新聞、教育、地方社團與人脈 | 關係是否真實存在，能否影響事件 |
| 間接影響 | 透過政策、著作、組織或他人影響另一人物 | 不可將間接影響寫成直接會面 |

### 3.2 關係必須具有時間範圍

人物關係不是永久不變的標籤。

例如，兩人可能先是政治盟友，後來因權力分配而競爭，最後成為敵對力量。資料應記錄不同階段，而非只寫「盟友」或「敵人」。

建議使用以下格式：

| 欄位 | 說明 |
|---|---|
| 關係編號 | 唯一識別碼，例如 `REL-0001` |
| 人物A | 第一位人物 |
| 人物B | 第二位人物 |
| 關係類型 | 合作、上下級、競爭、親屬等 |
| 開始時間 | 可確認的日期或時間區間 |
| 結束時間 | 關係終止或轉變的時間 |
| 形成原因 | 制度、利益、共同目標或私人因素 |
| 關係變化 | 何時、因何事改變 |
| 證據來源 | 公文、書信、日記、回憶錄或研究著作 |
| 證據狀態 | 已核實、部分核實、待查證、存有爭議 |
| 敘事用途 | 此關係如何推動事件或呈現制度問題 |
| 相關章節 | 所有使用此關係的章節 |

## 四、政治互動的分析模型

政治人物的行動不能只用性格或道德評價解釋。每項重大選擇都應從以下層次分析。

### 4.1 五個分析層次

**第一層：個人條件**

- 出身、教育、經歷與政治生涯。
- 對風險、權力與制度的理解。
- 個人聲望、家庭與職位所帶來的限制。

**第二層：組織利益**

- 所屬政黨、軍隊、政府機關或地方勢力的需求。
- 組織內部的權力競爭。
- 人物是否有能力代表整個組織作出決策。

**第三層：制度條件**

- 法令、憲制、官僚程序與行政能力。
- 財政、軍事、交通、通訊及人事任命制度。
- 名義上的權力與實際執行能力之間的差距。

**第四層：外部壓力**

- 外國政府、國際局勢與戰爭。
- 地方勢力、商業利益與社會運動。
- 經濟危機、人口流動、饑荒與公共秩序。

**第五層：資訊與選擇**

- 當時人物知道什麼、不知道什麼。
- 消息是否即時、可靠或受到刻意隱瞞。
- 當事人有哪些可行選項。
- 其選擇造成哪些預期外後果。

### 4.2 不可使用的簡化方式

以下解釋不能在沒有充分證據的情況下直接作為小說定論：

- 「因為他天生多疑，所以必然發動某次政治清洗。」
- 「因為他有遠見，所以早已知道未來的結果。」
- 「某人物反對某政策，必定只是為了爭權。」
- 「某人接受某項安排，就代表完全認同整套制度。」
- 「某政權取得勝利，證明其所有決策都正確。」
- 「某人物失敗，證明其能力、人格或理想必然有問題。」

人物可以有野心、恐懼、偏見與誤判，但這些特質必須透過史料、行動與環境來呈現。

## 五、跨卷人物管理

### 5.1 一級人物必須建立完整人物時間線

每位一級人物至少應有以下資料：

1. 出生、教育與早期經歷。
2. 進入政治或組織體系的時間。
3. 重要職位、權力來源與人際網絡。
4. 重大決策及其背景。
5. 政治立場或組織歸屬的變化。
6. 與其他核心人物的關係變化。
7. 退場、死亡、流亡或政治影響力衰退。
8. 後世如何重新詮釋此人。

### 5.2 跨卷一致性檢查

每次人物跨卷出現，必須檢查：

- 年齡是否正確。
- 職位是否符合當時情況。
- 人物所在地是否合理。
- 是否已經與某人決裂、合作或失去聯絡。
- 是否已知某件事件的結果。
- 其資源、權力與社會網絡是否已經改變。
- 後續卷是否沿用前卷已確立的人物性格與行動邏輯。

人物的性格可以發展，立場可以轉變，但改變必須有過程，而不是為了配合單章劇情而任意變化。

## 六、人物網絡與組織網絡分開管理

歷史政治不是單純的人際關係集合。人物即使互相認識，也不代表其所屬組織必然合作。

因此，至少要建立三種相互連結的網絡。

### 6.1 個人關係網

呈現人物之間的親屬、師承、私人往來、政治合作與衝突。

### 6.2 組織關係網

呈現政府、政黨、軍隊、地方勢力、商業組織、學校、新聞機構及社會團體之間的關係。

### 6.3 制度與資源網

呈現權力如何透過職位、財政、軍隊、交通、通訊、教育、司法與地方行政運作。

例如，兩位人物可能有私人交情，卻因所屬組織利益不同而相互競爭；也可能彼此不信任，卻因共同面對外部壓力而合作。

小說應呈現這種多層次關係，而不是把政治史寫成單純的朋友與敵人之爭。

## 七、1840—1912年人物網絡的初步配置

本節只建立研究方向，並非最終人物名單。

### 7.1 清廷與地方官僚

研究人物包括道光帝、咸豐帝、慈禧太后、恭親王奕訢、曾國藩、左宗棠、李鴻章等。

重點問題：

- 中央決策與地方執行之間存在什麼落差？
- 地方官員如何取得財政、軍事與人事資源？
- 洋務建設如何改變官僚之間的權力關係？
- 新式機構與傳統行政體系如何並存？
- 地方軍事力量的擴大，對中央權威造成什麼長期影響？

### 7.2 改革、立憲與革命網絡

研究人物包括康有為、梁啟超、譚嗣同、孫中山、黃興、宋教仁、袁世凱等。

重點問題：

- 改革派與革命派的目標何時重合，何時分歧？
- 海外組織、地方新軍、商會與新式教育如何參與政治變化？
- 清廷新政為何同時可能強化國家能力，也可能激化政治不滿？
- 1911年各省響應革命時，各地的政治與軍事條件有何不同？
- 共和制度建立後，中央權力與地方力量為何難以迅速整合？

## 八、1912—1949年人物網絡的初步配置

### 8.1 共和與軍閥政治

研究人物包括袁世凱、黎元洪、段祺瑞、馮國璋、曹錕、吳佩孚、張作霖等。

重點問題：

- 中央政府的名義權威與地方軍事實力如何互動？
- 財政、軍隊與鐵路控制權如何影響政治聯盟？
- 軍閥之間的合作是否有固定原則，還是隨利益與局勢變化？
- 地方民眾如何受到徵兵、稅賦、軍事衝突與行政更替的影響？

### 8.2 國民黨、共產黨與其他政治力量

研究人物包括孫中山、蔣中正、汪精衛、毛澤東、周恩來、朱德、張學良、楊虎城等。

重點問題：

- 國共合作的組織安排與政治目標如何變化？
- 1927年分裂如何改變雙方的組織與社會基礎？
- 蔣中正與毛澤東各自依靠哪些制度、組織、人事與資源？
- 地方軍事力量如何影響中央決策？
- 抗戰期間各政治力量如何合作、競爭並擴大自身影響？
- 1945年以後的政治衝突如何受到戰爭遺產、接收問題、財政危機與社會不滿影響？

### 8.3 臺灣戰後接收與地方社會

研究人物與群體不能只限於中央政治人物，也應包括：

- 臺灣省行政長官公署及相關行政人員。
- 地方仕紳、商業團體、教育界與新聞界。
- 戰後返臺或遷入臺灣的各類人口。
- 二二八事件中不同地區的參與者、受害者與行政機關。
- 戒嚴體制下的地方治理、政治案件與家庭生活。

人物網絡必須區分全臺共同的制度背景與各地不同的事件經過，不可把所有地方經驗合併成單一模式。

## 九、1949年後人物網絡的初步配置

第八卷須把臺灣與中國大陸視為不同政治制度下持續互相影響的歷史社會。

### 9.1 臺灣政治與社會

人物網絡應涵蓋：

- 蔣中正及其後的政治領導者。
- 中央政府、地方政府、軍方與黨國體制。
- 民主運動、社會運動、新聞界與知識界。
- 不同世代的家庭、教育與社會記憶。

### 9.2 中國大陸政治與社會

人物網絡應涵蓋：

- 毛澤東及其後的政治領導者。
- 中國共產黨的組織、國家機構與地方治理。
- 土地改革、經濟政策、社會運動與制度變化。
- 城鄉差異、人口流動、教育與日常生活。

### 9.3 兩岸關係

研究對象包括政府、政黨、軍事與外交機構，也包括：

- 親屬、探親與家庭分隔。
- 經貿往來、投資與勞動人口流動。
- 媒體、教育、文化與歷史敘事。
- 國際關係與區域安全。
- 不同世代對戰爭、分治、威權與民主的記憶。

本卷不應只靠領導者的公開發言推進，而應呈現政策如何經過制度，最後影響具體的人。

## 十、虛構人物與歷史人物的連接規則

小說可以創作虛構人物，但不能讓虛構人物取代真實歷史人物的決策權，也不能讓虛構人物成為所有重大事件的唯一見證者。

### 10.1 虛構人物可以承擔的功能

- 連接不同社會階層與地理區域。
- 呈現普通人對制度變化的感受。
- 讓讀者看見檔案中較少留下記錄的生活經驗。
- 透過商業、教育、家庭、交通與地方社會，連接不同歷史事件。
- 展現不同政治選擇的生活代價。

### 10.2 虛構人物不可任意承擔的功能

- 直接決定已知的重大歷史結果。
- 取代史實中的政治人物，成為真正的政策制定者。
- 被安排參與沒有證據支持的重大密會，並以此解釋全部歷史。
- 透過一個人的遭遇代表整個社會的唯一經驗。
- 以虛構對話掩蓋史料中的重要分歧。

若虛構人物與歷史人物相遇，必須先確認時間、地點、身分與接觸管道是否合理。

## 十一、人物資料的標準格式

每位重要人物建立獨立資料檔，並以統一欄位管理。

### 人物基本檔案

| 欄位 | 說明 |
|---|---|
| 人物編號 | 唯一編號，例如 `CHR-0001` |
| 姓名 | 使用統一名稱 |
| 別名與稱謂 | 字、號、官稱、職稱及其他常用名稱 |
| 生卒年 | 依可靠史料記錄 |
| 人物分級 | 一級、二級、三級 |
| 主要活動地 | 依時間區間記錄 |
| 職位與組織 | 分別記錄名義職位及實際隸屬 |
| 核心利益 | 依史料與行動分析，不作無根據的心理推定 |
| 政治立場 | 記錄各時期的具體主張與變化 |
| 主要關係 | 連結關係編號 |
| 關鍵事件 | 連結事件編號 |
| 證據狀態 | 已核實、部分核實、待查證、存有爭議 |
| 相關卷章 | 列出出場與被提及的卷、章 |
| 修訂紀錄 | 保留修改原因與影響範圍 |

## 十二、人物關係驗收表

每章完成後，針對涉及的人物關係進行檢查。

- [ ] 人物在該時間點的職位與組織歸屬正確。
- [ ] 人物間的關係符合當時狀態。
- [ ] 已經結束的合作或衝突沒有被當作仍然存在。
- [ ] 人物所知道的資訊符合消息傳遞的時間與管道。
- [ ] 政治選擇能由人物利益、制度條件與當時資訊加以解釋。
- [ ] 立場變化有可追蹤的原因與過程。
- [ ] 沒有把名義上的上下級誤寫成完全控制。
- [ ] 沒有把私人交情直接等同政治合作。

## 十五、總結

人物關係網的核心不是判斷誰是朋友、誰是敵人，而是理解人物如何在不同時代、制度與利益條件下形成合作、競爭與衝突。

同一個人可以在某個階段成為改革的推動者，在另一個階段成為制度的維護者；也可以在面對不同危機時，作出看似矛盾但有其歷史條件的選擇。

《天下易主》必須讓人物的選擇有根據，讓政治關係有變化的過程，讓組織利益與普通人的生活彼此連結。

**人物不是歷史的標籤，而是身處制度與時代之中、必須作出選擇的人。**
