# **下冊｜分途之後**

主題：共和如何走向分裂，歷史又如何延續至當下。

從民國初年的政治困局開始，經歷北洋政府、國民革命、國共分裂、抗日戰爭、戰後內戰與政府遷臺，最後回顧兩岸不同的政治與社會道路。

# **四、16 卷共同的寫作規範**

為了避免作品變成一部單純的政治人物編年史，我建議兩冊共用以下原則。

| 項目 | 規劃原則 |
| ----- | ----- |
| 歷史人物 | 以一級、二級、三級人物分層，不以簡單的正反派標籤取代史實 |
| 一級人物 | 貫穿多卷、影響主要歷史走向的人物 |
| 二級人物 | 官員、軍人、知識分子、商人、地方領袖及重要的中介人物 |
| 三級人物 | 普通百姓、工匠、學生、士兵、婦女、難民、商販與虛構的日常生活人物 |
| 事件描寫 | 以時間、人物選擇、制度變化與事件後果為主 |
| 戰爭描寫 | 不以戰術推演或戰場殺伐為主，著重徵發、物價、書信、遷徙、家庭離散與地方秩序 |
| 歷史判斷 | 區分確鑿史實、合理推演與小說虛構 |
| 臺灣視角 | 從 1895 年割臺開始就納入主線，不把臺灣當成結尾才出現的附錄 |
| 上下冊銜接 | 相同事件可以重現，但必須有不同的敘事目的與人物視角 |
