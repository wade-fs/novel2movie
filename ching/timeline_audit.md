# 《天下易主・故國潮聲》年代總表與史實校核

> 文件狀態：初版，持續校訂中  
> 適用範圍：清末至現代，1840年至暫定2020年  
> 核心用途：建立全系列共用的年代基準，校核歷史事件、人物行蹤、政治制度、地理位置與章節情節。  
> 本文件不取代各卷詳細年表，也不代表列出的每項史實均已完成原始史料考證。

---

## 一、文件目的與基本原則

《天下易主》不是依照年份排列事件的教科書，而是以歷史人物、政治互動與社會生活呈現舊秩序的瓦解，以及新秩序如何形成、分裂與延續。

因此，年代校核必須同時回答四個問題：

1. **事情何時發生？** 包含起始日期、結束日期、事件先後與因果關係。
2. **人物當時在哪裡？** 包含任職地點、實際活動範圍、交通所需時間與可取得的資訊。
3. **當時的政治現實是什麼？** 包含名義上的中央政府、實際控制區域、地方勢力與制度變化。
4. **普通人的生活受到什麼影響？** 包含糧價、稅賦、貨幣、交通、教育、家庭、工作與地方秩序。

小說中每項重要情節，都必須能夠放回當時的時間、地點與制度環境中檢驗。

### 1.1 史實標記

全系列統一使用以下標記：

- **【史實骨架】**：有可靠史料支持的事件、日期、人物行蹤或制度。
- **【合理推演】**：史實條件成立，但具體情境、人物反應或事件間的因果連結屬於推論。
- **【小說虛構】**：為小說而創作的人物、對話、私人書信、家庭關係或具體遭遇。

以上標記與證據狀態分開管理。某件事即使屬於【史實骨架】，仍可能存在日期、數量、責任歸屬或不同史料記載不一致的問題。

### 1.2 證據狀態

每項重要年代記錄應有一個校核狀態：

| 狀態 | 定義 | 使用規則 |
|---|---|---|
| 已核實 | 已找到可靠史料，關鍵日期與事件基本吻合 | 可作為章節基準 |
| 部分核實 | 事件成立，但日期、細節或因果仍有待確認 | 可使用已確認部分 |
| 待查證 | 目前只有初步年表或二手資料支持 | 不可據此設計關鍵轉折 |
| 存有爭議 | 學界或史料存在不同說法 | 必須保留不同解釋 |
| 已修訂 | 舊記錄經考證後修改 | 保留修訂理由與影響範圍 |

### 1.3 年代精度

不可把不同精度的日期混為一談。

- **精確日期**：年、月、日皆有可靠依據。
- **月份級**：可確認月份，但日次尚未確認。
- **年份級**：只能確認年份。
- **時間區間**：事件延續一段時間，須分別記錄開始、發展與結束。
- **後世追述**：事件日期來自回憶錄、傳記或後世整理，須另行確認其可靠性。

若只知道某人「約在1919年前後」開始某項活動，不可為了方便排章而擅自指定為1919年某月某日。

## 二、全系列時間範圍與分卷基準

全書暫分上下兩冊，共16卷。以下是創作規劃的工作版本，不是不可更改的歷史分期。

### 2.1 上冊：舊國新生（1840—1912）

| 卷次 | 暫定書名 | 年代範圍 | 核心歷史問題 |
|---|---|---|---|
| 第一卷 | 《海門洞開》 | 1840—1860 | 清朝如何面對海上強權、內亂與制度危機？ |
| 第二卷 | 《天下多故》 | 1850—1870 | 大規模內亂如何改變地方秩序、財政與人口？ |
| 第三卷 | 《自強與新局》 | 1860—1884 | 新式軍政、外交、教育與工業如何進入舊制度？ |
| 第四卷 | 《海疆失色》 | 1884—1895 | 東亞國際秩序變動如何衝擊清朝與周邊地區？ |
| 第五卷 | 《變法與激盪》 | 1895—1900 | 戰敗後的改革、革命與社會動員如何交錯？ |
| 第六卷 | 《庚子之後》 | 1900—1905 | 戰敗、賠款與列強壓力如何改變國家運作？ |
| 第七卷 | 《新政未竟》 | 1905—1911 | 新政、立憲、革命與地方政治如何彼此牽動？ |
| 第八卷 | 《故國易主》 | 1911—1912 | 帝制終結後，共和政體如何建立？ |

**分卷注意：** 1850—1860、1895—1900、1911—1912等時段在相鄰卷之間具有高度連續性。重疊年份不是錯誤，但每卷必須明確標示敘事重點，不能讓同一事件在不同卷中出現互相矛盾的版本。

第一卷與第二卷存在明顯重疊。第一卷以對外戰爭、通商秩序與太平天國興起為主；第二卷則應將重心轉向內亂擴大、地方治理、財政與社會重組。

### 2.2 下冊：分途之後（1912—暫定2020）

| 卷次 | 暫定書名 | 年代範圍 | 核心歷史問題 |
|---|---|---|---|
| 第一卷 | 《共和初立》 | 1912—1916 | 共和制度如何在袁世凱與各政治力量的競逐中受挫？ |
| 第二卷 | 《山河未定》 | 1916—1924 | 軍閥政治、地方勢力與新思想如何重塑中國？ |
| 第三卷 | 《革命同途》 | 1924—1927 | 國共合作如何形成，又如何走向破裂？ |
| 第四卷 | 《道路分岔》 | 1927—1931 | 南京國民政府、共產黨與地方力量如何形成新的對抗？ |
| 第五卷 | 《外患逼近》 | 1931—1937 | 日本侵略如何改變中國的政治選擇與社會生活？ |
| 第六卷 | 《共赴國難》 | 1937—1945 | 全面抗戰如何改變國家、社會與各政治力量？ |
| 第七卷 | 《分途而行》 | 1945—1949 | 戰後接收、政治衝突、國共內戰與政府遷臺如何交錯？ |
| 第八卷 | 《潮聲未歇》 | 1949—約2020 | 分治後的臺灣、中國大陸與兩岸關係如何演變？ |

**分卷注意：**

1. 1924—1927年的國共合作、北伐與1927年分裂，應以具體事件安排轉折，不可將合作寫成一個毫無變化的固定狀態。
2. 1931年九一八事變至1937年七七事變之間，不應被寫成單純的戰爭前奏；東北、華北、上海、南京及各地方的處境並不相同。
3. 1945年日本戰敗後，臺灣的接收與治理具有自身的制度背景，不能只作為中國大陸戰後政治的附屬章節。
4. 1949年是政府控制區域與兩岸政治格局的重要轉折，但不能把所有地區的政權變化簡化成同一天完成。
5. 第八卷的終點暫定約2020年。正式編寫前，應決定是否以2020年為回顧終點，或延伸至更接近本書完成時的年代。

## 三、上冊年代總表：清末至共和建立

### 3.1 1840—1860：外部衝擊與內部危機

| 年份 | 主要事件 | 校核重點 | 狀態 |
|---|---|---|---|
| 1840 | 第一次鴉片戰爭爆發 | 戰爭爆發、英軍行動與清廷決策須分別記錄 | 部分核實 |
| 1842 | 《南京條約》簽訂 | 條約日期、割讓香港及通商安排 | 部分核實 |
| 1850—1851 | 太平天國運動興起 | 洪秀全的活動、金田起事與太平天國建制不可混為單一事件 | 部分核實 |
| 1853 | 太平軍攻占南京，改稱天京 | 城市控制、人口變動、地方官府與江南交通 | 部分核實 |
| 1856 | 第二次鴉片戰爭爆發 | 亞羅號事件、廣西西林教案及英法政策需分開處理 | 部分核實 |
| 1858 | 《天津條約》簽訂 | 各國條約日期、條款與批准程序不可合併 | 部分核實 |
| 1859 | 大沽口戰事 | 英法使團、清軍防務及外交衝突的先後關係 | 待查證 |
| 1860 | 英法聯軍進入北京，《北京條約》簽訂 | 北京陷落、圓明園遭焚毀、咸豐帝行蹤及各國條約分別核對 | 部分核實 |

基本年代骨架可參照亞洲歷史資料中心的年表，以及相關條約與外交史料。該中心將《南京條約》列於1842年、《天津條約》列於1858年、《北京條約》列於1860年；這些資料可用來建立日期基準，但小說涉及條約內容時仍須查閱各條約原文及相關研究。參考：[日本亞洲歷史資料中心年表](https://www.jacar.go.jp/learning/menu01.html)。

#### 第一、二卷特別校核

- 道光、咸豐兩朝的決策必須依照當時可取得的情報呈現，不可直接套用後世已知結果。
- 太平天國不能只以洪秀全一人代表；地方士紳、清廷官員、團練、商人、農民與流民各有不同處境。
- 《南京條約》《天津條約》《北京條約》涉及不同國家、不同時間與不同法律內容，不可籠統寫成一次性「割地賠款」。
- 圓明園遭焚毀的事件與聯軍進入北京的過程須分開校核，不可把所有暴行、搶掠與焚毀行為簡化成同一個瞬間。
- 太平天國的政權建立、制度運作與軍事擴張應分階段處理，尤其注意南京、江南與其他地區的時間差。

### 3.2 1861—1895：改革、地方權力與東亞變局

| 年份 | 主要事件 | 校核重點 | 狀態 |
|---|---|---|---|
| 1861 | 辛酉政變及清廷權力重組 | 奕訢、慈禧、慈安及顧命大臣之間的權力關係 | 待查證 |
| 1864 | 太平天國天京失陷 | 天京失陷不等於所有相關武裝與地方衝突同時終結 | 部分核實 |
| 1860年代起 | 洋務運動逐步展開 | 各地軍工、船政、翻譯、教育與外交機構的成立年份不同 | 部分核實 |
| 1874 | 日本出兵臺灣 | 日本出兵、清日交涉、牡丹社事件及臺灣地方社會的關係 | 待查證 |
| 1884—1885 | 中法戰爭 | 越南局勢、福建與臺灣戰事、清廷外交決策及戰後條約 | 部分核實 |
| 1894—1895 | 甲午戰爭 | 朝鮮問題、清日戰爭、海陸戰局與外交談判的先後關係 | 部分核實 |
| 1895 | 《馬關條約》簽訂，臺灣及澎湖列入割讓範圍 | 條約簽訂、割讓生效、日軍接收與臺灣地方抵抗須分開記錄 | 部分核實 |

#### 校核原則

1. 洋務運動不是由一紙詔令在全國同時開始的單一政策。各地機構、人物與發展節點應各自建立年代紀錄。
2. 中法戰爭與甲午戰爭涉及越南、朝鮮、臺灣及其他地區，不能只從北京的決策視角呈現。
3. 臺灣在清末的歷史不能只用「被割讓」一個事件概括。必須保留清廷治理、地方社會、原住民族、日本的對外政策與國際交涉等不同層次。
4. 1895年應區分條約簽訂、臺灣民主國成立、日軍登陸、地方抵抗與日本殖民統治逐步建立的不同階段。

### 3.3 1895—1912：改革、革命與帝制終結

| 年份 | 主要事件 | 校核重點 | 狀態 |
|---|---|---|---|
| 1898 | 戊戌變法及政變 | 變法措施、政治人物的實際參與及政變前後的時間順序 | 部分核實 |
| 1900 | 義和團運動與八國聯軍進入北京 | 義和團活動、清廷宣戰、聯軍進軍與各地衝突分開記錄 | 部分核實 |
| 1901 | 《辛丑條約》簽訂 | 賠款、駐兵、外交與清廷後續政策 | 部分核實 |
| 1905 | 科舉制度廢除 | 廢科舉的政策與各地教育、仕途及社會影響 | 部分核實 |
| 1905 | 中國同盟會成立 | 孫中山與革命組織的形成及海外網絡 | 部分核實 |
| 1908 | 光緒帝與慈禧太后相繼去世 | 死亡日期、權力交接及宣統帝繼位 | 待查證 |
| 1911 | 武昌起義及各省響應 | 武昌起義、各省獨立、軍政轉換與南北談判 | 部分核實 |
| 1912 | 中華民國成立；清帝退位 | 臨時政府成立、孫中山就任、袁世凱接任與退位詔書的先後關係 | 部分核實 |

#### 1911—1912年不可混淆的四個節點

1. **1911年10月10日：** 武昌起義。
2. **1912年1月1日：** 中華民國臨時政府在南京成立，孫中山就任臨時大總統。
3. **1912年2月12日：** 清帝退位。
4. **1912年3月：** 袁世凱在北京就任臨時大總統。

中華民國的成立與清帝退位不是同一事件。帝制終結、共和政體宣告成立與中央權力轉移，是相互關聯但各有程序的政治變化。可參考行政院「中華民國之肇建」及相關官方史料：[中華民國之肇建](https://www.ey.gov.tw/state/62879155A536D543/bf75db05-30af-4c3a-bdda-3fe32e3f8e5a)。

**敘事要求：** 不可把1912年以後的中國寫成中央政府完全失去作用，也不可把名義上的中央政府直接等同於全國實際控制者。各省的行政、軍事、財政與交通控制程度必須依年份及地區判斷。

|---|---|---|---|

| 1931 | 九一八事變 | 日本關東軍行動、東北地方政權與南京政府的反應 | 部分核實 |

#### 必須保留的歷史複雜性

- 國共合作並非所有參與者都有相同目標。
- 1927年的政治分裂不能只用單一人物的個人恩怨解釋。
- 國民政府建立後，名義統一與實際治理能力仍存在差距。
- 共產黨的組織發展、地方武裝與根據地建立，必須依具體時間和地點呈現。
- 蔣中正與毛澤東的長期對照應建立在兩人的實際活動軌跡、組織位置與政策選擇上，不能讓他們在早期階段就以後來的歷史地位支配所有敘事。

| 1934—1936 | 中央紅軍長征及各地政治軍事變化 | 行軍路線、時間、沿途社會與其他紅軍部隊的活動不可混為一談 | 待查證 |
| 1936 | 西安事變 | 張學良、楊虎城、蔣中正及各方交涉的實際順序 | 待查證 |
| 1937 | 七七事變與全面抗戰爆發 | 華北衝突擴大、上海戰事、南京陷落及政府遷移的時間順序 | 部分核實 |

**校核要求：** 不應將1931至1937年視為一段沒有獨立歷史意義的空白期。東北、華北、上海、南京及西北的政治局勢不同，民眾受到的影響也不同。

### 4.4 1937—1945：全面抗戰

| 年份 | 主要事件 | 校核重點 | 狀態 |
|---|---|---|---|
| 1937 | 七七事變、淞滬會戰、南京陷落 | 政府機關、軍民撤離、難民與城市秩序的變化 | 部分核實 |
| 1938 | 武漢會戰及國民政府遷往重慶 | 政府機關遷移、交通中斷與戰時行政 | 待查證 |
| 1939—1940 | 戰爭延續、日軍占領區與各方政治組織發展 | 各地占領、游擊活動、物資與人口流動 | 待查證 |
| 1941 | 太平洋戰爭爆發，中國戰場與世界戰爭進一步連結 | 中國與美、英等國的外交、軍事與經濟關係 | 部分核實 |
| 1942—1944 | 戰時動員、經濟困難與各地軍政變化 | 徵糧、通貨膨脹、教育、難民與地方治理 | 待查證 |
| 1945 | 日本宣布投降，第二次世界大戰結束 | 投降消息、受降程序、戰區安排與各地接收時間 | 部分核實 |

#### 抗戰卷的時間管理規則

1. 「日本宣布投降」「正式簽署投降文書」「各戰區接受投降」應分別記錄。
2. 國民政府、中共及其他地方力量在不同地區的軍政活動不能統一寫成同一套流程。
3. 重慶、延安、南京、上海、東北與臺灣的時間線必須分開建立，再透過人物、交通、新聞與政策相互連結。
4. 戰爭不應只以戰役為章節單位。糧食徵購、物價、人口遷徙、學校停辦、難民救濟、交通運輸與家庭失散都應納入年代表。

### 4.5 1945—1949：戰後接收、內戰與政府遷臺

| 年份 | 主要事件 | 校核重點 | 狀態 |
|---|---|---|---|
| 1945 | 日本投降；國民政府接收臺灣 | 受降儀式、行政長官公署成立、軍事與行政接收的不同程序 | 部分核實 |
| 1946 | 制憲國民大會召開 | 憲政安排、國共政治關係與內戰發展 | 待查證 |
| 1947 | 《中華民國憲法》公布；二二八事件 | 憲政進程、臺灣地方行政、官民衝突與武力鎮壓須分開校核 | 部分核實 |
| 1948 | 行憲後第一任總統選舉；國共內戰局勢劇變 | 總統選舉、臨時條款、戰局及各地政治變化 | 部分核實 |
| 1949年1月 | 北平和平方式易手 | 談判、城市接管及地方行政變化 | 待查證 |
| 1949年4月 | 南京易手，國民政府機關繼續遷移 | 首都失守、中央機關所在地與政府遷移程序 | 部分核實 |
| 1949年5月 | 臺灣省實施戒嚴 | 戒嚴令日期、適用範圍及實際執行情形 | 部分核實 |
| 1949年10月 | 中華人民共和國成立 | 北京的建政程序與各地政權更替的不同時間 | 部分核實 |
| 1949年12月 | 中華民國政府遷臺北 | 中央政府機關、人員、資金與物資的遷移時間 | 部分核實 |

1945年臺灣的接收具有獨特的制度與社會背景。國家發展委員會檔案管理局相關教學資料，記錄了受降儀式、臺灣省行政長官公署、軍事接收與行政接收等事項，適合用來建立臺灣線的基本架構。參考：[臺灣戰後初期的接收與治理](https://art.archives.gov.tw/tw/art/373.html)。

#### 1949年校核的特別要求

**不能把「政府遷臺」寫成一個沒有過程的單日事件。**

必須區分：

- 中央政府的決策與各機關遷移。
- 蔣中正、李宗仁及其他政治人物的實際所在地。
- 南京、廣州、重慶、成都與臺北之間的政府活動。
- 軍事撤退、行政機關遷移、銀行與財政機構移轉。
- 臺灣本地原有行政體系、戰後接收與戒嚴治理。
- 中華人民共和國在大陸建立政權的進程。

中華民國政府遷臺與中華人民共和國成立分別涉及不同日期、地點與政治程序，應在年代表中分列。可參考：[行政院「中華民國之肇建」](https://www.ey.gov.tw/state/62879155A536D543/bf75db05-30af-4c3a-bdda-3fe32e3f8e5a)。

本卷不是前七卷的簡單尾聲，而是獨立的歷史回顧。敘事主體至少包含臺灣、中國大陸及兩岸關係三條相互影響、但不能互相取代的時間線。

## 六、人物行蹤與年代校核

人物年表不能只列出生、死亡、官職與著名事件。每位一級人物都必須建立可與章節對接的行蹤表。

### 6.1 必要欄位

| 欄位 | 說明 |
|---|---|
| 人物姓名 | 使用統一姓名，別名另列 |
| 年月日／時間區間 | 依史料可確認的精度填寫 |
| 所在地 | 城市、縣府、軍營、流亡地或海外地點 |
| 身分與職位 | 名義職位及實際權力分開記錄 |
| 所屬政治力量 | 中央政府、地方勢力、政黨、軍隊或社會組織 |
| 行動 | 任命、辭職、出走、談判、演說、參戰、被捕等 |
| 資訊來源 | 當時公文、日記、書信、報刊、回憶錄或研究著作 |
| 證據狀態 | 已核實、部分核實、待查證、存有爭議 |
| 相關章節 | 連結實際使用此人物的卷、章 |
| 修訂紀錄 | 日期或行蹤修正後，記錄受影響章節 |

### 6.2 不可違反的規則

1. 人物不能在沒有合理交通時間的情況下，同時出現在兩個相距甚遠的地點。
2. 人物的職位變動必須有任命、免職、辭職或其他可解釋的時間節點。
3. 名義上的職位不代表實際掌握相應權力。
4. 回憶錄中的敘述不能自動視為當時的即時記錄。
5. 不可為了讓兩位人物見面而虛構會面；若沒有證據，必須標記為【合理推演】或【小說虛構】。
6. 人物的政治立場可以改變，但轉變應有可追蹤的環境、利益、資訊與選擇，不可僅因章節需要而突然轉向。

## 七、歷史事件的時間拆解規則

重要事件應拆成可驗證的階段，而非只留下一個年份。

例如，一場政治變局至少可能包含：

1. 背景條件逐漸形成。
2. 直接導火線出現。
3. 決策者獲得消息。
4. 各方作出反應。
5. 正式宣布或採取行動。
6. 地方執行或抵抗。
7. 制度、權力或生活秩序發生變化。
8. 後續結果逐漸顯現。

並非每項事件都需要八個階段，但凡涉及重大政權轉換、戰爭、條約、改革、鎮壓或社會運動，都必須確認是否存在被簡化的中間過程。

### 7.1 條約校核

條約類事件至少記錄：

- 簽約日期與地點。
- 簽約代表及其授權。
- 條約文本與主要條款。
- 批准、換約或生效日期。
- 相關國家、地區與地方政府的反應。
- 實際執行時間與後續爭議。

### 7.2 政權轉換校核

政權更替至少區分：

- 宣告成立或退位的日期。
- 中央政府機關的所在地。
- 首都或主要城市的實際控制狀態。
- 地方官署是否仍在運作。
- 軍隊、警察、司法、財政與交通機構的轉移。
- 民眾何時真正感受到制度改變。

### 7.3 戰爭校核

戰爭不能只記錄開戰與停戰。必須建立戰區、交通線、補給、占領區、難民、物價、徵兵、徵糧與地方治理的時間線。

本系列不以戰術推演為主，但戰爭造成的社會影響仍必須符合當時的交通、通訊與行政能力。

## 八、地理、交通與消息傳遞的時間限制

年代表必須與歷史地理文件互相校核。

每項重要行動至少檢查：

- 出發地與目的地。
- 當時可用的陸路、水路、鐵路與海運。
- 正常情況與戰亂情況下的旅行時間。
- 電報、郵遞、報刊與口頭消息的傳遞速度。
- 季節、天候、封鎖、道路破壞與邊境管制。
- 人物是否有足夠時間收到消息、決策並採取行動。

不可將今日的高速交通、即時通訊與行政能力套用到十九世紀或二十世紀初。

如果小說中的人物比史料所能支持的時間更早收到消息，必須說明其來源，例如親歷事件、私人書信、官方電報或其他合理管道；不能只因劇情需要就讓所有人同時知情。

## 九、日常生活的年代限制

年代校核也必須檢查生活用品、制度與社會習慣。

| 項目 | 校核內容 |
|---|---|
| 貨幣與物價 | 當時流通貨幣、兌換制度、通貨膨脹與地區差異 |
| 糧食與生計 | 主要作物、運輸方式、糧價、徵糧與饑荒 |
| 通訊 | 書信、電報、電話、報紙及其普及程度 |
| 交通 | 馬車、轎、帆船、輪船、鐵路、公路及其可達範圍 |
| 教育 | 科舉、私塾、新式學堂、學制與識字能力 |
| 行政制度 | 地方官署、警察、司法、稅務與戶籍制度 |
| 社會身分 | 士紳、商人、農民、工人、學生、軍人及婦女的不同處境 |
| 戰爭與治安 | 徵兵、徵糧、難民、封鎖、宵禁、通行證與地方秩序 |
| 臺灣地方社會 | 清治、日治、戰後接收及戒嚴時期的制度差異 |

任何具體生活場景，都必須同時符合當時的年代、地點與社會階層。不能因某項制度在全國已經頒布，就假設所有地方立即、同樣地執行。

## 十、史料使用與來源優先順序

### 10.1 來源類型

**第一層：當時形成的原始資料**

- 政府公文、奏摺、法令、條約與會議紀錄。
- 日記、書信、私人筆記與當事人手稿。
- 報刊、廣告、商業帳冊、學校紀錄及地方檔案。
- 外交檔案、軍政檔案與司法檔案。

**第二層：整理與研究資料**

- 以原始史料為基礎的學術專著與期刊論文。
- 經過整理的檔案目錄、年表與人物年譜。
- 大學、研究機構、博物館及檔案機關的研究資料。

**第三層：一般參考資料**

- 教科書、通史、百科與普及讀物。
- 網路文章、新聞回顧及其他二手整理。

第三層資料適合用來發現研究方向，但重大事件、爭議性人物、精確日期與政治責任不能只靠第三層資料定案。

### 10.2 來源衝突的處理方式

若兩份資料記載不同：

1. 確認是否使用不同曆法或日期換算方式。
2. 確認兩者記錄的是同一事件，還是同一事件的不同階段。
3. 比較資料形成時間、作者身分、資訊取得方式與可能立場。
4. 查找能夠獨立互證的第三份資料。
5. 無法排除差異時，標示【存有爭議】，保留不同說法與理由。

不能單純以「官方資料一定正確」或「民間記載更接近真相」作為判斷標準。

## 十一、年代校核紀錄表

所有重要事件應建立一筆標準化紀錄。

| 欄位 | 填寫方式 |
|---|---|
| 事件編號 | 使用全系列唯一編號，例如 `EVT-1842-001` |
| 事件名稱 | 使用統一名稱，別稱另列 |
| 開始日期 | 年月日或可確認的時間區間 |
| 結束日期 | 適用時填寫 |
| 事件地點 | 明確到城市、地區或機構 |
| 主要人物 | 連結人物檔案 |
| 所屬卷次 | 列出主要敘事卷及跨卷關聯 |
| 史實摘要 | 只寫有史料支持的內容 |
| 史料依據 | 作者、書名／檔案名稱、出版資訊、頁碼或檔號 |
| 證據狀態 | 已核實、部分核實、待查證、存有爭議、已修訂 |
| 小說用途 | 說明此事件對人物與社會生活的影響 |
| 相關章節 | 列出所有涉及此事件的章節 |
| 修訂紀錄 | 日期、修改前後內容與理由 |

### 範例：1842年《南京條約》

- 事件編號：`EVT-1842-001`
- 事件名稱：《南京條約》簽訂
- 年份：1842

## 十三、修改與版本管理

年代表不是一次完成的文件。隨著新史料或新研究加入，可能需要修訂。

每次修訂必須記錄：

1. 修訂日期。
2. 被修訂的事件或人物。
3. 原有記載。
4. 新記載。
5. 修訂依據。
6. 受影響的卷、章、人物檔案與地理文件。
7. 是否需要重寫已完成章節。

### 修訂優先順序

1. **重大日期錯誤：** 事件年份、月份、日期或先後順序錯誤。
2. **人物行蹤衝突：** 同一人物不可能在同一時間出現在不同地點。
3. **政治制度錯誤：** 職位、政權、法令或控制範圍不符。
4. **因果關係錯誤：** 把後發事件當成先發事件的原因。
5. **地理與交通錯誤：** 路線、距離、交通能力或消息傳遞不合理。
6. **社會生活錯誤：** 貨幣、物價、教育、職業與日常用品不符合年代。

一旦發現上游年代錯誤，必須向下游檢查所有依賴該事件的章節，不能只改總表而保留小說中的舊版本。

## 十四、下一階段校核工作

本文件建立的是全系列的時間骨架。下一步不應立刻把所有事件擴寫成章節，而應優先補足最容易造成全書矛盾的資料。

### 第一優先：建立可追溯的事件資料

- [ ] 為1840—1912年的主要戰爭、條約、改革與革命補上可靠來源。
- [ ] 為1912—1949年的政權更替、政治運動與戰爭補上精確日期。
- [ ] 為1945年後臺灣的接收、戒嚴、民主化及兩岸關係建立獨立時間線。
- [ ] 對所有爭議性事件建立來源對照，而非只留單一敘述。

### 第二優先：建立人物行蹤表

先處理跨卷的一級人物，以及直接影響重大轉折的人物。蔣中正、毛澤東等人物的跨卷活動，尤其需要避免年代錯置與過度簡化。

### 第三優先：將年代表連結至分卷與章節

每個重要事件都應能追溯至：

`timeline_audit.md → timeline.md → volumeN.md → chapter_ledger.md → chapterNNN.md`

其中：

- `timeline_audit.md`：記錄史實基準、證據狀態與修訂。
- `timeline.md`：呈現全系列的事件時間線。
- `volumeN.md`：安排各卷的歷史範圍與敘事重心。
- `chapter_ledger.md`：管理章節事件、人物與連續性。
- `chapterNNN.md`：實際小說正文。

### 第四優先：重新驗收第一卷

在第一卷《海門洞開》進入大量正文寫作前，應先校核1840—1860年的戰爭、條約、太平天國、清廷決策、人物行蹤與地方社會。只有當時間骨架足以支撐人物行動，才適合進一步鎖定90章的細部情節。

## 十五、總結

`timeline_audit.md` 的任務不是把歷史變成一份永遠不變的日期清單，而是讓整個小說專案具備一套可以追溯、驗證與修正的歷史基準。

**所有重大情節都必須同時通過時間、地點、人物、制度與證據五項檢查。**

歷史小說可以推演人物的選擇，可以創作沒有留下記錄的普通人的生活，也可以讓不同人物透過合理的虛構情節相遇；但不能因為故事需要，就任意改動已確認的歷史事實。

《天下易主》所要呈現的，不只是誰取得政權，而是政權更替如何進入普通人的生活，以及舊時代留下的制度、記憶與矛盾，如何在新的時代繼續回響。
