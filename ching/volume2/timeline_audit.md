## 一、文件目的與校核原則

### 1.1 文件目的
本文件負責管理第二卷《天下多故》涉及的歷史年代、政治決策、人物行蹤、制度變化、地理空間與社會生活，確保第二卷建立在可核對、可追溯的史實骨架上。

本卷承接第一卷《海門洞開》（止於 1860 年 11 月《北京條約》換約與聯軍退兵）：清廷在兩次鴉片戰爭、條約體系與太平天國運動的衝擊下，已無法只依靠原有制度維持天下秩序。

第二卷的核心問題不是清廷是否「開始學習西方」，而是：
1. 清廷如何在內部叛亂（太平天國、捻軍、西北回亂）、財政壓力與外國條約勢力之間維持統治？
2. 地方督撫（湘系、淮系）、中央官僚（總理衙門、軍機處）、軍事力量與新式官督商辦企業之間，如何重新分配權力？
3. 所謂「同治中興」與「自強新政」，是國家整體能力的提升，還是局部制度與技術的修補？
4. 條約口岸、海外華工、傳教教案、新式學堂與電報輪船，如何改變普通人理解世界的方式？
5. **臺灣與東亞海疆**：從 1862–1864 年臺灣四口正式開關設稅、1867–1868 年羅發號與安平樟腦衝突、1874 年牡丹社事件、1879 年日本併吞琉球、1884–1885 年中法戰爭基隆滬尾之役，到 1885 年臺灣建省與劉銘傳新政，海疆如何從邊陲躍升為帝國海防與東亞秩序的焦點？

### 1.2 歷史分線（與第一卷 A–F 線無縫接軌）
- **A 線（中樞政局與條約外交）**：1861 總理衙門設立、公使入駐北京、熱河皇權交替與辛酉政變、兩宮垂簾、蒲安臣使團、天津教案、同光交替與清流派崛起。
- **B 線（知識、教育與近代傳播）**：京師同文館、上海廣方言館、江南製造總局翻譯館、1872–1881 留美幼童計畫、《申報》等近代報刊與西方科學知識傳播。
- **C 線（太平天國終局、捻亂與戰後社會重建）**：1860–1861 安慶合圍戰、1862–1864 天京攻防戰與太平天國覆滅、捻軍戰爭、江南與長江流域的招墾、減賦與基層社會重組。
- **D 線（督撫權力、湘淮軍制與洋務企業）**：湘軍裁撤與淮軍崛起、釐金與海關稅收（赫德總稅務司體系）的財政支柱、安慶內軍械所、江南製造總局、福州船政局、輪船招商局、開平礦務局、電報與鐵路爭議。
- **E 線（塞防與海防、中法戰爭與北洋水師）**：左宗棠西征平定阿古柏、伊犁交涉與 1884 新疆建省；1874 海防與塞防大論戰；1883–1885 中法戰爭（馬尾海戰、鎮南關大捷）；1888 北洋水師成軍與 1894 朝鮮東學黨危機。
- **F 線（臺灣開港、牡丹社事件與建省新政）**：1862–1864 淡水、雞籠、打狗、安平開關設稅；茶、糖、樟腦出口與洋行買辦興起；1867 羅發號事件與 1868 樟腦戰爭；1874 牡丹社事件與沈葆楨開山撫番；1884–1885 清法戰爭臺灣戰場（基隆、滬尾之役）；1885 臺灣建省與劉銘傳新政。

## 二、史實狀態與校核標記（與第一卷完全統一）

### 2.1 史實狀態標記
| 標記 | 意義 | 使用規則 |
| :--- | :--- | :--- |
| `[待核]` | 尚未完成來源查證 | 不得當成最終定稿依據 |
| `[初核]` | 已找到可用資料，但尚未完成交叉核對 | 可供研究與初步規劃，不宜鎖定細節 |
| `[已核]` | 已有足夠可靠的史料支持 | 可作為小說史實骨架 |
| `[有爭議]` | 不同史料對事件、日期、動機或細節存在差異 | 必須記錄不同說法與採用理由 |
| `[已修正]` | 原有記載經查證後已更正 | 必須保留修訂紀錄 |
| `[不採用]` | 曾列入考慮，但證據不足或不適合本卷 | 記錄原因，避免日後重複引入 |

### 2.2 證據與小說內容的區別
- **【史實骨架】**：有可靠證據支持的日期、事件、職務、地點及公開行動。
- **【合理推演】**：依當時制度、交通、資訊與社會條件推演的情境。
- **【小說虛構】**：為故事需要創作的角色、私人對話、家庭關係及未見於史料的互動。
- **【待考事項】**：目前證據不足，尚不能決定應採用何種說法。
