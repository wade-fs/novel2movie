# **`characters.md` — 人物分級與角色追蹤總表**

《天下易主》副標題：《故國潮聲》｜上下兩冊・十六卷

## **一、文件定位**

本文件建立《天下易主：故國潮聲》的跨卷人物系統，涵蓋晚清、民國建立、北洋時期、國民革命、國共分途、抗日戰爭、國共內戰，以及中華民國政府遷台後的歷史回顧。

本書不以單一人物的成敗作為歷史主軸，而是透過不同人物的選擇、利益、制度位置與生活經驗，呈現中國舊秩序瓦解後，各方如何重新理解國家、民族、政權與故土。

人物分級依據的是敘事重要性與跨卷影響力，不是歷史地位、道德評價或最終勝敗。

### **1.1 人物分級原則**

| 分級 | 定義 | 敘事功能 |
| ----- | ----- | ----- |
| 一級人物 | 貫穿多卷、直接影響歷史主線，或能代表重大政治與社會轉折的人物 | 建立長期人物弧線，串連歷史事件 |
| 二級人物 | 在特定時期、事件、地區或制度中具有重要影響的人物 | 補足政治派系、地方社會、制度變化及人物關係 |
| 三級人物 | 普通人、地方人物、基層官吏、士兵、商人、工人、農民、學生、婦女及小說虛構人物 | 呈現大歷史如何改變日常生活 |

\*\*注意：\*\*人物可以隨卷次改變敘事比重。一級人物不代表每卷都必須出場；二級人物也可能在特定卷中成為核心。

## **二、一級人物：貫穿歷史主線**

一級人物分為五組。這些人物不必平均分配篇幅，而應依歷史發展自然進出。

### **2.1 晚清與舊秩序**

**![道光皇帝 - 故宫博物院]**

道光帝（1782–1850）

主要時段：第一卷

代表清廷面對西方貿易、軍事與外交壓力時的決策困境。敘事重點是既有制度如何理解一種不同於傳統朝貢與邊疆治理的國際秩序。

![清文宗咸丰皇帝朝服像/Portrait of Xianfeng \| Moa]

咸豐帝（1831–1861）

主要時段：第一至第二卷

面對太平天國、第二次鴉片戰爭與北京失守。其統治可呈現中央權威受到內亂、外患及財政壓力共同侵蝕的過程。

![史景遷的《康熙與曹寅》｜如懿傳裡的包衣們還有曹雪芹與他的阿公]

慈禧太后（1835–1908）

主要時段：第二至第七卷

晚清權力結構的重要核心。不能只寫成阻礙改革的單一反派，而要呈現宮廷權力、改革需求、政治安全與王朝延續之間的矛盾。

![《走向共和》李鸿章被洗白，我们到底该如何评论历史人物？]

李鴻章（1823–1901）

主要時段：第二至第六卷

洋務運動、軍政建設、外交談判與條約體系的交會人物。適合用來呈現改革者如何在既有制度中尋求生存空間，以及局部改革為何不一定能轉化為整體國力。

![竟有大臣以死相逼反对慈禧让光绪继位 最终获益者是翁同龢\_凤凰网]

光緒帝（1871–1908）

主要時段：第五至第七卷

戊戌變法、宮廷權力衝突與晚清改革的象徵性人物。須區分其個人意願、改革派的政治主張，以及實際掌握的權力。

![How the Chinese General Yuan Shikai Tried to Make Himself Emperor \| TheCollector]

袁世凱（1859–1916）

主要時段：第七卷至下冊第一卷

從晚清新軍、清帝退位到民初共和與帝制復辟，串連舊王朝的終結與新共和制度的脆弱。其政治選擇應放回軍權、中央財政與政黨競爭的環境中理解。

### **2.2 革命、共和與國家重建**

**![Sun Yat-sen Autograph Letter Signed to Mrs. Cantlie \| RR Auction]**

孫中山（1866–1925）

主要時段：上冊第五至第八卷、下冊第一至第三卷

革命、共和、民族國家與政治整合的核心人物。其思想與政治實踐存在發展變化，不能把晚年政治路線直接套用到早期革命活動。

![Chiang Kai-shek \| All Works \| The MFAH Collections]

蔣中正（1887–1975）

主要時段：下冊第一至第八卷

下冊主要貫穿人物之一。從國民革命、南京國民政府、抗日戰爭、國共內戰到遷台後的政治統治，必須同時追蹤其軍政決策、國家建設、政治控制及社會影響。

![BIO-MAO ZEDONG-LONG MARCH]

毛澤東（1893–1976）

主要時段：下冊第二至第八卷

下冊另一位主要貫穿人物。從中共早期組織、農村革命、長征、抗日戰爭、國共內戰到中華人民共和國建立，呈現其政治思想、組織路線與權力結構的變化。

![宋教仁的死亡，凶手武士英离奇暴毙，所有幕后黑手无一善终]

宋教仁（1882–1913）

主要時段：下冊第一卷

代表議會政治、政黨競爭與責任內閣理想的早期探索。其遇刺事件是共和制度與政治暴力交會的重要節點。

![CHINA-SINO-JAPANESE WAR-ZHOU ENLAI]

周恩來（1898–1976）

主要時段：下冊第二至第八卷

串連中共組織、國共合作、抗戰外交、重慶談判與建政後的政治運作。敘事應區分其公開職務、組織角色與實際決策權。

## **四、三級人物：讓歷史落到人身上**

三級人物不是可有可無的背景角色。這一級是本書區別於政治人物編年史的關鍵。

### **4.1 建議設計的生活角色**

### **4.2 三級人物的三種來源**

1. \*\*史料人物：\*\*地方志、日記、書信、報刊、判決、戶籍、學校紀錄與口述歷史中可查到的人物。  
2. \*\*合成人物：\*\*將多個真實人物的共同經驗整理成單一角色。不得將其誤標為真實歷史人物。  
3. \*\*完全虛構人物：\*\*用來連接不同地區與社會階層，補足史料未能直接記錄的日常生活。

建議每個虛構人物都建立簡短角色卡，包含出生地、家庭背景、教育、職業、經濟條件、語言、政治認知、親屬網絡與跨卷行蹤。

虛構人物可以改變立場、失去財產、搬遷、入伍、逃亡或死亡，但其經歷必須符合當時交通、法律、階級與資訊傳播條件。

## **五、蔣中正與毛澤東的雙主線追蹤**

這兩位人物是下冊的長期軸線，但不能讓整部小說只剩下兩位領導人的對照。

| 歷史階段 | 蔣中正線 | 毛澤東線 | 必須並行呈現的社會背景 |
| ----- | ----- | ----- | ----- |
| 1912–1924 | 軍事經歷、革命網絡與政治上升 | 新文化環境、早期政治活動與組織形成 | 北洋政治、城市勞動、農村問題 |
| 1924–1927 | 黃埔軍校、國民革命與黨軍整合 | 國共合作、農民運動與革命組織 | 工會、商會、學生、地方自治 |
| 1927–1931 | 南京國民政府、清共與國家統合 | 中共轉入農村革命、根據地形成 | 政治暴力、土地與地方秩序 |
| 1931–1937 | 東北危機、攘外與安內的矛盾 | 長征、組織重整與陝北立足 | 難民、失業、農村負擔與地方防衛 |
| 1937–1945 | 國民政府抗戰、遷都重慶與戰時統治 | 中共敵後組織、軍隊擴張與根據地治理 | 戰時徵發、通貨膨脹、難民與合作／衝突 |
| 1945–1949 | 戰後接收、內戰、政府危機與遷台 | 東北與華北局勢、內戰勝利與建政 | 復員、物價、土地、家庭失散與政權轉換 |
| 1949後 | 台灣政權重建、戒嚴與國家治理 | 中華人民共和國建政、社會改造與政治運動 | 土地、教育、產業、政治控制與不同歷史記憶 |

### **5.1 雙主線的寫作限制**

* 不以「蔣代表失敗、毛代表勝利」作為先驗結論。  
* 不把兩人的政策簡化成個人性格所能解釋的結果。  
* 不忽略國民政府的財政、行政、軍隊與地方治理問題。  
* 不把中共的組織動員、土地政策與軍事勝利寫成沒有代價的歷程。  
* 不以領導人決策取代地方社會的真實經驗。  
* 不將1949年後的兩岸歷史寫成彼此完全無關的兩條線；制度、人口、家庭、記憶與政治認同仍有長期連結。

## **六、跨卷人物追蹤規則**

每位一級、二級人物都應建立人物追蹤紀錄，避免年代錯置、人物突然消失，或在不同卷中出現互相矛盾的敘述。

建議欄位如下：

| 欄位 | 內容 |
| ----- | ----- |
| 人物姓名 | 採用全書統一稱呼，必要時記錄字、號、別名 |
| 生卒年 | 註明確定程度與可能存在的異說 |
| 出身與籍貫 | 家庭、地方、階層與教育背景 |
| 首次登場 | 卷次、年份與事件 |
| 主要活動區域 | 地理位置、交通條件與移動原因 |
| 官職／組織 | 正式職務、實際權力及組織歸屬 |
| 派系與關係 | 合作、競爭、依附、衝突與轉變 |
| 關鍵選擇 | 人物在歷史條件下作出的重要決策 |
| 生活影響 | 家庭、財產、健康、名譽與社會關係 |
| 最後登場 | 最後出場年份、地點與狀態 |
| 史料可信度 | 確證、可信推定、爭議或小說虛構 |
| 待核問題 | 尚未確定的日期、行蹤、關係或動機 |

### **6.1 人物弧線的四個層次**

每位重要人物至少要區分以下四層，不能將它們混為一談。

* \*\*公開主張：\*\*人物對外宣稱的政治理念、改革方案或國家目標。  
* \*\*實際行動：\*\*人物在特定時刻真正做了什麼。  
* \*\*制度限制：\*\*人物受到財政、組織、軍事、地方勢力與國際環境的哪些限制。  
* \*\*歷史後果：\*\*人物的選擇造成了哪些預期外的結果，又如何被後人記憶。

這套規則適用於清帝、改革派、革命者、軍閥、國共領導人、台灣政治人物，也適用於普通人。

## **七、人物與史料的可信度標記**

人物檔案與章節綱要應使用一致標記。

| 標記 | 定義 | 寫作處理 |
| ----- | ----- | ----- |
| A — 確證 | 有可靠史料相互印證的基本事實 | 可直接作為情節骨架 |
| B — 可信推定 | 大致可信，但細節或因果仍有爭議 | 可合理敘述，避免過度斷言 |
| C — 存疑／待考 | 傳聞、單一來源、後世加工或互相矛盾的記載 | 應明示不確定性，必要時保留多種可能 |
| F — 小說虛構 | 原創人物、私下對話、合成經歷或無法證實的情節 | 不得冒充史實，不應反過來當成歷史證據 |

尤其要注意：人物的公開言論可以有史料，人物的內心動機卻不一定能直接考證。

小說可以推演人物為何猶豫、恐懼、妥協或改變立場，但應將推演建立在其處境、行動與可知資訊之上，而不是將作者的價值判斷當成歷史人物的真實心理。

## **八、人物名冊的後續整理順序**

這份文件是全書人物架構的第一版。後續不應繼續無限擴張名單，而應把人物與十六卷的歷史事件逐一對接。

建議依序建立：

1. `characters_late_qing.md`：上冊八卷，1840–1912，晚清人物、革命人物與台灣人物。  
2. `characters_republic.md`：下冊第一至第七卷，1912–1949，北洋、國民黨、共產黨、抗戰、台灣接收與內戰。  
3. `characters_echoes.md`：下冊第八卷，1949年至全書設定的回顧終點，兩岸政治人物、社會人物與歷史記憶。  
4. `character_ledger.md`：跨卷人物行蹤、年齡、官職、組織、地點、關係與史料狀態的總索引。

## **九、本文件的驗收標準**

* 一級人物能串連主要歷史轉折，而非只因知名度入選。  
* 二級人物能補足制度、地方、派系與社會網絡。  
* 三級人物能呈現普通人實際承受的歷史變化。  
* 台灣人物不只在割台、接收與遷台時出場。  
* 蔣中正與毛澤東的長期主線不排擠其他歷史人物。  
* 人物的公開主張、實際行動、制度限制與歷史後果彼此區分。  
* 傳聞、爭議與小說虛構不冒充確證史實。  
* 人物的生卒年、任職、活動地點與跨卷行蹤能互相核對。  
* 不以勝敗或善惡標籤取代人物的歷史處境。
