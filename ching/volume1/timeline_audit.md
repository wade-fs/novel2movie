## 一、文件目的
本文件用於管理第一卷涉及的歷史年代、事件順序、人物行蹤、制度變化與史料爭議。
本卷橫跨第一次鴉片戰爭、戰後條約體系形成、太平天國興起，以及第二次鴉片戰爭與英法聯軍進入北京等重大事件。這些事件彼此交錯，但不能為了方便小說編排，就將它們簡化成一條單一的因果鏈。
本文件的目的不是重新撰寫歷史年表，而是確保後續小說章節建立在可以核對、追蹤與修訂的歷史骨架上。

### 1.1 核心任務
1. 核對重大事件的日期（公曆／農曆對照）、地點、參與者與先後順序。
2. 區分事件發生、消息傳出、官府收到消息、朝廷作出決策及政策實際執行的時間。
3. 核對歷史人物在特定日期的官職、所在地、職務與行動能力。
4. 區分條約簽訂、批准、換約、生效、公布與實際執行等不同階段。
5. 檢查歷史事件是否被錯誤連接成單一因果關係。
6. 確認香港、廣州、上海、南京、北京、廣西、福建與臺灣的歷史時間線。
7. 記錄史料衝突、待考事項、採用依據與修訂理由。
8. 將校核結果回饋至 `volume1.md`、人物檔案、地理設定及 90 章章節總帳，並與 `volume2/timeline_audit.md`、`volume2/volume1_audit.md` 保持跨卷同步。

### 1.2 本文件不負責的工作
以下事項應由其他文件負責：
- 全系列各卷的敘事定位：`outline.md`
- 全系列總體事件安排：`timeline.md`
- 人物分級與人物關係：`characters.md`、`character_network.md`
- 史料來源與研究程序：`research_qa.md`
- 地理、交通與行政區劃：`historical_geography.md`
- 社會生活與制度背景：`social_life.md`
- 章節功能與敘事驗收：`narrative_validation.md`
- 90 章的具體內容與狀態：`chapter_ledger.md`

本文件負責提供年代與事件校核結果，不取代上述文件。

## 二、史實狀態與校核標記
每項歷史資訊必須標記目前的研究狀態。不得因為某項資訊出現在既有小說大綱、通俗歷史作品或其他 AI 生成內容中，就視為已經核實。

### 2.1 史實狀態
| 標記 | 意義 | 使用規則 |
| :--- | :--- | :--- |
| `[待核]` | 尚未完成來源查證 | 不得當成最終定稿依據 |
| `[初核]` | 已找到可用資料，但尚未完成交叉核對 | 可供研究與初步規劃，不宜鎖定細節 |
| `[已核]` | 已有足夠可靠的史料支持 | 可作為小說史實骨架 |
| `[有爭議]` | 不同史料對事件、日期、動機或細節存在差異 | 必須記錄不同說法與採用理由 |
| `[已修正]` | 原有記載經查證後已更正 | 必須保留修訂紀錄 |
| `[不採用]` | 曾列入考慮，但證據不足或不適合本卷 | 記錄原因，避免日後重複引入 |

以上標記描述研究進度，不代表事件本身的重要性。

### 2.2 史料可信度分級
史料可信度依 `research_qa.md` 的完整規範管理。第一卷至少應注意以下區別：
- **A 類**：同時代官文書（如《籌辦夷務始末》《清實錄》《宣宗成皇帝實錄》《文宗顯皇帝實錄》）、條約原文、奏摺、官方檔案及可確認來源的原始文書。
- **B 類**：同時代日記（如《林則徐日記》）、書信、報刊（如《澳門月報》《中國叢報》）、外國外交檔案（如英國外交部檔案 FO 17）、傳教士記錄及其他當事人記錄。
- **C 類**：後世學術研究、專業歷史著作與根據原始材料完成的研究（如茅海建《天朝的崩潰》、史景遷《上帝的中國兒子》等）。
- **D 類**：通俗歷史作品、網路文章、未提供可靠引據的轉述。

這是研究工作的初步分類，不表示 A 類材料必然正確（如清代官員奏報常有虛報戰功或隱匿敗績），也不表示 B、C 類材料必然較弱。重要事件應盡可能交叉比對不同來源。

### 2.3 證據與小說內容的區別
每項涉及歷史人物或重大事件的章節內容，應區分：
- **【史實骨架】**：有可靠證據支持的日期、事件、職務、地點及公開行動。
- **【合理推演】**：依當時制度、交通、資訊與社會條件推演的情境。
- **【小說虛構】**：為故事需要創作的角色、私人對話、家庭關係及未見於史料的互動。
- **【待考事項】**：目前證據不足，尚不能決定應採用何種說法。

不得將合理推演或小說虛構改寫成確定的歷史事實。

## 三、年代校核的基本規則

### 3.1 日期精度
每項事件應記錄目前可以確認的最精確日期。

| 日期精度 | 記錄方式 | 使用情境 |
| :--- | :--- | :--- |
| 年 | `YYYY` | 目前只能確定年份 |
| 年月 | `YYYY-MM` | 可以確定月份，日期仍待考 |
| 完整日期 | `YYYY-MM-DD` | 有可靠依據支持完整日期 |
| 日期區間 | `YYYY-MM 至 YYYY-MM` | 事件持續一段時間 |
| 約略時間 | `約 YYYY` 或 `某季` | 只能確定大致時期 |

不得為了安排章節而自行補上沒有史料支持的確切日期。
如不同史料採用不同曆法，必須保留原始記載（道光／咸豐年號與干支月日，以及太平天國「天曆」），並說明公曆換算方式。不得將清代農曆日期直接當成公曆日期使用。

### 3.2 必須分開記錄的時間
重大事件至少要檢查以下時間：
1. 事件實際發生時間。
2. 事件被目擊或記錄的時間。
3. 消息離開原發生地的時間。
4. 消息抵達地方官府或相關機構的時間。
5. 消息抵達中央（軍機處／御前）的時間。
6. 中央作出決策或發布命令（明發上諭／寄信上諭）的時間。
7. 命令抵達執行地的時間。
8. 政策實際執行或產生影響的時間。

以上時間不一定全部有資料可查。若無法確認，應參照 **8.2 節清代驛遞與航運基準**進行推算並標記 `[初核]`，不得以現代通訊速度推估清代消息傳遞時間。

### 3.3 事件先後與因果
事件 A 發生在事件 B 之前，不代表 A 必然導致 B。
每個重大事件應區分：
- 時間上的先後關係。
- 當事人是否知道前一事件。
- 當事人是否因前一事件採取行動。
- 後世研究者對因果關係的解釋。
- 小說為了敘事而建立的連接。

尤其不能將第一次鴉片戰爭、太平天國與第二次鴉片戰爭寫成一場持續二十年的單一戰爭。

### 3.4 人物行蹤與可知資訊
人物在某一章出場之前，必須確認：
- 當時是否仍然在世。
- 當時的官職、身分及所屬組織。
- 當時所在地與可行的移動路線。
- 他是否有機會收到相關消息。
- 他是否具有參與該項決策或行動的權限。
- 他是否能夠接觸小說安排給他的其他人物。

若史料未記載人物當時的具體行蹤，應記錄可證明的時間與空間範圍；不得將「可能在某地」直接寫成「確實在某地」。

## 四、第一卷總體年代範圍

### 4.1 時間界線
| 項目 | 設定內容 |
| :--- | :--- |
| **前史起點** | 1838 年 12 月 31 日（道光十八年十一月十五日，林則徐受命欽差大臣） |
| **正式敘事起點** | 1839 年 3 月（林則徐抵粵查禁鴉片）至 1840 年 6 月（英軍封鎖珠江口） |
| **主要敘事終點** | 1860 年 11 月（中英、中法、中俄《北京條約》簽訂換約、聯軍撤出北京，以及恭親王奕訢等留京醞釀通商外交善後章程） |
| **下一卷銜接** | 第二卷《天下多故》（1861 年 1 月總理衙門正式獲准設立、1861 年 8 月咸豐帝崩於熱河、11 月辛酉政變，以及 1860–1861 年安慶合圍戰起） |
| **年代校核範圍** | 1838 年 12 月–1860 年 11 月 |
| **核心事件** | 兩次鴉片戰爭、條約體系形成、太平天國興起及清廷地方權力變化 |

第一卷雖以 1840–1860 年為主要範圍，但第一單元已使用 1838 年底林則徐受命及 1839 年虎門銷煙作為開篇，因此校核文件必須包含 1838 年底至 1839 年，不得只核對標題上的起訖年份。

### 4.2 本卷必須維持的歷史分線
- **A 線：第一次鴉片戰爭與戰後秩序**
  1839 年禁煙及外交衝突、1840–1842 年戰爭、1842 年《南京條約》及後續條約安排、五口通商與香港的制度變化。
- **B 線：知識與外交制度轉變**
  外國資訊的傳播、翻譯與知識整理（《四洲志》《海國圖志》《瀛寰志略》）、條約體系的建立，以及清廷官僚如何理解新的外交問題。
- **C 線：太平天國與地方社會危機**
  廣西地方社會、拜上帝會、金田起事、太平天國建立、南京（天京）政權及江南社會的變化。
- **D 線：地方軍事與財政力量的變化**
  團練、湘軍、地方士紳、釐金制度、海關稅務司制度與清廷軍事資源的調整。
- **E 線：第二次鴉片戰爭與北京危機**
  修約要求、廣州亞羅號衝突、英法軍事行動、《天津條約》、1859 年大沽口戰事、1860 年聯軍再次北進、圓明園被焚及《北京條約》。
- **F 線：臺灣與福建海疆**
  海防、1841–1842 雞籠與大安之役、地方行政、郊商航運、1850 年代外商探路，以及條約中的臺灣開港安排與實際落實的時間差。

各線應互相影響，但必須保留各自的歷史背景、人物與發展邏輯。

### 6.2 條約與地方生活的連接（寫作防呆原則）
1. **不得混用不同條約的權限**：例如 1842–1858 年間，外國人**不得**合法進入五口以外的內地經商或傳教（五口設有嚴格的「界址」，如上海規定外人出行以「一日往返」為限）；外人合法持護照進入內地，是 1858 年《天津條約》（實際 1860 年換約後）才開放的權利。
2. **公使駐京的時間線**：1860 年以前，外國最高外交代表為「駐華全權公使兼香港總督」（英國，常駐香港）或常駐廣州、澳門、上海的公使，日常外交由「兩廣總督兼五口通商大臣」辦理；外國公使正式入駐北京東交民巷是 **1861 年 3 月**以後的事（歸入第二卷）。
