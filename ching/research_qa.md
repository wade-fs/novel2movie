# research_qa.md
# 史料研究與章節驗收流程

> 文件狀態：初版，持續校訂中  
> 適用範圍：清末至現代，1840年至暫定2020年  
> 核心用途：建立可追溯、可複查、可修訂的史料研究流程，確保小說正文不因資料錯誤、推論過度或章節修改而產生歷史矛盾。

---

## 一、文件目的

《天下易主》以歷史為骨架，以人物為敘事核心，透過制度、政治互動、地理環境與日常生活，呈現政權更替如何改變普通人的命運。

本文件處理四個問題：

1. 如何找到足以支持小說內容的歷史資料？
2. 如何判斷資料是否可信，以及不同來源發生衝突時如何處理？
3. 如何區分確定史實、合理推演與小說虛構？
4. 如何在章節定稿前驗收歷史準確性、人物連續性與敘事合理性？

**基本原則：小說可以虛構人物的生活，不能把虛構偽裝成史實；可以提出合理解釋，不能把推測寫成已被證明的歷史因果。**

---

## 二、研究與寫作的基本流程

全系列統一採用以下工作流程：

```text
確定章節主題
    ↓
列出待回答的歷史問題
    ↓
蒐集原始史料與研究成果
    ↓
建立來源紀錄與證據判定
    ↓
校核年代、人物、地點、制度
    ↓
區分史實、推演與虛構
    ↓
設計人物行動與章節情節
    ↓
撰寫正文
    ↓
進行歷史與敘事雙重驗收
    ↓
修訂並檢查跨章影響
    ↓
通過驗收，鎖定版本
```

研究不必等到所有資料都蒐集完畢才開始寫作，但涉及重大歷史轉折的關鍵事實，必須在正文定稿前完成查證。

### 2.1 三種工作狀態

| 狀態 | 定義 | 處理方式 |
|---|---|---|
| 研究中 | 主要史實或人物關係尚未查清 | 可以規劃，不宜鎖定關鍵情節 |
| 待驗收 | 初稿已完成，仍需確認史實與敘事 | 不得視為定稿 |
| 已驗收 | 重要史實已查證，人物、年代及情節通過檢查 | 可進入版本鎖定 |

若章節中的關鍵事件仍有重大爭議，應保留待查標記，而不是為了趕進度任意選擇一個版本。

## 三、史料來源分級

來源分級是研究工具，不是機械式的可信度排名。同一份原始史料可能對某項事實非常可靠，對另一項事實卻帶有明顯偏見。

### 3.1 第一級：原始史料

包括：

- 政府公文、奏摺、法令、條約及會議紀錄。
- 外交照會、使節報告及相關檔案。
- 當事人的日記、書信、手稿與私人筆記。
- 同時代報紙、期刊、廣告及商業紀錄。
- 法院紀錄、地方行政資料、戶籍及學校紀錄。
- 企業帳冊、物價紀錄、交通資料及其他社會經濟檔案。

使用時必須確認：

1. 文件形成時間。
2. 作者、收件者與文件用途。
3. 作者是否親歷事件。
4. 文件是否為原件、抄件、節錄或後來整理的版本。
5. 文件是否具有政治宣傳、利益維護或自我辯護的目的。

原始史料不等於絕對真實。官方報告可能隱瞞失敗，私人日記可能記錯日期，報紙可能受審查或政治立場影響。

### 3.2 第二級：學術研究

包括：

- 歷史學專書。
- 同行評審學術期刊論文。
- 以檔案、文獻與考古材料為基礎的專題研究。
- 研究機構出版的史料整理與人物年譜。
- 大學、博物館及檔案機構的專業研究成果。

使用時應檢查：

- 作者的研究領域與專業背景。
- 是否列出可追溯的史料。
- 是否說明不同研究者的爭議。
- 是否把推論與確定事實分開。
- 出版年代是否早到可能缺少後來開放的檔案。

### 3.3 第三級：參考性資料

包括：

- 通史、教科書與百科全書。
- 政府機關的歷史介紹。
- 研究機構的線上年表。
- 博物館展覽說明與歷史教育網站。

這類資料適合建立初步年表、查找專有名詞與發現研究方向。涉及重大爭議、精確日期或人物責任時，仍須回到原始史料及專題研究。

### 3.4 第四級：線索性資料

包括：

- 新聞回顧。
- 個人部落格。
- 社群媒體貼文。
- 未提供來源的網路文章。
- 影音節目與通俗歷史敘述。

這類資料可以提供搜尋線索，但不能單獨作為重大史實的最終依據。

## 四、來源可信度的判定

每份資料都應依照具體用途評估，而不是只給一個總分便決定是否採用。

### 4.1 五項判定標準

| 標準 | 核心問題 |
|---|---|
| 來源身分 | 作者、機構與文件來源是否明確？ |
| 時間距離 | 資料形成於事件當時，還是多年後回憶？ |
| 親歷程度 | 作者親自參與、親眼見聞，還是轉述他人？ |
| 可交叉驗證性 | 是否有獨立來源支持？ |
| 立場與目的 | 作者是否具有政治、經濟、軍事或個人利益？ |

### 4.2 證據狀態

本專案統一使用：

- **已核實**：關鍵內容已獲可靠資料支持，且沒有尚未處理的重大矛盾。
- **部分核實**：事件基本成立，但細節、日期或因果仍待查證。
- **待查證**：目前資料不足以支持正式定稿。
- **存有爭議**：存在重要而尚未解決的不同記載或解釋。
- **已修訂**：原先記錄已被新資料或更可靠的考證修正。

不可因為同一說法在十篇網路文章中反覆出現，就認為有十份獨立證據。若十篇文章都抄自同一部書，實際上仍可能只有一條來源鏈。

## 五、史料衝突處理程序

當不同資料對日期、人物、事件經過或責任歸屬存在差異時，必須依照程序處理。

### 第一步：確認是否為同一件事

同一事件可能包含不同階段。例如：

- 宣布政策。
- 正式發布法令。
- 法令生效。
- 地方開始執行。
- 實際完成制度轉換。

不同來源記錄不同日期，不一定代表其中一方錯誤。

### 第二步：確認時間與名詞

檢查：

- 農曆與公曆是否混用。
- 舊曆日期換算是否正確。
- 同一地名是否在不同時期使用不同名稱。
- 同一機構是否曾經改名或重組。
- 後世使用的事件名稱是否與當時稱呼不同。

### 第三步：比較來源性質

比較各來源的形成時間、作者身分、資訊取得方式與記錄目的。

### 第四步：尋找獨立證據

優先尋找不同機構、不同作者或不同類型的資料。例如，官方命令可與私人日記、報紙、地方紀錄相互參照。

### 第五步：保留無法解決的差異

若資料仍無法得出確定結論，必須記錄不同說法與各自依據。

小說可以選擇一種合理的敘事呈現，但不能宣稱爭議已經解決。

## 六、史實、合理推演與小說虛構的界線

全系列統一使用三種標記。

### 6.1 【史實骨架】

用於有可靠史料支持的事件、人物行蹤、制度與可確認的社會條件。

例如：

- 某條約於特定日期簽訂。
- 某人物於特定時期擔任某項職務。
- 某政權在某地建立行政機構。

史實骨架仍須保留證據狀態；若細節尚有爭議，不能因事件本身確定，就把所有細節一併視為確定。

### 6.2 【合理推演】

用於符合歷史條件、但無法直接證明的情境。

例如：

- 根據物價、徵糧與交通中斷，推演一個家庭如何調整生計。
- 根據當時的官僚制度，推演地方官員可能面臨的行政困境。
- 根據已知政治立場，推演某人物可能如何權衡選項。

合理推演必須具備可說明的依據，並避免宣稱這就是歷史人物真正的想法。

### 6.3 【小說虛構】

用於創作的人物、對話、私人生活、家庭關係與具體遭遇。

例如：

- 一個虛構商人家庭在通商制度變動下失去原有生計。
- 一位虛構教師因政局變化而輾轉不同城市。
- 兩名虛構人物透過書信維持聯絡。

虛構情節不能任意改寫已確認的歷史結果，也不能冒充真實人物的原始書信或私人日記。

### 6.4 三種標記可以出現在同一章

一章可以有史實事件、合理推演與虛構人物交錯，但各自的邊界必須清楚。

例如，某次真實的政策公布是【史實骨架】；地方商人如何理解政策可能屬於【合理推演】；某位虛構商人因而與家人爭執，則屬於【小說虛構】。

這三者可以形成完整故事，但不可互相冒充。

## 七、歷史人物的心理與私人生活

歷史小說不可完全避免人物心理描寫，但必須區分史料所能證明的內容與作者的詮釋。

### 7.1 可以直接採用的內容

- 當事人在書信、日記或公開言論中明確表達的主張。
- 有多項證據支持的政治選擇與行動。
- 可由可靠史料確認的家庭、教育與職業背景。
- 能由行為與制度條件合理推導的處境。

### 7.2 必須謹慎處理的內容

- 人物未曾公開的真正動機。
- 私人談話與密室會議。
- 對某人內心恐懼、嫉妒、仇恨或愛情的確定描述。
- 沒有可靠證據支持的秘密交易。
- 將後來的政治結果寫成當事人早已預知的必然結局。

### 7.3 建議寫法

與其直接宣稱某人物「早已看穿一切」，不如呈現：

- 他當時收到哪些消息。
- 他可以選擇哪些方案。
- 他相信哪些人或制度。
- 他為何排除其他選項。
- 決策後出現了哪些意料之外的結果。

這種寫法既能保留人物深度，也不會將作者的歷史解釋冒充當事人的真實心理。

## 八、每章的研究準備表

正式寫作前，每章至少應先建立一份簡短研究準備表。

| 欄位 | 內容 |
|---|---|
| 章節編號 | 例如 `V01-C001` |
| 章節暫定名稱 | 本章的工作標題 |
| 時間範圍 | 年、月、日或合理時間區間 |
| 地理位置 | 主要場景及相關地點 |
| 歷史事件 | 本章涉及的真實事件 |
| 核心人物 | 史實人物與虛構人物分列 |
| 主要問題 | 本章需要查清的歷史問題 |
| 必要史料 | 需要取得的原始資料或研究成果 |
| 主要不確定性 | 尚未解決的日期、因果或人物關係 |
| 生活細節 | 貨幣、交通、食物、制度、通訊等 |
| 預定敘事功能 | 本章如何推動人物與全書主題 |
| 驗收狀態 | 研究中、待驗收、已驗收 |

研究準備表的目的不是增加文書工作，而是避免正文寫到一半才發現人物不可能在場、制度尚未建立，或消息不可能及時傳到。

## 九、章節驗收的五個面向

每章初稿完成後，依下列五個面向進行驗收。

### 9.1 歷史事實驗收

檢查：

- 重大事件的日期與先後是否正確。
- 人物生卒、職位與行蹤是否符合史料。
- 法令、條約與制度的內容是否正確。
- 是否把傳聞、後世評價或政治宣傳誤寫為確定事實。
- 是否因劇情需要改變已確認的歷史結果。

### 9.2 人物關係驗收

檢查：

- 人物當時的政治立場與組織歸屬。
- 合作、競爭或決裂是否符合時間順序。
- 私人關係是否被錯誤地當成政治控制。
- 人物是否掌握當時尚未傳到的資訊。
- 跨卷人物的性格與行動是否有連續性。

### 9.3 歷史地理驗收

檢查：

- 地點、行政區劃與地名是否符合年代。
- 交通工具、道路與航線是否存在。
- 人物是否有足夠時間移動。
- 消息傳遞速度是否合理。
- 戰亂、封鎖與季節是否影響行程。

### 9.4 社會生活驗收

檢查：

- 貨幣、物價與經濟制度是否符合年代。
- 職業、教育與社會身分是否合理。
- 通訊、交通與生活用品是否符合當時條件。
- 普通人的生活是否受到歷史事件的具體影響。
- 不同地區、階層與政治制度的差異是否得到保留。

### 9.5 敘事與主題驗收

檢查：

- 本章是否有明確的人物問題或情境轉變。
- 歷史事件是否透過人物與生活呈現，而非只堆砌背景資料。
- 人物的選擇是否有可理解的條件與代價。
- 是否把勝敗簡化成道德高低或能力高低。
- 虛構人物是否自然地連接史實，而非強行控制歷史。
- 本章是否有助於呈現舊制度的變化、普通人的命運與歷史記憶的延續。

## 十、驗收結果與缺陷分級

每章驗收後，必須明確標示結果。

### A級：阻擋定稿的重大問題

例如：

- 重大事件日期錯誤。
- 人物在當時尚未出生、已經去世或不可能在場。
- 政權、官職或制度與當時情況不符。
- 虛構情節改寫已確認的歷史結果。
- 章節核心因果建立在錯誤史實上。

處理方式：修正後重新驗收，不得直接定稿。

### B級：必須修正的實質問題

例如：

- 人物關係或職位變動有誤。
- 地理與交通安排不合理。
- 社會制度與生活細節明顯錯置。
- 對爭議性事件只採用單一說法，卻寫成確定結論。
- 合理推演被寫成歷史人物的確定動機。

處理方式：修正相關段落，必要時重新檢查整章。

### C級：建議改善的敘事問題

例如：

- 歷史背景說明過長。
- 人物行動與社會環境連結不足。
- 史實與虛構的界線不夠清楚。
- 某項制度只被提及，卻未呈現其對人物的實際影響。
- 章節缺少必要的地方生活細節。

處理方式：依敘事需求修訂，不必然阻擋定稿。

### D級：可保留的創作選擇

例如：

- 有充分歷史依據的合理推演。
- 不影響史實的虛構對話。
- 對同一歷史情境採取不同但有根據的敘事視角。
- 在不扭曲史實的前提下，調整場景順序或人物描寫重點。

處理方式：保留並記錄必要依據。

## 十一、史料紀錄與引用格式

所有會影響重大情節的資料，都應記錄可追溯的來源。

### 11.1 最低紀錄欄位

| 欄位 | 說明 |
|---|---|
| 資料編號 | 例如 `SRC-0001` |
| 作者或機構 | 文件作者、出版機構或檔案保存單位 |
| 資料名稱 | 書名、論文名、檔案名或網頁標題 |
| 資料類型 | 原始史料、學術研究、參考資料或線索性資料 |
| 出版資訊 | 出版社、年份、卷期等 |
| 頁碼或檔號 | 可供重新查找的位置 |
| 網址 | 線上來源的穩定網址 |
| 存取日期 | 網路資料的查閱日期 |
| 支持的主張 | 此資料實際支持哪一項事實 |
| 限制與偏差 | 來源可能存在的限制 |
| 使用章節 | 哪些卷章使用此資料 |

### 11.2 引用原則

1. 精確日期、重大事件與爭議性判斷，應能追溯到具體來源。
2. 轉述研究者的觀點時，應記錄其研究依據，而非只記錄結論。
3. 使用直接引文時，應保留原文、出處與頁碼。
4. 不可把現代整理的文字誤標為當時原文。
5. 不可因某資料來自官方機構，就省略對其形成背景的判斷。
6. 網頁內容可能更新或失效，重要內容應記錄存取日期及必要的存檔資訊。

## 十二、研究問題清單

開始研究一個歷史事件時，應先把模糊的「了解這段歷史」轉成可回答的問題。

例如，研究1911年革命時，可依序提出：

1. 武昌起義的確切日期與直接背景為何？
2. 起義前各地的新軍、革命組織與地方政治處於什麼狀態？
3. 各省宣布獨立的時間是否一致？
4. 清廷在不同階段取得哪些消息？
5. 袁世凱何時獲得任命，其實際權力如何形成？
6. 南京臨時政府何時成立，與清帝退位的程序有何不同？
7. 普通官員、商人、學生與家庭如何面對政權變化？
8. 哪些說法來自當時史料，哪些是後世的解釋？
9. 哪些情節可以由史實直接支持，哪些只能合理推演？
10. 哪些細節仍然無法確定，應留給小說以有限視角呈現？

研究的成果不必是對所有問題都找到唯一答案。能清楚說明「哪些已知、哪些未知、哪些存在爭議」，同樣是合格的研究成果。

## 十三、跨卷與跨文件的驗收

章節驗收不能只看單章。

同一事件可能在不同卷中被不同人物經歷、回憶或重新解釋。因此，必須同步檢查：

- `timeline_audit.md`：年代與事件是否一致。
- `character_network.md`：人物關係與政治互動是否一致。
- `historical_geography.md`：地點、交通與消息傳遞是否合理。
- `social_life.md`：制度與生活條件是否符合年代。
- `narrative_validation.md`：人物與情節是否符合敘事原則。
- `chapter_ledger.md`：章節事件、人物與前後連續性是否一致。

若某項新考證改變了人物任職時間，不能只修改人物檔案；所有依賴該職位安排的事件、章節與人物關係都必須重新檢查。

## 十四、版本鎖定與修訂紀錄

章節通過驗收後，應記錄版本與驗收結果。

建議格式：

| 欄位 | 內容 |
|---|---|
| 章節編號 | 例如 `V01-C001` |
| 版本號 | 例如 `v1.0` |
| 驗收日期 | 實際完成驗收的日期 |
| 歷史事實 | 通過／待修訂 |
| 人物關係 | 通過／待修訂 |
| 地理與交通 | 通過／待修訂 |
| 社會生活 | 通過／待修訂 |
| 敘事與主題 | 通過／待修訂 |
| 未解決問題 | 列出保留事項 |
| 驗收結果 | 通過／有條件通過／不通過 |
| 修訂紀錄 | 內容、理由與影響範圍 |

### 版本規則

- `v0.x`：研究與初稿階段。
- `v1.0`：完成基本驗收，可視為定稿版本。
- `v1.x`：不改變核心史實與章節結構的修訂。
- `v2.0`：重大史實修正、情節重構或章節順序變動。

版本號只是管理工具，不代表史實永遠不會再修正。即使是已定稿章節，若發現重大年代錯誤，仍必須重新開啟驗收。

## 十五、專案執行規則

本專案應遵守以下原則：

1. 不以搜尋到的第一個說法直接定案。
2. 不以多個相互抄錄的網站冒充獨立互證。
3. 不把後世評價直接套用到歷史人物當時的選擇。
4. 不把人物的私人動機寫成已證實的事實，除非有可靠證據。
5. 不因情節需要而任意改動已確認的日期、職位或歷史結果。
6. 不要求每個生活細節都有直接史料，但合理推演必須有歷史條件支撐。
7. 不把史料不足當成虛構任意擴張的理由。
8. 不因資料尚有爭議，就放棄呈現事件對人物與社會的影響。
9. 不以單一人物或單一政治立場代表整個時代。
10. 不把章節通過驗收理解成永遠不能修訂。

## 十六、總結

`research_qa.md` 的核心任務，是讓《天下易主》建立一套可追溯的歷史研究與小說驗收機制。

史料研究的目的，不只是找出正確日期，更是理解資料如何形成、人物當時知道什麼、制度如何運作，以及後世如何重新解釋事件。

章節驗收的目的，也不只是排除錯誤，而是確保每個人物的選擇、每個事件的發展與每個普通人的生活，都建立在可以說明的歷史條件之上。

**歷史小說可以留下未知，也可以提出推演；但必須讓讀者與作者都能分辨，哪些是史實、哪些是解釋、哪些是創作。**
