# historical_geography.md
# 歷史地理與社會空間設定

> 文件狀態：初版，持續校訂中  
> 適用範圍：1840年至暫定2020年  
> 適用作品：《天下易主》上冊、下冊  
> 核心原則：以歷史時點為基準，將地理視為影響政治權力、經濟活動、人口流動與人物命運的實際條件。

---

## 一、文件目的

歷史地理不是地名資料庫，也不是在章節開頭介紹某座城市的背景文字。

在《天下易主》中，地理必須參與歷史敘事。

一座城市是否靠近港口、一條鐵路是否通車、一個地方是否能與中央保持聯絡、一個家庭能否在戰亂中離開故鄉，都可能改變人物的選擇。

本文件主要管理以下問題：

1. 不同年代的行政區劃、地名與政治管轄權。
2. 城市、港口、河流、山地、平原與交通路線。
3. 人物移動、書信往來、新聞傳播與命令下達的時間。
4. 中央政府與地方社會之間的實際距離。
5. 地理環境對財政、商業、軍事、教育與日常生活的影響。
6. 臺灣從清治、日治、戰後接收到兩岸分治的空間變化。
7. 同一地點在不同政治制度下的功能與意義如何改變。

**基本原則：不能因為現代地圖上的兩個地點距離很近，就認定歷史人物可以快速往返；也不能把現代行政區劃直接套用到十九世紀。**

## 二、歷史地理的四個層次

### 2.1 自然地理

包括：

- 山脈、河川、平原、海岸、島嶼與港灣。
- 氣候、季節、颱風、洪水、旱災與其他自然條件。
- 可耕地、森林、礦產、水源與其他資源。
- 地形對道路、交通、聚落與行政管理的影響。

自然地理通常不會因政權更替而改變，但其政治與經濟功能可能隨技術、人口與制度而改變。

### 2.2 行政地理

包括：

- 省、道、府、州、縣等傳統行政區劃。
- 省、縣、市、州等近現代行政區劃。
- 殖民政府、軍事占領機構與戰後接收機構的管轄範圍。
- 首都、行省治所、縣治與地方行政中心。
- 行政區劃調整、生效日期及實際執行狀況。

必須分清楚：

- 法令宣布設置的日期。
- 機構正式成立的日期。
- 行政區劃開始實際運作的日期。
- 新制度全面取代舊制度的時間。

這些日期不一定相同。

### 2.3 交通地理

包括：

- 步行、轎子、騎乘、馬車與驛站。
- 河運、沿海航運、帆船與輪船。
- 鐵路、電車、汽車與公路。
- 航空運輸及現代交通網絡。
- 港口、車站、碼頭、渡口與轉運地點。

交通工具的出現，不代表所有人都能使用。必須同時考慮票價、身分、財力、路線、班次、治安與交通是否中斷。

### 2.4 社會空間

包括：

- 官署、軍營、商館、商業街區與市場。
- 學校、書院、教會、寺廟與其他宗教場所。
- 工廠、礦區、農村、漁村與移民聚落。
- 租界、殖民行政區、住宅區及不同階層的居住空間。
- 難民收容地、臨時市場、交通樞紐與政治集會場所。

社會空間必須呈現誰能進入、誰被排除，以及不同群體如何使用同一個地方。

## 三、歷史地名與行政區劃管理

### 3.1 地名必須附帶年代

所有重要地名都應記錄其適用時期，避免把後世名稱誤當成當時用語。

例如：

- 北京在清代官方語境中常稱京師，近現代名稱與政治地位則隨政權變化。
- 臺灣在不同時期使用不同的行政建制與官方稱謂。
- 上海的租界、華界與不同時期的行政管理範圍不可混為一談。
- 南京在不同政權下曾有不同政治地位，不能僅因今日稱呼就推定當時的首都地位。

小說正文可依敘事視角使用當時稱呼或讀者熟悉的現代地名，但研究檔案必須保留正式名稱、使用年代與必要的異名。

### 3.2 地名資料表

每個重要地名建立以下資料：

| 欄位 | 說明 |
|---|---|
| 地點編號 | 例如 `GEO-0001` |
| 正式名稱 | 該時期的官方名稱 |
| 常用名稱 | 當時民間或文獻常用稱呼 |
| 異名 | 舊稱、別稱、外文名稱 |
| 適用年代 | 名稱使用的時間範圍 |
| 行政隸屬 | 當時的行政層級與上級機構 |
| 地理類型 | 城市、港口、縣城、村落、山區等 |
| 主要功能 | 政治、商業、交通、教育、軍事或其他 |
| 交通連結 | 航線、道路、鐵路與鄰近聚落 |
| 社會構成 | 主要人口、職業、階層與族群等 |
| 重要變化 | 政權更替、行政調整、都市擴張等 |
| 證據來源 | 地圖、方志、檔案與研究成果 |
| 相關卷章 | 使用該地點的章節 |

### 3.3 現代地名的使用原則

現代地名可以用於研究者的定位與檢索，但不能自動代替歷史名稱。

若一座城市在歷史上經歷改名、行政層級變動或疆界調整，必須記錄各階段的變化。

對讀者而言，必要時可以在正文首次出現時補充現代地名，但不應讓現代行政概念破壞歷史語境。

## 四、1840—1860年：海上通道與傳統帝國空間

本階段的主要地理議題，是傳統帝國行政秩序如何面對海上貿易、外國勢力與內部動亂的共同壓力。

### 4.1 主要地理舞台

- 北京與京畿：朝廷決策、官僚任命與政治責任。
- 廣州及珠江三角洲：對外貿易、地方商業、官府與外國商人互動。
- 香港：1842年後的英國殖民據點及逐漸擴大的港口功能。
- 上海：1843年開埠後逐步發展的通商與金融空間。
- 南京與長江下游：太平天國及清廷控制權變化的重要區域。
- 江南與沿江城鎮：稅收、商業、農業、人口流動及戰亂影響。
- 天津與大沽口：京畿通海門戶及外交、軍事壓力所在。

### 4.2 需要呈現的空間差異

廣州的對外貿易並不等於整個中國已經直接融入相同的國際商業體系。

通商口岸、內陸州縣與農村之間，可能存在明顯的資訊、收入與生活條件差異。

小說應呈現：

- 沿海商人如何接觸新制度與外國商品。
- 內陸官府如何透過傳統行政體系處理新問題。
- 河運、海運與陸路運輸如何影響商品價格。
- 戰亂如何改變市場、渡口、道路與人口流向。
- 京城的政治決策如何經過多層官僚體系才抵達地方。

### 4.3 地理驗收問題

- 某地在該年份是否已經開埠？
- 某個外國機構是否已經成立？
- 城市的管轄範圍是否符合當時情況？
- 人物所走的道路或航線是否實際存在？
- 地方居民能否取得小說中提到的消息或商品？

## 五、1860—1895年：洋務建設、交通轉型與海疆

本階段應呈現新式交通、工業與軍政機構逐漸出現，但傳統地方社會仍然持續運作的過渡狀態。

### 5.1 重要地理議題

- 上海與長江流域的商業及金融網絡。
- 天津、北京與北方外交及軍政體系。
- 福州、馬尾與船政建設。
- 廣東、香港與華南海上貿易。
- 臺灣的清代行政建制、港口與地方社會。
- 東北、朝鮮半島周邊與北方海疆的戰略位置。

### 5.2 交通與資訊變化

輪船、電報、鐵路等新技術逐步改變交通與資訊傳播，但各地採用的時間不同。

不得把新技術的出現直接寫成全面普及。

每次使用新式交通或通訊工具，都要確認：

1. 該地當時是否已有相關設施。
2. 設施是否已經投入實際運作。
3. 使用者是否有資格或能力使用。
4. 交通與通訊是否受到戰爭、天候或行政限制。
5. 設施對一般居民的實際影響有多大。

## 六、1895—1912年：割臺、殖民治理與革命空間

### 6.1 臺灣的空間轉折

1895年《馬關條約》及其後的日本統治，使臺灣進入新的政治與行政體系。

本階段不可只把臺灣寫成清朝失去的領土，也應呈現：

- 清朝官民撤離、留下與轉換身分的不同選擇。
- 臺灣地方士紳、商人、農民與其他群體的反應。
- 日本殖民政府如何逐步建立行政、警察、交通與財政體系。
- 港口、道路、鐵路與城市空間如何隨殖民治理改變。
- 不同地區面對新政權的經驗差異。

### 6.2 臺灣研究必須區分的層次

1. 條約與國際法上的主權變化。
2. 日本殖民政府的行政建制。
3. 地方實際控制權的建立過程。
4. 地方社會的抵抗、合作、適應與生活延續。
5. 後世對割臺及殖民統治的不同記憶。

不得將某一地區的經驗直接當作全臺一致的經驗。

### 6.3 中國大陸的革命空間

武昌、南京、北京、上海、廣州及其他省城的政治功能各不相同。

革命組織、商會、新軍、學校、報館與交通樞紐之間的聯繫，是理解1911年革命的重要空間條件。

各地宣布獨立、建立軍政府或改變行政隸屬的時間可能不同，不能將各地政治變化寫成同一天完成。

---

## 七、1912—1927年：共和制度與交通網絡

本階段的地理核心，是名義上的國家統一與實際地方控制之間的差距。

### 7.1 主要空間

- 北京：北洋政府及中央政治。
- 南京：革命政治記憶與後續政權建設的重要地點。
- 上海：商業、金融、新聞、教育與政治組織的匯聚地。
- 廣州：革命組織、軍政建設與南方政治活動的重要基地。
- 東北：地方軍政力量與對外關係的交會地。
- 各省省城與交通樞紐：地方行政、軍事控制與經濟活動的核心。

### 7.2 交通網絡與政治權力

鐵路、輪船與電報能縮短部分距離，但不代表中央政府能有效控制所有交通沿線地區。

小說應分別檢查：

- 鐵路由誰經營與控制。
- 車站是否受到軍事或行政力量控制。
- 電報線路是否可用，以及誰有權使用。
- 地方軍事力量能否切斷交通或封鎖消息。
- 商人與普通居民是否能負擔相關交通費用。

---

## 八、1927—1937年：中央建設、地方差異與戰爭逼近

### 8.1 地理研究重點

- 南京國民政府的中央行政與制度建設。
- 上海、天津、廣州等城市的經濟與政治空間。
- 各省地方軍政力量及中央政府的互動。
- 農村與城市之間的財政、教育與交通差距。
- 東北在日本擴張下的政治與經濟變化。
- 長江流域與沿海地區的交通、商業與人口流動。

### 8.2 都市與鄉村不可混為一談

同一項政策在大城市與偏遠鄉村可能有不同的執行效果。

研究時應確認：

- 地方行政機關是否具備執行能力。
- 教育、警政、司法與公共建設是否實際覆蓋該地。
- 居民能否接觸報紙、學校與新式交通。
- 地方經濟主要依靠農業、手工業、商業還是工業。
- 戰爭風險是否已經改變人口與資源流動。

## 九、1937—1945年：戰爭、遷徙與多重行政空間

本階段不以戰場戰術為主，而應研究戰爭如何重新分配城市、交通、資源與人口。

### 9.1 重要地理問題

- 首都與政府機關遷移後，行政功能如何重新配置。
- 交通中斷與航運變化如何影響物資供應。
- 難民遷徙如何改變城市、學校與家庭。
- 戰時工業與教育機構如何遷移。
- 不同占領區、國民政府控制區與其他政治力量控制區的行政差異。
- 港口、鐵路與公路如何影響物價與生活條件。

### 9.2 交通時間必須重新計算

戰時地圖上的距離並不等於實際旅程。

需要考慮：

- 道路或鐵路是否仍可通行。
- 是否需要通行證、證件或特殊許可。
- 是否存在封鎖、檢查、空襲或其他風險。
- 旅客是否能取得交通工具與食宿。
- 難民與普通居民的移動條件是否不同於政府人員。

人物移動應以當時實際交通條件推算，不可直接套用現代導航時間。

## 十、1945—1949年：戰後接收與兩岸分途

### 10.1 中國大陸

研究重點包括：

- 戰後行政接收、交通恢復與物資調度。
- 各地軍政力量的控制範圍。
- 通貨膨脹、物資供應與人口流動。
- 城市、鄉村及交通線的控制權變化。
- 政府機關、軍隊、學校、工廠與家庭的遷移。

### 10.2 臺灣

臺灣戰後接收不能只從中央政府的行政命令理解，也必須呈現地方空間中的實際變化。

研究重點包括：

- 日本殖民時期行政設施的延續與改組。
- 中央與地方行政機構的設置及運作。
- 臺北與其他城市在行政、商業與交通上的差異。
- 地方仕紳、商人、教師、學生與一般居民的生活變化。
- 二二八事件在不同地區的發展及其地方差異。
- 1949年前後人口、軍政機構與物資的移動。

### 10.3 兩岸分途

1949年後，兩岸在不同政治制度下發展，地理上的海峽成為軍事、政治、經濟與家庭生活的重要分界。

但海峽不只是阻隔，也影響：

- 親屬聯絡與家庭分離。
- 海上交通與漁業活動。
- 軍事部署與沿海居民生活。
- 外交與國際交通。
- 後續的經貿往來、探親與人口流動。

## 十一、1949年後：臺灣、中國大陸與跨海峽空間

### 11.1 臺灣內部的空間變化

第八卷必須兼顧不同時期的臺灣城市、鄉村、產業與人口分布。

研究重點包括：

- 臺北作為政治與行政中心的發展。
- 中南部農業、工業與城市的變化。
- 港口、鐵路、公路與航空交通的發展。
- 工業區、住宅區與都市擴張。
- 教育、就業與人口遷移。
- 不同世代與不同地方的歷史記憶。

臺灣不能只透過總統府、中央政府或主要政治人物來呈現。

### 11.2 中國大陸內部的空間變化

研究重點包括：

- 中央政治與地方治理的關係。
- 城鄉制度與人口流動。
- 工業建設、農業政策與城市化。
- 交通基礎設施與區域經濟差異。
- 不同時期的行政區劃與地方制度。
- 政策如何在不同地區產生不同效果。

### 11.3 兩岸空間不能固定不變

兩岸交通、經貿、探親、旅遊與政治往來，在不同年代具有不同限制。

每一項跨海峽行動都應確認當時的政策、證件要求、航線、交通方式與實際可行性。

不可把後來開放的交通或往來方式，提前放入較早年代。

## 十二、人物移動與消息傳播

這是本文件最重要的實務規則之一。

### 12.1 人物移動表

重要人物的跨城市移動應記錄：

| 欄位 | 說明 |
|---|---|
| 人物 | 移動者 |
| 出發地 | 當時正式或常用地名 |
| 目的地 | 抵達地 |
| 出發時間 | 日期或合理區間 |
| 抵達時間 | 日期或合理區間 |
| 交通方式 | 步行、船運、鐵路、汽車等 |
| 路線 | 主要中途地點 |
| 旅行目的 | 公務、商業、逃難、求學等 |
| 交通條件 | 票價、天候、封鎖、通行限制等 |
| 證據狀態 | 已核實、部分核實、待查證或存有爭議 |
| 相關章節 | 使用此行程的章節 |

### 12.2 消息傳播必須有路徑

人物不能因為作者已經知道某件事，就自動知道該事件。

每項重要消息都應考慮：

1. 消息由誰產生？
2. 何時開始傳播？
3. 透過官文、電報、報紙、書信、口耳相傳或其他方式傳遞？
4. 需要經過哪些地點或機構？
5. 是否受到審查、封鎖、誤傳或延遲？
6. 收件人何時可能真正得知？
7. 收件人是否能理解消息的完整意義？

### 12.3 通訊方式的年代限制

| 通訊方式 | 必須確認的事項 |
|---|---|
| 官文與驛遞 | 驛站路線、行政層級與傳遞速度 |
| 私人書信 | 寄送管道、郵政服務與收件地址 |
| 電報 | 電報網路是否已建成、是否可用及費用 |
| 報紙 | 發行地點、出版日期、流通範圍與審查 |
| 廣播 | 電台設置、接收設備與實際覆蓋範圍 |
| 電話 | 線路、使用權限與普及程度 |
| 電視與網路 | 設備、基礎設施、年代與使用條件 |

不得只根據技術已經存在，就推定某地居民普遍可以使用。

## 十三、地圖、方志與空間資料的研究規範

### 13.1 優先使用的資料

- 同時代地圖與地形圖。
- 歷史行政區劃圖。
- 地方志、府縣志與港口資料。
- 鐵路、航線、郵政與電報相關檔案。
- 都市計畫、地籍、人口與商業統計。
- 殖民政府與戰後行政機關的地圖、報告及檔案。
- 學術研究中的歷史地理分析。

### 13.2 使用現代地圖的限制

現代地圖可以協助定位，但不能單獨證明歷史上的：

- 道路是否存在。
- 河道是否相同。
- 海岸線是否未變。
- 行政疆界是否一致。
- 城市建成區是否已經延伸至該地。
- 港口是否具有相同的航運能力。

涉及河道變遷、填海、港口工程、鐵路建設與都市擴張時，必須使用相應年代的資料。

### 13.3 空間資料紀錄

每張重要地圖應記錄：

- 地圖名稱與製作者。
- 製作年代。
- 地圖所表示的時間。
- 比例尺與涵蓋範圍。
- 行政區劃或地名的使用方式。
- 資料來源與保存機構。
- 可能的測繪誤差或政治目的。
- 對哪些卷章具有參考價值。

## 十七、總結

歷史地理的任務，不是替故事提供背景，而是說明人物為什麼能夠行動、為什麼受到限制，以及同一件事為什麼會在不同地區產生不同結果。

城市、道路、港口、鐵路、河流與海峽，既是物理空間，也是政治權力、商業利益、人口流動與生活經驗交會的地方。

《天下易主》必須讓讀者看見：歷史不只發生在朝廷與政治中心，也發生在通往城市的道路、等待消息的碼頭、失去生計的市場，以及被政權更替重新劃分的家園。

**地理決定了人能到哪裡、消息能走多遠，也決定了歷史變化如何真正進入人的生活。**
