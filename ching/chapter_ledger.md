# 《天下易主》全系列章節總帳

## 一、文件定位

本文件是《天下易主》全系列的章節管理索引，負責追蹤每一章的規劃、研究、撰寫、驗收與修訂狀態。

全系列目前規劃為上下兩冊、共十六卷。每卷暫定九十章，合計一千四百四十章。

本文件不直接承擔所有史料考證，也不取代各卷大綱、人物檔案、年代總表或章節正文，而是將這些資料連接起來，確保每一章都能回答以下問題：

1. 這一章發生在什麼時間、什麼地方？
2. 本章涉及哪些歷史事件、人物、制度與社會群體？
3. 哪些內容有史料依據，哪些屬於合理推演，哪些是小說虛構？
4. 歷史大勢如何具體影響人物、家庭、地方社會與日常生活？
5. 本章與前後章節、其他卷冊有什麼因果或資訊上的關聯？
6. 本章的內容是否已經完成研究、撰寫與驗收？
7. 如果未來發現史實錯誤，應該回頭檢查哪些章節？

本文件的核心目標不是把一千四百四十章填滿，而是建立一套可以持續維護的章節管理制度。

### 2.3 章節編號規則

統一採用：

`C卷次-章次`

例如：

- `C01-001`：上冊第一卷第一章。
- `C01-090`：上冊第一卷第九十章。
- `C09-001`：下冊第一卷第一章。
- `C16-090`：下冊第八卷第九十章。

章節編號是永久識別碼，不代表事件的實際年代，也不應因為章節調動就任意重編。

如果某章需要拆分，原章編號保留為舊版紀錄，新增章節使用新的編號並在修訂紀錄中說明。正式出版前可以另行調整閱讀順序，但內部識別碼應保持穩定。

## 三、章節總帳的管理原則

### 3.1 一章一筆主紀錄

每章應有一筆主要紀錄，保存其核心資訊與目前狀態。

研究筆記、史料摘錄、人物檔案與章節正文可以存放在不同文件，但章節總帳必須能指向相應資料。

不得因為某項內容已寫入正文，就省略其研究來源、人物行蹤或跨章依賴紀錄。

### 3.2 區分四種時間

每章至少區分下列時間：

- **事件時間：**歷史事件實際發生的時間。
- **敘事時間：**小說安排讀者看到事件的時間。
- **資訊時間：**人物何時得知事件、收到消息或形成判斷。
- **撰寫時間：**本章規劃、撰寫、驗收與修訂的時間。

四者不可混為一談。

例如，某地在五月發生的事件，消息可能六月才傳到另一地；小說也可能先寫六月的人物反應，再以回憶或書信呈現五月的事件。

此種敘事可以成立，但必須交代資訊傳遞的合理性，不能讓人物無故掌握尚未傳到的消息。

### 3.3 不以章節篇幅代替歷史重要性

歷史事件的篇幅，應依其對人物、制度、社會與全書主題的作用決定。

重大戰爭可以只作為背景，透過徵發、糧價、交通中斷、家庭失散、地方官署的應對等方式呈現；普通人的生活也可以承擔重要的歷史敘事功能。

章節總帳不要求每章都直接呈現重大政治事件，但要求每章具有明確的敘事功能。

### 3.4 不預先把所有空格當成待填劇情

尚未確定的內容應標示為「待研究」「待決策」或「待規劃」。

不得為了讓表格看起來完整，就把推測寫成史實，或在沒有史料依據時自行補出確定日期、人物行蹤與歷史對話。

## 四、章節主紀錄欄位

每章至少管理以下欄位。

| 欄位 | 說明 |
|---|---|
| 章節編號 | 唯一識別碼，例如 C01-001 |
| 所屬冊卷 | 上冊／下冊及卷次 |
| 單元編號 | 所屬十章單元，例如 U01 |
| 暫定章名 | 尚未確定時可以使用工作標題 |
| 事件時間 | 本章事件的起訖日期或合理時間範圍 |
| 敘事時間 | 讀者在全書中看到本章的位置 |
| 主要地點 | 城市、州縣、港口、村落、交通節點等 |
| 地理索引 | 連結 `historical_geography.md` |
| 主要歷史事件 | 本章涉及的史實事件 |
| 主要人物 | 推動本章主要行動的人物 |
| 人物分級 | 一級、二級、三級人物 |
| 人物行蹤 | 人物當時所在位置及可確認的活動 |
| 史實骨架 | 有依據的事件、制度、人物行動 |
| 合理推演 | 根據史料與情境推導的可能情況 |
| 小說虛構 | 原創人物、虛構事件、私下對話等 |
| 敘事功能 | 本章對人物弧線、歷史理解或全書結構的作用 |
| 生活影響 | 政治事件如何影響普通人的生活 |
| 制度索引 | 官制、法律、財政、軍政、教育、社會制度等 |
| 人物關係索引 | 連結 `character_network.md` |
| 前置依賴 | 本章必須承接的事件、資訊或人物變化 |
| 後續依賴 | 本章內容將影響哪些後續章節 |
| 史料來源 | 來源名稱、版本、頁碼或檔案位置 |
| 待查問題 | 尚未解決的史實與推演問題 |
| 驗收狀態 | 依第七節的狀態規則管理 |
| 版本 | 本章內容的版本編號 |
| 最後修訂 | 日期、修訂人或修訂原因 |
| 驗收紀錄 | 驗收結果、缺陷及處理情況 |

上述欄位不必全部重複寫進每份章節正文。總帳保存摘要與連結，詳細資料放在相應的研究文件中。

## 六、十章單元管理

每卷暫定九十章，分為九個十章單元。

單元編號採用 `C卷次-U單元次`，例如 `C01-U01` 代表第一卷第一單元。

每個單元應建立單元總覽，管理下列內容：

1. 單元的年代範圍與地理範圍。
2. 單元所處的歷史背景。
3. 主要歷史事件及其前因後果。
4. 一級、二級、三級人物的配置。
5. 人物在單元開始與結束時的狀態。
6. 重要制度與社會條件的變化。
7. 普通人生活受到影響的具體途徑。
8. 臺灣及其他海疆地區的相關發展。
9. 十章之間的敘事分工。
10. 單元結束時必須完成的情節與歷史交代。
11. 尚未解決的研究問題。
12. 單元驗收結果。

### 6.1 十章分工原則

十章不必平均分配重大事件，也不必每章都安排政治高層人物出場。

可以依需要安排：

- 歷史事件的發生與直接影響。
- 官署、地方士紳與民間社會的反應。
- 家庭、生計、物價與交通的變化。
- 不同地區接收到同一事件消息的時間差。
- 人物在制度限制下作出的選擇。
- 一項政策在地方執行時產生的落差。
- 歷史事件多年後留下的後果。

這些只是可使用的敘事功能，不是固定章節公式。

### 6.2 單元驗收條件

十章完成初稿後，至少檢查：

- 十章的年代與人物行蹤沒有不可解釋的衝突。
- 重大事件有可追溯的史料依據。
- 史實、合理推演與小說虛構已明確區分。
- 人物的選擇符合其當時能取得的資訊與資源。
- 歷史事件不只是背景，而是能透過合理因果影響人物生活。
- 單元的開始與結束具有可辨識的狀態變化。
- 臺灣及海疆線索沒有因中原政治敘事而被遺漏。
- 尚未解決的問題已列入清單，不以虛構補成確定答案。

## 七、章節狀態管理

章節狀態必須能反映真實進度，不得只因為已經寫出文字就視為完成。

| 狀態 | 定義 | 進入條件 |
|---|---|---|
| 未規劃 | 只有章節位置或編號 | 尚無具體內容 |
| 規劃中 | 正在決定章節功能與事件配置 | 已建立條目 |
| 研究中 | 正在核對史實、人物、地理或制度 | 已列出研究問題 |
| 待決策 | 存在需要作者決定的結構性問題 | 問題與選項已記錄 |
| 提綱完成 | 章節目的、事件與人物安排已有初步方案 | 提綱經初步檢查 |
| 初稿完成 | 已有可供驗收的完整章節文字 | 初稿已保存 |
| 驗收中 | 正在進行史實與敘事檢查 | 驗收項目已建立 |
| 修訂中 | 依照缺陷清單修改 | 修訂項目已記錄 |
| 通過 | 已通過目前規定的驗收 | 重大缺陷已解決 |
| 鎖定 | 本版本已核定，不接受未記錄的任意修改 | 修訂紀錄完整 |
| 重新開啟 | 新證據或上游修改使已通過章節必須重查 | 已記錄重開原因 |
| 暫停 | 因史料不足、結構問題或其他原因暫停 | 已記錄原因與恢復條件 |
| 取消 | 章節經正式決策後不再使用 | 已記錄取消原因及替代安排 |

### 7.1 狀態轉換規則

一般流程：

`未規劃 → 規劃中 → 研究中 → 提綱完成 → 初稿完成 → 驗收中 → 修訂中 → 通過 → 鎖定`

實際流程可以因章節性質而有所調整。

若章節仍有重要史實疑點，可以在提綱完成後開始撰寫，但必須標示未決問題，不得把未經確認的內容當成已核定史實。

已鎖定的章節如果受到上游設定變更影響，必須重新開啟，並記錄受影響的內容與修訂原因。

## 八、跨章依賴與事件先後管理

### 8.1 不可只依章節編號判斷歷史順序

章節編號代表管理識別碼與目前閱讀順序，不一定等於事件的時間順序。

如果小說採用平行敘事、倒敘、回憶、書信或不同地區交錯呈現，必須分別管理：

- 事件實際發生的時間。
- 人物知道事件的時間。
- 訊息抵達目的地的時間。
- 小說呈現該事件的章節位置。

因此，章節之間的關係應另外建立依賴紀錄。

### 8.2 依賴類型

| 代碼 | 依賴類型 | 說明 |
|---|---|---|
| T | 時序依賴 | 某事件必須先於另一事件發生 |
| C | 因果依賴 | 前章事件造成後章的局勢或選擇 |
| I | 資訊依賴 | 人物必須先收到消息才能作出反應 |
| P | 人物依賴 | 後章承接人物先前的行動、承諾或狀態 |
| G | 地理依賴 | 行程、交通與距離限制後續行動 |
| S | 制度依賴 | 官制、法律、政策或組織變動影響後續事件 |
| L | 生活依賴 | 生計、家庭、財產或社會關係延續到後續章節 |
| R | 回憶／照應 | 後章回顧、引用或重新解釋先前內容 |

### 8.3 依賴紀錄模板

```markdown
## 章節依賴紀錄

- 前置章節：
- 後續章節：
- 依賴類型：
- 必須承接的事實：
- 必須承接的人物狀態：
- 必須承接的資訊：
- 是否允許倒敘或交錯敘事：
- 若前章修改，是否必須重查本章：
- 備註：
```

### 8.4 消息傳播檢查

任何以消息推動劇情的章節，都必須檢查：

1. 消息何時產生？
2. 誰知道消息？
3. 消息經由何種渠道傳遞？
4. 傳遞需要多少合理時間？
5. 途中是否可能遭到延誤、封鎖、誤傳或截留？
6. 接收者能否辨別消息的真偽？
7. 接收者的反應是否建立在當時可得的資訊上？

官方公文、私人書信、商旅口述、報刊、電報與無線電等渠道，在不同年代的可用性與傳播速度不同。不得把後世的傳播條件直接套用到早期時代。

## 九、人物出場與行蹤管理

人物在不同章節的出場，必須與人物檔案及人物關係網保持一致。

### 9.1 每次重要出場至少檢查

- 人物當時是否仍在世。
- 人物的年齡與身分是否正確。
- 人物當時的職務、政治立場與組織歸屬。
- 人物的實際所在位置是否合理。
- 人物能否在指定時間抵達場景。
- 人物是否已經知道本章所提及的事件。
- 人物與其他角色的關係是否已經建立。
- 人物是否具有作出該行動所需的權限、資源與資訊。

### 9.2 人物出場索引

建議另外建立人物出場索引，讓每位主要人物都能查到其在全書中的出場章節。

```markdown
## 人物出場索引

- 人物名稱：
- 人物分級：
- 相關人物檔案：
- 首次出場章節：
- 最後出場章節：
- 重要出場章節：
- 主要活動地區：
- 重要身分變化：
- 重要關係變化：
- 行蹤待核問題：
```

人物分級依其在本書的敘事功能決定，不代表人物的道德高下、歷史成敗或實際官位高低。

### 9.3 歷史人物與虛構人物的不同要求

歷史人物的生卒、職務、行蹤與公開行動，應依史料核對。

歷史人物的私下對話、心理活動與未見於史料的個人決策，必須注意證據界線。即使符合人物形象，也不能直接標成確鑿史實。

小說虛構人物可以補足歷史場景中的生活經驗，但不得以虛構人物的存在，暗中改寫重大歷史事件的既定因果，除非作者明確決定採取架空歷史並在全書規範中標明。

## 十、史實校核與修訂回溯

### 10.1 任何史實修訂都必須向下游追蹤

如果發現某個日期、人物關係、職務、地點或制度設定有誤，不能只修改最先發現錯誤的章節。

必須追蹤所有使用該資訊的章節。

例如：

某人物的任職時間被修正，可能影響：

1. 該人物首次出場的章節。
2. 其與其他官員互動的章節。
3. 依據其職權安排的政策或公文情節。
4. 其他人物得知其任職消息的章節。
5. 後續涉及升遷、罷免或政治責任的章節。

以上是修訂追蹤方式的示例，不代表任何特定歷史人物的日期已經完成考證。

### 10.2 修訂影響分級

| 等級 | 定義 | 處理方式 |
|---|---|---|
| A級 | 影響全書歷史框架、重大事件或核心因果 | 暫停相關章節鎖定，全面追蹤 |
| B級 | 影響多章人物行蹤、政治關係或制度設定 | 重查所有直接與間接受影響章節 |
| C級 | 影響單章局部史實、生活細節或敘事銜接 | 修正相關章節並檢查相鄰章節 |
| D級 | 不影響史實與因果的文字、格式或表述問題 | 局部修訂並保留版本紀錄 |

### 10.3 史實修訂紀錄模板

## 十一、臺灣線與海疆線索索引

臺灣不應只在清廷割臺、日治時期、戰後接收或1949年政權遷移等節點才出現在章節總帳中。

本系列應將臺灣及其海疆關係視為持續存在的歷史地理與社會空間，依各時期的實際情況管理。

### 11.1 臺灣線索索引欄位

每章應視需要記錄：

- 是否涉及臺灣。
- 是否涉及澎湖、金門、馬祖或其他海疆地區。
- 是否涉及福建沿海與臺灣之間的移民、商業或交通。
- 是否涉及海上貿易、漁業、航運、港口或海防。
- 是否涉及殖民統治、行政制度或地方治理。
- 是否涉及人口移動、家庭分離、語言、教育或地方社會。
- 是否涉及不同政權對臺灣及周邊海域的政策。
- 是否涉及臺灣與中國大陸、日本及其他區域的關係。
- 是否存在尚未查證的臺灣史問題。

### 11.2 臺灣線的使用原則

不要求每章都必須安排臺灣場景，也不應為了提高臺灣出場率而虛構歷史聯繫。

管理目的在於避免臺灣因全書以中原政治為主要敘事軸線，而被不合理地排除於歷史進程之外。

當某項事件確實影響臺灣，應以當時的行政制度、交通條件、消息傳播、地方利益與社會反應來呈現，不可直接把後來的政治格局套回早期歷史。

### 11.3 臺灣章節索引

## 十二、每章驗收清單

每章在標記為「通過」之前，至少完成下列檢查。

### A. 年代與史實

- [ ] 事件日期已核對，或已明確標示不確定範圍。

- [ ] 人物的資訊來源與接收時間合理。
- [ ] 人物關係與政治互動符合既有設定。
- [ ] 歷史人物的心理與私下行為沒有被無根據地寫成確鑿史實。
- [ ] 人物分級符合其在全書中的敘事功能。

- [ ] 地名、行政區劃與地理條件符合當時情況。

- [ ] 官制、法律、財政與其他制度沒有時代錯置。
- [ ] 人物的行動沒有超越當時制度所允許的條件，除非小說明確交代其例外。

- [ ] 日常生活細節符合年代、地域與社會階層。

## 十三、每卷與每冊驗收

### 13.1 每卷驗收

每卷九十章完成後，應檢查：

1. 九十章是否具有完整的整體結構。
2. 各單元是否形成連貫的歷史與人物進程。
3. 重大事件的年代、因果與人物行蹤是否一致。
4. 是否有重複敘述、無效章節或重要事件遺漏。
5. 主要人物是否有清楚的出場、轉變與退出方式。
6. 政治事件是否能透過制度與社會生活落到人物身上。
7. 臺灣及海疆線索是否符合本卷的歷史背景。
8. 本卷與前後卷的事件、人物及制度設定是否銜接。
9. 尚未解決的研究問題是否有明確的後續處理計畫。
10. 是否需要調整章節順序、篇幅或單元配置。

### 13.2 每冊驗收

每冊八卷完成後，應檢查：

- 全冊的年代與歷史脈絡是否連貫。
- 全冊的主要歷史問題是否有充分呈現。
- 人物關係與政治互動是否隨時間合理變化。
- 重要制度與社會條件的變化是否有前後呼應。
- 不同地區的歷史經驗是否被適當呈現。
- 上冊與下冊的敘事重心是否清楚。
- 各卷是否各有功能，而非只是按年份排列事件。
- 全冊史實疑點是否已有研究紀錄。

### 13.3 全系列驗收

全系列完成後，還需進行一次整體核對：

- 1840年至全書最終年代的時間線是否完整。
- 同一事件是否在不同卷中被矛盾地描述。
- 人物的年齡、身分、行蹤與關係是否前後一致。
- 同一制度在不同年代是否有合理變化。
- 臺灣與海疆是否作為持續的歷史空間被呈現。
- 各冊的結尾是否回應其主題。
- 所有重大史實修訂是否已同步至受影響章節。
- 所有仍無法確定的歷史問題是否有適當標示。

## 十七、最高管理原則

《天下易主》的章節總帳遵守以下原則：

**第一，歷史日期不可為了敘事方便而任意更改。**

**第二，人物不能知道尚未傳到的消息，也不能無視當時的交通與制度限制。**

**第三，推演可以合理，虛構可以存在，但兩者都不能冒充史實。**

**第四，歷史不能只剩下政治人物的決策，還必須呈現政策、戰亂、制度與權力變化如何進入普通人的生活。**

**第五，臺灣與海疆應依各時期的真實條件納入歷史敘事，而不是只在少數重大轉折中出場。**

**第六，任何重要設定一旦修訂，就必須檢查所有受影響的章節與文件。**

**第七，章節的完成標準不是文字已經寫完，而是史實、人物、因果、生活細節與跨章銜接都經過適當檢查。**

本文件的最終用途，是讓《天下易主》在長篇、多卷、多人物與跨世代的敘事規模下，仍然保持可查證、可追蹤、可修訂與可驗收的歷史一致性。

**歷史是骨架，人物是承載歷史的人，日常生活是歷史真正落地的地方；章節總帳則負責確保三者不會在長篇寫作中彼此脫節。**
