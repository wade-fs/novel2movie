## 二、本卷核心定位

### 2.1 歷史主軸

本卷從 1900 年庚子危機延伸至 1905 年科舉制度廢除，探討清廷在重大戰敗、外交屈辱、財政壓力與內部政治危機後，如何推動新政、調整行政與軍事制度、改變教育體系，同時又無法消除地方社會、中央政治及新舊勢力之間的矛盾。

本卷不只是《辛丑條約》的形成史，也不只是晚清新政的制度清單，而是追問：

1. 庚子危機後，清廷如何重新取得行政控制與外交承認？
2. 《辛丑條約》的賠款、駐兵、外交與制度要求，如何影響國家財政及地方生活？
3. 清廷為何推動新政？不同官員對改革的目標、速度與範圍是否一致？
4. 新式教育、留學、警政、軍制與行政改革如何改變人才流動及官僚結構？
5. 地方督撫與中央政府如何分配改革成本、政治權力與財政資源？
6. 科舉廢除如何改變讀書人、地方士紳、學堂學生及家庭的生活選擇？
7. 革命思想、立憲主張與地方改革如何在新制度中繼續發展？

### 2.2 本卷敘事原則

- 不把清廷新政視為單純的虛假改革，也不預設改革必然能挽救王朝。
- 不將所有改革都描述為革命的前奏；須呈現改革者自身的制度目標。
- 不把《辛丑條約》的所有條款都化約成單一的「賠款」問題。
- 不把清廷、地方督撫、立憲派、革命派及新式知識群體寫成內部完全一致的陣營。
- 不以 1911 年辛亥革命的結果，倒推 1900 年後所有改革均注定失敗。
- 以公文、財政、學籍、官員任免、軍隊訓練、留學、地方治安及家庭選擇呈現制度轉型。
- 戰爭只在影響制度、地方秩序及人物命運時呈現，不以戰場戰術作為主要敘事內容。

## 三、跨卷年代邊界

### 3.1 與第五卷《變法與激盪》的銜接

第五卷處理戊戌變法、義和團運動及 1900 年庚子危機的爆發。

第六卷承接庚子危機，但將焦點轉向危機善後、制度重整及改革實施。

| 議題 | 第五卷主要處理 | 第六卷主要處理 |
|---|---|---|
| 義和團運動 | 地方發展、清廷政策變化與危機形成 | 危機後果及相關政策清理 |
| 八國聯軍進入北京 | 1900 年局勢惡化與清廷離京 | 北京秩序重建及後續交涉 |
| 《辛丑條約》 | 危機善後的前奏 | 談判、簽訂、批准與執行 |
| 清廷政治 | 危機前後的權力衝突 | 回鑾、官僚調整與新政 |
| 改革 | 戊戌變法及其政治挫敗 | 新政、教育改革與科舉廢除 |

**驗收要求：**不得重複第五卷已處理的危機起因及主要戰事；可回顧其後果，但須以 1900 年末至 1901 年的制度轉折為主。

### 3.2 與第七卷《新政未竟》的銜接

第七卷預計聚焦 1905 年後的立憲準備、政治改革、革命活動及清廷制度轉型的深層矛盾。

第六卷以 1905 年科舉制度廢除作為重要結點，並處理新政的制度基礎。

| 議題 | 第六卷主要處理 | 第七卷主要處理 |
|---|---|---|
| 新式教育 | 學制改革、學堂擴張與科舉廢除 | 新式知識群體與政治參與 |
| 留學 | 派遣、學習與人才制度的形成 | 留學生政治網絡及思想分歧 |
| 軍制 | 新軍制度建立及地方軍事資源變化 | 新軍與政治危機的關係 |
| 行政改革 | 官制、警政、財政與地方治理調整 | 改革的政治後果與權力衝突 |
| 立憲與革命 | 1905 年前後的思想及組織背景 | 立憲運動、革命組織與政治競爭 |

### 3.3 年代界線注意事項

1905 年不是所有改革同時完成的年份。

必須區分：

- 改革倡議。
- 詔令發布。
- 制度正式成立。
- 地方開始執行。
- 新制度實際運作。
- 舊制度停止使用。
- 改革帶來的長期後果。

科舉制度的廢除、各級學堂的建立、學制的調整及新式人才的形成，不應被寫成同一瞬間完成的轉變。

## 八、歷史地理與社會空間驗收

### 8.1 北京：清廷決策與外交善後

應呈現清廷回鑾前後的政治空間、官僚運作與外交關係。

驗收問題：

- 清廷西行期間，公文與命令如何傳遞？
- 回鑾後，哪些機構恢復運作，哪些制度發生變化？
- 《辛丑條約》的執行如何影響北京及周邊地區？
- 官員、商人、差役與普通居民如何面對戰後秩序重建？

### 8.2 天津、上海及沿海城市：外交、商業與新式制度

應呈現港口、海關、商業機構、報刊、學堂及外國機構之間的關係。

必須區分：

- 外國租界與清廷直接行政區。
- 外國企業、華商與官辦企業。
- 海關制度與地方稅收。
- 新式學堂與傳統書院。
- 外國軍事存在與一般商業活動。

### 8.3 湖北、直隸及其他新政重點地區

新軍、教育及行政改革在不同地區的實施情況並不相同。

每個地區應建立：

- 地方督撫及主要官員的任職表。
- 新軍與地方行政的關係。
- 學堂、教育機構及人才來源。
- 地方財政、稅收及改革成本。
- 商業、交通與人口流動。
- 地方士紳及居民對改革的反應。

不得將某一省份的改革成果直接視為全國情況。

### 8.4 留學與跨國知識網絡

應呈現學生出國前的資格、家庭資助、交通、學校選擇及回國後的職業安排。

驗收問題：

- 哪些留學計畫由政府推動，哪些由個人或民間組織支持？
- 留學生的經費由誰承擔？
- 學習內容與回國後的工作是否一致？
- 海外經驗如何經由書信、翻譯、報刊與人際網絡傳回中國？
- 留學生是否具有不同政治立場，而非單一思想群體？

### 8.5 臺灣與東亞區域關係

1900 年後，臺灣已處於日本統治之下。本卷應注意臺灣與清廷新政的關係，主要以區域背景、知識交流及制度比較處理。

不得把臺灣直接寫成清廷新政的行政實施區，也不得因全書以中國政權更替為主軸而忽略臺灣自身的歷史。

## 九、社會制度與日常生活設定

### 9.1 《辛丑條約》與財政生活

- 官員任免、職權調整及新舊機構的磨合。
- 公文、考核、預算及行政程序的變化。

### 9.3 教育改革與家庭選擇

- 科舉、書院、學堂及留學之間的選擇。
- 家庭如何負擔學費、住宿、交通與出國費用。
- 教師資格、教材、課程與學校管理的變化。
- 讀書人的功名、聲望及職業期待如何改變。

### 9.4 新軍與地方社會

### 9.5 改革成本與社會差異

- 地方士紳如何參與、支持、調整或反對改革。
- 改革對不同階層、地區與家庭的影響是否一致。

## 十一、史料使用與核驗規則

### 11.1 史料優先順序

依事件性質，交叉參照：

1. 清廷詔令、奏摺、官文書與地方行政紀錄。
2. 《辛丑條約》原文、外交照會及相關執行文件。
3. 學制章程、學堂檔案、留學名冊與軍事制度資料。
4. 官員日記、私人書信、報刊及當事人回憶。
5. 現代學術研究與專題史著。
6. 後世傳記、通俗敘述與民間傳聞。

重要制度的「成立日期」必須先確定定義。例如，發布章程、正式成立、開始招生、實際運作可能是不同日期。

### 11.2 每項事件的最低核驗欄位

- 事件編號。
- 事件正式名稱。
- 起始日期與結束日期。
- 地點。
- 主要人物與當時職務。
- 政策提出者。
- 批准或發布機構。
- 執行機構及實施範圍。
- 直接結果與長期影響。
- 原始史料及現代研究。
- 史料差異。
- 核驗狀態。
- 對應章節與跨卷關聯。
- 尚待解決的問題。

### 11.3 史實、推演與虛構的分界

- **【史實骨架】**：日期、人物、制度及主要行動有可靠史料支持。
- **【合理推演】**：符合已知制度與生活條件，但無法直接證實的私人情境。
- **【小說虛構】**：為串聯事件而創作的人物、對話與私人經歷。
- **【待考事項】**：存在史料缺口或解釋分歧，尚未完成核驗。

不得把小說人物安排成實際制定《辛丑條約》、正式發布科舉廢除詔令或決定新軍制度的人物。
