# Volume 4 – 金陵築牆與北方裂局（1356—1359）

本卷聚焦朱元璋在金陵（今南京）築城與防禦，張士誠的吳王稱號與對抗，脫脫的最後流放與死亡，以及陳友諒建立漢政權的擴張與衝突。

| 章號 | 時間範圍 | 主要事件 | 角色聚焦 |
|------|----------|----------|-----------|
| 1‑6   | 1356‑1356上 | 朱元璋奪取集慶，改名應天，開始金陵城牆建設 | 朱元璋 |
| 7‑12  | 1356‑1356下 | 張士誠控制平江，擴充鹽稅與軍事基地 | 張士誠 |
| 13‑18 | 1357‑1357上 | 脫脫被召回北方，策劃河道工程，最終失勢被流放 | 脫脫 |
| 19‑24 | 1357‑1357下 | 陳友諒在長江中游殺徐壽輝，稱帝建漢，擴張長江流域 | 陳友諒 |
| 25‑30 | 1358‑1358上 | 朱元璋在金陵完善城牆、設置防禦塔與糧倉 | 朱元璋 |
| 31‑36 | 1358‑1358下 | 張士誠向元廷投降，獲得官職，暫時緩和衝突 | 張士誠 |
| 37‑42 | 1359‑1359上 | 脫脫被流放至邊疆，途中死亡 | 脫脫 |
| 43‑48 | 1359‑1359下 | 朱元璋向張士誠發起最終圍剿，金陵防線測試 | 朱元璋、張士誠 |
| 49‑54 | 1360‑1360上 | 陳友諒與朱元璋在長江沿岸多次爭奪，戰事升級 | 陳友諒、朱元璋 |
| 55‑60 | 1360‑1360下 | 韓林兒的宋政權在河南漂泊，逐漸失勢 | 韓林兒 |
| 61‑66 | 1361‑1361上 | 朱元璋加強金陵城防，開始稅收改革與民生政策 | 朱元璋 |
| 67‑72 | 1361‑1361下 | 張士誠在平江被圍，最終被俘，結束吳王勢力 | 張士誠 |
| 73‑78 | 1362‑1362上 | 劉基正式加入朱元璋幕府，擔任策士與稅制設計者 | 劉基 |
| 79‑84 | 1362‑1362下 | 陳友諒在鄱陽湖與朱元璋決戰，最終戰死 | 陳友諒 |
| 85‑90 | 1363‑1363上 | 朱元璋在金陵完成城牆與官府體系，確立地方政權基礎 | 朱元璋 |

> **說明**：每章根據 `outline.md` 的硬性人物行蹤與 `characters.md` 中的角色弧線展開敘事。
