# 元末明初歷史群像小說：總綱、史實硬性約束與 540 章全書導覽

**工作稿 v2.1｜時間跨度：1328—1368（四十載）｜規模：6 卷 540 章｜敘事定位：多線人物群像、編年推進、非戰場中心、民俗神秘與宿命異象**

---

## 一、整體判斷與修訂原則

本大綱保留原有的**六卷結構、六條歷史人物主線**，以及「以同一時代的不同人生互相映照」的核心構想，並將全書擴展為 **6 大卷、每卷 90 章、總計 540 章** 的長篇巨著規模。各卷逐章詳綱分別獨立存放於同目錄下的 `volume1.md` 至 `volume6.md`。

本小說**不以戰術推演或戰場劈殺場面為主**。戰爭與天下大勢只在人物生活確實受到影響時出現，主要透過**徵發、糧價、書信、官文、家人失散、官職升降、難民流動、城門開閉、地方秩序改變**，以及**民間信仰、風水厭勝、天象占驗、夢境通感**來呈現。

### 三種敘事層級標記
在 `volume1.md` 至 `volume6.md` 的全部 540 章中，每章皆明確標註以下三種層級：
- **【史實骨架】**：有歷史記載支持的事件、制度、年代與人物關係。
- **【合理推演】**：史料沒有完整記錄私人生活，依元末明初制度、地理與人物處境合理推演的日常細節。
- **【小說虛構】**：包含新造的基層配角、信物、偶遇，以及全書特有的「民俗神秘／方外穿線人」情節。

### 全書核心主題
不是「朱元璋如何打贏所有人」，而是：**當舊秩序逐漸失去供養、保護與裁決的能力，凡人與修行者如何面對天命與劫數——有人試圖為舊帝國續命，有人煽動劫火焚世，有人在紅塵交易中求存，有人在屍山血海中重建秩序；而當新秩序最終建立，它又如何吞噬並重塑了曾經共同求生的人。**

## 二、1328–1368 年重要歷史事件年表

### 1. 1328–1351：舊秩序仍在運作，危機逐漸累積

| 年份 | 重要事件與主要地區 | 對小說的意義 |
| :--- | :--- | :--- |
| **1328** | 朱元璋出生於濠州鍾離（今安徽鳳陽一帶）。 | 可作為朱元璋人物線的起點；其他人物不必同年出場。 |
| **1330 年代** | 元廷持續面臨財政、政治與地方治理問題。劉基在元朝科舉及仕途體系中成長。 | 適合描寫官府文書、地方士人、賦役與日常秩序，不必急著進入起義劇情。 |
| **1340** | 脫脫在元順帝支持下，參與排除伯顏勢力，開始其政治改革時期。 | 脫脫此時是元廷權力核心人物，可從朝廷治理與政策改革切入。 |
| **1343–1344** | 淮北旱災、饑荒與疫病造成嚴重民生危機；朱元璋家人相繼死亡，他進入皇覺寺。 | 是朱元璋人生的重要斷裂點，也是小說從普通人生活切入歷史的關鍵。 |
| **1340 年代後期** | 元廷治理與地方民生之間的矛盾持續累積；劉基的仕途並不順遂。 | 可描寫人物如何理解制度，而非讓他們預先知道王朝即將崩潰。 |
| **1351** | 賈魯主持治理黃河；韓山童、劉福通等人在潁州一帶發動紅巾軍起事。韓山童被捕後，劉福通成為重要領導者。徐壽輝勢力在長江中上游興起。 | 黃河工程、徭役、宗教預言、地方動員與饑荒可以形成多條相互交錯的故事線。 |

> **資料依據**：故宮博物院對朱元璋早年、脫脫與紅巾軍的整理，以及元末年表。

### 2. 1352–1359：地方勢力成形，人物開始選擇陣營

| 年份 | 重要事件與主要地區 | 主要人物狀態 |
| :--- | :--- | :--- |
| **1352** | 朱元璋投奔郭子興，加入濠州紅巾軍；脫脫率元軍攻取徐州。 | 朱元璋是新加入起事勢力的軍事人物；脫脫仍是元廷重要軍事統帥。 |
| **1353** | 張士誠在淮東起事，攻取高郵等地，建立自己的政治與軍事勢力。 | 張士誠從地方鹽丁領袖轉為割據勢力首領；朱元璋仍在郭子興系統內發展。 |
| **1354** | 張士誠稱誠王、建國號周。脫脫奉命征討高郵，卻在戰事進行中遭元廷罷免。 | 元廷內部政治鬥爭直接影響軍事行動；脫脫由權力核心轉為政治失勢者。 |
| **1355** | 劉福通等擁立韓林兒於亳州稱帝，建立宋政權、使用龍鳳年號。郭子興去世；朱元璋逐步取得其部眾的實際領導權。 | 韓林兒成為紅巾軍宋政權的名義君主；朱元璋仍奉其年號，尚未公開稱王。脫脫遭流放並在此後不久去世，確切公曆年份需特別核對。 |
| **1356** | 朱元璋攻取集慶，改名應天府，建立江南根據地。張士誠勢力進入平江（今蘇州一帶）。 | 朱元璋從地方軍事領袖轉向建立穩定的區域政權；張士誠掌握江南重要城鎮。 |
| **1357** | 張士誠向元廷投降，接受元朝官職。紅巾軍宋政權開始大規模北伐。 | 張士誠採取對元廷妥協的策略；韓林兒與劉福通的勢力仍試圖向北擴張。 |
| **1358** | 紅巾軍北伐勢力進入河南、山東、河北等地；戰局反覆，部分地區易手。 | 適合呈現軍隊經過後的地方秩序、逃難、徵糧與行政中斷。 |
| **1359** | 紅巾軍北伐逐漸失利，韓林兒與劉福通退至安豐一帶。朱元璋勢力擴大至浙西、徽州等區域；劉基與朱元璋建立聯繫的過程開始。 | 朱元璋逐漸從地方軍閥走向有制度雛形的政權；劉基正處於離開元朝仕途、選擇新政治歸屬的階段。 |

> **資料依據**：故宮博物院的朱元璋、張士誠、韓林兒及脫脫人物條目，以及元末大事年表。

### 3. 1360–1368：區域政權競爭、江南統一與明朝建立

| 年份 | 重要事件與主要地區 | 主要人物位置與政治狀態 |
| :--- | :--- | :--- |
| **1360** | 陳友諒殺徐壽輝，稱帝建漢；率軍東進攻打朱元璋控制的太平、應天方向，朱元璋在龍灣擊敗陳軍。 | **朱元璋**：以應天為根據地。<br>**劉基**：約於此時正式進入朱元璋幕府。<br>**陳友諒**：以長江中游為根據地，建立漢政權。<br>**張士誠**：控制平江及江南部分地區，仍與元廷保持名義上的政治關係。<br>**韓林兒**：宋政權名義君主，與朱元璋保持政治隸屬關係。 |
| **1361** | 朱元璋軍隊沿長江進攻陳友諒勢力，陳友諒退守武昌方向。 | **朱元璋**：擴張江南與江西方向的控制區。<br>**陳友諒**：漢政權仍存，但與朱元璋的軍事競爭持續。<br>**張士誠**：維持江南政權，尚未與朱元璋決戰。 |
| **1362** | 朱元璋勢力進一步控制江西重要地區；元朝北方則仍有多支軍事力量彼此競逐。 | **朱元璋**：從應天向江西擴張。<br>**劉基**：參與政權決策與軍政規劃。<br>**陳友諒**：以武昌為重要據點。<br>**張士誠**：仍以平江為核心。 |
| **1363** | 陳友諒圍攻洪都（今南昌），朱元璋回軍救援，雙方在鄱陽湖展開決戰，陳友諒戰死。張士誠勢力進攻安豐，韓林兒與劉福通一度陷入危局；朱元璋派軍救援。張士誠稱吳王。 | **朱元璋**：擊敗陳友諒，成為長江中下游的重要競爭者。<br>**劉基**：已在朱元璋政權中參與決策。<br>**陳友諒**：戰死，漢政權由其子陳理繼承。<br>**張士誠**：自立為吳王。<br>**韓林兒**：仍是宋政權君主，依賴朱元璋的軍事保護。 |
| **1364** | 朱元璋在應天稱吳王；陳理向朱元璋投降，陳漢政權終結。 | **朱元璋**：從地方政權領袖升為吳王，建立更完整的官僚機構。<br>**陳友諒**：已死亡，其政權被消滅。<br>**張士誠**：仍是吳王，與朱元璋形成江南競爭格局。<br>**韓林兒**：名義上的宋君主地位仍在，但實際政治影響力逐漸下降。 |
| **1365** | 朱元璋派徐達等將領攻取張士誠控制的淮東地區，雙方衝突升高。 | **朱元璋**：對張士誠展開持續軍事壓迫。<br>**張士誠**：主要依靠平江及江南城鎮網絡維持政權。<br>**劉基**：參與朱元璋政權的戰略規劃。 |
| **1366** | 朱元璋軍隊攻取張士誠部分重要城鎮，圍攻平江。韓林兒在前往應天途中遇溺身亡，宋政權隨之終結。 | **朱元璋**：同時處理張士誠與宋政權的政治問題。<br>**張士誠**：被圍困於平江。<br>**韓林兒**：死亡，船難是否出於朱元璋授意，涉及史料解讀與政治推論。 |
| **1367** | 朱元璋軍隊攻破平江，張士誠被俘後死亡。朱元璋命徐達、常遇春北伐；方國珍向朱元璋投降。 | **朱元璋**：控制江南主要區域，開始全面北伐。<br>**劉基**：繼續參與政權規劃。<br>**張士誠**：政權覆亡。<br>**韓林兒**：已死一年，龍鳳年號不再使用。 |
| **1368** | 朱元璋在應天稱帝，建立明朝；明軍攻克大都，元順帝北逃。 | **朱元璋**：明朝開國皇帝。<br>**劉基**：成為新政權的重要文臣。<br>**張士誠、陳友諒、韓林兒、脫脫**：均已去世。<br>**元順帝及元廷**：退往北方，元朝在中原的統治結束，但元政權並未於此年完全消失。 |

> **資料依據**：故宮博物院的人物年表與元末大事年表交叉核對。

## 三、六名歷史人物的行蹤與政治狀態（硬性約束）

這張表作為小說中人物行蹤的「硬性約束」。沒有明確記載的地方不必補寫成史實；方外幼徒作為串場角色出現在相關區域，但不需要讓他們成為歷史人物的私人顧問或重大事件的幕後操作者。

### 1. 朱元璋（1328–1398）
- **主要活動區域**：濠州、滁州、集慶／應天、江西、平江及北伐路線
- **1328–1344**：出生於濠州；經歷家中重大變故後入寺為僧。
- **1352–1355**：加入郭子興部，逐漸取得獨立軍事力量。
- **1356–1362**：以應天為根據地，向江南與江西擴張。
- **1363–1364**：擊敗陳友諒，稱吳王。
- **1365–1367**：逐步消滅張士誠勢力，準備北伐。
- **1368**：稱帝，建立明朝；明軍攻克大都。

### 2. 劉基（1311–1375）
- **主要活動區域**：浙江青田及浙東、浙西一帶，後至應天
- **1330 年代–1350 年代前期**：在元朝仕途與地方活動之間進退。
- **1353–1358 前後**：涉及方國珍問題與浙東地方局勢；詳細任官、去職和居留時間應再按傳記核實。
- **1359–1360**：受朱元璋延聘，前往應天，開始參與其政權決策。
- **1360–1367**：參與朱元璋的軍政規劃。
- **1368**：明朝建立後成為開國文臣之一。

### 3. 脫脫（1314–1355／1356，年份有記載差異）
- **主要活動區域**：元大都、朝廷與黃河、徐州、高郵等軍事行動區域
- **1340**：參與排除伯顏勢力，進入政治核心。
- **1340 年代**：推動朝廷改革，主持遼、金、宋三史修撰等事務。
- **1351–1352**：元軍鎮壓紅巾軍，脫脫出任重要軍事統帥。
- **1354**：征討張士誠，圍攻高郵時遭罷免。
- **1355–1356**：遭流放，最後死於政治鬥爭；死亡的公曆年份在不同資料中有差異。

### 4. 張士誠（1321–1367）
- **主要活動區域**：高郵、淮東、平江（今蘇州）及江南城鎮
- **1353**：起事，攻取高郵。
- **1354**：稱誠王、建周政權。
- **1356**：取得平江，建立江南核心。
- **1357**：向元廷投降，接受官職。
- **1363**：稱吳王。
- **1365–1367**：與朱元璋勢力交戰，平江被攻破，張士誠被俘後死亡。

### 5. 陳友諒（1320–1363）
- **主要活動區域**：長江中游、江州、武昌、洪都、鄱陽湖
- **1350 年代前期**：加入徐壽輝的紅巾軍勢力，逐步掌握軍權。
- **1360**：殺徐壽輝、稱帝建漢，東進攻打朱元璋。
- **1361–1362**：與朱元璋爭奪長江及江西方向的控制權。
- **1363**：圍攻洪都，後在鄱陽湖之戰中戰死；陳理繼位。
- **1364**：陳理投降，陳漢政權覆亡。

### 6. 韓林兒（生年不詳–1366）
- **主要活動區域**：亳州、安豐及滁州方向
- **1351–1354**：父親韓山童死後，由劉福通等人推舉為重要政治象徵；本人尚未正式稱帝。
- **1355**：在亳州稱帝，建立宋政權，使用龍鳳年號。
- **1355–1359**：紅巾軍宋政權向北擴張，後因戰局失利退往安豐。
- **1363**：朱元璋出兵援救安豐，韓林兒被轉移至較安全的控制區。
- **1364–1366**：仍保有名義上的君主地位，但對朱元璋的實際控制能力有限。
- **1366**：在前往應天途中遇溺身亡，宋政權結束。

> **人物資料依據**：故宮博物院的相關人物詞條與劉基生平資料。

## 四、尚未核實的年代與需要保留的歷史疑點

這部分在小說寫作初期不必全部「解決」。有些需要查證，有些可以保留為歷史不確定性，再由【小說虛構】提供一個故事內的解釋，但不能把小說解釋倒過來當作史實。

| 項目 | 目前狀態 | 寫作時的處理方式 |
| :--- | :--- | :--- |
| **脫脫的死亡年份** | 常見資料將其列為 1355 年；也有資料將流放、死亡的過程分別記於 1355 年與 1356 年初。 | 建議採用「1354 年罷免、1355 年流放、1355 年末至 1356 年初死亡」的過程式寫法；正式年表應再核對史籍版本。 |
| **劉基正式加入朱元璋的時間** | 常見說法在 1359–1360 年之間，部分資料把受聘、離鄉與抵達應天分別記錄。 | 可以把 1359 年作為接觸或受聘階段、1360 年作為正式進入幕府階段，避免把過程壓成單一天。 |
| **韓林兒死亡的確切經過** | 1366 年十二月遇溺的記載較常見；船隻如何沉沒、誰下令以及各方知情程度，仍須區分史料記載與後世推論。 | 可保留政治疑雲，但把「朱元璋是否下令」與「誰實際執行」分成不同問題。 |
| **張士誠與劉福通的關係及相關事件日期** | 不同年表對部分事件的歸年與敘述方式不完全一致，且可能將軍事衝突、人物死亡、稱王等不同事件合併記述。 | 先固定張士誠 1353 年起事、1354 年稱王、1356 年取得平江、1363 年稱吳王、1367 年覆亡的主線；其他細節逐條查證。 |
| **郭子興死亡與朱元璋接掌部眾的過程** | 通行年表多列郭子興於 1355 年去世，但朱元璋取得實際控制權是一個逐步發生的過程。 | 不必把郭子興之死直接寫成朱元璋立即完全接掌所有部眾；應保留派系、親族與將領之間的權力轉移。 |
| **韓林兒的出生年與早年經歷** | 生年不詳，早年細節的史料遠少於朱元璋等人物。 | 不宜替他設定一套過度確定的童年年表；可以把他的私人生活列為小說虛構，但須與史實骨架分開。 |
| **朱元璋是否預先策劃韓林兒之死** | 部分後世敘述及歷史解讀認為朱元璋有政治動機；但動機、命令與實際執行之間不能直接畫上等號。 | 建議保留為政治疑案，不把單一推論寫成已被完全證實的事實。 |
| **1368 年「元朝滅亡」的範圍** | 明軍攻克大都，結束元朝在中原的統治；元廷仍退往北方延續。 | 文字上宜寫「明軍攻克大都、元朝退出中原」，而非「蒙古政權於 1368 年完全消失」。 |

> **特別說明**：其中脫脫與韓林兒的問題，最值得優先核實。故宮博物院的脫脫條目採用 1355 年卒年；另一種史料整理則將他被流放與被迫自盡分別繫於 1355 年、1356 年初。這正是年表應保留註記，而非直接把不同資料硬併成同一個日期的例子。

## 五、對本小說最實用的三條時間線規則

1. **歷史人物線只鎖定重要節點**：例如朱元璋攻取集慶、陳友諒戰死、張士誠覆亡；節點之間的日常生活可以充分小說化。
2. **地點與政治狀態比精確日期更重要**：若某年劉基的具體行蹤不明，只需避免把他寫在已知不可能到達的地方，不必每一年都替他安排一場事件。
3. **保留不確定性，不等於放棄考證**：有史料的部分盡量核實；缺乏史料的部分由小說補足，並且不要把小說補足的細節回填成歷史事實。

## 六、民俗神秘世界觀與「四方幼徒」穿線設定（低魔／魔幻寫實）

### 1. 低魔與民俗神秘原則
書中的超自然元素嚴格控制在**「民俗神秘與宿命異象（魔幻寫實）」**範疇，且**絕不讓方外幼徒成為歷史人物的私人顧問或重大歷史決策的幕後操作者**。歷史人物的決策出於自身的利益、處境與性格，方外幼徒則是穿行於各區域的見證者、基層推手與宿命折射鏡：
1. **氣運與望氣**：王朝與豪傑皆有「氣運」，但氣運由「民心、糧道、地脈、法度」匯聚而成。修行者可觀星望氣，卻無法強行逆轉百萬人的生計流向。
2. **厭勝與鎮物**：元廷密宗在大都與黃河埋設「鎮龍釘」，白蓮邪派在黃陵岡埋設「獨眼石人」。法術的作用在於引發心理暗示、瘟疫瘴氣、堤防蟻穴或君臣猜忌，在凡人眼中皆有現實成因，在方外人眼中則是氣機牽引。
3. **夢境與命格反噬**：強行借運、造讖或替王朝續命者，必遭「業障反噬」（如失明、折壽、眾叛親離）。

### 2. 四名下山歷練的「方外幼徒」（全書穿線樞紐）
1328年（致和元年／天曆元年）秋，泰定帝崩於上都，大都政變，紫微垣星象大亂；同年濠州鍾離一處破敗草屋有赤氣一閃即逝。四脈隱世方外之門同時感應到「四十年天地大劫」開啟，各遣一名年約十至十二歲的幼徒下山入紅塵歷劫。他們隨歷史人物一同從少年走到中年，出現在相關區域，將原本互不相識的六大歷史線緊密編織：

## 八、避免 540 章群像變成流水帳的寫作章法

每章在撰寫正文時，皆須扣緊以下四個問題：
1. **這個人物本章想保住什麼？**（口糧、官印、鹽引、性命、家族體面、或心中道統）
2. **他／她本章失去了什麼？**（即使沒有流血，也有信任、退路或良知的耗損）
3. **宏觀歷史與民俗異象如何進入日常生活？**（透過一紙加派的稅單、一碗發苦的符水、一場不合時節的霜凍）
4. **章末有什麼新的限制或選擇？**（推動下一章的滾動張力）
