# 史料研究與章節驗收流程（research_workflow.md）

## 一、文件目的

本文件規範《明末清初歷史小說》從歷史事件選擇、史料查證、人物行蹤校核，到小說章節完成的研究流程。

本小說不是歷史教科書，也不是完整的編年史。研究的目的，是確保小說中的人物、事件、制度與社會環境具有可信的歷史基礎，同時保留小說呈現人物命運、生活細節與人際關係的空間。

核心原則：

1. **先確認史實，再進行合理推演，最後才加入小說虛構。**
2. 不以單一史料的敘述直接等同於歷史真相。
3. 不以官書、勝利者記錄或當事人的供詞作為唯一判斷依據。
4. 不為了讓故事流暢而改動已確認的關鍵年代、人物身分與事件順序。
5. 不要求每一項生活細節都有史料直接記載，但必須符合當時的制度、地理與生活條件。
6. 考證應服務於小說，不得讓次要疑點無限延伸，妨礙整體寫作。

---

## 二、研究工作流程

每一個重要歷史事件，均依照以下七個階段處理。

### 第一階段：定義研究問題

開始查資料之前，先把問題寫清楚。

例如：

- 鄭成功於 1662 年去世，哪些資料可以確認其病逝經過？
- 鄭克𡒉遇害的時間、政治背景與參與者有哪些可靠記載？
- 朱一貴事件中，王珍的行政行為與民變之間有何關係？
- 1683 年清軍取得台灣之後，何時正式設置台灣府？
- 洪承疇被俘之後，何時開始接受清廷任用？

問題應盡可能拆分，不要把事件、動機、責任與後世評價混成一個問題。

**研究問題模板：**

- 研究編號：
- 研究主題：
- 涉及人物：
- 涉及年代：
- 必須確認的事實：
- 尚待釐清的疑點：
- 對小說的影響：
- 最晚需要完成研究的章節：

### 第二階段：建立來源清單

先找出可以回答問題的史料，再決定採用哪一種敘述。

來源可分為：

1. **同時代官書與行政記錄**：實錄、奏摺、檔案、公文、軍報、任免記錄。
2. **同時代私人記錄**：日記、書信、見聞錄、文集。
3. **接近事件發生時的歷史著作**：編年史、紀事本末、人物傳記。
4. **後來編纂的史書**：正史、地方志、史料彙編。
5. **外國或跨政權記錄**：荷蘭東印度公司檔案、傳教士記錄、外國使節報告等。
6. **後世傳聞與文學作品**：野史、演義、地方傳說、戲曲與民間故事。

來源分類不是固定的可信度排名。同時代記錄可能帶有政治立場，後來編纂的著作也可能保存現已散佚的材料。

每份來源至少記錄：

- 書名或檔案名稱。
- 作者、編者或形成機關。
- 大致成書或形成時間。
- 記錄者與事件的關係。
- 記錄目的及可能的政治立場。
- 是否直接記錄該事件。
- 是否可能轉抄其他來源。
- 可支持的具體事實。
- 無法支持或不能單獨證明的事項。

### 第三階段：追查原始依據

不能只看某本書寫了什麼，還要盡可能確認它根據什麼材料寫成。

例如，三本後世史書都寫洪承疇受到皇太極優待，不代表一定有三份獨立證據。三本書可能引用同一份官書，也可能互相轉錄。

因此，必須區分：

- 三份獨立記錄。
- 一份原始記錄被三本書引用。
- 一份原始記錄經不同作者改寫。
- 後世作者根據政治立場推演出的故事。

如果暫時無法確認來源之間的關係，應標記為「來源依賴關係待查」，不得直接計算成多源互證。

### 第四階段：建立證據鏈

每一項重要主張都應有清楚的證據鏈。

證據鏈至少包含：

**歷史主張 → 支持來源 → 原文或具體記載 → 來源限制 → 交叉比對 → 暫定結論**

例如：

| 項目 | 記錄方式 |
|---|---|
| 歷史主張 | 鄭成功於 1662 年去世 |
| 直接依據 | 記載其去世的同時代或接近事件的材料 |
| 交叉依據 | 其他具有一定獨立性的記錄 |
| 來源限制 | 不同來源對死因及臨終情況的描述可能不一致 |
| 暫定結論 | 去世年份可確認；具體死因與臨終細節另行評估 |
| 小說處理 | 可寫病逝及其政治後果；不可把未證實的戲劇性細節寫成確定史實 |

證據鏈的目的不是讓每個細節都變成定論，而是明確知道哪些內容可以確定、哪些只能推測，以及哪些必須保留。

### 第五階段：評估可信程度

每一項主張均應獨立評估，不要直接把整本書標成「可信」或「不可信」。

建議採用以下標籤：

- **【多源互證】**：不同來源支持核心事實，且來源具有一定獨立性。
- **【單一來源】**：目前主要依據一份材料。
- **【異說並存】**：不同材料對關鍵細節存在衝突。
- **【合理推演】**：由已知史實、制度與環境推導出的可能情況。
- **【後世傳聞】**：主要流傳於後來的筆記、傳說或文學作品。
- **【待考】**：目前材料不足，無法作出穩妥判斷。

這些標籤是研究狀態，不是永久判決。後續找到新資料時，可以重新評估。

### 第六階段：轉化為小說內容

史料完成初步評估後，才決定如何寫進小說。

| 研究結果 | 小說處理方式 |
|---|---|
| 核心事件已確認 | 保留事件及必要的時間順序 |
| 日期有小幅差異 | 使用較穩妥的時間表述，或在研究註記保留異說 |
| 人物動機不明 | 透過行動、選擇與後果呈現，不直接宣稱內心真相 |
| 私人對話沒有史料 | 可虛構，但須符合人物處境，不冒充歷史原話 |
| 日常生活缺少直接記錄 | 依當時制度、物價、交通、居住環境合理推演 |
| 傳聞具有重要文化影響 | 可呈現傳聞如何流傳，但不必將其寫成真實事件 |
| 爭議尚無法解決 | 選擇不影響主線的寫法，或明確保留不確定性 |

### 第七階段：章節驗收

章節完成後，檢查人物、年代、制度與敘事是否相互矛盾。

驗收不只看事件有沒有寫錯，也要看虛構人物是否被安排在不可能出現的地方、消息是否能及時傳到、官職是否符合當時制度，以及人物的行動是否有足夠的生活條件支撐。

## 三、證據類型與使用限制

### 3.1 直接證據

直接證據是指材料直接記載研究問題中的事實。

例如：

- 官員任免文書記載某人獲任某職。
- 同時代文書記錄某項命令已經下達。
- 當事人的書信記載自己收到某一消息。

但直接記載仍可能存在問題：作者可能誤報、隱瞞、誇大，或只記錄自己所知的一部分。

因此，直接證據不等於絕對真實。

### 3.2 間接證據

間接證據不能直接證明某項主張，但能協助判斷其可能性。

例如：

- 某人於某年已在另一地任職，可用來檢查小說安排的行蹤是否合理。
- 官員的往返信件可以顯示雙方是否存在聯繫。
- 糧餉、交通與行政記錄可以協助評估一項命令是否可能迅速執行。

間接證據應與直接證據分開記錄。

### 3.3 推論

推論是研究者根據多項已知資訊提出的解釋。

例如，某政權同時面臨軍費、糧餉與地方控制問題，可以推論決策者的選擇受到資源限制；但不能因此斷言某個人物必然出於特定動機行事。

推論必須回答兩個問題：

1. 這項解釋依據哪些已知事實？
2. 是否存在其他同樣合理的解釋？

### 3.4 傳聞

傳聞可以作為研究對象，但不能自動升格為史實。

例如：

- 洪承疇與莊妃之間的傳聞。
- 鄭成功臨終時的戲劇性描述。
- 鄭克𡒉血統受到質疑的說法。
- 朱一貴的特殊身世或民間傳奇。

這些內容可以用來研究後世如何理解歷史、如何塑造英雄與奸臣，卻不能僅憑流傳廣泛，就當作已經證實的事件。

## 四、來源依賴關係與證據矩陣

### 4.1 為什麼要畫來源關係圖

史料數量多，不代表證據必然強。

假設甲、乙、丙三本書都記載某事件，但乙引用甲、丙又引用乙，實際上可能只有一條主要傳承鏈。

研究時應盡可能畫出來源關係：

```text
原始奏報
   ├── 官修實錄
   │      └── 後世史書甲
   └── 私人筆記
          └── 後世史書乙
```

這只是一種示意，不代表任何特定事件的真實來源關係。實際使用時，必須根據序跋、引文、成書背景及內容相似程度判斷。

### 4.2 證據矩陣模板

| 歷史主張 | 來源甲 | 來源乙 | 來源丙 | 來源關係 | 暫定結論 |
|---|---|---|---|---|---|
| 事件發生年份 | 支持／不支持 | 支持／不支持 | 未記載 | 獨立性待查 | 待評估 |
| 人物曾任某職 | 直接記載 | 間接支持 | 未記載 | 待查 | 暫可採用 |
| 某人具有特定動機 | 作者推論 | 後世傳聞 | 未記載 | 可能同源 | 不宜當成定論 |
| 某次對話的原句 | 未記載 | 後世轉述 | 文學化描述 | 來源較晚 | 不直接引用為史實 |

使用時，將「支持／不支持」改成具體記載，不要只填勾選符號。不同來源的沉默也不等於反證，必須考慮該來源原本是否有理由記載此事。

## 五、人物與事件交叉校核

明末清初人物跨越多個政權、地區與政治階段，人物行蹤必須與事件年表一起檢查。

### 5.1 人物校核項目

每位重要人物至少檢查：

- 出生與去世年代。
- 每一階段的所在地。
- 官職、爵位及政治身分。
- 任職開始與結束時間。
- 所屬政權及其變化。
- 重要親屬與繼承關係。
- 與其他人物的接觸可能性。
- 是否具備接收某項消息的時間與管道。
- 其行動是否符合當時可取得的資訊。

### 5.2 事件校核項目

每項重要事件至少檢查：

- 發生日期或可確認的時間範圍。
- 發生地點及地名變化。
- 當時的政權與行政隸屬。
- 事件發生前的必要條件。
- 參與者當時的職務與所在地。
- 消息傳播的路徑與時間。
- 事件後的行政、財政與社會影響。
- 是否有不同來源對事件順序的記載差異。

### 5.3 九卷交界特別檢查

九卷的時間範圍彼此相接，但第九卷《海國風雲》刻意與前八卷重疊。

因此：

1. 同一事件在不同卷出現時，日期與人物行動必須一致。
2. 第九卷可以使用不同的觀察視角，但不得因此改寫前八卷已確認的史實。
3. 前八卷以中原政權及人物為主時，不應把台灣、海商與原住民族社會簡化成中原政治的附屬背景。
4. 同一歷史人物在不同卷中出場，須共用同一份人物年表。
5. 若不同史料的時間記載不一致，應在共用資料中統一註明，而不是讓各卷各自選擇不同版本。

## 六、章節寫作前檢查表

每章動筆前，先確認以下項目。

- [ ] 本章主要歷史事件已明確定義。
- [ ] 本章時間範圍與總年表一致。
- [ ] 主要人物的所在地、職務與身分已確認。
- [ ] 事件的重要參與者及其關係已核對。
- [ ] 重要日期有來源依據或已標示不確定性。
- [ ] 本章涉及的制度、官職與行政區劃符合當時情況。
- [ ] 地理距離、交通方式與消息傳播時間合理。
- [ ] 已區分史實、推演與虛構。
- [ ] 本章有明確的人物處境或社會問題，不只是事件摘要。
- [ ] 本章內容能推動人物關係、生活處境或政權變化。

若只是日常生活章，也不必強行安排重大政治事件；但生活細節仍須符合當時的社會條件。

## 七、章節寫作中檢查表

寫作過程中，特別注意以下問題。

- [ ] 沒有讓人物提前知道尚未傳到的消息。
- [ ] 沒有讓人物在不可能的時間內跨越過遠的距離。
- [ ] 沒有將後來形成的制度提前套用到早期年代。
- [ ] 沒有把後世官職、地名或政治稱號直接放進當時人物的口中。
- [ ] 沒有把未證實的對話寫成有史料依據的原話。
- [ ] 沒有把人物的政治立場直接等同於其全部人格。
- [ ] 沒有把降清、抗清、歸附或改變立場簡化為單一的道德判決。
- [ ] 沒有讓虛構人物取代歷史人物的關鍵決策與實際功績。
- [ ] 沒有為了戲劇性，擅自改動已確認的重大事件結果。
- [ ] 沒有把戰爭敘事變成與人物生活脫節的戰術推演。

本小說的戰爭與政權變化，應主要透過徵發、糧價、書信、官文、家人失散、職務變動、移民、地方秩序與生活資源呈現。

## 八、章節完成後驗收表

### 8.1 歷史正確性

- [ ] 年代、人物、地點與職務沒有明顯錯誤。
- [ ] 已知的重大事件順序沒有顛倒。
- [ ] 不同來源的異說沒有被不當消除。
- [ ] 引用的歷史材料確實支持相關敘述。
- [ ] 未將作者推論寫成已證實的客觀事實。

### 8.2 敘事合理性

- [ ] 人物的選擇受到當時條件約束，而非只為情節服務。
- [ ] 人物之間的接觸、通信與資訊取得具有合理管道。
- [ ] 虛構人物沒有不合理地介入所有重大歷史事件。
- [ ] 社會生活細節符合當時的物質條件與制度。
- [ ] 本章能呈現歷史變動如何影響普通人的生活。

### 8.3 全書一致性

- [ ] 本章與其他卷的人物年表一致。
- [ ] 同一事件在不同卷中的描述沒有互相矛盾。
- [ ] 人物的性格發展與其經歷相符。
- [ ] 台灣、海商與原住民族社會的敘述保有自身脈絡。
- [ ] 本章沒有為追求完整而加入與主線無關的大量史事。

### 8.4 研究記錄

- [ ] 新確認的史實已回填年表。
- [ ] 新發現的疑點已加入待考清單。
- [ ] 重要推演已記錄其依據。
- [ ] 有影響後續章節的修正已通知相關卷次。
- [ ] 本章的研究狀態已更新。

## 九、發現新史料後的修訂流程

新資料出現時，不應立即推翻既有結論，也不能因為原稿已完成而拒絕修訂。

依照以下步驟處理：

### 步驟一：確認新資料的性質

先判斷新資料屬於：

- 新發現的原始材料。
- 已知史料的新版本或新校勘。
- 後世著作中的新說法。
- 其他研究者提出的新解釋。
- 尚未獲得可靠來源支持的網路資訊。

### 步驟二：確認是否真正新增證據

新資料若只是重述已知史料，通常不會直接提高可信度。

若新資料來自獨立來源，或能證明原先的引用存在誤讀，才可能實質改變判斷。

### 步驟三：更新研究紀錄

記錄：

- 新資料的名稱與位置。
- 發現日期。
- 新資料支持或反駁的主張。
- 與舊資料的異同。
- 是否改變既有結論。
- 受影響的人物、事件與章節。

### 步驟四：評估修訂範圍

將影響分為三級：

- **重大修訂**：改變事件年代、人物身分、政權歸屬或主要因果關係。
- **局部修訂**：改變某個細節、人物行蹤、職務或對話安排。
- **註記修訂**：不影響正文，只需更新研究備註或異說說明。

### 步驟五：同步修改

重大修訂必須同步檢查總年表、人物檔案、卷綱、章綱及已完成章節，不能只改單一文件。

若新資料尚不足以推翻舊結論，應保留原有判斷並註明新說，不要為了追求最新說法而過度修訂。

## 十、研究優先級與時間管理

考證資源應優先用在會改變小說理解或情節成立與否的問題上。

### 第一級：必須確認

- 重要人物的生卒、身分與政治歸屬。
- 政權建立、覆亡與重大轉折的時間。
- 重要人物的任免、被俘、降附、死亡與繼承事件。
- 重大事件的基本順序。
- 會影響人物能否相遇、通信或採取行動的關鍵年代。
- 台灣治理與東寧政權的重要行政變化。

### 第二級：應盡可能確認

- 重要人物之間的關係。
- 政策形成與執行的過程。
- 地方官員的實際權限。
- 交通、糧餉、商業與人口移動的條件。
- 人物的政治選擇及其可能原因。
- 地方志與官書對同一事件的不同記載。

### 第三級：可以合理推演

- 一般家庭的日常對話。
- 沒有個別記錄的飲食與居住細節。
- 虛構人物在歷史事件中的私人經歷。
- 不影響重大史實的日常行程。
- 符合制度與社會條件的普通人際互動。

第三級不是可以任意編造，而是允許在不違反已知條件的前提下，透過小說完成歷史材料沒有記錄的生活面貌。

### 避免無止盡考證的規則

遇到一項疑點時，先問：

1. 它會改變重大歷史事件的理解嗎？
2. 它會改變主要人物的行動或責任判斷嗎？
3. 它會影響人物行蹤、年代或制度是否合理嗎？
4. 它會影響讀者對某個政權、社會群體或台灣歷史的理解嗎？

若四項皆否，且疑點不會影響後續章節，可以先記錄為待考，不必立即追查到底。

若疑點涉及重大指控、人物血統、降附動機、臨終情節或政治責任，則應提高研究優先級。

## 十二、最終原則

本小說的研究流程不是為每一件事尋找唯一答案，而是讓每一項敘述都知道自己站在哪一層證據上。

史實應盡可能準確；推演應有根據；虛構應服務人物與敘事；傳聞則應保留其作為傳聞的身分。

對於明末清初這段歷史，政權更替、忠誠與背叛、降附與抵抗、海疆與內地、中央政策與地方社會之間，往往不存在單一而簡單的解釋。

研究工作的責任，是避免用後世的定論取代當時人的處境；小說創作的責任，則是讓讀者看見這些處境如何影響人的選擇、生活與命運。
