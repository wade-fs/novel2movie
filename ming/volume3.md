# Volume 3 – 濠州暗局與高郵落日（1352—1355）

本卷聚焦於朱元璋投奔郭子興、紅巾軍在濠州的崛起，以及張士誠在高郵的鹽稅擴張與政治衝突。描寫劉基在農村的暫時退隱、脫脫的最終流放與死亡，以及韓林兒被擁立為宋皇的象徵性政權。

| 章號 | 時間範圍 | 主要事件 | 角色聚焦 |
|------|----------|----------|-----------|
| 1‑6   | 1352‑1352上 | 朱元璋投奔郭子興，加入紅巾軍；劉基返回故里務農 | 朱元元璋、劉基 |
| 7‑12  | 1352‑1352下 | 紅巾軍在濠州組織訓練，初步整合部眾 | 朱元璋 |
| 13‑18 | 1353‑1353上 | 張士誠在高郵起事，稱誠王，開始徵收鹽稅 | 張士誠 |
| 19‑24 | 1353‑1353下 | 脫脫被召回北方，策劃河道工程，但因政治鬥爭失勢 | 脫脫 |
| 25‑30 | 1354‑1354上 | 朱元璋在濠州組織農民武裝，防禦地方豪族衝突 | 朱元璋 |
| 31‑36 | 1354‑1354下 | 韓林兒於亳州被擁立為宋皇，使用龍鳳年號 | 韓林兒 |
| 37‑42 | 1355‑1355上 | 張士誠擴張鹽稅，與地方官府衝突；劉基受邀加入朱元璋幕僚 | 張士誠、劉基 |
| 43‑48 | 1355‑1355下 | 脫脫被流放至邊疆，最終在流放途中身亡 | 脫脫 |
| 49‑54 | 1355‑1355上 | 朱元璋在濠州建立臨時糧倉，開始稅收與糧食調度實驗 | 朱元璋 |
| 55‑60 | 1355‑1355下 | 張士誠與朱元璋首次正面衝突，雙方兵力較量於高郵近郊 | 張士誠、朱元璋 |
| 61‑66 | 1355‑1355上 | 韓林兒的宋政權因缺乏實務支撐逐漸失勢，官員內部分裂 | 韓林兒 |
| 67‑72 | 1355‑1355下 | 朱元璋在濠州成立地方行政機構，開始民生治理 | 朱元璋 |
| 73‑78 | 1355‑1355上 | 劉基正式加入朱元璋幕府，擔任策士角色 | 劉基 |
| 79‑84 | 1355‑1355下 | 張士誠在高郵被朱元璋圍攻，戰事升級 | 張士誠、朱元璋 |
| 85‑90 | 1355‑1355上 | 朱元璋收編部分張士誠勢力，鞏固濠州根據地 | 朱元璋 |
