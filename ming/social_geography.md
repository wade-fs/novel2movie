# 歷史地理與社會空間設定（social_geography.md）

## 一、文件目的

本文件建立《明末清初歷史小說》的共用地理與社會空間框架，供九卷的事件安排、人物行蹤、交通路線、地方治理與日常生活描寫使用。

本書涵蓋 1624–1722 年，經歷明朝覆亡、南明政權延續、清朝統治建立、鄭氏政權在台灣的發展，以及清廷接管台灣後的行政與社會變化。

這段歷史不能只用政權疆域的顏色變化來呈現。每一次疆域、行政或軍事控制的改變，都可能與地方居民的土地使用、交易方式、移動路線、家庭關係及生計發生連動。

本文件的主要任務：

1. 建立各卷共用的地域框架。
2. 區分行政管轄、軍事控制與實際社會影響範圍。
3. 管理歷史地名、行政區劃與名稱變化。
4. 檢查交通、通信及人物移動的合理性。
5. 建立港口、商路、河道、山區與聚落的社會功能。
6. 呈現不同地域居民如何受到政權變化影響。
7. 確保台灣、海商與原住民族社會具有獨立的歷史敘事空間。

## 二、地理研究的基本原則

### 2.1 地理不是背景板

地理會限制人物能做什麼，也會創造新的機會。

河流可能是運輸路線，也可能是洪水與交通中斷的來源；港口能促進交易，也可能成為徵稅、檢查、封鎖與軍事控制的節點；山區可以提供避難空間，但不代表完全與外部世界隔絕。

小說中的地理描寫，應與人物的生活和選擇發生關係。

### 2.2 必須區分三種控制範圍

- **行政管轄**：官府依法或依制度宣稱管轄的區域。
- **實際控制**：某一政權或勢力在特定時間真正能夠執行命令、徵收資源或維持秩序的區域。
- **社會影響**：即使不在直接控制之下，仍受到交易、移民、消息、宗族、海上活動或戰事影響的區域。

這三者未必重合。

例如，某政權可能名義上管轄一地，卻無法穩定執行命令；另一勢力也可能沒有正式行政機構，卻透過商業與地方關係影響居民生活。

### 2.3 地名與行政區劃必須符合年代

使用地名時，必須確認：

- 當時是否已存在該名稱。
- 當時屬於哪個行政層級。
- 當時由哪個政權管轄。
- 該地名是當代用語還是後世通稱。
- 地方邊界是否曾經調整。
- 同一地名是否可能指不同範圍。

研究文件可以使用現代地名協助定位，但正式敘事應依當時語境選擇稱呼。

### 2.4 不以現代交通條件推估歷史行程

人物移動時間應考慮：

- 交通工具與道路條件。
- 河流、潮汐、風向與季節。
- 天候與地形。
- 是否攜帶貨物或隨從。
- 關卡、檢查、徵用與治安。
- 是否必須避開衝突區域。
- 旅途中能否取得食物、飲水與住宿。
- 當時的政治與行政控制。

現代地圖上的直線距離，不能直接換算成歷史旅程所需時間。

## 三、全書主要地理區域

### 3.1 北京與北方政治核心

主要涉及第一至三卷，並透過清初政治延伸至第四至八卷。

主要功能：

- 皇帝與中央官僚體系的決策空間。
- 官員任免、奏報與政策形成的中心。
- 北方軍事壓力、財政需求與地方治理的交會點。
- 政權更替後，行政制度與政治秩序重新組合的場域。

敘事重點不在宮廷建築的靜態描述，而在消息如何進入決策核心、政策如何下達，以及命令在地方執行時產生哪些差異。

### 3.2 陝西與西北內陸

主要涉及第二、三卷。

主要功能：

- 災荒、糧食供應與地方生計問題。
- 農民起事與地方秩序變動。
- 官府徵收、治安與人口流動。
- 中央政策與地方實際條件的落差。

不應將地方動亂單純歸結為個人煽動。氣候、農業生產、稅役、債務、地方行政及軍政壓力，可能以不同方式共同影響居民生活。

具體事件的成因仍須依個別史料判斷，不可把一般性背景直接當作某次起事的唯一原因。

### 3.3 遼東、關外與華北

主要涉及第一至三卷。

主要功能：

- 明廷與後金、清政權的長期對峙。
- 軍事資源與財政支出的連動。
- 邊境居民的遷移、徵發與生計改變。
- 軍政消息由前線傳入中央的過程。
- 政權變化對地方秩序與人口分布的影響。

不以戰場攻防作為主要敘事，而是呈現軍事壓力如何透過徵兵、運糧、地方徵用、物價與家庭分離影響人物。

### 3.4 河南、湖廣與中原交通網絡

主要涉及第二至四卷。

主要功能：

- 人口移動與商業流通。
- 不同政治勢力活動區域之間的連接。
- 地方城鎮在戰亂及政權轉換中的角色。
- 河流、驛路與道路對消息傳遞的影響。

地圖上相鄰的區域，不代表居民可以自由通行。關卡、地方勢力、道路安全及交通工具，都可能改變實際的移動路徑。

### 3.5 南京、江南與東南沿海

主要涉及第三至六卷，並與第九卷的海疆敘事相連。

主要功能：

- 南明政治中心與士人社會。
- 城市商業、手工業及地方財政。
- 江河水運與沿海航路的連接。
- 地方官府、宗族、商人及移民網絡。
- 政權更替後的文教活動與社會重建。

江南不能只作為政治失敗後的避難區，也不能只用繁華與衰敗兩種意象描述。不同城鎮、階層與家庭受到政權變化的影響可能非常不同。

### 3.6 西南山地與邊疆地區

主要涉及第四至六卷。

主要功能：

- 南明政權的延續與地方軍政勢力的交會。
- 山地交通、河谷聚落與糧食供應的限制。
- 地方社群、行政機構與軍事勢力的互動。
- 政權控制範圍的變化及消息傳播的延遲。

敘事應避免把西南簡化成遙遠、封閉的邊地。地方社會有自己的交通網、交易方式、政治關係與生活秩序。

### 3.7 福建、澎湖與台灣海峽

主要涉及第六、九卷，並與第三至五卷的沿海歷史相連。

主要功能：

- 鄭氏政權的海上活動與資源網絡。
- 福建沿海居民、海商與台灣之間的聯繫。
- 港口、航路、船隻與季風對生活的影響。
- 沿海遷界、海禁及其對家庭與商業的衝擊。
- 1683 年前後海疆控制權的轉變。

海峽不是一條靜止的邊界，而是一個由船隻、港口、商人、軍事力量與地方居民共同構成的活動空間。

### 3.8 台灣本島

主要涉及第九卷，並與第六卷鄭成功攻台及清初海疆政策相連。

台灣應以本島內部的歷史發展為主軸，而不是只以中原政權是否控制台灣來安排章節。

主要研究面向：

- 原住民族社群及其地域關係。
- 荷蘭與西班牙據點及其活動範圍。
- 鄭氏政權的行政、軍事與商業網絡。
- 外來移民與地方社會的形成。
- 土地使用、農業生產、交易與人口移動。
- 清廷接管後的行政建制與地方治理。
- 1721 年朱一貴事件與清初台灣社會的變化。

應區分原住民族社群的不同生活區域、政治關係與歷史經驗，不得以單一的「台灣居民」概念抹去各群體之間的差異。

## 四、台灣歷史的分期與空間變化

### 4.1 1624 年前後：荷蘭據點的建立

荷蘭東印度公司自 1624 年起在台灣南部建立據點，西班牙勢力則於 1626 年進入台灣北部。

寫作時必須區分：

- 據點建立。
- 對周邊地區的影響。
- 與地方社群的接觸。
- 實際控制範圍的變化。

不能將據點的存在直接寫成對全島的完整統治。

### 4.2 1642 年：荷蘭逐出西班牙勢力

1642 年荷蘭勢力逐出西班牙在北台灣的主要據點。

此事件改變了歐洲殖民勢力在台灣的競逐，但不能因此假設台灣各地的社會關係立即變得一致。

不同地方社群與外來勢力之間的互動，仍須分別研究。

### 4.3 1661–1662 年：鄭成功進入台灣

鄭成功於 1661 年展開對荷蘭在台據點的軍事行動，荷蘭方面於 1662 年退出主要據點。

此階段的空間變化包括：

- 鄭氏勢力在台灣的政治與軍事據點。
- 港口、道路及物資調度的變化。
- 原有交易網絡受到的影響。
- 外來移民與地方社群的互動。
- 荷蘭統治機構撤離後，行政與經濟活動如何調整。

不得把軍事據點的易手等同於整座島嶼在同一天完成全面治理。

### 4.4 1662–1683 年：東寧政權

此階段應從政權治理與海上網絡兩方面理解。

研究項目包括：

- 鄭氏政權的行政與軍政安排。
- 海上交易、軍事資源及財政來源。
- 台灣與福建、澎湖及其他海上活動區域的聯繫。
- 地方社會、農業開墾與移民生活。
- 鄭氏內部的繼承與政治競爭。
- 清廷海疆政策與鄭氏政權之間的互動。

此時的台灣不應只被寫成鄭氏勢力的基地，也應呈現其自身的地方生活與社會變化。

### 4.5 1683–1684 年：政權轉換與行政建制

1683 年清軍取得台灣，1684 年台灣府正式設置。

兩者必須分開處理：

- **1683 年**：軍事控制與政治歸降的轉折。
- **1684 年**：清廷正式建立相關行政建制。

行政建制的成立，不代表所有地方秩序、土地關係及社會問題立即完成調整。

小說應呈現制度建立與實際治理之間的時間差。

### 4.6 1684–1722 年：清治初期台灣

研究重點包括：

- 行政區劃與地方官府的變化。
- 人口移動、農業開墾與土地使用。
- 商業交易及地方社會的形成。
- 官府徵收、治安與地方治理。
- 原住民族社群與新政權之間的互動。
- 1721 年朱一貴事件及其後續影響。
- 1722 年康熙去世與清初政治階段的結束。

不得將清治初期台灣寫成一個已經完全穩定、沒有內部差異的行政區域。

## 五、行政區劃與地名管理

### 5.1 行政區劃紀錄格式

每個重要地點應建立以下資料：

| 欄位 | 說明 |
|---|---|
| 地點編號 | 唯一識別碼 |
| 歷史名稱 | 當時常用名稱 |
| 現代定位 | 協助辨識的現代地理位置 |
| 行政層級 | 府、州、縣、廳、鎮、村落或其他適用層級 |
| 所屬政權 | 特定年代的行政或政治歸屬 |
| 有效年代 | 該名稱或行政安排適用的時間 |
| 地理特徵 | 河流、海岸、山地、平原、港口等 |
| 交通功能 | 道路、水運、海運或轉運節點 |
| 社會功能 | 行政、商業、宗族、農業或其他 |
| 史料依據 | 地方志、檔案、地圖及其他來源 |
| 待考事項 | 名稱、邊界或管轄權的不確定性 |

### 5.2 歷史名稱與現代名稱

研究文件可同時記錄歷史名稱及現代定位，但正式敘事不能任意混用。

例如，現代地名可以幫助讀者理解位置，卻不一定適合直接放進十七世紀人物的對話。

行政區劃亦應按年代記錄，避免將清代後期或現代行政安排提前套用到明末。

### 5.3 政權更替時的行政變化

政權更替後，行政名稱、實際權限及地方執行方式可能分階段改變。

每次變化都應分別確認：

1. 新政權何時取得實際控制。
2. 何時宣布或實施新的行政安排。
3. 原有官員、書吏與地方中介者如何處理。
4. 地方居民何時開始感受到實際改變。
5. 原有的社會關係是否延續。

不能假設制度公告發布後，所有地方都會在同一天完成轉換。

## 六、交通與消息傳播

### 6.1 交通方式

人物的交通方式應符合其身分、財力、地理環境及年代。

可能使用：

- 步行與肩挑。
- 馬匹及其他陸路交通。
- 河船、渡船與沿河運輸。
- 沿海帆船及其他海上交通工具。
- 官府驛傳與正式文書傳遞。
- 商旅、親友與地方中介者攜帶的私人消息。

不同交通方式的速度、成本與可用性不同，不應一概而論。

### 6.2 消息傳遞的四個階段

小說中的消息應區分：

1. 事件實際發生。
2. 消息被目擊或記錄。
3. 消息透過某種管道傳播。
4. 接收者獲得並理解消息。

這四個階段之間可能存在延遲、誤傳、選擇性報告或刻意隱瞞。

例如，某地發生政權更替，不代表遠方商人、地方官或普通家庭當天就會得知正確消息。

### 6.3 行程校核表

| 項目 | 必須確認的內容 |
|---|---|
| 出發地 | 當時的實際所在地 |
| 目的地 | 當時可到達的地點 |
| 出發時間 | 是否與人物其他行動衝突 |
| 交通方式 | 是否符合身分、地形與年代 |
| 路線 | 是否受河流、山區、海況或控制區域影響 |
| 行程時間 | 是否符合當時交通條件 |
| 沿途限制 | 關卡、戰事、天候、補給與治安 |
| 消息延遲 | 人物何時可能取得相關資訊 |

在缺乏可靠資料時，應採用合理的時間範圍，不必假裝能精確到每一天。

## 七、地方社會與生活空間

### 7.1 城鎮

城鎮應依其實際功能描寫：

- 行政中心。
- 市場與交易節點。
- 交通轉運地。
- 文教與宗族活動中心。
- 避難與人口集散地。
- 港口及海上活動的連接點。

不同城鎮的規模、人口、資源及行政功能差異很大，不宜把所有城鎮寫成同一種生活環境。

### 7.2 農村與土地

農村生活應考慮：

- 土地所有與使用關係。
- 租佃、債務及家庭勞動。
- 季節、收成與糧食儲備。
- 地方徵收、徵發及行政負擔。
- 農產品如何進入市場。
- 交通中斷與價格波動。
- 戰亂、遷徙與家庭分離。

土地關係不能只以地主與農民二分法處理。實際關係可能涉及不同形式的租佃、債務、契約、中介與地方習慣，需按具體地區研究。

### 7.3 港口與海岸聚落

港口是海商、地方居民、行政機構及軍事力量的交會處。

應研究：

- 船隻停泊與貨物裝卸。
- 水手、商人與船主的生活。
- 貨物來源與交易對象。
- 稅收、檢查、禁運與地方管制。
- 港口與內陸市場的連接。
- 季風、海況與航行限制。
- 港口活動如何影響周邊家庭與勞動者。

港口不只屬於大型商人，也涉及挑夫、工匠、供應者、翻譯者與其他地方居民。

### 7.4 山區與邊緣地帶

山區與偏遠地區不應一律描寫為封閉、落後或無法治理的空間。

應確認：

- 地方交通與交易路線。
- 居民與鄰近城鎮的聯繫。
- 地方社群的組織與規範。
- 行政機構實際能到達的範圍。
- 不同社群之間的合作、競爭與資源使用。
- 山區在避難、移動與消息傳播中的作用。

## 八、地理如何影響人物命運

每一個重要場景都應思考地理是否真正參與了情節。

可以從以下問題開始：

- 為什麼人物必須經過某座城鎮？
- 為什麼某個消息比預期晚到？
- 為什麼某個家庭無法及時逃離？
- 為什麼某種商品在某地價格特別高？
- 為什麼某個政權能控制港口，卻難以深入周邊地區？
- 為什麼某個地方的居民會接觸到不同政治勢力？
- 為什麼海上航路能維持某些關係，卻也可能造成新的風險？
- 為什麼行政命令在不同地區產生不同結果？

地理不必每章都成為主要衝突，但應在需要時提供實際限制，而不是只用來增加景色描寫。

## 九、地理研究的史料來源

依研究問題選擇來源，不必所有地點都使用相同材料。

### 9.1 地方志

適合研究：

- 歷史地名與行政沿革。
- 地方官員及行政建置。
- 地方物產、風俗與部分社會活動。
- 城鎮、道路、水利與地方治理。

使用限制：

- 成書年代可能晚於事件。
- 編纂者可能受地方政治、士紳立場與行政需求影響。
- 地方志對不同社會群體的記錄往往不均衡。

### 9.2 官書與行政檔案

適合研究：

- 行政區劃及官職。
- 政策公告與執行情況。
- 地方官員的奏報。
- 稅收、徵發、治安與人口管理。

使用限制：

- 官方記錄的範圍通常由行政目的決定。
- 奏報內容可能包含自我辯護、邀功或責任推卸。
- 政策規定不一定等於地方實際執行狀況。

### 9.3 海外檔案與外國記錄

適合研究：

- 海上交易與航路。
- 港口活動。
- 荷蘭、西班牙等外來勢力的據點及行政活動。
- 外來勢力與地方社群的接觸。
- 貨物流通與跨海消息傳播。

使用限制：

- 記錄者的政治、商業與宗教目的會影響內容。
- 外國記錄中的地名、族群名稱及人物譯名可能不一致。
- 對地方社群的描述可能只反映記錄者接觸到的部分。

### 9.4 地圖與地理研究

適合研究：

- 地形、河流、海岸與交通節點。
- 港口及聚落的相對位置。
- 歷史道路與行政區域。
- 地名變化與不同年代的空間差異。

使用限制：

- 地圖可能只呈現特定用途的資訊。
- 歷史地圖的比例、定位與邊界未必精確。
- 現代地理條件不一定完全等同於十七世紀。

## 十二、最終原則

地理不是歷史事件的裝飾，而是人物選擇與社會變化的條件之一。

城鎮、農村、港口、河流、山地與海峽，既限制人們的行動，也建立新的交易、資訊與生活關係。

本書應讓讀者理解：政權可以在某一天改變名義上的統治者，但地方生活、行政執行、人口移動與社會關係往往需要更長的時間才能改變。

尤其台灣的歷史，不應只在鄭成功抵台或清廷取得台灣時才出現在敘事中。台灣各地原有的社會、外來勢力的據點、海商活動、移民與地方治理，都應擁有自己的歷史時間與空間。
