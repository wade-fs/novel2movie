# 明末清初歷史小說｜討論成果整理包

**文件版本：** v1.0  
**整理日期：** 2026 年 10 月 26 日  
**專案範圍：** 明末至康熙去世、雍正即位前後，約 1624–1722 年  
**文件性質：** 專案規劃、史料考證與小說創作規範的工作底稿

## 一、專案定位

本專案以明末清初的政治變局、南明政權、清初統治、鄭氏政權及台灣海疆為主要歷史背景，採取歷史人物群像的方式，探索王朝興亡如何影響不同階層的人。

小說不以戰術推演或戰場殺戮為主要內容，而是透過人物的選擇、官職升降、徵糧、軍餉、物價、書信、交通、家族離散、移民、地方治理與文化延續，呈現歷史變局如何進入日常生活。

本專案不要求完整重現所有歷史事件，而是選取具有代表性的事件與人物，藉由彼此交互作用，表現制度、利益、選擇與時代條件共同造成的歷史變化。

## 二、九卷規劃

1. 《帝國的裂縫》：1627–1632
2. 《天下多故》：1633–1638
3. 《故國將傾》：1639–1644
4. 《南北易位》：1644–1646
5. 《遺民與新朝》：1646–1652
6. 《山河未定》：1653–1661
7. 《少年天子》：1662–1667
8. 《親政之始》：1667–1673
9. 《海國風雲》：1624–1722

第九卷為獨立海疆卷，與前八卷的時間重疊，但以台灣、海上貿易、原住民族社會、福建海商、鄭氏政權、移民與地方治理為主體，不將台灣僅當作中原政權變遷的附屬背景。

## 三、史實與創作的界線

所有重要歷史內容均應盡可能採用以下標籤：

- **【史實骨架】**：可由可靠史料支持的日期、公開行動、官職、政權更迭及基本事件。
- **【合理推演】**：依據當時制度、地理、交通、經濟與社會條件推導出的生活細節。
- **【小說虛構】**：虛構人物、家庭關係、私人對話及缺乏史料支持的情節。
- **【異說並存】**：不同史料對同一事件存在衝突，暫不武斷裁定。
- **【後世傳聞】**：主要見於後世筆記、演義、傳說或政治宣傳，不作為已證實的歷史事實。

## 四、史料考證的基本原則

1. 官書不必然客觀，第一手材料也不必然沒有偏見。
2. 一件事見於多部書，不代表已獲多個獨立來源互證；必須檢查材料之間是否互相抄錄或出自同一份原始報告。
3. 供詞、奏摺、軍報與私人筆記都必須放回其形成情境判讀。
4. 人物的實際行動、公開主張與後世對其動機的解釋，應分開處理。
5. 對於史料不足的私人對話與內心活動，不得偽裝成有文獻根據的史實。
6. 不因某一細節有爭議，就全盤否定一部史料；也不因一部書整體有價值，就認定其中每一細節都可靠。
7. 每一個重要歷史命題都應建立自己的證據鏈。

## 五、文件清單

本專案建議維護以下文件：

- `README.md`：專案定位、目錄及使用方式。
- `outline.md`：九卷規劃與各卷敘事重點（原稿寫作 `project_outline.md`，實際檔名為 `outline.md`）。
- `historical_evidence_review.md`：史實、疑點、異說與小說使用限制。
- `source_bibliography.md`：核心史料、版本資訊及來源特性。
- `chronology_and_fact_checks.md`：年代骨架與優先待核事項。
- `research_workflow.md`：證據鏈、史料標籤及修訂驗收規範。
- `characters.md`：歷史人物分級、行蹤、職位及人物關係。
- `chapter_writer_rules.md`：逐章寫手規範（明末清初版，2026-10-28 改寫；原稿誤為元末明初專案）。
- `relationships.md`、`social_geography.md`、`social_systems_and_daily_life.md`：人物關係、歷史地理、社會制度與生活設定。
- `volume1.md`～`volume9.md`：九卷逐章章綱（共 810 章，第九卷章號為 721–810）。
- `generate_novel.py`：依上列文件逐章生成小說的指令碼，輸出於 `chapters/`。
- `chapter_ledger.md`（尚未建立）：章節事件、人物交互與史實校核記錄，由生成流程逐章累積。
- `source_notes/`（尚未建立）：按南明、洪承疇、鄭氏政權、海疆及朱一貴事件分別建立的史料筆記。

## 六、目前的工作狀態

目前已建立九卷的基本規劃，也已整理出五大史實考證議題：

1. 1644–1646 年南明政權興替。
2. 1642–1665 年洪承疇被俘、降清及後續仕途。
3. 1661–1683 年鄭氏政權與東寧內部政治。
4. 1673–1683 年三藩之亂與海疆局勢。
5. 1683–1722 年台灣治理與朱一貴事件。

這些內容仍屬工作底稿。尚未逐條核實的日期、卷次、原文及來源關係，應列入待核清單，不得因為已經寫進規劃文件，就視為考證完成。

## 七、後續工作順序

建議依序完成：

1. 確認九卷的時間範圍、主題與主要人物。
2. 建立完整年代骨架，標出日期爭議。
3. 整理一級、二級、三級人物的行蹤與互動。
4. 建立史料命題及來源證據鏈。
5. 再進入逐卷、逐章的事件安排。
6. 每次修改章節時，同步檢查人物行蹤、制度、地理與年代是否矛盾。

**總原則：歷史負責提供骨架，考證負責限制虛構，小說則透過人物的生活與選擇，讓時代變遷具體可感。**
