# Volume 5 – 大江爭霸與雙雄對決（1360—1364）

本卷聚焦朱元璋與陳友諒（漢帝）在長江流域的爭奪，張士誠（已被俘）與韓林兒（宋皇）逐漸淡出，劉基與朱元璋的幕僚合作深化稅制與民生改革。

| 章號 | 時間範圍 | 主要事件 | 角色聚焦 |
|------|----------|----------|-----------|
| 1‑6   | 1360‑1360上 | 陳友諒殺徐壽輝，稱帝建漢，聚集長江上游勢力 | 陳友諒 |
| 7‑12  | 1360‑1360下 | 朱元璋在應天擴張，派徐達等將領攻擊陳友諒勢力 | 朱元璋 |
| 13‑18 | 1361‑1361上 | 陳友諒在長江中游建立兵站，控制洪都（今南昌） | 陳友諒 |
| 19‑24 | 1361‑1361下 | 劉基協助制定稅制、糧食流通，促進民生穩定 | 劉基 |
| 25‑30 | 1362‑1362上 | 朱元璋與陳友諒在長江沿岸多次衝突，雙方勢力拉鋸 | 朱元元璋、陳友諒 |
| 31‑36 | 1362‑1362下 | 張士誠已被俘，朱元璋收編其餘部眾，鞏固金陵北部防線 | 朱元璋 |
| 37‑42 | 1363‑1363上 | 韓林兒的宋政權在河南漂泊，因缺乏實務支撐逐漸瓦解 | 韓林兒 |
| 43‑48 | 1363‑1363下 | 陳友諒在洪都與朱元璋決戰，最終於鄱陽湖戰敗身亡 | 陳友諒、朱元璋 |
| 49‑54 | 1364‑1364上 | 朱元璋完成長江中游的稅收與糧食網絡，開始調整官制 | 朱元璋 |
| 55‑60 | 1364‑1364下 | 劉基在新設的官府中擔任稅制總監，推行標準化文書 | 劉基 |
| 61‑66 | 1364‑1364上 | 陳友諒子陳理投降，漢政權正式終結，部分軍隊納入朱營 | 陳理 |
| 67‑72 | 1364‑1364下 | 朱元璋在金陵實行「六部」制度雛形，開始官僚體系建設 | 朱元璋 |
| 73‑78 | 1364‑1364上 | 劉基整理《大明律》草稿，為未來明朝法典奠基 | 劉基 |
| 79‑84 | 1364‑1364下 | 民間反應與稅務調整的社會矛盾顯現，朱元璋親赴地方調查 | 朱元璋 |
| 85‑90 | 1364‑1364上 | 卷末總結四大勢力的轉折，為下一卷的「平吳滅元」鋪陳 | 朱元璋、劉基 |
