# 全書人物名冊與角色管理規範（character_registry.md）

## 一、文件目的

本文件是《明末清初歷史小說》的共用人物索引。

全書採九卷結構，年代涵蓋 1624–1722 年。政治人物、軍政官員、士人、海商、地方居民與台灣各社會群體分布於不同地域及政權之中，必須建立統一的人物管理規則。

本文件不取代個別人物的詳細角色檔案，而是負責：

1. 建立全書人物索引。
2. 區分主要歷史人物、次要歷史人物與基層人物。
3. 管理人物的生卒、任職、所在地及政治身分。
4. 記錄人物之間的親屬、政治、商業及社會關係。
5. 標示人物在哪些卷次及章節出場。
6. 防止人物行蹤、職務、立場與事件順序互相矛盾。
7. 區分歷史記錄、合理推演及小說虛構。

本文件以人物在全書中的敘事功能作為主要分類依據，而不是以忠臣、奸臣、英雄、叛徒等道德標籤分類。

---

## 二、人物分類原則

### 2.1 依敘事重要性分級

| 層級 | 定義 | 使用原則 |
|---|---|---|
| 一級人物 | 長期推動全書或某一主要歷史階段的核心人物 | 建立完整人物檔案，追蹤其生平、行蹤、政治關係與重要選擇 |
| 二級人物 | 與一級人物或重要事件密切相關，負責連接政治、制度、地域與社會網絡的人物 | 記錄重要經歷、任職、關係及出場事件 |
| 三級人物 | 普通百姓、地方人物、家庭成員、基層官吏、商人、工匠、移民及虛構人物 | 以生活環境、社會身分、地方關係及歷史變動下的處境為重點 |

**分級是小說的敘事管理工具，不是歷史人物的價值排名。**

一級人物不必然比二級人物更有道德價值；三級人物也不只是背景。普通人的生活可以承擔全書最重要的社會觀察。

### 2.2 依人物性質分類

每個人物另設性質標籤：

- 【歷史人物】：可確認為真實存在的人物。
- 【虛構人物】：為小說創作的人物。
- 【合成人物】：由多種歷史情境或人物經歷整合而成的虛構角色，不得冒充真實歷史人物。
- 【身分待考】：人物存在與否、身分或關係尚有重要疑點。

合成人物只能用於一般生活與社會情境，不應將其虛構經歷錯誤地歸給特定歷史人物。

### 2.3 依研究狀態分類

人物的重要資訊可以使用以下標籤：

- 【多源互證】
- 【單一來源】
- 【異說並存】
- 【合理推演】
- 【後世傳聞】
- 【待考】

這些標籤應附著在具體資訊上，而不是直接用來判定整個人物可信或不可信。

## 三、人物登錄欄位

每位人物建立唯一編號。人物編號一經使用，不因更名、政治立場改變或後續修訂而重新編號。

### 3.1 基本資料

| 欄位 | 說明 |
|---|---|
| 人物編號 | 全書唯一識別碼 |
| 姓名 | 主要使用的姓名 |
| 異名 | 字、號、別名、曾用名及不同史料中的寫法 |
| 性質 | 歷史人物、虛構人物、合成人物或身分待考 |
| 層級 | 一級、二級或三級 |
| 生卒 | 出生、去世年份及不確定性 |
| 籍貫 | 按史料記載，注意歷史行政區劃 |
| 主要活動地 | 人物實際活動的區域 |
| 政治身分 | 明、南明、清、鄭氏政權、荷蘭殖民政權或其他地方群體等 |
| 職務與身分 | 官職、爵位、軍職、商業身分、家庭角色等 |
| 主要關係 | 親屬、師友、上下級、盟友、對手及交易關係 |
| 出場卷次 | 所屬卷次與章節 |
| 研究狀態 | 資料完整度及待考事項 |
| 詳細檔案 | 個別人物檔案的檔名或索引 |

### 3.2 人物編號建議

為避免人物資料在不同文件中混淆，採用固定前綴：

- `H-001`：歷史人物。
- `F-001`：虛構人物。
- `C-001`：合成人物。
- `U-001`：身分或存在情況待考的人物。

編號只用來識別，不代表人物的歷史重要性或道德評價。

若某人物最初被誤判為虛構，後續證實為歷史人物，應保留修訂紀錄，並統一調整相關文件中的分類。

## 五、二級人物名冊的建立方式

二級人物主要負責把中央政治、地方行政、社會生活及不同地域的歷史連接起來。

初始候選群體如下，實際名單應隨各卷章綱調整。

### 5.1 明末政治與軍政

- 袁崇煥
- 孫傳庭
- 洪承疇相關的明廷同僚與上級
- 馬士英
- 阮大鋮
- 左良玉
- 鄭芝龍相關的海商與軍政人物

### 5.2 清初政治與官僚體系

- 索尼
- 蘇克薩哈
- 遏必隆
- 鰲拜
- 康熙朝重要地方官員
- 與河工、漕運、科舉及地方治理相關的人物

### 5.3 台灣、海商與地方治理

- 鄭氏政權內部的軍政官員。
- 荷蘭東印度公司在台灣的主要官員。
- 西班牙在北台灣據點的相關人物。
- 原住民族社群的領袖與地方中介者。
- 福建海商、船主、通事與移民網絡人物。
- 施琅及其相關軍政幕僚。
- 藍廷珍及朱一貴事件相關官員。
- 地方文人、地方志編纂者與基層行政人員。

二級人物不能只作為一級人物的陪襯。其存在應能解釋不同政權的運作、地方社會的反應或人物之間的實際聯繫。

## 六、三級人物與基層社會

三級人物是全書呈現歷史生活的重要部分。

明末清初的政權變化不只發生在宮廷與軍政機構，也會透過稅賦、徵發、物價、土地、移民、海上貿易及地方治安改變普通人的生活。

### 6.1 建議人物類型

- 農戶、佃農、地主與土地中介者。
- 城鎮商人、行商、船主與水手。
- 工匠、店員、挑夫、腳夫及碼頭勞動者。
- 地方書吏、差役、里甲相關人員與基層行政人員。
- 遺民士人、塾師、抄書者與地方文人。
- 逃難家庭、移民家庭及失去原有生計的人。
- 沿海居民、漁民、海商家屬及島嶼社群。
- 台灣不同原住民族社群中的人物。
- 與地方治理、土地開墾、交易及文化交流相關的人物。

### 6.2 三級人物的角色檔案

三級人物不一定需要完整傳記，但至少要交代：

- 家庭與生計。
- 所在地及生活環境。
- 認識哪些人。
- 如何接觸官府、市場、宗族或地方社群。
- 透過何種途徑得知外部事件。
- 事件發生後，生活受到什麼具體影響。
- 哪些經歷屬於史實背景，哪些屬於小說虛構。

### 6.3 避免把普通人寫成現代人的投射

三級人物的價值觀、資訊來源與行動能力，必須符合其時代。

例如，普通人不應自然擁有今日完整的全國政治資訊；對政權的理解可能來自告示、商旅、地方官差、親友、宗族與市井傳聞。

不同人物也不必對同一件事形成一致的看法。

## 七、人物關係管理

人物關係不能只記錄親屬與敵友，還必須考慮關係形成的時間及其變化。

### 7.1 關係類型

- 親屬與婚姻。
- 君臣與上下級。
- 同僚與政治派系。
- 軍政合作與指揮關係。
- 商業交易與債務關係。
- 地方宗族與社會網絡。
- 師友、文學與學術往來。
- 政治對立與軍事衝突。
- 暫時合作、談判與盟約。
- 傳聞中存在、但尚未證實的關係。

### 7.2 關係必須有時間範圍

同一組人物在不同時期可能有不同關係。

例如：

- 某人先效力明廷，後來降清。
- 某兩個勢力先結盟，之後因利益衝突而決裂。
- 某人與另一人有正式官場關係，但不一定存在私人交情。
- 某個政治指控被記載，不代表被指控的關係確實存在。

因此，關係表應包含：

| 欄位 | 說明 |
|---|---|
| 人物甲 | 關係的第一方 |
| 人物乙 | 關係的第二方 |
| 關係類型 | 親屬、上下級、盟友、對手等 |
| 起始時間 | 可確認或推定的開始時間 |
| 結束時間 | 關係終止或發生變化的時間 |
| 證據依據 | 史料或小說設定 |
| 可信度 | 研究標籤 |
| 備註 | 關係的限制與變化 |

### 7.3 關係圖的使用限制

人物關係圖適合呈現誰與誰有聯繫，但不能單憑圖形推導權力大小、忠誠程度或私人感情。

正式的政治關係、實際的利益合作與私人情感應分開記錄。

## 八、人物時間線管理

每位一級人物都應建立時間線；重要二級人物亦應建立。

### 8.1 時間線欄位

- 年份與日期。
- 人物所在地。
- 當時身分與職務。
- 主要行動。
- 與之相關的歷史事件。
- 可確認的消息來源。
- 不確定性。
- 涉及的小說章節。

### 8.2 時間線示例

以下僅為人物時間線格式示例，並非完整人物年表：

| 年份 | 地點／身分 | 事件 | 校核事項 |
|---|---|---|---|
| 1661 | 鄭氏政權 | 鄭成功勢力轉向台灣 | 核對抵台與相關政治事件的時間 |
| 1662 | 台灣 | 鄭氏政權建立其統治基礎 | 區分鄭成功去世與後續政權發展 |
| 1681 | 東寧 | 鄭經去世，繼承危機發生 | 核對鄭克𡒉與鄭克塽相關記載 |
| 1683 | 台灣海疆 | 清軍取得台灣 | 區分軍事控制、歸降與後續行政建制 |
| 1684 | 清治台灣 | 台灣府正式設置 | 核對行政制度與實際治理的時間差異 |

正式寫入小說時，必須回到年代文件與相關史料確認細節，不得把示例表當成完整考證成果。

## 九、歷史人物與虛構人物的互動規則

虛構人物的主要功能，是讓讀者進入歷史材料較少涉及的生活空間，而不是代替歷史人物解決歷史問題。

### 9.1 可以安排的互動

- 虛構人物因工作、交易或家庭關係接觸歷史事件。
- 虛構人物透過書信、告示、商旅與地方傳聞得知政局變化。
- 虛構人物因徵發、物價、移民、土地或行政變動而受到影響。
- 虛構人物在歷史事件周邊經歷失散、遷徙、求生或家庭重組。
- 虛構人物與歷史人物有合理且不改變重大史實的接觸。

### 9.2 應避免的安排

- 虛構人物決定某項重大政權更替。
- 虛構人物成為歷史人物所有重要決策的幕後推手。
- 虛構人物掌握沒有合理途徑取得的機密。
- 將虛構的私人對話包裝成歷史人物的真實原話。
- 讓虛構人物在各卷反覆出現在所有重要事件中，造成不合理的全知視角。
- 將虛構人物的價值觀當作歷史人物的實際思想。

### 9.3 虛構人物的連續性

若同一虛構人物跨卷出場，必須建立完整的年齡、家庭、行蹤、職業與關係表。

若人物跨越數十年，應合理處理年齡增長、世代交替、家庭成員變化及生活條件的改變。

若某人物不可能親身經歷所有事件，可以透過後代、親友、書信、商業網絡或地方記憶延續敘事，不必強迫同一角色貫穿全書。

每位一級人物建立詳細檔案時，至少確認：

- [ ] 基本身分與異名已整理。
- [ ] 生卒年代及重要日期已核對。
- [ ] 主要任職與政治身分已整理。
- [ ] 重要行蹤已建立時間線。
- [ ] 親屬及政治關係已區分史實與推測。
- [ ] 重要事件已有來源依據。
- [ ] 有爭議的傳聞已明確標示。
- [ ] 人物動機沒有被簡化為單一的道德評價。
- [ ] 相關卷次與章節已標記。
- [ ] 人物在不同卷中的描述一致。
- [ ] 後續仍待確認的問題已列出。

二級人物依其重要性選擇性完成；三級人物則以生活合理性、地方關係與出場連續性為主要驗收標準。

## 十一、人物名冊的維護規則

1. **新增人物**：先登錄名冊，再寫入正式章綱。
2. **更改人物分類**：記錄原因，並同步更新人物檔案與相關卷綱。
3. **發現史實錯誤**：優先修改共用人物資料，再修訂所有受影響章節。
4. **出現新異說**：保留原有紀錄，新增不同說法與來源，不直接覆寫。
5. **虛構人物更名**：保留固定編號，更新姓名與相關引用。
6. **人物退出主線**：保留名冊與已完成的歷史紀錄，不因減少戲份而刪除重要設定。
7. **人物死亡或離場**：檢查後續章節是否仍安排其親自行動，並確認消息傳遞方式。
8. **跨卷出場**：共用同一份人物檔案，禁止各卷自行建立互不相容的版本。

## 十三、最終原則

本書的人物管理，不是把所有歷史人物排成一張忠奸善惡榜，而是理解每個人在特定年代、制度、地理與社會條件下的位置。

一級人物負責承擔主要歷史變化，二級人物呈現政治與社會網絡，三級人物則讓讀者看到政權興亡如何落實到普通人的生活。

三個層級共同構成全書的人物群像。歷史人物的真實行動應盡可能忠於史料；虛構人物則應讓歷史中未被記錄的生活得以呈現，而不是改寫歷史本身。
