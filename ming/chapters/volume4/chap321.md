# 第三百二十一章　處州烽火

至正十八年（1358）十二月二十五日深夜，浙江處州路（麗水）北面門戶——古樓洞峽谷。

朔風呼嘯，大雪冰封了甌江上游奔騰的急流。古樓洞如同一柄巨斧劈開的崇山絕壁，古道逼仄，僅容一人一騎通行，乃是由婺州（金華）進入處州的唯一咽喉要道。

在峽谷兩側陡峭如削的花崗岩峭壁之上，數以千計身披白色斗篷的精銳步甲，正手攀古藤鐵索，冒著粉身碎骨的奇險，悄然向峽谷深處的元軍大寨摸去。

而在峽谷下方的一處避風岩石下，兩道身影正並肩端坐於雪地之中。

左側一人，身材魁偉如鐵塔，滿面虯髯，手按一柄重達六十斤的開山大斧，正是朱元璋麾下威震浙東的常勝虎將——**胡大海**！

而坐在胡大海身側的，卻是一位極其引人注目的奇特文士——

此人身高六尺三寸，身形高大偉岸，然而面容卻黝黑如生鐵，更奇特的是，他左腿微有殘疾，走起路來略顯跛足。但他那雙深邃如星的眼眸之中，卻透出一股睥睨天下、文武兼備的萬丈豪氣！

此人正是南宋理學名門之後、句容大名士、朱元璋破金陵時親自登門禮聘的謀略大才——三十五歲的**孫炎**（字伯融）！

孫炎自幼博學強記、精通兵書戰策，為人慷慨剛烈、雄辯滔滔。朱元璋克婺州之後，深知處州山地險惡、山民苗獠剽悍難治，尋常將領只知殺戮必難成事，於是特命三十五歲的孫炎隨胡大海、耿再成統軍南下，全權參贊浙東軍機！

「伯融先生！」

胡大海呵出一口白氣，搓了搓粗糙的大手，低聲問道：

「城裡的元朝江浙行省參政石抹宜孫，帶著一萬多蒙古與色目精騎退守處州；又有處州山民苗酋在兩翼結寨策應。剛才探子回報，石抹宜孫在古樓洞內設了三道擂石機與連環火弩！耿再成將軍正帶死士在崖頂摸暗哨，咱們何時發動總攻？」

孫炎手握一柄未出鞘的青銅古劍，嘴角泛起一抹洞悉敵膽的從容微笑：

「胡將軍莫急。石抹宜孫雖是名將，但他自婺州兵敗退守處州，早已成驚弓之鳥；處州山民苗兵之所以依附於他，無非是因為元朝平日以重金厚幣相誘！今夜天降大雪、滴水成冰，守關元兵必定躲入洞內烤火飲酒！聽——！」

孫炎豎起食指。

只見古樓洞兩側絕壁之上，驟然亮起了三道刺目的紅色火箭，劃破了雪夜的長空！

「信號來了！耿再成拔掉山頂哨所了！」

孫炎霍然站起身來，雖然跛著一隻腳，但拔劍出鞘的姿態卻如同一頭矯健的下山猛虎，劍鋒直指古樓洞隘口，厲聲斷喝：

「胡將軍！破陣就在此刻！依計行事：只誅首惡石抹宜孫親兵，凡投降山民一概不殺！」

「弟兄們！隨俺胡大海衝啊——！」

胡大海虎吼一聲，掄起六十斤開山大斧，率領三千精銳鐵甲死士如怒濤般自雪谷中狂暴衝出！

「轟隆隆——！」

火藥陶罐與滾木擂石在古樓洞隘口劇烈爆炸，硝煙與烈火瞬間將古樓洞化作了一片火海！

正在洞內飲酒取暖的元軍措手不及，防線瞬間崩潰。元將石抹宜孫在亂軍之中被胡大海的大斧生生劈落馬下，受重傷後在親信死士的拼死護衛下，倉皇翻越括蒼山古道向福建方向狼狽遁逃！

拂曉時分，大宋江南行省的大軍如風捲殘雲般殺入處州路治所——麗水城！

然而，當麗水城池光復之際，城外崇山峻嶺之中的數十座少數民族山寨苗兵，見元軍潰敗，卻紛紛手持毒箭長矛封閉山道、結寨自保，甚至一度聚集了萬餘青壯，揚言要與進城的漢軍死戰到底！

「胡將軍，不可妄動刀兵！」

就在胡大海準備調集回回砲強攻山寨之際，黑面跛足的孫炎一把按住了胡大海的韁繩。

「先生，這幫山民刁頑得很，不給他們點顏色瞧瞧，他們怎肯降服？」胡大海急道。

孫炎朗聲長笑，將佩劍解下扔給侍衛，整了整身上的藍布儒袍：

「山民困於窮山惡水，皆天子赤子也！昔日諸葛孔明七擒孟獲，全在攻心！某孫炎願單騎上山，若不能說降各寨，任憑將軍軍法處置！」

說罷，在全軍將士震驚的目光中，三十五歲的孫炎牽著一匹沒有任何甲冑的老馬，手無寸鐵，一瘸一拐地獨自踏上了通往深山苗寨的冰雪險道！

在那座聚集了數千苗獠青壯的虎頭寨大門前，面對上百支對準自己心口的淬毒利箭，孫炎面不改色，昂首挺胸大步跨入寨門！

他站在寨主大廳正中央，面對滿堂拔刀怒目的山寨頭領，以其驚世駭俗的雄辯之才與浩然正氣，當堂陳說天下興亡大勢、痛陳大元殘暴虐民之弊，並當場以項上人頭立誓保證：

**「吳國公朱公大軍進處州，保山民耕織、永除苛課、茶鹽自由通商！凡山寨頭領皆授行省巡檢、千戶，各自安撫族人！」**

孫炎那如洪鐘大呂般的宏亮嗓音與無所畏懼的剛烈氣度，深深震撼了全寨首領。

不到兩個時辰，處州深山十八座山寨的苗獠頭目無不心悅誠服，紛紛擲刀於地，牽著耕牛、捧著美酒，跟在孫炎的馬後下山，歸順大軍！

三日後，金陵朱元璋的加急賞功手令快馬送抵麗水。

朱元璋大喜過望，當即下旨：

**改處州路為「安慶府」（後改處州府），正式任命三十五歲的黑面名士孫炎為「處州總制」！全權總理處州九縣軍政、撫綏山民、督造糧餉！**

至此，浙東重鎮處州全境徹底平定！

十二月二十八日傍晚，處州麗水城南門最高的城樓望江閣之上。

夕陽西下，殘陽將滔滔甌江水照映得一片金紅。

新任處州總制孫炎披著一領粗呢大氅，手拄一根斑竹手杖，獨立於呼嘯的寒風之中。

在他身後，侍從遞上一份剛剛自金陵送來的吳國公密信。信中，朱元璋用了整整半頁紙，極其急迫地叮囑孫炎同一件事——

**「處州既定，青田近在咫尺！務必為咱打探青田南田山劉伯溫之行蹤！此人若得，江山定矣！」**

孫炎放下信函，轉過身，目光深邃而熾熱地望向東南方向那片被茫茫大雪與雲海籠罩的巍峨山脈——

括蒼山脈，青田縣，南田山！

那裡，距離處州麗水城，不過短短百里水程！

「劉伯溫……劉先生……」

孫炎撫摸著腰間那柄陪伴了自己多年的青銅古劍，眼中閃爍著前所未有的興奮與崇敬，喃喃自語：

「孫炎在句容時，便聞先生大名如雷貫耳！先生隱居深山，著《郁離子》以待真主。今日孫伯融既坐鎮處州，縱踏破這括蒼山的千山萬壑，也定要親手扣開先生的草堂柴門，為這江南萬民，請出一位擎天白玉柱！」

風雪獵獵，戰旗飛揚。

處州的大定，如同一把鎖鑰，徹底打開了通往青田武陽村的最後一道關卡！

一場關乎大明帝國未來命運的三顧草廬傳奇，在處州的烽火餘燼中，正式拉開了歷史的序幕！

### 【工作紀錄】
- **【史實骨架】**：《明史·太祖本紀》、《胡大海傳》及《明史·孫炎傳》載：至正十八年（1358）十二月，朱元璋命胡大海、耿再成進攻處州（麗水），句容名士孫炎參贊軍事。大軍奇襲古樓洞，大破元江浙行省參政石抹宜孫，收復處州。朱元璋即命孫炎為「處州總制」。孫炎黑面跛足、才氣縱橫、為人慷慨剛烈，以單騎撫定處州少數民族山寨，境內大安。朱元璋嚴令孫炎就近尋訪禮聘青田名士劉基。
- **【待核事項】**：孫炎時年35歲（生於1323年），為明初開國最卓越的文臣儒將之一，後以身殉國；處州之戰為朱元璋勢力直接接觸青田劉基的唯一地理前哨。
- **【合理推演】**：透過胡大海的勇猛攻關與孫炎單騎撫定山寨的「文武協同」，生動勾勒出朱元璋軍團成熟高效的統治手腕。孫炎登麗水城樓遠眺青田南田山，將朱元璋的密旨與個人對劉基的崇敬深度結合，天衣無縫地引出後續南田山三請劉基的經典篇章。
- **【小說虛構】**：古樓洞崖頂三道火箭信號夜襲；孫炎手無寸鐵單騎入虎頭寨折服山民；城樓手拄斑竹手杖遙望南田山誓言請出劉基。
- **【連續性變更】**：
  - **孫炎**：35歲，黑面跛足名士，建奇功受封處州總制，成為朱元璋在浙東最關鍵的軍政樞紐與引薦劉基的首席使者。
  - **胡大海**：克婺州、破處州，打通金華至甌江全線。
  - **保住什麼**：保全了處州城郭與甌江上游各族山民的安定，穩固了浙東南大後方。
  - **失去什麼**：元軍徹底被逐出浙東全境。
  - **哪些變成日常**：處州府衙整修、少數民族首領納貢通商、驛騎密探日夜打聽青田劉基下落，成為麗水新日常。
  - **章末狀態變化**：處州平定，劉基隱居之地已在金陵勢力掌控範圍之內；而此時在青田南田山武陽村的草堂雪夜中，劉基手握桑皮紙，正全神貫注地寫下了《郁離子》最後一卷的千古定稿！
- **【後續銜接】**：第322章將視角轉向青田武陽村草堂，除夕前夕劉基在葉守拙協助下完成五卷百八十篇《郁離子》最後定稿，將全書與半枚青田石印合存竹箱中以待真主（〈郁離大成〉）。
