# 第509章　血戰塔兒灣

洪武元年閏三月。

河南，洛陽城東二十里，塔兒灣洛水畔。

春水初生，冰雪消融的洛水奔騰東流，兩岸的泥沼與土坡在春風中泛著泥濘的黑褐色。這座背靠十三朝古都洛陽的險要灣道，在今日成了兩支當世最強鐵血軍團的絞殺場！

元朝知樞密院事、大將托音帖木兒，統帥蒙古、色目與中原精銳騎兵整整五萬人，依託洛水與塔兒灣高亢的地勢，排開了延綿數里的鐵騎連環陣。

戰馬嘶鳴，長槊如林。這是元帝國在中原腹地最後一支成建制的野戰精銳集團，亦是阻擋大明王師收復洛陽的最後一道鐵閘！

「殺——！」

地平線的盡頭，震天動地的喊殺聲伴隨著雷霆般的馬蹄聲洶湧而來。

一面巨大的朱紅「大明副將軍鄂國公常」戰旗，在狂風中迎風招展。三十八歲的常遇春頂盔貫甲，手持丈八點鋼矛，身先士卒，單騎狂飆在五萬明軍鐵騎的最前方！

「放箭！射死他！」元陣中軍，托音帖木兒拔刀狂吼。

「崩崩崩崩——！」

元軍弓弩手齊齊扣動機括，黑壓壓的狼牙箭雨如同暴雨蝗群，遮天蔽日般朝著常遇春傾瀉而下！

常遇春長矛舞動如車輪，將身前箭矢紛紛挑飛。然而箭雨太過密集，胯下神駿的烏騅戰馬悲嘶一聲，胸腹連中七八箭，轟然向前栽倒！

「常帥落馬了！」後方明軍將士失聲驚呼。

托音帖木兒大喜，揮刀厲喝：「斬常遇春者，賞萬金、封千戶！」數百名元軍重裝鐵騎如餓狼般拍馬狂撲而來！

然而，就在戰馬栽倒的同一剎那，常遇春雙足在馬鐙上猛然借力一蹬，魁梧的身軀宛如大鵬展翅般騰空躍起，重重砸落在泥濘的陣地中央！

他沒有後退半步，甚至沒有看一眼死去的戰馬，順手自腰間抽出一柄重達三十斤的百煉生鐵大砍刀！

「大明鄂國公在此！胡虜受死！」

常遇春爆發出一聲驚天動地的暴喝，整個人如虎入羊群，迎著狂奔而來的元軍重騎猛撲上去！

「咔嚓！」

第一名衝上來的元軍百戶連人帶馬尚未來得及出刀，常遇春手中大刀凌空劈落，竟將那名百戶身上的厚重熟鐵札甲硬生生劈成兩半，血雨狂噴！

常遇春側身避過一柄刺來的長槊，反手一刀斬斷馬腿，第二名元軍騎兵跌落馬下，被他一腳踩碎胸膛！

大刀翻飛，血光如瀑！

常遇春一人步行於千軍萬馬之中，大刀劈砍砍缺了刃口，他左手成拳砸碎敵人的面門，右手短刀割斷敵將咽喉，短短十數息之內，連斬元軍騎兵二十八人！

「嘶律律——！」

一名元軍怯薛千戶挺槍策馬衝來，常遇春不退反進，矮身避過槍尖，左手閃電般扣住長槍桿，猛然一拽，硬生生將那名千戶自馬背上拽了下來，隨後反手一刀切開其脖頸！

常遇春飛身躍上那匹無主的棗紅駿馬，奪韁勒馬，仰天長嘯：「大明兒郎！隨某破陣！」

「萬歲！大明萬歲！」

後方五萬明軍鐵騎目睹主將如此神勇，熱血沸騰到了極點，山呼海嘯般撞入了元軍的大陣！

兩股鋼鐵洪流在塔兒灣的泥沼中狠狠對撞在一起。骨骼碎裂聲、兵刃交擊聲、瀕死的慘嚎聲交織成人間地獄。

就在元軍主力被常遇春死死咬住、難解難分之際，戰場兩翼的號角聲陡然變換！

大將軍徐達統率的十萬步兵主力主力大陣，如同一堵緩慢而不可阻擋的鋼鐵城牆，從塔兒灣南北兩翼排山倒海般合圍而來！

神機營火銃齊射，硝煙蔽日；重裝長牌手步步推進，將元軍退路徹底截斷！

「中伏了！全軍撤退！撤退！」

托音帖木兒看著被三面合圍的慘狀，嚇得魂飛魄散，再無戰意，在親衛的拼死掩護下，狼狽棄陣西逃！

失去指揮的元軍頓時全線大崩潰。

兵敗如山倒，數萬潰軍爭相跳入冰冷的洛水逃命，溺死者不計其數。

殘陽如血。

塔兒灣這場驚心動魄的血戰，在黃昏時分終於落下了帷幕。

洛水河灘之上，遍地狼藉。到處是元軍丟棄的生牛皮鐵盔、折斷的彎刀與無主的戰馬。

幾名明軍小卒在血泊中穿梭，熟練地拔出射在盾牌與泥土裡的完好箭矢，裝入自己的牛皮箭囊中，臉上洋溢著大勝後的狂喜。

常遇春勒馬立於高坡之上，身上的精鋼重甲已被鮮血染成了赤黑色。

他拄著長刀，看著遠方洛陽城頭那面在夕陽中緩緩墜落的元軍狼頭大旗，長長吐出一口血沫，露出了勝利的豪邁笑容。

塔兒灣一戰，元廷在中原最後的五萬野戰主力全軍覆沒，神都洛陽，已成囊中之物！

## 【本章工作紀錄】

### 【史實骨架】
- 洪武元年（1368）閏三月，常遇春、徐達在洛陽塔兒灣大破元將托音帖木兒五萬大軍。
- 斬首數千級，元軍潰敗，托音帖木兒逃奔陝西。
- 塔兒灣之戰是北伐中原期間最具決定性的野戰騎兵大碰撞，直接奠定了洛陽收復與河南全境平定。

### 【待核事項】
- 《明史·常遇春傳》記載：「遇春轉戰至洛陽，元將托音帖木兒等屯兵塔兒灣，遇春單騎突其陣，破之，追奔五十餘里，遂克洛陽。」正史高度凸顯其勇冠三軍的悍將本色。

### 【合理推演】
- 常遇春戰馬被射倒後的步戰連斬、奪馬再戰，將其「百萬軍中取上將首級」的猛將形象刻畫得淋漓盡致。
- 徐達主力步兵側翼及時包抄，展現徐常二人「一勇一謀、一奇一正」的完美名將搭檔特質。

### 【小說虛構】
- 常遇春手持百煉生鐵大砍刀連劈二十八人的動作特寫。
- 洛水河灘戰後小卒收箭裝囊的士兵視角白描。

### 【連續性變更】
- 承接第508章徐達常遇春進兵洛陽。
- 徹底粉碎元軍在中原平原的野戰抵抗能力。
