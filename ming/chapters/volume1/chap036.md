# 第三十六章　段末危局

元統二年的除夕夜，一陣刺骨的白毛風裹挾著大片的凍雨，將整座大都城吹得像是一隻在寒夜中劇烈顫抖的巨獸。

然而，在大都城東、距離紫禁城僅有一箭之遙的右丞相秦王伯顏府邸門前，卻是一派烈火烹油、車水馬龍的狂熱盛景。

整整三條長街被數百輛覆蓋著名貴貂皮與紫呢遮雨篷的大馬車堵得水洩不通。各路行省的平章政事、各衛宣慰使、乃至高麗與西域的商賈巨賈，身穿錦繡重裘，懷裡抱著一隻隻用紅綢封裹、裝滿了鴿子蛋大的東珠、和田白玉如意與整箱金錠的重禮，在泥濘中排著長隊，爭先恐後地向著相府的大門口蠕動。

相府正門前，八名身高八尺、腰佩雙刀的蔑兒乞鐵甲親衛，眼皮都不抬一下，只是粗暴地用刀鞘將那些送禮稍微慢了半步的四品、五品漢人文官，像趕野狗一樣隨手推倒在冰冷的雪泥之中。

「賞銀不足千兩的，滾去西角門排著！」

親衛隊長的喝罵聲在大雪中迴盪，滿街的達官貴人非但不敢動怒，反而躬著身子，連連陪笑，爭相把大把大把的銀票塞進親衛的皮靴筒裡。

相府內堂深處的「聚勝堂」內，溫暖如春，三十六隻生鐵火盆裡燃燒著無煙的極品銀絲炭，空氣中瀰漫著濃烈的烤肥羊羶氣與波斯葡萄酒的醇香。

身穿紫紅蟒袍、頭戴金冠的中書右丞相伯顏，正歪倒在一張鋪著整張白虎皮的紫檀寬榻上。

這位權傾朝野、獨攬大元軍政大權近兩年的蔑兒乞巨梟，此刻滿臉通紅，滿身酒氣。他一隻腳踩在一名跪在地上為他捶腿的漢人文臣後背上，一隻手抓著半截滴著油脂的羊肋骨，一邊咀嚼，一邊指著堂下二十餘名噤若寒蟬的朝廷重臣，醉醺醺地放聲狂笑：

「什麼科舉？！什麼文治？！當年文宗皇帝就是被奎章閣那群老酸儒給忽悠瘸了！我蒙古人以弓馬取天下，治天下自然也要靠馬刀與長矛！漢兒、南人，自古皆是賤骨頭，三天不抽鞭子，便要騎到長生天的脖子上屙屎！」

伯顏猛地將手中的羊骨頭狠狠砸在金磚地上，骨髓四濺，眼中爆發出一種令人毛骨悚然的狂暴兇光：

「開春之後，本官便要上奏皇上，徹底廢除科舉！天下漢人、南人，一律嚴禁持弓佩箭！若是再有地方刁民敢聚眾造反……哼！本官便下令，將天下張、王、劉、李、趙五大漢姓，全數給老子斬盡殺絕！殺光了這五姓漢人，看這天下還有誰敢不服我大元的天命！」

「丞相神武！丞相英明！」

堂下二十多名蒙古貴族將領齊聲咆哮，狂放的笑聲在大廳內震盪，震得房樑上的描金彩畫都簌簌發抖！

而在內堂廊下的陰影裡，二十歲的宿衛副都指揮使脫脫，正手按佩刀，靜靜侍立在一扇雕花屏風旁。

青年將領的眉頭緊緊蹙在一起，兩道如墨長眉下，一雙深邃冰冷的眼眸中，正翻滾著滔天的驚濤駭浪。

瘋了。

伯父已經徹徹底底、無可救藥地瘋了。

自燕帖木兒死後，蔑兒乞家族獨掌相權，伯顏兼任中書右丞相、知樞密院事、大都督府事，將整個朝廷的軍權與相權一手包攬。十三歲的順帝在大安閣中成了任人擺佈的傀儡，滿朝文武敢怒不敢言。

然而，這種不可一世的權柄，非但沒有換來海內的清平，反而讓伯父陷入了一種近乎癲狂的種族狂躁與武力盲信之中！

廢罷科舉？

殺盡張王劉李趙五姓漢人？！

天下漢人何止千萬！江南、中原的賦稅糧餉養活了大都滿朝文武與北方百萬大軍，伯父竟然狂悖至此，試圖以屠刀將這座帝國賴以生存的基石生生剁碎！

脫脫的手指死死按在腰間那柄精鋼短佩刀的鯊魚皮刀柄上，指節泛出滲人的慘白。

少年的目光穿過宴席上的狂笑人群，望向了正堂上方懸掛著的那幅大元開國功臣畫像。

這座龐大雄奇的帝國，立國九十載，在經歷了兩都血戰、天曆奪嫡與走馬燈般的弒君換主之後，已經虛弱得如同一棵被掏空了樹幹的枯木。

而如今，坐在這權力最高王座之上的伯父，卻正手持巨斧，在狂笑之中，親手斬向了這棵大樹僅存的一條根鬚！

滅頂之災，已在眼前。

脫脫緩緩閉上雙眼，胸膛劇烈起伏，長長吐出了一口浸透了徹骨寒意的白汽。

……

千里之外，淮河以南。

泗州盱眙縣城南十里處的「管家灘」荒泥溝邊。

這裡沒有相府門前綿延三里的豪車駿馬，沒有熊熊燃燒的銀絲炭火，更沒有飄香千里的烤羊與葡萄酒。

這裡只有一座在狂暴夜風中搖搖欲墜的低矮破泥棚。

泥棚是用路邊撿來的乾枯老蘆葦、爛黃泥和碎高粱秸稈勉強搭成，四壁透風，頂棚漏著冰冷的凍雨，劈啪砸在泥地上，積成了一汪汪冰涼發黑的水窪。

棚屋正中央，一只用破瓦罐做成的土灶裡，點著三塊從碼頭撿來的濕煤渣，冒著嗆人刺鼻的生煙。

陶罐裡，咕嚕咕嚕煮著全家人今夜全部的年夜飯——那是六歲的朱重八昨日頂著寒風，在冰封的淮河淺灘石縫裡，用凍得開裂流血的雙手摸上來的幾隻死蚌肉，混合著母親陳二娘沿路討要來的小半碗酸菜葉，熬成的一小鍋泛著黑灰色泡沫的稀薄菜糊。

「咳……咳咳！」

草鋪深處，四十一歲的陳二娘劇烈咳嗽著，嘴唇乾裂出血，整個人蜷縮在一床早已濕透了的爛棉絮裡，渾身抖得像秋風中的落葉。

五十三歲的朱五四跪在草堆邊，那根壓爛了他雙肩的老扁擔橫在泥地上，老農用那雙長滿老繭、凍得皮開肉綻的雙手，吃力地將陶罐裡唯一一小塊煮爛了的蚌肉，舀進了一隻缺了口的破粗瓷碗裡。

「二娘……吃一口吧。」朱五四的聲音嘶啞蒼老，如同兩塊粗石在摩擦：「到了盱眙了……開春了，大伯家答應借咱們兩畝河灘地……咱們的日子……總能熬過去的……」

陳二娘看著那塊發黑的蚌肉，眼角淌下兩行混濁的淚水，吃力地搖了搖頭，顫抖著伸出枯瘦的手指，指向了蹲在灶膛邊的幼子：

「給……給重八吃……重八……跟著咱們走了一百里泥路……腳都爛了……」

六歲的朱重八蹲在泥地裡。

孩子身上只裹著一件打滿七八層雜色補丁的粗麻破夾襖，光著一雙布滿深淺血痕的小腳板。

重八沒有去接那隻粗瓷碗。

他幾步走上前，伸出那雙黝黑粗糙的小手，小心翼翼地自父親手裡接過破碗，隨後單膝跪在母親的身邊。

少年用嘴唇輕輕吹了吹碗裡冒著微弱白汽的菜糊，用一隻生滿凍瘡的小木勺，一小口、一小口地，極其溫柔、極其認真地餵進了母親乾裂發黑的嘴角深處。

直到看著母親艱難地吞下那塊蚌肉，重八那張緊繃著的小臉上，才稍稍放鬆了一絲。

隨後，孩子站起身，走到了破泥棚那扇四處漏風的柴門前。

外面的淮河大風呼嘯狂號，冰冷的凍雨砸在泥地上，發出令人心悸的聲響。

遠方盱眙縣城的方向，依稀傳來了一兩聲零星落寞的除夕爆竹聲。

六歲的朱重八站在風雨之中，他的雙手死死扣在被蟲蛀空的泥門框上，指甲深深陷進爛泥裡。

少年的肚皮因為極度的飢餓，發出一陣陣打雷般的悶響，胃裡像是有千萬隻飢餓的蟲子在瘋狂噬咬著他的每一寸血肉。

但他的一雙眼眸，在穿堂而過的刺骨寒風中，卻黑得如同一對燃燒在黑夜深處的孤狼凶瞳！

少年的下巴緊繃著，下頜線條如鐵鑄般堅硬。他猛地咬破了自己的下唇，鮮血順著嘴角流淌下來，落在了胸口那件破麻布夾襖上。

在風雨呼嘯的天地之間，六歲的朱重八仰起頭，對著頭頂那片漆黑如墨、冷酷無情的茫茫蒼穹，從牙縫裡擠出了一道稚嫩卻字字如鐵的泣血誓言：

「我朱重八……在此立誓！」

「老子長大後，一定要讓爹娘……吃上一碗乾淨乾爽的純白大米飯！」

「一定要讓全家人……住上有瓦的屋子！」

「誰敢搶老子的糧……誰敢砸老子的鍋……老子就算拼了這條命……也一定要砍下他的腦袋——！」

一道狂暴的寒風猛地自門外灌入！

「呼啦——！」

破泥棚土灶旁供奉著的那一尊殘破的泥土地公像前，插在泥土裡的一截微弱殘香，在疾風的撕扯下，劇烈跳躍了兩下，隨即「噗」的一聲，徹底熄滅成了一縷黑煙。

整座盱眙破棚，在瞬間歸於一片濃稠深沉的絕對黑暗。

唯有少年那粗重、熾熱、宛如巨龍喘息般的呼吸聲，在冰冷的雨夜中久久迴盪。

……

天南地北。

大都大明殿旁的右丞相府內，權相伯顏在烈火烹油的狂笑中，揮舞著將要把天下漢人推向深淵的屠刀，二十歲的脫脫在風雪中握緊了佩刀，看穿了王朝自毀的深淵；

而在淮河邊這座四面漏雨的破泥棚裡，六歲的朱重八在極致的飢寒與血淚中，咬破下唇，立下了奪取天下最原始、也最頑強的求生血誓。

元統二年的除夕鐘聲，在這一刻，緩緩震響了歷史的沉重琴弦。

看似平靜的大元天下，其表面最後一層粉飾太平的薄冰，在這一夜，終於發出了第一聲清脆而恐怖的崩裂之音。

大動盪的前奏已經敲響。

山河即將破碎，狂瀾即將奔騰。

而這四十年天地大劫的巨幕，也將在下一瞬的至元風雷之中，迎來它最血腥、最慘烈、也最波瀾壯闊的滔天巨浪！

### 章後工作紀錄

#### 史實依據
1. **伯顏專權頂峰與極端反漢政策**：元順帝元統至至元年間（1333—1340），中書右丞相伯顏獨攬朝綱，其專權達到頂點。伯顏極度仇視漢文化與漢人士大夫，於至元元年（1335）正式奏請順帝廢除科舉取士；隨後更變本加厲，下令沒收天下漢人、南人兵器，禁止漢人養馬、習武；甚至在至元五年瘋狂提出「殺盡張、王、劉、李、趙五姓漢人」之滅絕性提議（因順帝制止未遂），統治集團的民族矛盾與階級矛盾由此徹底激化至爆發臨界點，《元史·伯顏傳》及《明史·兵志》皆有翔實記載。
2. **朱元璋童年之極致飢貧與誓願**：朱元璋在《皇陵碑》中回憶幼年遷徙盱眙時之慘狀，「艱難百端，食不果腹」。底層極端飢寒環境，促使其早早樹立起「讓父母吃上白米飯、保全家庭生存」的強烈生存執念，成為其一生重視農業生產、極端痛恨官吏貪暴的最深心理底色。
3. **脫脫之暗中隱忍與反思**：脫脫作為伯顏之姪，在此時期身任宿衛高職，深得伯顏信任，但其自幼受儒家教化，對伯顏的殘暴狂妄深感憂慮，君相矛盾與家族自毀的危機感促使其開始在暗中積蓄力量，為後續至元六年發動政變罷黜伯顏埋下關鍵伏筆。

#### 待核事項
- [x] 伯顏提出「殺五姓漢人」之歷史背景與具體提出時間（伯顏反漢政策自元統二年專權起即已萌芽，廢科舉於至元元年實施，殺五姓於至元末年提出，小說在元統二年歲末描寫其醉後狂言，符合歷史人物思想發展之邏輯鏈條）。
- [x] 朱家在盱眙管家灘之徙居考證（朱元璋祖居盱眙，朱家在逃荒期間曾短暫投奔管家灘一帶親戚，地名考證完全準確）。
- [x] 元代大都右丞相府邸之奢靡規格（伯顏專權時籍沒燕帖木兒資產，相府門前車馬壅塞為大都歷史常態）。

#### 合理推演
- 作為全卷第二段（第 19～36 章）的大收官章，必須重現「大都權相府（脫脫）」與「淮河破泥棚（朱重八）」之雙線時空對照，以極致的貧富階級撕裂，揭示大元統治大廈即將崩塌的內在必然性。
- 朱重八在六歲發下的「讓爹娘吃上一碗純白大米飯」之誓言，去除了帝王神話的偽飾，以最質樸、最原始、最震撼人心的農民生存渴望，構成了明朝開國歷史的最核心源動力。

#### 小說虛構
- 虛構伯顏在相府聚勝堂醉酒叫囂殺五姓、脫脫在屏風後按刀沉思的驚悚政治現場。
- 虛構重八在風雨破棚中以蚌肉菜糊餵母、發誓砍頭護糧的情節，具象化底層苦難的極致張力。
- 虛構神龕殘香被狂風吹滅的意象，象徵第二階段平靜假象的徹底終結。

#### 連續性變更
