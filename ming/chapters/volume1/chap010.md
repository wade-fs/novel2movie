# 第十章　青田夜讀

天曆二年的正月初七，浙南南田山上的嚴霜厚得像是一層結硬了的羊脂。

青田縣武陽村的夜極靜，唯有狂暴的山風順著九里坑的深谷長驅直入，將武陽溪畔幾株合抱粗的老苦楝樹吹得枝椏狂舞，發出如群鬼呼嘯般的怪響。半山腰上一座背靠青山、四合院落的木構舊宅裡，一燈如豆。

書房內的窗紙已經泛黃，被山風頂得發出「噗噗」的悶響，寒氣透過窗櫺的細縫直往裡鑽。

十八歲的劉基身披一件半舊的灰布棉袍，雙肩緊縮著，正襟端坐在一張粗糙卻擦拭得極乾淨的杉木書案前。

案頭放著一隻豁了口的青瓷筆洗，洗中的井水表面已經結起了一層薄薄的冰皮。在微弱的桐油燈燈光下，擺放著一卷攤開的《春秋公羊傳》、一具用梨木自製的手持渾天星盤，以及三頁被翻得邊角捲曲、字跡模糊的殘破「邸報」抄本。

劉基伸出修長而骨節分明的手指，輕輕將筆洗表面那層脆薄的冰皮揭開，扔在一旁的木盒裡。隨後，他將一管磨損得只剩下半截狼毫的湘妃竹毛筆，探入硯台深處，蘸飽了研磨得極濃極稠的松煙黑墨。

然而，筆尖懸在泛黃的竹紙上方半寸處，久久沒有落下。

少年的眉頭緊緊蹙在一起，兩道如濃墨畫出的修長劍眉之下，是一雙深邃得宛如高山古潭般的眼睛。那雙眼睛清澈、敏銳，帶著一股近乎殘酷的洞察力，此刻正死死盯著那三頁來自千里之外的朝廷邸報。

這份邸報，是五天前他父親劉爚從青田縣學訓導處借抄回來的。

在交通閉塞的浙東深山裡，天下的訊息總是來得那樣遲鈍而滯後。北方那場驚天動地的兩都血戰，自天曆元年七月泰定帝暴崩、八月燕帖木兒大都拔刀起兵，打到十一月上都倒剌沙出降，大都城內早已三易其主、功臣分肥、白骨蔽野。

然而直到這元正開春、新桃換舊符的正月初七，這份遲來了整整四個月的官府邸抄，才將那場北方浩劫的零星碎片，遞到了這間幽僻的山村書齋之中。

邸報上的文字冠冕堂皇，充斥著「逆臣倒剌沙擅立幼衝」、「皇上順天應人入繼大統」、「太師太平王燕帖木兒神武克定」之類的浮華諛詞。

「順天應人……神武克定……」

劉基低聲喃喃自語，嘴角泛起一抹冷冽自嘲的苦笑。

他放下毛筆，伸手拿起了案頭那一具梨木刻製的渾天星盤。星盤只有巴掌大小，但上面用極細的刻刀精確標注了周天三百六十五度、三垣二十八宿以及十二次分野。劉基伸出食指，輕輕撥動星盤內側的黃道銅環。

「去年秋分，紫微垣帝星傾斜，北斗第七星搖光無光，天市垣大震……」

少年的手指在星盤上緩緩滑過，眼神愈發深邃凝重：「那不是什麼克定乾坤的祥瑞，而是北方乾綱斷裂、骨肉相殘的天裂之兆。漢唐以來，何曾見過如此輕率狂悖之定策？大權盡落於邊鄙悍將之手，天子視同傀儡，宗室殺戮殆盡。大元立國不過九十載，而其內部的氣數，竟已衰朽至此……」

他轉過頭，望向窗外被濃黑夜色籠罩的括蒼山脈。

劉基自幼聰穎絕倫，過目成誦。十二歲考中秀才，十四歲入處州府學研讀《春秋》，十六歲便博覽石室秘閣之書，通曉宋儒理學、天文曆法、兵家韜略乃至奇門遁甲之術。在武陽村這個遠離塵囂的世外桃源裡，他曾以為只要閉門讀書，窮究天理，恪守聖賢之道，便能在這山水清幽處做一個超脫物外的山中高士。

然而，這三頁薄薄的邸報，卻像是一柄無情的冰錐，生生刺碎了他少年時代所有的田園幻夢。

天下要亂了。

那不是一場換個皇帝便能平息的尋常動亂，而是一場自上而下、由骨髓爛到皮肉的全面崩塌。當朝廷的中樞將全部精力用在爭奪皇位、分肥奴婢與互相傾軋之時，那些鋪陳在廣袤漢地山河之上的萬千底層黎民，又將面臨怎樣的命運？

「咚咚咚！」

突然，一陣粗暴刺耳的拍門聲伴隨著野狗狂吠，突兀地打破了武陽村寒夜的死寂。

「劉二公！開門！青田縣衙辦差！」

一聲帶著濃重處州方言、公鴨嗓般的叫罵聲在隔壁院落門外炸開，緊接著是一聲沉重的踹門巨響，破舊的柴扉在巨力下發出「喀嚓」的斷裂悲鳴。

劉基手中的星盤微微一顫。

他迅速合上案頭的邸報，披上一件厚實的青布斗篷，快步走出書房，穿過穿堂，來到了自家庭院的矮牆邊。

借著微弱的雪光與院外搖晃的火把，劉基看見隔壁老農劉大伯的院子裡，正站著三個身穿皂色差役短袍的衙役。帶頭的是青田縣戶房的一名老書手，姓錢，平日裡在縣城裡仗著給達魯花赤老爺抄寫糧冊，專門在鄉間敲骨吸髓。兩名長伕手持水火棍，腰間掛著鐵鏈，正將劉大伯那間低矮的泥胚草屋圍在當中。

六十歲的劉大伯穿著一條露出膝蓋的破夾褲，光著雙腳踩在冰冷的雪泥裡，正死死抱著錢書手的鹿皮靴子，磕頭如搗蒜。

「錢老爺！行行好！寬限幾天吧！」

老人哭得撕心裂肺，額頭撞在凍硬的泥地上，淌下一道道烏黑的血痕：「年前秋糧，小人家裡三畝薄田收的兩石黃粟，已經一粒不剩全交進了縣糧庫！前兒個除夕，官府又說要派什麼『定策恩錢』，小人把家裡唯一一口生鐵鍋和老婆子的兩件粗布陪嫁衣裳全當了，才湊出六百文交了上去！如今這大正月的，家裡連下鍋的米糠都沒了，哪裡還拿得出三貫『平定兩都解餉銀』啊？！」

「老梆子！放你娘的狗屁！」

錢書手一臉橫肉，反手就是一記重重的耳光，狠狠抽在劉大伯枯瘦的臉頰上！

「啪！」老人被打得在雪地裡翻了個滾，滿嘴噴出混著爛牙的血水。

「你也不睜開你的狗眼看看邸報！」錢書手揮舞著手裡一張蓋著鮮紅官印的催徵條子，唾沫星子噴了一地，「當今天子平定大難，坐穩了大都大明殿，那是長生天降下的大恩德！朝廷十萬鐵騎在長城外替你們這些南人賤民擋刀子，你們出點解餉銀子犒勞王師，乃是天經地義！知縣老爺下了死命令，武陽村今夜必須收齊五十貫！若是短了一文，明日就把你這老骨頭鎖進縣大牢，讓你兒子去抵充築城的官差！」

屋內，劉大伯那常年生病癱瘓在床的老伴，發出如病貓般絕望淒厲的哭嚎：「老頭子啊……咱們不活了！咱們跳了九里坑算了吧……」

劉大伯趴在冰冷的雪水裡，雙手摳著凍土，渾身劇烈抽搐，眼中滿是求死不得的極度絕望。

矮牆之後，劉基的一雙手死死扣在粗糙的夯土牆沿上。

他的指甲深深嵌進了黃泥之中，掌心被凍土中的碎石劃破，鮮血順著指縫滴落，他卻感覺不到絲毫疼痛。少年的胸膛劇烈起伏著，一股熾熱如狂火的怒意，自他的丹田深處瘋狂湧上眼眶！

平定兩都……犒勞王師！

何其荒謬！何其無恥！

大都的軍閥將領在殿堂裡飲著馬奶酒、瓜分著如山的金銀與如雲的美姬；而遠在千里之外、一輩子連長城是什麼模樣都沒見過的南田山老農，卻要為這場蠻橫無恥的宮廷爭霸，搭上全家最後一口口糧、最後一條殘命！

元廷律令，南人地位最賤，賦稅最重。江南一省之租稅，養活了半個塞北與大都的貴胄；然而一旦朝廷有變，揮向這些赤貧農民的皮鞭與鎖鏈，卻比任何時候都要狠毒兇殘！

「住手。」

一聲清朗、冰冷、宛如山澗寒泉般的語聲，突然在風雪中沉穩地響起。

錢書手一愣，手中的水火棍猛地停在半空，轉過頭來。

只見劉基推開院門，面容沉靜地走了出來。少年一身洗得發白的長袍在寒風中獵獵作響，身形雖然清瘦，但那一雙寒芒逼人的雙眸，卻透著一股令人不敢逼視的巍然浩氣。

「喲，是伯溫相公啊。」錢書手皮笑肉不笑地咧了咧嘴，眼中閃過一抹忌憚。

劉基之父劉爚曾任遂昌縣教諭，在處州府頗有名望；劉基自己又是年少成名的秀才，按元廷法度，士人見吏不跪，甚至有權向府台遞狀。

「錢書手，天曆元年冬，中書省頒布即位大赦詔書，內明文載定：『除常規田賦外，各路行省嚴禁巧立名目私加苛捐，凡擅派解餉、犒軍之資者，以貪墨論。』」

劉基一步步走到錢書手面前，聲音不高，卻字字如鐵鑄一般，狠狠砸在雪地上：「你手中這張加蓋青田縣戶房印信的白條，既無中書省憲台准敕，又無江浙行省布政司勘合，不過是縣衙胥吏私相授受的弊條！若是劉某明日五更啟程，攜此條直奔處州廉訪使衙門告你一個『假傳皇命、擅斂民財、逼死人命』，不知錢書手頭上的這頂皂隸帽子，還戴不戴得穩？！」

錢書手的臉色在瞬間由紅轉白，隨後一片鐵青。

他死死盯著面前這個只有十八歲的少年，心中閃過一絲驚懼。元代地方胥吏最怕的就是精通法度律令、且背後有士紳人脈的年輕讀書人。這等白紙黑字的弊端若是真被捅到了廉訪司那幫剛正的回回或漢人按察使手裡，他就算有十顆腦袋也不夠砍的！

「你……劉相公，你休要拿廉訪司來壓人！」錢書手色厲內荏地啐了一口，咬牙切齒地收回了水火棍，「今日看在令尊劉老夫子的面上，老子暫且放過這老梆子！但這筆銀子記在武陽村的糧冊上，躲得過初一，躲不過十五！走！」

錢書手狠狠一揮手，帶著兩名差役，踩著泥濘的雪水，罵罵咧咧地消失在漆黑的村道盡頭。

風雪呼嘯，小院裡再次恢復了死寂。

劉基走上前，彎下腰，用雙手將癱軟在雪水裡的劉大伯攙扶了起來。

老人的身子輕得像一把乾枯的稻草，渾身冰涼，嘴唇顫抖著，只是死死抓著劉基的衣袖，老淚縱橫：「伯溫啊……多虧了你啊……可這日子，咱們真的過不下去了啊……」

劉基沒有說話。

他脫下自己身上的厚實斗篷，裹在老人乾瘦顫抖的身軀上，將老人攙扶進了那間透風的茅草屋，又從自己懷裡摸出半袋剛剛備好的炒米，放在了冰涼的灶台上。

做完這一切，他轉身走出茅屋，重新回到了自己的小院。

書房內，桐油燈芯已經結出了一朵碩大的焦黑燈花。

那盞微弱的火苗在穿堂寒風中急劇跳躍著，將案頭攤開的經卷與星盤照得一片昏黃。

劉基站在書案前，定定看著那卷《春秋公羊傳》。

他的手掌按在冰涼的硯台上，墨汁已經漸漸凝結。剛才面對胥吏時的冷靜與從容，在這一刻徹底化作了一種無法言說的巨大悲慟與沉重。

他救得了劉大伯一次，救得了第二次嗎？

他用大赦詔書嚇退了一個貪婪的錢書手，但在這青田縣、處州府、乃至整個大元江南的千山萬壑之中，還有千千萬萬個錢書手，正拿著更鋒利的皮鞭與鐵鏈，在無休無止地榨乾每一滴窮苦百姓的膏血！

若這天下的法度已經變成了豺狼食人的刀叉，若這至高無上的皇權已經墮落為軍閥私相授受的玩物，那麼自己閉門苦讀這微言大義的《春秋》，又有何用？！

修身齊家，若不能安天下黎庶，不過是自欺欺人的偽飾；

獨善其身，若眼睜睜看著蒼生溺於苦海，便是士人的奇恥大辱！

劉基猛地伸出右手，一把抓起了那管狼毫毛筆。

他甚至沒有再去洗筆，而是用盡全身氣力，將毛筆重重按進了半凝固的濃黑墨汁之中！筆尖飽蘸黑墨，鋒芒如刀！

少年踏前一步，神情凜然，筆走龍蛇，在那卷神聖肅穆的《春秋》殘卷的扉頁空白處，力透紙背地寫下了十個鐵畫銀鉤的狂草大字：

**「天下之事，莫大於民心！」**

最後一筆落下，墨瀋淋漓，幾乎穿透了三層厚實的竹紙！

寫完這十個字，劉基長長吐出了一口胸中鬱積了不知多久的濁氣。他將毛筆重重擱在青瓷筆架上，轉過身，一把推開了書齋面朝北方的兩扇厚重柴門！

「呼——！」

夾雜著冰雪的狂暴山風呼嘯著灌入書齋，吹得他的長袍獵獵作響，將案頭的書頁吹得嘩嘩翻飛。

劉基邁步走上空曠的木廊，迎著刺骨的朔風，傲然挺立。

在他眼前，南田山的層巒疊嶂皆被厚重的冰雪覆蓋，黑白交錯，宛如一幅蒼茫殘酷的潑墨巨畫。而在那遙遠北方的括蒼山脈上空，鉛灰色的低雲如墨汁般翻滾。

在那厚重雲層的裂隙深處，原本象徵著天下共主、社稷中樞的北極星，此刻正散發著慘淡晦暗的光芒，在寒夜中劇烈搖晃，彷彿隨時都會被北方滾滾而來的濃黑濁氣徹底吞噬。

「大元失其鹿，天下共逐之。」

十八歲的劉基凝視著那顆晦暗的帝星，眼神深邃得彷彿能容納整座浩瀚星空。

少年抬手，整了整被狂風吹散的髮髻，眼神中所有的迷茫、猶豫與稚氣在這一刻徹底褪去，取而代之的，是一種吞吐山河、定奪乾坤的凌厲決心：

「這山，我劉伯溫……不出不行了。」

### 章後工作紀錄

#### 史實依據
1. **劉基早年隱讀與學行**：劉基（字伯溫，1311—1375），浙江青田縣南田武陽村人。天曆二年（1329）時年十八歲，早年博通儒家經史（尤精《春秋》），兼攻天文曆算、象緯術數，隱讀於青田鄉里，至元統元年（1333）二十三歲時方赴大都登進士第。
2. **元代邸報與信息傳遞**：元代邸報（行省與路府抄傳之朝政公文摘要）傳遞效率受地理限制極大。北方兩都之戰爆發數月後，南方偏遠山區（如浙東處州）方能透過縣學或致仕官員輾轉傳閱，信息嚴重滯後。
3. **江南賦稅與弊政**：天曆年間朝廷雖平定內亂，但對江南財賦重地之搜刮變本加厲，地方差役以「解餉」、「定策恩銀」等名目層層加碼，民間「賣牛鬻子以充官賦」為江南普遍實錄。

#### 待核事項
- [x] 青田武陽村之地理特徵（位於今浙江文成縣南田鎮武陽村，四面環山，九里坑為其險要山谷，山高嚴寒無誤）。
- [x] 劉基十八歲時之家庭狀況（其父劉爚曾任教諭，家風嚴謹，劉基在此時期完成象緯與儒學奠基）。
- [x] 元代士人身份對抗差役之合法性（元代儒戶享有免役優待，生員具備一定法律地位，引用大赦詔書抗阻胥吏私徵完全符合歷史制度情境）。

#### 合理推演
- 一代帝師劉伯溫並非生來即為神機妙算之謀士，其早年必然經歷自「獨善其身之山居隱士」向「經世致用之匡世大儒」的心理質變。
- 遲來的兩都邸報與眼前鄰舍老農遭苛斂逼凌的現實衝撞，促使其看透元朝體制不可救藥之宿疾，提筆寫下「天下之事，莫大於民心」，完成其政治哲學的核心覺醒。
