# 第二十一章　私鹽夜渡

至順二年的二月早春，淮東草盪上的大霧濃得像是一鍋剛熬滾的熱米湯。

自鹽城往西通向高郵湖的縱橫水道，全被白茫茫的濃霧吞沒。蘆葦蕩裡的乾枯老葦稈結著一層厚厚的白霜，在刺骨的春寒中挺立著，像是一根根密不透風的長矛。水面上沒有半點波浪，只有冰涼的霧水凝結在船板上，積成一層滑膩的水膜，順著縫隙滴答作響。

「咕嘟……咕嘟……」

兩艘長不過丈五、吃水深得幾乎貼近舷邊的雙櫓小平底木划子，正像兩條貼著泥底游動的黑魚，無聲無息地滑行在狹窄的港汊之中。

划子的船艙深處，用三層浸透了生桐油的厚黃牛皮死死裹著十隻麻袋。

那是整整一千斤用白駒場海灘上最好的熟滷、由張家四兄弟連熬了七天七夜熬出來的頂級「雪花白鹽」。每一粒鹽都晶瑩剔透，乾淨得沒有一絲雜質，若是拿到高郵或者揚州的黑市客棧裡，一斤能換到精細苞穀面三斤，外加兩文現錢。

但在官府的眼裡，這十袋白鹽，是足以讓整條船上所有人腦袋搬家的「通天死罪」。

十歲的張士誠（張九四）光著腳板，緊緊貼伏在頭船的尖窄木船艄上。

他的身上裹著一件又濕又冷的粗麻短褂，褲腿高高捲到大腿根部，露出兩截結實如生鐵、被湖風凍得通紅的小腿。他的右手死死攥著一根只有兩尺長、用生棗木削成的圓頭短木棍。

木棍的頂端鑲著半截打磨鋒利的生鐵刮刀——那是他防身也是殺人的傢伙。

少年的下巴緊緊貼在冰涼的船舷上，一雙濃黑的劍眉在霧氣中凝結著水珠，兩隻耳朵像草原上的孤狼一樣豎起，捕捉著四面八方哪怕一絲一毫的水流異響。

在身後狹窄的後艙裡，八歲的二弟張士德雙手握著一隻用厚棉布包裹了槳葉的短櫓，正以一種極其緩慢、極其柔和的手法，一下、又一下地在水底推動著暗流。

整條划子在水面上行進，竟然聽不見一聲水響，唯有水草被船底分開時發出極其輕微的「沙沙」聲。

「九四……前頭……前頭該過『黑鷓鴣梁』了吧？」

蹲在後艙正中央、滿臉蠟黃的中年漢子張友仁，壓低著嗓子，聲音顫抖得幾乎不成調子。

這位白駒場的老鹽戶因為常年吸入灶膛煙氣，肺部早已咳出了爛洞，此刻嘴裡死死咬著一團髒布巾，把湧上喉嚨的劇烈咳嗽硬生生堵在肚子裡，憋得滿臉青紫，冷汗大滴大滴落在鹽袋上。

在他身側，五十歲的鄒老六也蜷縮在泥水裡，一雙爛瘡未愈的雙腿浸在船底的積水之中，痛得牙關「咯咯」打戰。

他們不能不走這趟死路。

開春以來，大都的朝廷為了修築文宗生母的壽安宮，將兩淮鹽司的「官鹽引價」從去年的每引六十貫，一口氣暴漲到了整整一百二十貫！而鹽商巨賈轉過頭來，卻將收購灶戶官鹽的「工本鈔」壓低了整整四成！

辛辛苦苦熬出一百斤白鹽，交給官府換回來的廢紙鈔票，在米市上甚至買不起五升發霉的雜糠！

若是再不鋌而走險販運這趟私鹽換糧，整個白駒場二十二號灶的十幾口人，不出這個二月，全都要變成草盪裡的餓殍凍屍！

「爹，莫慌。」

張士誠沒有回頭，聲音極其低沉，透著一種與十歲年齡絕不相符的沉穩與冷靜：「過了黑鷓鴣梁，就是高郵湖的盲水泊。到了那兒，徐州過來的私糧駁船就有人接應了。」

然而，這句話剛剛落地，張士誠的瞳孔驟然一縮！

「嘶——」

一陣極其微弱、自西北風向飄過來的鐵器碰撞聲，猛地穿透了厚重的白霧！

緊接著，在前方百步之外原本漆黑一片的河汊中心，忽然亮起了一點、兩點、三點暗紅色的幽光！

那不是漁火！

那是沾了松脂與生桐油的大號防雨火把！

伴隨著火把的亮起，兩艘高達兩丈、船頭架設著巨型生鐵拍竿與狼牙拍的水路巡私哨船，如同一雙張開翅膀的黑色水怪，自濃霧中緩緩滑了出來，橫刀立馬般死死堵住了整個黑鷓鴣梁唯一的深水航道！

「汪！汪汪汪——！」

哨船船頭上，兩條戴著鐵嘴套的巡私大狼狗猛地站立起來，隔著重重濃霧，朝著張士誠這條小划子的方向，瘋狂地狂吠起來！

「搜！給老子睜大眼睛搜！」

哨船上傳來一聲凶暴陰狠的咆哮，正是鹽城巡私緝捕司的副千戶「鐵鷂子」劉成！

「大都下了死命令，至順二年嚴打私梟！凡查獲私鹽一擔，賞銀十兩！若是抓到私販鹽丁，就地格殺！」

劉成手中的雁翎刀在火把映照下泛起森森青光，厲聲喝令道：「兩船散開，放排鉤！把這片水草蕩給老子梳一遍！」

「匡當！匡當！」

四名膀大腰圓的巡私甲士合力抬起兩排掛滿了數百枚倒刺利鉤的沉重生鐵「滾江排」，帶著刺耳的鐵鏈拉扯聲，狠狠砸進了河道正中央的深水之中！

鐵鉤順著水流在河底瘋狂拖拽，任何試圖自水底潛渡的船隻與水鬼，一旦觸碰到這等密密麻麻的生鐵排鉤，瞬間就會被生生掛爛肚腸、勾碎琵琶骨！

「完了……是劉鐵鷂子……」

後艙裡的張友仁嚇得魂飛魄散，手裡的半截木槳啪嗒一聲掉進了船艙，面如死灰。

一旦被查獲，私鹽充公，全家斬首，連八歲的士德和六歲的士信都要被充沒入官奴，發配去北方的苦寒之地為奴隸！

鄒老六更是嚇得渾身篩糠，嘴唇哆嗦著，眼中滿是絕望的淚水：「九四……跳水吧……咱們跳進蘆葦蕩逃命吧……這鹽……不要了啊！」

「不能跳！」

張士誠猛地扭過頭，眼中爆發出一抹凌厲至極的寒芒，壓低著聲音厲聲喝道：「這千斤白鹽是全家人的命！丟了鹽，一家老小回去也是餓死！二弟，穩住船身！誰也不准動！」

十歲的少年伏在船頭，心跳快得如同擂鼓，但他的神經卻緊繃得像一張拉滿的硬弓。

他看著前方越來越近的火把光芒，腦海中飛速閃過這片水網的每一道暗溝。

黑鷓鴣梁的水道雖然被封死，但在這片水域生長了十年的張士誠，比任何一個官府巡檢都清楚這片沼澤的秘密。在官船右側三十步外，看似是一片長滿了密密麻麻枯蘆葦與厚實浮萍的「死泥灘」，但就在那片浮萍的最深處，赫然隱藏著一條只有三尺寬、被當地老漁民稱為「鬼見愁」的乾枯盲溝！

那條溝底全是爛泥，水深不足一尺，大船進去必被淤泥卡死，但若是吃水極淺的小划子……

「爹，老六叔，下水！」

張士誠果斷下令，聲音如寒冰撞擊：「不要劃槳！把身體沉在水裡，只露鼻子！手扣住船底龍骨，用腳掌蹬著泥底往前推！」

說罷，張士誠連半分猶豫都沒有，身子如同一條靈活的泥鰍，悄無聲息地滑進了冰冷刺骨的河水之中！

「嘶——！」

二月的初春江水寒徹入骨，像千萬根細鋼針瘋狂扎進少年的每一寸皮肉。

張士誠咬破了下唇，硬生生用劇痛壓下胸口的抽搐。他的一雙手掌深深摳進划子底部的杉木護板，雙腳踏進了深達半尺的滑膩黑泥之中，用盡全身的力氣，推動著載重千斤的木划子，朝著那片看似絕路的枯蘆葦蕩深處一寸寸挪去！

張友仁與鄒老六見狀，骨子裡的求生野性也被徹底逼了出來，紛紛滑入水中，三人用肩膀頂著船幫，踩著冰冷的爛泥，拼命向前推進。

「嘩……沙……」

小划子的船頭撞開了枯黃的蘆葦稈，水草與浮萍密密麻麻覆蓋了上來，將整條小船在頃刻間吞沒在濃黑的草影之中。

就在划子剛剛完全滑入盲溝的一瞬間！

「呼啦——！」

一柄長達丈二的生鐵「探水三股叉」，帶著刺耳的破空呼嘯聲，猛地自巡私哨船的船舷處凌空刺了下來！

鋒利的鐵叉尖端，擦著張士誠頭頂不到三寸處的蘆葦叢，狠狠插進了小划子右舷上方的油布篷頂上！

「噗嗤！」

一聲厚布撕裂的悶響！

鐵叉尖端生生刺穿了兩層油布，深深扎進了下方的一隻麻袋之中！

雪白如霜的鹽粒，順著破口如細沙般簌簌漏了下來，灑落在一隻橫陳在草叢裡的死水鳥羽毛上。

水底深處，張士誠整個人緊緊貼在冰冷黏稠的黑泥之中，口鼻隱藏在兩片巨大的死浮萍下方。

他的右手死死按在腰間的那根棗木短棍上，掌心的青筋暴起如絞索。只要上方的官兵稍微用力向下按壓、或者拔出鐵叉察覺到白色鹽粒，他便會立刻破水而出，用手中的生鐵刮刀狠狠挑斷那名甲士的喉嚨！

整片草盪在這一刻死寂得令人窒息。

火把的暗紅色光芒透過密集的蘆葦縫隙，在張士誠頭頂的水面上投下一道道晃動的鬼影。

「劉大人！這片浮萍溝太淺，只有死泥，鐵叉扎進去全是爛草根，沒見著船底板！」一名甲士在哨船上高聲回稟。

「呸！這幫私梟比泥鰍還滑溜，八成是聽見狗叫，順著東邊的大河溜了！」

劉鐵鷂子吐了一口唾沫，罵罵咧咧地揮動馬鞭：「調轉船頭！升全帆！朝著東汊口給老子追！今夜要是抓不到這批私鹽，你們這幫廢物的月餉全給老子扣光！」

「得令——！」

沉重的號角聲再次吹響。

兩艘巨大的巡私哨船緩緩調轉船頭，生鐵排鉤在水底拉扯出嘩啦啦的悶響，帶著兩條狂吠的惡犬，漸漸遠離了黑鷓鴣梁，消失在濃濃的大霧深處。

風，漸漸平息了下來。

「嘩啦！」

張士誠猛地自水底破水而出，大口大口地喘著粗氣，胸膛劇烈起伏，渾身被冰冷的泥水浸得發黑。

張友仁和鄒老六也吃力地自泥沼中爬上船舷，癱坐在滿是泥漿的船板上，兩個人渾身發抖，牙齒打戰，臉色慘白得如同剛從棺材裡爬出來的活鬼。

但當他們看見船艙裡那十袋雖然破損了一角、但絕大部分依然完好無損的雪花白鹽時，這兩個年過半百的漢子，眼眶裡終於忍不住滾下了兩行混濁滾燙的熱淚。

活下來了。

他們保住了這十袋鹽，也保住了全家老小的這條殘命。

張士誠抹了一把臉上的泥水，從懷裡摸出一塊乾布條，手腳麻利地將剛才被鐵叉刺穿的麻袋口子死死紮緊，連一粒漏在船板上的白鹽都捨不得丟棄，用手指沾著舔進嘴裡。

半個時辰後。

小划子穿過了漫長的黑鷓鴣盲溝，終於滑進了水天一色、煙波浩渺的高郵湖深水灣。

在一處廢棄的古渡口蘆葦蕩後，一艘掛著半盞死羊角燈的徐州大糧船早已在此等候多時。

交割進行得極快。

那徐州糧商是個常年在黑市行走的老油條，看見張家兄弟運來的鹽色晶瑩雪白、顆粒如霜，眼中滿是驚嘆。當場過秤，一千斤私鹽，折抵了整整三石精細苞穀雜面、五大袋黑豆，外加一吊足色的一百文大元新銅錢與一小壇驅寒的老燒酒！

糧食與酒壇被搬上了小划子，原本空蕩蕩的船艙，頓時被沉甸甸的生機填滿。

渡口背風的泥灘上，張友仁抱著那壇老燒酒，仰起脖子狠狠灌了一大口，辛辣的酒液順著喉嚨落進肚子裡，嗆得他眼淚直流，卻終於讓這具快要凍僵的軀體泛起了一絲活人的血色。

張士誠站在泥灘邊，拍了拍手上的麵粉渣。

他轉過身，沒有絲毫猶豫，一把抱起那袋足足有五十斤重的上等苞穀面，不由分說，狠狠塞進了鄒老六那艘空蕩蕩的划子後艙裡！

鄒老六嚇了一大跳，連忙擺手推拒：「九四！使不得！使不得啊！這趟私鹽是你帶著士德冒死運出來的，老漢我……我連槳都沒搖幾下，怎能要你家這麼多救命糧？！」

「老六叔，拿著！」

十歲的張士誠雙手按在鄒老六乾癟顫抖的肩膀上，那一雙深邃黝黑的大眼睛在晨霧中亮得驚人：

「你孤身一人，身上全是爛瘡，若是沒這袋面，這個春天你熬不過去！我張九四說過，白駒場的兄弟同甘共苦！只要我張家有口乾的吃，就絕不會看著自家的叔伯兄弟咽氣等死！」

鄒老六看著面前這個只有十歲的少年，看著他那張被晨光映照得如同青銅澆鑄的面龐，嘴唇瘋狂顫抖著，眼淚大顆大顆砸在粗糙的麵袋上，隨即撲通一聲跪在泥地裡，對著少年重重磕了個頭。

「九四……你……你將來必不是凡人啊……」老鹽丁泣不成聲。

東方的天際線盡頭，大霧漸漸被一抹慘淡的魚肚白撕開了一道裂口。

初春的晨風吹過高郵湖的三萬頃波濤，帶來了一股微弱的泥土復甦氣息。

十歲的張士誠立在船艄最前端，雙手插在油膩的短褐衣兜裡，任由冰涼的湖風吹拂著他額前凌亂的黑髮。

少年轉過頭，望向了遠方官府巡私哨船離去的方向。

那裡依舊烏雲低垂，重重的水路關卡森嚴如鐵。

但在這片被大元朝廷視為死地的貧瘠草盪深處，這個十歲的鹽丁少年，卻用他的膽魄、智謀與手中這根生硬的棗木短棍，在至高無上的皇權法網之上，硬生生撕開了一道染滿鮮血與求生渴望的豁口。

江湖很大，朝廷很遠。

而草莽英雄的崛起，從來不需要名門望族的冠冕，唯有這刺骨的冰水、腰間的尖刀，以及兄弟之間生死相托的一把白鹽與一袋粗糧！

小划子破開碧波，載著滿船的生機與少年冷峻的目光，朝著白駒場深處疾馳而去。

#### 史實依據
1. **元代私鹽盛行與官逼民反**：元代實行極其嚴苛的食鹽國家專賣制度，兩淮鹽場（泰州、鹽城、高郵一帶）為全國鹽課重心。至順年間，因宮廷開支激增，官府鹽引價格飛漲而對灶戶收購價一再壓低，灶戶「終歲辛勞，不得一飽」。官逼之下，兩淮鹽丁普遍鋌而走險販運私鹽，形成龐大的武裝走私水網，私鹽成為沿海破產鹽民唯一的生存路徑。
2. **張士誠之早年私鹽生涯**：張士誠（張九四）少時即與其弟張士德、張士信及同里壯士操舟運鹽，「任俠好施，得鄉里心」。其日後發動十八條扁擔起義的核心班底，正是這批常年跟隨其在水網中涉險走私、生死相依的底層鹽丁兄弟，《明史·張士誠傳》詳載其早年私鹽販運背景。
3. **官府查私防禦手段**：元代在長江、淮河水網設有密集的「海防巡檢司」與「巡私緝捕所」，利用生鐵排鉤、阻江巨網、鐵錨搜查水底，對私販動輒處以絞刑或籍沒為奴，刑罰極其酷烈。

- [x] 盲溝「伏水推舟」之民間水上逃生技巧（江南與淮東水上船戶常於極淺盲溝下水以背扛舟避開排鉤盤查，細節真實生動）。

#### 合理推演
- 一代草莽梟雄張士誠之所以能在成年後一呼百應，其根本威信絕非一日之功，而是自幼在多次生死攸關的私鹽夜渡中，展現出超越常人的「冷靜避險、護庇全船、義氣散糧」之領袖特質。
- 將換來的粗糧毫不猶豫分給鄰舍孤寡老鹽丁鄒老六，生動刻畫其「仗義疏財、收攬人心」的早期性格烙印。

#### 小說虛構
- 虛構「黑鷓鴣梁」遭遇鐵鷂子劉成排鉤巡查、十歲張士誠下水沉伏推舟避險的情節，強化情節張力。
- 虛構生棗木短棍與鐵刮刀之防身信物，與其日後「十八條扁擔」起義形成器物精神上的前後呼應。
