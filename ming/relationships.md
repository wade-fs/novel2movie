# 人物關係網與政治互動管理（relationships.md）

## 一、文件目的

本文件建立《明末清初歷史小說》全書共用的人物關係模型。

本書不以忠奸善惡或固定敵我陣營解釋歷史，而是透過人物之間的親屬、職務、利益、政治立場、商業交易、地域聯繫與資訊傳遞，呈現政權興亡如何發生。

人物關係必須具備三個特徵：

1. **具有時間性**：同一批人物在不同年代可能合作、衝突、疏遠或重新結盟。
2. **具有多重性**：政治對手可能同時存在商業往來；名義上的盟友也可能彼此競爭。
3. **具有證據層次**：正式官職、親屬關係、政治合作與私人情感不能混為一談。

本文件不試圖收錄所有歷史人物，而是管理對主要情節、歷史解釋及人物行動有實質影響的關係。

---

## 二、人物關係的基本分類

### 2.1 親屬與家庭關係

包括：

- 父子、兄弟、姻親與婚姻。
- 家族繼承與宗族關係。
- 養育、收養及其他家庭關係。
- 家族內部的權力競爭。

**校核原則：** 血緣、婚姻、收養與政治上的親近必須分開記錄。政治對手提出的血統指控，不能直接作為客觀的親屬事實。

例如，鄭克𡒉的身世爭議應記錄為繼承政治中的指控與爭議，不可未經證實便將其寫成確定的血緣結論。

### 2.2 官僚與上下級關係

包括：

- 君主與臣僚。
- 上級與下級官員。
- 軍事指揮與行政管轄。
- 同僚之間的合作與競爭。
- 任免、舉薦、彈劾及問責。

應區分正式職權與實際影響力。

一名官員可能名義上位居高職，卻受到其他權力中心制約；另一名官員也可能沒有最高官銜，卻因掌握資訊、人事或資源而具有重大影響。

### 2.3 政治派系與利益聯盟

包括：

- 宮廷內部的政治集團。
- 朝臣之間的政策分歧。
- 地方官員與中央權力的互動。
- 軍事勢力與文官體系的合作。
- 因共同敵人或短期利益形成的聯盟。

派系不應被寫成永遠一致的組織。成員可能因利益、政策、地位與外部環境改變立場。

### 2.4 軍事與政治歸附關係

包括：

- 投降、歸附與接受任用。
- 暫時合作與正式結盟。
- 保留原有部屬或勢力的政治安排。
- 對舊主的忠誠、對新政權的依附與現實生存考量。
- 盟約破裂與勢力重組。

不得僅憑一次降附，就斷言人物此後的所有行動都由單一動機支配。

### 2.5 商業與海上網絡

包括：

- 海商、船主、商行與地方市場。
- 港口、航路與貨物流通。
- 軍事勢力與商業資本的互相依賴。
- 海上貿易與沿海行政的關係。
- 交易、債務、保護、徵稅與禁運。

在鄭氏政權及台灣相關篇章中，商業網絡不能只作為軍事力量的補給背景。它本身就是人物取得資源、建立影響力與維持生活的重要社會結構。

### 2.6 地方社會關係

包括：

- 宗族、鄉里與地方領袖。
- 地主、佃農、商人與勞動者。
- 官府與地方中介者。
- 移民群體之間的合作與衝突。
- 原住民族社群與外來政權、商人及移民的互動。

這些關係不能全部歸入中央政治的附屬網絡。地方社會可能有自身的利益、規範與決策方式。

### 2.7 資訊與消息傳遞關係

包括：

- 正式公文與官府命令。
- 私人書信與商業通信。
- 口頭傳聞與地方消息。
- 使者、商旅、船員及地方中介者。
- 消息延遲、誤傳、隱瞞與選擇性傳播。

人物是否知道某件事，必須有合理的消息來源。關係網不只是人物之間的聯繫圖，也應呈現資訊如何流動。

## 三、關係紀錄的標準格式

每一項重要關係建立獨立紀錄。

| 欄位 | 內容 |
|---|---|
| 關係編號 | 唯一識別碼，例如 `R-001` |
| 人物甲 | 第一方人物編號與姓名 |
| 人物乙 | 第二方人物編號與姓名 |
| 關係類型 | 親屬、上下級、盟友、交易、對立等 |
| 開始時間 | 可確認的起始時間或時間範圍 |
| 結束時間 | 關係終止或轉變的時間 |
| 關係狀態 | 持續、變化中、已終止、存在爭議 |
| 形成原因 | 可確認的制度、利益、家庭或政治背景 |
| 重要事件 | 改變關係的關鍵事件 |
| 史料依據 | 相關文獻、檔案或研究紀錄 |
| 證據標籤 | 多源互證、單一來源、異說並存、合理推演、後世傳聞、待考 |
| 小說用途 | 影響哪些人物選擇或章節 |
| 備註 | 不確定性、限制及後續研究事項 |

### 關係狀態的使用方式

- **持續**：關係仍存在，且沒有明確證據顯示其終止。
- **變化中**：關係正在發生重要轉變。
- **已終止**：關係因死亡、免職、決裂或其他事件而終止。
- **存在爭議**：史料對關係性質或形成時間存在衝突。

關係狀態必須附有時間範圍。不能因某人在某年投降，就將其一生的政治關係都標為「降清」。

## 四、主要政權的關係網

### 4.1 明廷與地方軍政體系

明廷內部的關係應從制度、財政、軍事責任與資訊不對稱理解。

主要研究方向：

- 皇帝與中央官僚之間的決策關係。
- 中央財政與地方軍事需求的衝突。
- 官員之間的責任歸屬、舉薦、彈劾及政策分歧。
- 地方行政機構與軍事指揮體系的協調。
- 中央命令在地方執行時所面臨的資源與資訊限制。

小說不應把明末的困局全部歸結為某一位奸臣或某一次錯誤決策，而應呈現制度、財政、戰事、地方秩序與個人選擇如何彼此影響。

### 4.2 南明政權的內部關係

南明不是一個政治立場完全一致的整體。

研究應分別處理：

- 皇位與政權正統性的競爭。
- 宮廷、朝臣與軍事勢力的關係。
- 不同地方勢力對中央政權的支持程度。
- 地方軍隊的實際控制範圍與財政來源。
- 軍事合作與政治互信之間的落差。
- 政權覆亡後，原有官僚與地方網絡如何變化。

例如，弘光政權、隆武政權、魯王監國與永曆政權不能被簡化成同一個穩定的政治組織。不同政權的繼承主張、活動地區、官僚組成與軍事資源，都應分開建檔。

人物在不同南明政權間的移動，也應以具體時間和行動記錄，不宜僅用「南明官員」一個標籤涵蓋所有階段。

### 4.3 清初中央權力與官僚體系

清初政治關係應區分：

- 皇帝與攝政、輔政體系。
- 宮廷權力與正式官僚制度。
- 滿洲、蒙古、漢軍旗籍及漢官的制度位置。
- 軍政任用與行政治理的關係。
- 中央政策與地方執行之間的差異。
- 官員的正式權力與非正式影響力。

索尼、蘇克薩哈、遏必隆與鰲拜等人物，不應只依「忠於皇帝」或「威脅皇權」的單一標籤處理。需要追蹤各人在輔政體系中的位置、利益與政治行動。

康熙親政及鰲拜被捕，應作為權力結構變化的過程來寫，而不只是少年皇帝戰勝權臣的簡單故事。

## 五、鄭氏政權與海上網絡

### 5.1 鄭芝龍、鄭成功與鄭經

三人的關係不能只用父子傳承描述，還應考慮海商網絡、軍事資源、政治歸附與政權建立之間的變化。

研究問題包括：

- 海商資源如何轉化為政治及軍事力量？
- 海上交易與政權財政如何互相依賴？
- 鄭芝龍與明廷、清廷的關係如何隨時間變化？
- 鄭成功如何建立自身的政治正當性與組織基礎？
- 鄭經如何處理東寧政權的內部治理與外部談判？
- 鄭氏內部的繼承與派系關係如何影響政權穩定？

人物的政治選擇必須放回其當時掌握的資源、資訊與可行方案中評估。

### 5.2 鄭氏政權內部關係

應獨立管理：

- 鄭氏宗族與繼承關係。
- 軍政官員的職務及權力。
- 文官與軍事勢力的合作。
- 陳永華等人物與制度建設的關係。
- 鄭經時期的內部政治競爭。
- 鄭克𡒉與鄭克塽相關的繼承危機。
- 1681 年政權內部變動的時間順序與不同史料說法。

不得將政治上的血統指控直接當作已確認的親屬事實，也不得只依後世戲劇化敘述判斷人物的私人動機。

### 5.3 鄭氏政權與清廷的關係

應將雙方關係拆成多個層面：

1. 政治正統性與歸附條件。
2. 海上貿易與財政資源。
3. 沿海軍事與行政控制。
4. 遷界、海禁及其社會後果。
5. 三藩之亂期間的軍事與政治合作。
6. 鄭經與清廷之間的談判及衝突。
7. 施琅與清廷海疆政策的關係。
8. 1683 年軍事結果與 1684 年行政建制的區別。

不得把鄭經的政治目標簡化成「只想割據」或「必然要逐鹿中原」。應根據談判條件、實際行動、財政限制與當時的政治局勢，分析各種可能的考量。

## 六、台灣的地方關係網

第九卷《海國風雲》應建立獨立的台灣人物與社會關係資料，避免所有關係都從中原政權出發。

### 6.1 關係網的主要節點

- 台灣原住民族社群及其內部組織。
- 荷蘭與西班牙在台據點及相關人員。
- 鄭氏政權的行政、軍事與商業網絡。
- 福建海商、船主、移民與地方中介者。
- 農業開墾、土地使用與地方社會關係。
- 清治初期的地方官府與基層治理。
- 1721 年朱一貴事件相關人物及地方網絡。

這些節點不是單一陣營。每個群體內部都可能存在不同的利益、語言、身分、政治選擇與生活需求。

### 6.2 原住民族社群的書寫規則

- 不將不同原住民族社群合併為單一、沒有內部差異的群體。
- 不假設所有社群對荷蘭、西班牙、鄭氏或清廷具有一致立場。
- 區分直接衝突、交易、翻譯、協商與日常接觸。
- 優先查明特定年代、特定地區的社群名稱與相關記錄。
- 若歷史資料主要來自外來政權，須考慮記錄者的觀察角度與語言限制。
- 不把缺乏文字記錄直接解讀為缺乏政治組織或社會秩序。

### 6.3 移民與地方社會

應記錄移民如何透過親屬、同鄉、商業、土地開墾與工作關係建立生活網絡。

地方社會中的矛盾，不應全部解釋為族群衝突；土地、債務、行政徵收、資源使用與權力分配，也可能是重要因素。

同樣地，不能預設所有移民與地方社群都處於持續敵對狀態。具體關係應依地區、年代與史料判斷。

## 七、關係變化與歷史轉折

人物關係的變化通常由事件觸發，但不能把單一事件當成所有變化的唯一原因。

每次重要轉變都應記錄：

- 轉變前的關係。
- 當時雙方的政治及生活處境。
- 觸發事件。
- 可確認的行動。
- 雙方可能獲得或失去的利益。
- 轉變後的實際關係。
- 史料是否能支持對動機的判斷。

例如，一名官員從明廷轉而效力清廷，可以記錄其任職、受命與政治身分的變化；但對其內心是否出於恐懼、利益、保護家族、政治信念或其他原因，應另外尋找證據，不可由結果直接倒推動機。

## 八、關係圖與關係矩陣

### 8.1 關係圖的建議格式

```text
人物甲
 ├── 正式職務關係 ── 人物乙
 ├── 商業交易關係 ── 人物丙
 ├── 親屬關係 ────── 人物丁
 └── 政治競爭關係 ── 人物戊
```

每條關係都應附上時間範圍與來源標籤。

圖中連線只能表示已記錄的關係，不能以連線粗細或顏色代替證據評估。

### 8.2 關係矩陣

| 人物甲 | 人物乙 | 關係 | 時間 | 證據狀態 | 敘事用途 |
|---|---|---|---|---|---|
| 人物 A | 人物 B | 上下級 | 年代範圍 | 待填 | 顯示行政權責 |
| 人物 A | 人物 C | 商業交易 | 年代範圍 | 待填 | 解釋資源流動 |
| 人物 B | 人物 D | 政治競爭 | 年代範圍 | 待填 | 解釋決策衝突 |
| 人物 C | 人物 E | 親屬 | 年代範圍 | 待填 | 建立家庭與社會網絡 |

此表為空白模板，實際填寫時應使用人物名冊的固定編號。

## 九、人物關係的史料驗收

每項重要關係至少檢查：

- [ ] 關係類型是否定義清楚。
- [ ] 關係存在的時間是否合理。
- [ ] 是否把正式職務誤寫成私人交情。
- [ ] 是否把政治合作誤寫成完全信任。
- [ ] 是否把政治指控當作已確認事實。
- [ ] 是否區分人物實際行動與後世對其動機的解釋。
- [ ] 是否檢查來源之間的依賴關係。
- [ ] 是否保留必要的異說。
- [ ] 是否與人物年表及事件年表一致。
- [ ] 是否有助於解釋小說中的選擇、衝突或生活變化。

## 十、關係網如何服務小說

關係網不是單純的背景資料，而是安排章節交互性的工具。

每一個重要事件，都可以從以下角度觀察：

1. 誰有正式決策權？
2. 誰掌握必要的資訊？
3. 誰提供資源或承擔成本？
4. 誰執行命令？
5. 誰因命令而受益？
6. 誰承擔意料之外的後果？
7. 誰無法直接參與決策，卻必須承受結果？

這種設計能讓歷史事件不只呈現少數政治人物的決定，也呈現官僚、商人、家庭與地方社會之間的連鎖反應。

### 避免兩種極端

**極端一：所有事件都由少數人物的陰謀造成。**

這會把複雜的歷史變化過度簡化成密室政治。

**極端二：所有事件都只是抽象制度的必然結果。**

這會抹去人物的選擇、利益衝突與偶然性。

本書應同時呈現制度限制、資源競爭、人物決策與意料之外的結果。

## 十一、維護與更新規則

1. 新增重要人物時，先在 `character_registry.md` 登錄。
2. 新增重要關係時，建立獨立關係編號。
3. 關係變化時，新增時間段或修訂紀錄，不直接抹去舊關係。
4. 發現史料衝突時，保留不同說法及來源。
5. 人物死亡、政權覆亡或政治身分改變時，同步檢查關係網。
6. 第九卷中的台灣人物關係應有獨立脈絡，不必全部連接到中原核心人物。
7. 同一歷史事件若跨卷重複出現，所有卷次共用同一份關係紀錄。
8. 虛構人物可以建立關係，但必須清楚標記小說設定，不得與歷史證據混淆。

---

## 十二、最終原則

人物關係不是固定不變的善惡分類，而是歷史條件下持續變動的網絡。

親屬不一定同心，盟友不一定互信，對手也可能有共同利益；政治上的選擇不能直接取代對人物動機的研究。

對於明末清初的小說而言，最值得追蹤的往往不是誰與誰永遠站在一起，而是人在局勢改變時，為何選擇合作、妥協、抵抗、離開或重新結盟。

透過關係網，才能把政權更替、海疆變動、地方治理與普通人的生活放在同一個歷史世界裡。
