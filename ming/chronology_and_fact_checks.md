# 明末清初歷史小說｜年代總表與史實校核

**文件名稱：** `chronology_and_fact_checks.md`  
**版本：** v1.0  
**時間範圍：** 1624–1722 年  
**用途：** 統一九卷年代、校核人物行蹤、避免政權與行政建制的時間錯置。

---

## 一、年代校核規則

### 1. 每個事件至少記錄五個時間資訊

1. **事件時間：** 事情實際發生的時間。
2. **記錄時間：** 文書、日誌或記載形成的時間。
3. **消息傳遞時間：** 其他地區何時可能知道此事。
4. **政治生效時間：** 命令、任命或制度何時開始實施。
5. **後世編纂時間：** 現存史書何時整理、編寫或刊印。

這些時間可能相差數日、數月，甚至多年。

### 2. 日期精度分級

| 等級 | 定義 | 使用方式 |
|---|---|---|
| A | 有可靠材料支持到日 | 可使用具體日期 |
| B | 年份確定，月份或日期有異說 | 寫年份，細節保留 |
| C | 事件先後大致確定，確切年份仍需核對 | 暫列時間區間 |
| D | 主要依靠後世傳聞或存在重大矛盾 | 不作確定性敘述 |

此分級只表示專案目前的校核狀態。每項事件仍須記錄實際依據，不可只標等級而不附來源。

## 四、必須特別追查的年代與概念

### 1. 洪承疇：被俘與降清

不能把「松錦戰局中被俘」與「正式接受清廷任用」當成同一天的事件。

**待辦：**
- 查明被俘日期與相關戰局記錄。
- 查明被俘後清方接觸與勸降的資料。
- 查明首次接受清廷安排及任官的時間。
- 比較清方記錄、明方記錄與後來人物傳記。

### 2. 鄭成功：病逝與後世敘事

1662 年去世可作為基本史實，但具體死因與臨終細節不能只依戲劇化記載判定。

**待辦：**
- 比較鄭氏方面的記錄。
- 查閱荷蘭方面相關記錄。
- 區分當時記載、後來傳記及《臺灣外記》的敘事。
- 不以現代醫學推測取代史料證據。

### 3. 鄭克𡒉：繼承危機

**待辦：**
- 建立鄭經去世前後的人物行蹤表。
- 核對鄭克𡒉遭殺害的時間與經過。
- 追查「非鄭經親生」指控最早可確認的文本。
- 分析血統指控與政治權力競爭的關係。

### 4. 鄭經、耿氏與施琅

**待辦：**
- 建立 1673–1683 年逐年事件表。
- 分別記錄鄭經與耿氏的聯盟、衝突及相關軍事行動。
- 查核施琅的任命、奏議及清廷海疆政策變化。
- 區分各方的公開主張、實際行動與後世對動機的解釋。

### 5. 朱一貴與杜君英

**待辦：**
- 對照《平臺紀略》《臺案彙錄己集》及地方志。
- 查核朱一貴渡台年份及早年經歷。
- 分開記錄朱一貴與杜君英的投首、被捕、審訊及處決時間。
- 確認供詞的形成時間、記錄機關及文本傳承。
- 不將朱一貴的血統傳聞與養鴨傳說直接當作史實。

## 六、行政建制與地理校核

### 1. 不同層次的「接收」

下列概念不可混用：

- 軍事上攻取或迫使對方撤出。
- 政治上接受降附或建立新的統治安排。
- 中央朝廷正式決定行政建制。
- 行政機關實際設立並開始運作。
- 地方政策逐步推行並產生效果。

例如，1683 年清軍攻取台灣與 1684 年設置台灣府，應作為不同事件記錄。

### 2. 地名校核

每個地點應盡可能記錄：

- 當時名稱。
- 所屬政權與行政區劃。
- 現代地理位置對照。
- 名稱變化的時間。
- 該地在事件中是實際控制區、軍事據點、行政中心，還是僅為活動範圍。

不可直接將現代縣市界線套用到十七、十八世紀。

### 3. 台灣地理與族群

台灣的歷史地理不應只依漢人行政區劃理解。不同原住民族群的活動範圍、聚落與交換網絡，未必與後來的縣廳界線相符。

涉及特定聚落、族群或土地使用時，應另查專門研究與當時材料。

## 七、事件與消息傳遞的校核

小說人物不應無故知道尚未傳到當地的消息。

每項重大事件可建立以下欄位：

| 欄位 | 說明 |
|---|---|
| 事件發生地與日期 | 事件本身 |
| 第一份已知記錄 | 文書或日誌的形成時間 |
| 消息傳出方式 | 驛遞、官文、商旅、船舶、口耳傳聞等 |
| 可能抵達時間 | 依交通條件與材料推估 |
| 人物得知時間 | 有史料支持，或屬小說推演 |
| 消息可信度 | 官方通報、私人書信、傳聞或未證實消息 |

若沒有可靠材料可以確定某人物何時得知事件，應將其作為【合理推演】，不要偽裝成史實。
