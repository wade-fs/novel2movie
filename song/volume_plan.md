# 《宋末》八卷分卷規劃（volume_plan.md）

> 每卷固定 90 章。以下每卷分成十個九章單元，先確立敘事功能與事件區間；這不是最終 720 章逐章綱。逐章化時，必須回查 `chronology.md`、`characters.md`、`geography.md`，並把史實標籤落到每章。

## 第一卷：汴京繁華與裂縫（約1100–1125）

| 章節 | 單元 | 主要任務 |
|---|---|---|
| 1–9 | 城市初見 | 以汴京市場、河運、宮廷需求與普通家庭建立時代質感 |
| 10–18 | 宮廷與官署 | 介紹徽宗朝政治網絡、文書流程與權力分配 |
| 19–27 | 北方邊情 | 以邊報、商旅、軍需與外交消息呈現遼金格局變化 |
| 28–36 | 地方徵調 | 展示財政、營建、物資徵集與地方社會承受的成本 |
| 37–45 | 士人與名聲 | 士人、書籍、科舉、官場升降及對朝廷的不同理解 |
| 46–54 | 金國崛起 | 交代女真政權與宋、遼之間的戰略關係 |
| 55–63 | 海上之盟 | 展示外交預期、情報落差與軍事合作的實際限制 |
| 64–72 | 燕京問題 | 寫軍事行動、補給、指揮與預期落差 |
| 73–81 | 危機擴大 | 北方戰局與朝廷內部的不同解讀互相碰撞 |
| 82–90 | 金軍南下前夜 | 以邊境、汴京與地方三條線交錯，收束於危機不可再被視為遠方消息 |

## 每卷九十章的進一步拆分規則

以上十個單元各九章，後續每個九章單元再細分為：
- 1–2章：建立場景、人物目標與當前限制。
- 3–5章：衝突升級，至少有一個具體事件或新資訊。
- 6–7章：選擇、代價與人物關係改變。
- 8章：結果開始顯現。
- 9章：章末轉折，將人物或事件推入下一單元。

此規則只是節奏參考，不得為了符合形式而扭曲史實時間。
