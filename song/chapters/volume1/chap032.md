# 第三十二章　杭州南關的「羨餘」抽解

政和六年二月十七日，丙子。

錢塘江的春潮初退，露出兩岸濕漉漉的泥灘，混著鹹腥與腐草的氣息。旭日微露，金色的光芒斜斜地灑在杭州南關碼頭上，卻驅不散空氣中那股揮之不去的陰寒。林元度站在江漲橋畔，裹緊了身上的湖絲棉袍，感覺到一股從骨子裡透出的寒意，比這早春的江風還要凜冽。

他已在碼頭邊枯坐了近一個時辰，望著那兩艘自三佛齊歸來的海舶，船帆收攏，桅杆筆直地指向灰濛濛的天空。那是「豐裕號」和「順風號」，載著他與泉州林氏全族的希望，在南洋的驚濤駭浪中搏命三年，如今終於抵達大宋的繁華之都。然而，這份希望，此刻卻如風中殘燭，搖搖欲墜。

碼頭上已是人聲鼎沸。胡商、蕃客、牙行、腳夫、挑擔的小販，摩肩接踵。他們的服飾五彩斑斕，口音南腔北調，卻都匯聚成一條喧鬧的河流，在江漲橋下蜿蜒流淌。空氣中瀰漫著濃郁的香料氣味——乳香、丁香、檀香、沉香，混雜著魚腥與海鹽的鹹濕，還有碼頭邊酒肆裡飄出的米酒糟味。林元度嗅著這熟悉的味道，心頭卻是一片苦澀。這些香料，本該是他的財富，如今卻更像是催命的符咒。

他今年四十六歲，臉上飽經風霜，眼角堆疊著深深的魚尾紋。他不是第一次跑南洋，也不是第一次來杭州市舶司辦理抽解。但這一次，與以往任何一次都不同。三年前，為了籌集遠航的巨額資本，林元度以林氏全族在泉州的田產、鋪面為抵押，向宗族內的幾個大戶借了十萬貫高利海債，言明三年為期，本利併還。若此次不能獲利豐厚，林氏一族將會傾家蕩產，祖業盡失。

三年的海上漂泊，幾度與風暴搏鬥，同海盜周旋，手足兄弟病死異鄉。他終於載譽而歸，兩艘船艙內塞滿了珍貴的番貨：百餘擔上等乳香，數十對象牙，還有那最為稀少的龍腦香，以及數十斤從蘇門答臘深山中採得的極品沉香。他曾以為，憑此等貨物，足以還清債務，甚至讓林氏一族在泉州商界更上一層樓。

然而，杭州市舶司外高懸的官府告示，卻如一盆冰水，將他所有的熱望澆滅。

「祖宗舊制，市舶抽解，十抽其一或十抽其二。」林元度在心裡默唸著。這是大宋開國以來，為鼓勵海外貿易而定下的良法。可現在呢？兩浙路安撫使與造作局，以「進奉御前羨餘」為名，巧立科條，強行將抽解比例提高到驚人的四成！這還不算，最珍貴的象牙、龍腦、頂級沉香，更是被官府以極低的「官價」強買，發給商人一種名為「崇寧錢券」的憑由。

「崇寧錢券……」林元度咬緊牙關，這簡直是聞者傷心。崇寧年間發行的錢券，如今已是市面上一文不值，連尋常百姓都不願收受。官府拿這種廢紙來強買商人的血汗，美其名曰「御前綱物」，實際卻是為內廷搜刮奇珍異寶，為造作局私囊添補。他算過，若按此制，此次遠航不僅血本無歸，甚至還要倒貼數萬貫，那十萬貫海債便成了壓垮林氏的最後一根稻草。

他不能垮。林元度握緊了拳頭，指甲幾乎掐入掌心。

日頭漸高，碼頭上的人流越來越密。林元度終於起身，整理了一下衣冠，努力讓自己看起來沉穩一些。他叫來了跟隨他多年的老夥計林福。林福是林氏的家生子，忠心耿耿，此刻也是愁眉不展。

「元度叔，我們……」林福欲言又止。

「走吧。」林元度聲音低沉，帶著一絲疲憊，「去市舶司。是福不是禍，是禍躲不過。」

市舶司與榷貨務的官署連成一片，位於江漲橋以東。高大的圍牆，青磚灰瓦，門前兩尊石獅子威嚴地蹲踞著。與碼頭的喧囂形成鮮明對比的是，這裡顯得格外肅穆，帶著一股令人窒息的官僚氣息。門口的禁軍甲士身披鐵甲，手持長槍，面色冷峻，使得任何試圖靠近的商賈都不由自主地放輕了腳步。

林元度深吸一口氣，走進了市舶司的大門。庭院寬闊，幾株老樹枝葉扶疏，卻遮不住庫房外堆積如山的番貨。那些都是剛從船上卸下，等待抽解的貨物：一堆堆用藤條捆紮的乳香，散發著甜膩的芬芳；一根根巨大的象牙，白皙光潤，在陽光下閃著微光；還有裝在密封木箱裡的龍腦香，以及各色來自海外的奇珍異寶。

他看到了不少熟悉的面孔，有來自廣州的潘氏海商，也有從明州來的王氏牙行。他們臉上無一例外地帶著焦慮與憤怒，卻又都強忍著，不敢發作。大宋的商人，即便再富有，在官府面前，終究只是待宰的羔羊。

林元度徑直走向辦理抽解的廳堂。廳堂內，數名書吏端坐案後，埋頭書寫，偶爾抬頭，目光中帶著慣有的冷漠與傲慢。一位身著青色官袍的押司，正懶散地靠坐在太師椅上，慢悠悠地喝著茶。他姓王，人稱王押司，是市舶司裡出了名的貪婪之徒，卻也手眼通天，能辦旁人辦不了的事。

林元度走到王押司的案前，恭敬地拱手作揖：「押司大人，林元度前來辦理抽解手續。」

王押司眼皮都沒抬一下，慢悠悠地呷了一口茶，才施施然放下茶盞，將目光投向林元度。那目光帶著審視與不屑，彷彿林元度不是一位遠道而來的海商大賈，而是一個前來乞食的叫花子。

「哦？是泉州的林綱首啊。」王押司皮笑肉不笑地說道，語氣中帶著一絲不易察覺的嘲諷，「聽說林綱首這次可謂是滿載而歸，兩艘海舶，實屬罕見呐。想必收穫頗豐，也該為朝廷，為聖上，多貢獻些『羨餘』才是。」

「羨餘」二字，被他咬得特別重，像是一把鈍刀，狠狠地扎在林元元度心上。

林元度擠出一個比哭還難看的笑容：「押司大人說笑了。海上風險大，能平安歸來已是萬幸，哪敢奢求什麼『豐厚』？此番貨物，除去路上的耗損與折舊，已然所剩無幾了。」

王押司嗤笑一聲，用手指輕輕敲了敲桌面，發出「篤篤」的聲響。「林綱首是做大買賣的人，這些話，去哄那些剛出海的毛頭小子吧。你船上的象牙、龍腦，碼頭上誰人不知？那等成色，可是百年難遇的極品。依我看，單是這些，便足以抵上你此行的所有開銷了。」

他頓了頓，目光掃過林元度，語氣忽地低沉下來，帶著一絲威脅：「林綱首是個聰明人，應該知道，我市舶司的規矩，可不是擺設。若有人膽敢瞞報漏報，一經查出，輕則貨物沒官，重則刺配遠州，林綱首可擔待不起啊。」

林元度心頭一顫，知道王押司這是在敲打他。他早有準備，從懷中掏出一個沉甸甸的錢袋，不動聲色地推到王押司面前，又將一個用精美錦盒包裹的木盒，輕輕放在錢袋旁。

「押司大人教訓的是。」林元度壓低了聲音，盡量讓自己的語氣顯得真誠，「小人豈敢瞞報？只是……只是此次確實遭遇了不少波折，同行之人，多有折損。為求林氏一族不致斷絕，小人斗膽，還請押司大人高抬貴手，在抽解上，略作通融。」

王押司的目光落在錢袋與木盒上，臉上那層僵硬的假笑，終於有了一絲鬆動。他拿起錢袋，掂了掂，又打開錦盒，一股濃郁的沉香氣息撲鼻而來。

「這是……奇楠？」王押司的眼神亮了起來，連呼吸都變得有些急促。他雖貪婪，卻也識貨。盒子裡躺著的，正是五十斤頂級奇楠沉香，烏黑油亮，香氣醇厚，是沉香中的極品。

林元度點了點頭，輕聲道：「正是。此乃小人從三佛齊深山尋得，本欲獻於佛前，但如今……也只能先借花獻佛，聊表寸心了。錢袋裡，是五十兩足色黃金，還請押司大人笑納。」

五十斤奇楠沉香，五十兩黃金！這幾乎是此次航運利潤的兩成！林元度在心裡滴血。但他知道，這是他唯一的活路。

王押司的臉上終於堆滿了真誠的笑容。他輕輕咳了一聲，將錦盒合上，又將錢袋推到自己案下，不動聲色地將它們隱藏起來。

「林綱首果然是個豪爽人，深明大義。」王押司的語氣變得親熱起來，彷彿剛才的威脅從未存在過，「既然林綱首如此實誠，本官也斷不能讓林綱首空手而歸。也罷，念在你為我大宋海外貿易奔波，為內廷進奉珍寶不易，本官就破例一次。你的貨物，乳香抽解三成，象牙、龍腦則按官府定價，全數收購，發予崇寧錢券。至於你那批『私貨』……」

王押司朝林元度眨了眨眼，笑容中帶著一絲狡黠：「『私貨』嘛，只要不被查出來，那便是『合理損耗』。本官會為你簽發一張減額抽解憑由，乳香的核定數量，便按你所報的七成計。至於那五十斤奇楠……」他指了指那錦盒，「便算作本官替你向上級『進獻』了。如此一來，你便可少繳一筆不少的稅賦，也能保下你那批『私貨』。如何？」

林元度心頭的石頭稍稍落地。乳香抽解三成，比四成少了一成，加上減額憑由，能讓他多出近萬貫的淨利。而那五十斤奇楠沉香，雖然被王押司「截胡」，但至少他那藏在夾層裡的「私貨」——另外一百斤上等沉香，有望瞞天過海。這百斤沉香，才是他為林氏一族留下的最後一點生機。

「多謝押司大人，多謝押司大人！」林元度連忙拱手作揖，心中說不出的百感交集。這一次，他不僅要面對官府的盤剝，還要賄賂貪官，才能為自己爭得一線生機。這大宋朝堂，究竟是怎麼了？

王押司滿意地點了點頭，拿起筆，在幾張公文上快速地簽署起來。他的筆尖在紙上沙沙作響，墨跡未乾，便蓋上了幾枚官印。隨後，他從案頭拿起一張早已準備好的劄子，遞給林元度。

「這是減額抽解憑由，你拿著它去庫房那邊辦理手續。」王押司的語氣恢復了冷淡，彷彿剛才的交易從未發生過，「記住，今日之事，天知地知，你知我知。」

林元度將劄子小心翼翼地收好，感覺到紙張上官印的凹凸觸感，以及墨跡的微涼。這輕薄的一紙憑由，此刻在他手中卻重如千鈞。他再次向王押司拱手，轉身走出廳堂，腳步有些虛浮。

他走到庫房外，看著腳夫們小心翼翼地搬運著貨物。他的兩艘海舶，此刻已被清空了大半。那些最珍貴的象牙與龍腦香，正被官府的吏員一一清點，然後裝入特製的木箱，貼上封條，顯然是準備直接起運汴京。林元度看著這些本該屬於自己的財富，心如刀絞。但他知道，至少還有那批乳香和藏起來的沉香，能讓他喘一口氣。

他走到自己船隻卸貨的區域，將那張減額抽解憑由遞給了負責清點的庫丁。庫丁掃了一眼憑由，又看了看林元度的貨單，臉上露出會意的笑容。

「林綱首稍候，小人這就去核對數量。」庫丁說道。

林元度點了點頭，站在一旁，心頭稍稍放鬆。他開始在心裡盤算著，泉州的債主們，或許可以拖延幾日。他會立刻派人快馬加鞭，將這批經過減額抽解的乳香運回泉州，然後將那批私藏的沉香，高價賣給相熟的番商，或許還能有一線生機。

就在這時，庫房內忽傳來一陣急促的腳步聲，伴隨著幾聲高亢的吆喝：「造作局朱應奉親至！閒雜人等，速速退避！」

這突如其來的變故，讓整個市舶司大院瞬間陷入一片死寂。所有商賈、腳夫、甚至連那些趾高氣揚的吏員，都彷彿被點了穴一般，僵立在原地。

林元度心頭猛地一緊。「朱應奉」？這個稱號，在兩浙路簡直就是瘟神般的存在。造作局的朱勔，權傾一時，號稱「花石綱」總辦，為內廷搜刮天下奇珍異寶，無所不用其極。他手下的「應奉」，更是狐假虎威，橫行霸道。

只見一行人快步走進大院。領頭的是一個身著緋色官袍的中年男子，面色陰沉，眼神凌厲。他的身後跟著十餘名彪形大漢，個個身披輕甲，手按刀柄，氣勢洶洶。

「朱應奉！」所有在場的官吏，無論大小，都立刻躬身行禮，臉上寫滿了恐懼與諂媚。

那位朱應奉根本不理會那些官吏，直接走到庫房門前，掃視了一圈，目光如刀，讓所有被他看到的人都忍不住打了個寒顫。

「你們這些廢物，平日裡搜刮民脂民膏倒是勤快，辦起正事來，卻是拖拖拉拉！」朱應奉的聲音響亮而充滿威嚴，在空曠的院子裡迴盪。

他猛地一揮手：「奉朱太尉鈞旨！凡此次入港之象牙、龍腦，不問官私，全數充作御前綱物起運汴京！爾等立刻封鎖庫門，任何人不得進出！違者，軍法從事！」

「不問官私，全數充作御前綱物！」這句話如同一道晴天霹靂，狠狠地劈在林元度頭頂。

他的腦袋嗡的一聲，眼前一黑，身體晃了晃，幾乎站立不穩。那些原本還堆放在庫房外的象牙與龍腦香，此刻已全部被朱應奉的隨從圍住，十幾名兵丁如狼似虎地衝上去，將庫房大門「砰」的一聲關上，然後用粗大的鐵鏈層層鎖住。

林元度只覺得全身的力氣瞬間被抽空，雙腿一軟，跌坐在濕冷的碼頭石階上。他手中那張剛才還視若珍寶的減額抽解憑由，此刻卻成了毫無意義的廢紙。

「御前綱物……」他喃喃自語，聲音嘶啞，帶著無盡的絕望。這意味著，他船上所有最值錢的貨物，包括那些原本就該被官府「強買」的，以及他精心計算，寄予厚望的象牙與龍腦，現在全部、徹底地被洗劫一空，甚至連那張一文不值的「崇寧錢券」都不會給他！

他的腦海中，泉州林氏宗族那十萬貫高利海債的數字，瞬間膨脹成一座無法翻越的巨山。他的田產、鋪面、祖宅，以及林氏全族數百口人的生計，此刻如同走馬燈般在眼前飛速閃過。

他望著那緊閉的庫門，望著那些面無表情的兵丁，望著那不可一世的朱應奉，只覺得整個世界都變成了一片漆黑。

他手中的算盤，不知何時從他的掌心滑落，珠子散落一地，發出清脆而刺耳的聲響，在喧囂漸止的碼頭上，顯得格外清晰。那些算珠骨碌碌地滾動著，最終停在泥濘與塵埃之中，就像他此刻破碎不堪的希望。

本章時間設定為政和六年（1116年），此時正值宋徽宗朝「花石綱」與「羨餘」之風盛行之際。宋徽宗崇寧、大觀、政和年間，內廷對奇珍異寶的需求極為旺盛，《宋史·食貨志·互市》記載：「崇寧以來，歲取羨餘，以供內用。」又載「政和間，市舶之利，幾於歲增……以充內府之用」。其中，兩浙路安撫使與造作局（朱勔所領），正是搜刮「羨餘」以進奉御前的主要執行者。朱勔本人即是專門為徽宗搜羅奇花異石、珍禽異獸、以及各類奇珍異寶的「應奉局」頭目，權勢薰天。他及其黨羽常以「御前綱物」為名，強行徵收甚至掠奪民財商貨，不給足額補償，甚至只發放形同廢紙的「舊錢券」。本章中市舶司押司的貪腐，以及朱應奉（代表朱勔勢力）的最終強取豪奪，均是對當時歷史真實狀況的寫照。泉州作為當時重要的海貿港口，其海商往來杭州市舶司進行貿易亦屬常態。章末提到的完顏阿骨打攻克遼陽府，遼東五十四州俱陷，是同年（1116年）的重要歷史事件，為宋金海上之盟以及後續宋遼金關係的變局埋下伏筆。

**【待核事項】：**
1.  **「朱應奉」官職與稱謂：** 文中「朱應奉」是朱勔手下一個具體職位，還是對朱勔本人或其主要親信的泛稱？史料中朱勔本人被稱為「應奉局使」，其下屬亦有「應奉」之職。為強化戲劇衝突與權力壓迫感，本章將其設定為一個直接代表朱勔權威並具有執行力的關鍵人物。若後續考證發現朱勔本人或其親信有更具體的職稱，可再行修改。
2.  **「崇寧錢券」具體貶值情況：** 崇寧年間發行的大觀通寶、崇寧重寶等銅錢，以及相關紙幣，在政和年間已存在一定程度的貶值。本章將「崇寧錢券」描述為「一文不值」，略帶誇張的文學手法，以凸顯商人的絕望。具體貶值到何種程度，仍需細緻考證，但其兌換能力遠低於官價是肯定的。
3.  **「減額抽解憑由」的具體文書格式：** 宋代公文程式繁多，劄子、牙帖、度牒、交子、會子、引鈔等各有其用。本章設定為「劄子」，一種下級對上級或平級的公文，在此處轉化為內部憑證，以顯示其私下操作的性質。具體格式細節若有更精確史料，可再補充。

**【合理推演】：**
1.  **海商的困境與賄賂：** 在官府嚴重盤剝的背景下，海商為保全財產和性命，被迫賄賂官吏是當時普遍存在的現象。林元度作為經驗豐富的大商賈，深知官場潛規則，故而選擇賄賂押司以求「減額抽解」是符合邏輯的自保行為。
2.  **「私貨」的夾帶：** 為了逃避高額抽解和強買，商人在貨物中夾帶少量珍貴私貨是常見手段。林元度將奇楠沉香藏於夾層，並以部分奇楠賄賂押司，以換取對其餘私貨的「睜一隻眼閉一隻眼」，是其在絕境中尋求生機的策略。
3.  **官吏內部層層盤剝：** 從市舶司押司的貪腐，到造作局朱應奉的強取豪奪，展現了宋代官僚系統內部自上而下的層層盤剝。押司可以為蠅頭小利與商人勾結，但當更高層次的權力介入時，這些私下交易便會被輕易推翻，商人的所有努力都將化為泡影。
4.  **資訊傳播與決策影響：** 林元度在遙遠的南洋，對國內政局變動的感知是滯後的。他歸來後才發現「羨餘」政策變本加厲，且朱勔勢力直接插手市舶事務。這種資訊不對稱導致他在決策上的被動，最終釀成悲劇。

**【小說虛構】：**
1.  **人物林元度及其家族背景：** 林元度是虛構人物，其泉州林氏宗族、三佛齊遠航、十萬貫高利海債等均為情節需要而虛構。
2.  **具體賄賂情節：** 林元度向王押司奉上五十斤奇楠沉香和五十兩黃金，以及王押司簽發「減額抽解憑由」的過程，是為塑造戲劇衝突而虛構的細節。
3.  **朱應奉突然駕臨並全數充公情節：** 朱應奉強行將所有象牙、龍腦「不問官私，全數充作御前綱物」的情節，是為製造章末轉折與悲劇性衝突而虛構的具體事件。雖然當時確有強奪商貨之事，但此處的精準時間、人物與貨物對應，屬於小說創作。
4.  **林元度的內心獨白與感官描寫：** 所有關於林元度個人情感、心理活動、對周遭環境的感官體驗，均為小說家對人物內心的藝術加工與想像。

**【連續性變更】：**
1.  **林元度狀態：** 從滿懷希望（儘管擔憂）的遠洋歸來者，變成一個傾家蕩產、瀕臨絕望的商人。他的財務狀況由極度緊張轉為徹底破產。
2.  **物資狀況：** 兩艘海舶滿載的番貨，其最核心、最值錢的象牙與龍腦香被悉數充公，連帶用於賄賂的五十斤奇楠沉香也「打了水漂」。其餘乳香雖經「減額抽解」，但已不足以彌補巨額損失。此前精心策劃的「私貨」沉香，也因朱應奉的全面查封而陷入困境。
3.  **人物關係：** 林元度與泉州林氏宗族之間的債務關係，從有機會償還變為徹底無望。他與王押司之間的關係，從交易者變為被利用的對象，而王押司的承諾也隨之落空。他與官府之間的關係，從潛規則下的妥協者，變為被徹底壓榨和剝削的受害者，對官府的信任蕩然無存，離心離德。
