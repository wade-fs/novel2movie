# 第三十章　太湖鑿巨石與萬夫拖挽

政和四年的四月初六日，天穹如鉛，低垂在兩浙路的湖州太湖之上，似要將人世間的塵埃盡數壓入泥濘深處。自卯時起，便有細雨如髮絲般綿密，到了巳時末，竟轉為瓢潑大雨，伴隨著狂風怒號，將洞庭東山的採石場攪成一片人間地獄。

阿狗的雙足深陷在淤泥裡，冰冷的泥漿已沒過他的膝蓋，裹挾著刺骨的寒意，直鑽肌骨。他赤裸著上身，任由雨水和泥漿混雜的污垢黏膩地糊在每一寸皮膚上，與汗水、血水一同流淌，分辨不清。身後，近八百名鄉親伕役，一個個如他這般，衣衫襤褸，面色灰敗，在風雨中瑟瑟發抖，卻又不得不咬緊牙關，將全身的氣力凝聚在粗麻絞成的巨繩之上。

「嘿——嗬！嘿——嗬！」

一聲聲淒厲而沙啞的號子，從數千張喉嚨裡迸發而出，與呼嘯的風聲、拍岸的浪濤、鞭笞的雨點交織在一起，形成一曲令人肝腸寸斷的悲歌。這聲音裡，裹挾著絕望、疲憊、憤怒，卻唯獨少了生氣。

那塊巍峨如小山的巨型太湖石，便是這一切苦難的源頭。它通體黝黑，嵌滿了犬牙交錯的孔洞，被雨水沖刷得油亮發光，彷彿一頭從地底深淵爬出的洪荒巨獸，此刻卻被死死地箍在數十條粗逾兒臂的麻繩中央。巨石周圍，密密麻麻地插滿了黃色旗幟，旗面上用朱砂繡著四個觸目驚心的大字——「御前應奉」。這四字如同四柄寒光閃閃的尖刀，懸在所有人的頭頂，讓他們不敢有絲毫懈怠。因為這代表著，這塊石頭將被運往遙遠的汴京，供奉給那位至高無上的官家，以點綴其「艮嶽」仙境。

阿狗是這片區域的伕長，掌管著三百人的性命。他知道，這塊石頭足有兩萬斤重，自前日鑿下，便耗費了數百鄉親的血汗。如今，要將它從這泥濘的灘塗上，拖入太湖邊特製的駁船艙底，簡直是要將人的五臟六腑都生生扯出來。

「起！再起！莫偷懶！這便是為官家出力，為自家積福！」

押石差役的嘶吼聲，伴隨著皮鞭劃破空氣的尖銳嘯音，如同毒蛇吐信，從人群後方傳來。這些差役，個個身披油布蓑衣，頭戴斗笠，手持長柄牛皮鞭，眼中閃爍著豺狼般的凶光。他們不必像伕役那般赤膊上陣，更不必深陷泥濘，只需在遠處督陣，偶爾揮動皮鞭，便能將任何一個稍顯遲疑的伕役抽得皮開肉綻。

阿狗親眼看見，就在半個時辰前，一個年過五旬的老丈，因連日勞作，雙腿脫力，一個踉蹌栽倒在泥水裡。他還未及呻吟，便有兩名差役如餓虎撲食般衝上前，一頓亂鞭將他抽得氣絕身亡。緊接著，另一名年輕的伕役，試圖上前攙扶，卻被另一名差役一刀捅穿了胸膛，鮮血噴濺，染紅了渾濁的泥水。兩具屍體，就那麼被直接拖到一旁，草草地用蘆葦蓆一裹，便丟在灘塗邊，任由風雨沖刷。

這不是第一回了。自開採花石綱以來，兩浙路鄉民死傷者何止數百。阿狗的心頭，像壓著一塊比眼前太湖石還要沉重的巨石，每一次呼吸都帶著血腥味。他知道，這不是什麼「積福」，這是活生生的催命！

「阿狗哥！繩子……繩子快斷了！」

身後傳來阿毛驚恐的喊聲。阿毛是村裡最小的，才十六歲，力氣卻不小，平日裡總是跟在阿狗身邊。阿狗猛地回頭，只見阿毛臉色煞白，指著勒在巨石上半部的兩股主繩。這兩股主繩是官府配發的，說是「上等麻繩」，實則多為劣質草麻混編，顏色駁雜，手感粗糙。此時，其中一股細絲已經崩裂，露出裡面發白的草芯，另一股也已繃緊如鐵弦，隨著眾人的拉扯，發出令人牙酸的吱呀聲，彷彿隨時都會徹底斷裂。

阿狗的心臟驟然收緊。他很清楚，一旦主繩斷裂，這塊兩萬斤重的巨石，將會順著已經被泥水浸泡得光滑無比的坡面，轟然滾下。後方數十名鄉親，根本來不及躲閃，便會被瞬間碾為肉醬，連骨頭渣子都尋不見。

「住手！停——」

這個念頭幾乎脫口而出。然而，他的喉嚨卻像被一隻無形的手死死扼住，發不出半點聲音。他腦海中浮現的，是那些差役皮鞭上沾染的血漬，是他們腰間晃動的亮閃閃的皮刀。若他此時大喊停手，無疑是在挑戰官府的權威，那皮刀，下一刻便會毫不猶豫地落在他的頭上。他死了，固然一了百了，可身後這些鄉親，誰來照應？誰來替他們擋住差役的鞭子和刀子？

汗水與雨水混雜著，模糊了阿狗的視線。他感到一股冰冷的恐懼從腳底直竄天靈蓋。拉，則可能死數十人；停，則自己必死，且那巨石終究要拉。這是一個無解的死局。

他猛地環顧四周。泥漿深滑，滾木極易深陷斷裂。他們用來墊在巨石下的滾木，已經有好幾根被壓斷，深陷泥中，使得巨石移動更加艱難。每一次拉扯，巨石只是向前蠕動一丁點，便又被泥漿和斷裂的滾木死死吸住。

阿狗的目光，最終落在了自己腰間。那是一條用了多年的老舊腰帶，外層是粗布，內裡卻秘密地編織著幾股牛筋繩。這是他年輕時狩獵所得，韌性十足，是他用來固定扁擔、綑紮獵物的寶貝。此刻，這條腰帶，或許是唯一的生機。

他不再猶豫，雙手猛地解開腰帶，將牛筋繩從布帶中迅速抽出。這時，又一聲清脆的「嘣」響，另一股麻繩的細絲也崩裂了！巨石在眾人拉扯下，發出「咯吱」一聲沉重的悶響，搖晃了一下，似乎隨時都會脫離掌控。

「阿狗哥！」阿毛再次驚呼，聲音已帶上了哭腔。

「莫慌！」阿狗厲聲喝道，聲音在風雨中顯得嘶啞而微弱。他將抽出的牛筋繩團成一團，猛地塞進那已經崩裂的麻繩裂口處，用盡全身力氣將其纏繞、綁緊。這牛筋繩比官府配發的麻繩細了許多，但卻堅韌無比，如同給瀕死的病人餵下了一劑猛藥。

「嘿——嗬！嘿——嗬！」

眾人見阿狗的動作，雖不知詳情，卻也感受到一股緊迫。他們被差役的皮鞭驅趕著，只能繼續賣力拉扯。阿狗知道，這只是權宜之計，牛筋繩雖韌，但畢竟只是輔助，無法承受如此巨石的全部重壓。

他再次看向巨石的底盤。那裡，幾根粗大的鐵楔，本該穩穩地卡在巨石與滾木之間，以防止巨石滑動。然而，由於連日陰雨，泥漿深滑，鐵楔與地面摩擦力大減，加上滾木的斷裂，有兩根鐵楔已經鬆動，歪斜著，幾乎失去了效用。

阿狗腦中只剩一個念頭：必須將鐵楔重新塞緊，固定巨石，哪怕只是爭取片刻喘息。

他猛地向前撲去，身子幾乎趴在泥漿裡，不顧一切地朝巨石底盤鑽去。冰冷、黏稠的泥漿瞬間灌滿他的口鼻，他拼命掙扎著，像一條泥鰍般滑向巨石的陰影。

「阿狗哥！危險！」阿毛驚恐地喊道。

但阿狗哪裡還聽得見？他的眼中，只有那兩根搖搖欲墜的鐵楔。他伸出右手，使盡全力，去推動其中一根。那鐵楔被泥漿和重壓死死吸住，紋絲不動。

「嗬！嗬！」他發出野獸般的低吼，青筋暴起，喉嚨裡泛起一股鐵鏽味。他用盡全身的力氣，試圖將鐵楔往裡推。然而，巨石的重量何止萬斤，他單薄的身軀，在它面前如同螻蟻。

就在這時，巨石在眾人的又一次拉扯下，發出了一聲令人心悸的「嘎吱」巨響，猛地向前滑動了半寸。那鬆動的鐵楔，瞬間被巨石的底盤狠狠擠壓。

阿狗的左手，此刻正不偏不倚地卡在鐵楔與巨石的縫隙之間。他甚至來不及發出慘叫，只感覺一股難以想像的劇痛，如閃電般貫穿全身。那劇痛是如此猛烈，以至於他全身的力氣瞬間被抽空，眼前一片漆黑，世界仿佛在這一刻靜止了。

他聽到骨頭碎裂的聲音，那聲音像乾枯的樹枝被生生折斷，清脆而殘酷。他感到溫熱的液體噴濺而出，混雜著泥水，模糊了他的視線。

劇痛過後，是一種麻木，以及一種冰冷的清醒。他知道，完了。

左手，食指、中指、無名指，三根手指被巨石生生擠斷！斷裂的指骨和血肉，在巨大的壓力下，被擠壓成了肉泥，黏連在冰冷的鐵楔上，與巨石的底盤融為一體。

阿狗發出一聲撕心裂肺的低吼，那聲音不像人，倒像一頭受傷的野獸。他猛地將左手從縫隙中抽回，只見那三根手指已然不見，只剩下血肉模糊的掌心，以及不斷噴湧的鮮血。鮮血瞬間染紅了泥漿，像一朵妖冶的紅花，在灰暗的世界中綻放。

然而，就在他受傷的這一剎那，或許是那鐵楔被他最後的掙扎稍微扶正了些許，或許是眾人的集體努力，巨石再次發出沉悶的摩擦聲，緩緩向前移動了一寸。

「起！再起！莫停！」押石差官的吼聲再次傳來，伴隨著更為頻繁的鞭打聲。他們根本沒有注意到阿狗的異狀，他們的眼中，只有那塊被他們視為功績的巨石。

阿狗忍著劇痛，眼前一陣陣發黑。他知道，自己不能倒下。他死了，這群鄉親便真的沒有主心骨了。他緊咬牙關，用右手緊緊捂住左手的斷指處，強迫自己站穩，重新將目光投向那巨石。

那牛筋繩與麻繩的混編，在風雨中發出不堪重負的吱呀聲，但至少，它還沒有完全斷裂。滾木在泥漿中緩慢地滾動著，巨石在數百人的拉扯下，如同蝸牛般，一點點地朝太湖邊的駁船靠近。

時間，彷彿被無限拉長。阿狗感覺自己的生命力，正隨著左手斷指處噴湧的鮮血一同流逝。每一次呼吸，都像是刀割般痛苦。他甚至能聞到自己血液的腥味，以及傷口處那種肉體被撕裂的腐臭氣息。

他不知道自己是如何堅持下來的。或許是心底那股對妻兒老小的牽掛，或許是對那些差役暴行的刻骨仇恨，或許，只是單純的求生本能。

一丈、半丈、三尺……

終於，在數百人近乎力竭的拉扯下，在差役們瘋狂的鞭打與嘶吼中，那塊巨型太湖石，在一個震耳欲聾的「轟隆」聲中，猛地滑入了特製的駁船艙底！

巨大的衝擊力，讓駁船猛烈地晃動了一下，湖水被巨石擠壓，濺起數丈高，如同白色的水柱，在灰暗的天空中劃出一道道刺目的痕跡。

「成了！成了！」

押石差官們爆發出一陣狂喜的歡呼。他們收起皮鞭，將斗笠往後一掀，露出被雨水打濕的得意面孔。其中領頭的差官，一個滿臉橫肉的壯漢，隨手從腰間的布袋裡掏出兩串劣質鐵錢，噹啷一聲扔在泥濘中，看也不看阿狗斷指處噴湧的鮮血。

「賞你們的！都給老子滾回去！明日卯時，再來拉第二塊！」

那兩串鐵錢，銹跡斑斑，成色極差，甚至連半文足值的銅錢都比不上。在眾人看來，這根本不是賞賜，而是對他們血汗與生命的踐踏。

阿狗木然地看著那散落在泥漿裡的鐵錢，眼中沒有悲傷，沒有憤怒，只有一片死寂的空洞。他的左手仍在滴血，但劇痛此刻似乎已經麻木。他感到一股徹骨的寒意，並非來自風雨，而是來自心底。

「阿狗哥……」阿毛扶住搖搖欲墜的阿狗，看著他血肉模糊的左手，眼淚止不住地流下來。

泥潭中，幾名年輕的民夫圍攏在阿狗身旁，他們臉上沾滿了泥漿和雨水，但眼中燃燒著的，卻是與以往不同的、嗜血的凶光。他們壓低了聲音，低語道：

「阿狗哥，你這手……」

「這群狗官，真他娘的不是人！」

「如此活受罪，不如隨青溪方大哥反了他娘的！」

「是啊，反了，反了！再這樣下去，遲早也是個死！」

這幾句話，如同火星，在阿狗死寂的心頭，點燃了一絲微弱的火苗。他抬頭望向遠方灰濛濛的太湖，湖水在風雨中翻湧，像一頭被激怒的巨獸。北方的金人，南方的花石綱，朝廷的昏聵，官吏的殘暴……這些原本抽象的概念，此刻在他心中，化作了左手斷指的劇痛，化作了鄉親們的累累白骨，化作了泥漿裡那兩串可笑的劣質鐵錢。

他感到一股前所未有的憤怒，在胸腔中熊熊燃燒。這種憤怒，超越了恐懼，超越了悲傷，直抵靈魂深處。他知道，有些東西，在今日，徹底變了。

## 章後工作紀錄

**【史實骨架】**
本章情節緊密圍繞宋徽宗時期「花石綱」這一重大歷史事件展開。《宋史·朱勔傳》有明確記載：「自是，歲歲開鑿，採花石綱。深水沈溺，山岩壓死，人畜之喪，不可勝數。所至，民間廬舍盡被拆毀，室無完堵。巨石運至京師，耗費萬金。」章中描繪的太湖巨石採運現場，動用數千民夫，惡劣天氣下的強行施工，民夫被鞭打致死，以及最終賞賜劣質鐵錢等細節，均是基於朱勔傳的記載進行的合理推演與藝術加工，旨在展現花石綱對江南百姓造成的深重災難。政和四年的時間點，也正值花石綱規模化運作時期。

**【待核事項】**
1.  **具體繩索材質與承重能力：** 章中提及「劣質草麻混編」和「牛筋繩」，其具體性能、成本與當時的實際應用狀況，仍需進一步考證。例如，宋代是否有專門用於巨石搬運的麻繩規格，以及牛筋繩在民間的使用普及度。
2.  **駁船形制與操作細節：** 運載巨石的「特製駁船」具體形制、艙底結構、承重上限，以及巨石入艙的具體操作流程（如是否有滑軌、緩衝裝置），需補充考證，以確保沉浸感與合理性。
3.  **「劣質鐵錢」的流通與實際價值：** 宋代貨幣體系複雜，鐵錢的鑄造與流通區域、成色與銅錢的兌換比率、以及其作為賞賜品的具體貶值程度，需要更精確的數據支撐。本章中「連半文足值的銅錢都比不上」是一種藝術化描述，實際貶值程度值得細究。
4.  **政和四年初，方臘起義的民間傳聞程度：** 章末民夫提及「青溪方大哥」，暗示方臘起義已在江南民間有所流傳。需核實政和四年四月時，方臘的聲望與組織活動是否已達到足以在民間廣泛傳播的程度（史載方臘起義為政和二年，但其秘密組織與傳播應有前期）。

**【合理推演】**
1.  **伕長阿狗的責任與困境：** 在高壓且無情的官府徵調體系下，伕長作為基層組織者，既要應對上級的殘酷命令，又要盡力保護鄉親，其兩難處境是必然的。面對生死攸關的繩索崩斷危機，阿狗的「大喊停手即刻身死，繼續死拉則鄉親被碾」的抉擇，是基於極端環境下對個人命運與集體安危的理性推演。
2.  **劣質器材與事故頻發：** 官府為了節省開支，常配發劣質材料，導致事故頻發，這在歷史上屢見不鮮。滾木深陷、麻繩斷裂等情節，正是這種制度性腐敗和草菅人命的直接結果。
3.  **基層資訊傳播與情緒積累：** 民夫間口耳相傳的「青溪方大哥」，是當時江南民間對地方豪強、反抗勢力的稱謂。在花石綱的長期壓迫下，底層百姓對官府的仇恨逐漸累積，對起義的期盼與討論，會以低語、暗示的方式在勞作中傳播，這是符合當時社會心理與資訊傳播邏輯的。阿狗斷指的慘烈事件，正好成為引爆這類情緒的導火索。
4.  **「御前應奉」對百姓心態的影響：** 早期百姓對「皇帝」有敬畏之心，但當「御前應奉」帶來的是殘酷剝削與死亡時，這種抽象的敬畏會迅速轉化為對具體暴政的切齒痛恨，進而挑戰其合法性。
