# 第十二章　曾布與韓忠彥的暗潮

建中靖國元年八月二十日，日頭才過午，汴京上空便積攢起沉重的烏雲，壓得人心頭發悶。雷聲隱隱，自西北方向滾滾而來，似巨獸在遠方低吼，將秋日的暑氣連同朝堂的煩躁一併攪動。中書省政事堂西花廳內，氣氛比窗外更凝滯，連空氣都似被無形之手擰絞，沉重得令人窒息。

何洵，年過而立有五，身著一襲青色團領公服，頭戴幞頭，額角滲出細密的汗珠。他垂首立於左壁下首，兩手交握於腹前，指尖因緊張而微微發白。廳中兩位宰執，左相曾布與右相韓忠彥，分坐於雕花紅木案後，相隔不過數尺，卻如隔萬仞深淵。

曾布，鬚髮已然半白，臉上溝壑縱橫，一雙精光內斂的眼眸此刻卻銳利如鷹隼。他身著紫色官袍，袍袖寬大，其間隱約可見補子上的獬豸紋樣。此刻，他正襟危坐，身體微向前傾，左手按在案上一疊厚重的卷宗上，指節因用力而泛白。那卷宗，正是《神宗實錄》的殘本。

韓忠彥則身形稍顯清瘦，面色卻是鐵青，目光如刀，直刺曾布。他身上的紫袍較之曾布，似乎更為新淨，補子上的仙鶴紋樣栩栩如生。案上堆疊著更多的《神宗實錄》謄抄本，還有幾份朝臣請罷王安石配享太廟的劄子，其上朱筆圈點，赫然可見數十處。廳內數名堂吏，皆屏息凝神，連大氣都不敢出，只聽得窗外秋蟬嘶鳴，與那漸近的雷聲交織成一片令人心悸的背景。

「曾相公，王安石新法流毒四海，民怨沸騰，此乃天下皆知之事，不容置喙！」韓忠彥的聲音，如金石相擊，帶著不容置疑的堅硬。他抬手指向案上那疊劄子，指尖幾乎觸及最上面一份：「向太后臨終前，亦曾有遺旨，言新法擾民，當議廢止。今欲配享神宗皇帝廟庭，豈非將神宗陛下置於不義之境？此舉，臣以為，斷斷不可！」

曾布聞言，猛地一拍紅木案，發出「砰」的一聲悶響，震得案上筆筒都跳了一跳。他霍然起身，雙目圓睜，怒氣勃發：「韓相公此言差矣！神宗皇帝親自頒佈新法，力圖富國強兵，雖有弊端，亦是為國為民之舉！今若因新法之議，便將王介甫（王安石字介甫）黜出太廟，豈非變相指責神宗皇帝為無道之君？臣子安得行此悖逆之舉！」

他踱出案後，走到廳中，背手而立，袍袖因其動作而輕輕拂動，帶起一股淡淡的沉檀香氣。那香氣，平日裡應是令人心神安寧的，此刻卻反而增添了幾分緊繃。

「神宗皇帝親自頒佈不假，然其時天下已然怨聲載道，陛下亦時有悔意！」韓忠彥毫不退讓，亦起身走到廳中，與曾布遙遙相對，距離不過數步。他聲如洪鐘，字字鏗鏘：「太后遺旨，乃是為社稷計，為陛下計，豈可輕忽？況且，哲宗元祐年間，朝廷已然議定，王安石不當配享。今欲翻舊案，是何道理？」

「元祐年間之議，乃是黨同伐異！是司馬光一黨排除異己之舉！」曾布怒斥，聲音因激動而有些嘶啞：「彼時，介甫公已逝，無法辯駁，任人攻訐。此非公論，乃私議也！況且，哲宗皇帝親政後，已然撥亂反正，恢復部分新法，並將介甫公之配享事宜，重新納入考量！」

何洵的心臟在胸腔裡瘋狂跳動，幾乎要從嗓子眼裡蹦出來。他知道，這不是尋常的政事堂議，而是兩位宰執之間，已然撕破臉皮的權力惡鬥。王安石配享太廟，看似只是追贈榮譽，實則關乎神宗皇帝蓋棺定論的評價，更是新舊黨爭的延續。一旦王安石配享成功，則新法之正當性將被確立，舊黨的政策基礎將被動搖。反之，則是新黨的重大挫敗。

他深吸一口氣，努力使自己鎮定下來。作為中書省檢正五房公事，他的職責便是為宰執們提供典章制度、歷史沿革的考證。此時此刻，他必須保持絕對的清醒與嚴謹。

「何洵！」曾布突然轉身，目光如炬地望向何洵，語氣中帶著不容置疑的威嚴：「去樞密院典籍庫與我中書省典籍庫，立刻找出哲宗朝議定王介甫配享之元豐原檔！本相記得，彼時哲宗皇帝親政後，曾就此議，有過明確批示！」

何洵心中猛地一沉。元豐原檔，那可不是尋常文書。元豐年間，王安石的新法推行得如火如荼，其配享之事，自然在那時便有過討論。哲宗皇帝親政後，雖曾短暫啟用舊黨，但很快便轉向，重用新黨，恢復新法。在那個轉圜的時期，關於王安石的地位評價，必然經歷了一番反覆。

他躬身應道：「諾！下官這就去辦！」說罷，他轉身快步走出西花廳。

秋雷更近，透過廳門，隱約可見院中高大的槐樹枝葉在風中狂舞，豆大的雨點已然零星落下。空氣中瀰漫著泥土與草木被雨水打濕的清新氣息，卻沖不散何洵心中的焦慮。

他穿過廊廡，避開了幾名行色匆匆的官員，徑直來到中書省典籍庫。庫房位於省院東北角，是一座三層高的磚木結構建築，牆體厚重，窗戶狹小，以防潮防火。推開厚重的木門，一股陳舊的書卷氣息撲面而來，混合著樟腦的微澀。庫中光線昏暗，唯有幾盞油燈在角落搖曳，映照出層層疊疊的書架與其上堆積如山的卷宗。

典籍庫的庫吏是個年邁的老者，姓張，頭髮花白，常年伏案整理，背已微駝。何洵向他拱手致意，張庫吏眯著眼，從老花鏡上方打量了他一眼，手中還捧著一本泛黃的《唐律疏議》。

「何檢正，今日是吹的哪陣風，將您吹到這等僻靜之處？」張庫吏聲音沙啞，帶著幾分調侃。

「張老，莫要打趣。事關緊要，曾相公命下官尋元豐年間關於王介甫配享太廟之原檔，哲宗皇帝親政後所議定者。」何洵急切地說明來意。

張庫吏聞言，臉色也嚴肅起來。他放下手中的書，從懷中掏出一串鑰匙，叮叮作響。

「元豐年間的案卷，都在這一層。」他指了指最靠裡的一排書架，架上盡是牛皮紙封套的卷宗，其上墨跡斑駁，記載著歲月的痕跡。

何洵領命，循著張庫吏所指的方向走去。他先在中書省的典籍庫中翻找。元豐年間的卷宗浩如煙海，他憑藉著對典籍類目的熟悉，很快便鎖定了幾處可能存放相關資料的書架。他戴上庫吏遞過來的白棉布手套，小心翼翼地從架上抽出一份份卷宗。

指尖觸及那些發黃的紙張，能感受到其纖維的粗糙與歲月的沉澱。墨跡已然淡去，但字跡依然清晰可辨。他翻閱著，一份份公文、劄子、奏議、旨意，無不訴說著百年前的朝堂風雲。他發現，關於王安石配享太廟的討論，在神宗朝末期和哲宗朝初期，確實有過數次反覆。

在其中一份卷宗裡，他終於找到了一份關於哲宗皇帝親政後，重議王安石配享太廟的成案。這是一份由中書省會同禮部、太常寺共同上呈的議案，其上明確記載了哲宗皇帝的批示：「王安石功過，自有定論，其配享事宜，當從先帝遺志，且議者勿再紛擾。」這批示語氣雖然委婉，但在當時的政治語境下，已然是傾向於配享的明確信號。

何洵的心頭稍定，正欲將此卷宗取出。然而，當他將卷宗翻至中間幾頁時，手卻驀地一僵，瞳孔驟然收縮。

在那份成案的數頁之間，竟夾著一份手書的劄子，其上墨跡猶新，赫然是曾布的親筆簽押！那劄子言辭謹慎，內容卻是建議章惇，彼時章惇權勢熏天，為平息元祐黨爭餘波，可以在《神宗實錄》中適當刪減神宗皇帝關於新法的某些過激言論，以求「彌合新舊之隙，維護朝堂清議」。

何洵的額頭，瞬間冒出豆大的冷汗。他雙手有些顫抖。這份劄子，雖然沒有直接否定王安石配享，卻透露出曾布在哲宗朝後期，為了政治妥協，曾對《神宗實錄》的編修動過手腳。若將此物呈給曾布，他固然可以壓制韓忠彥，但曾布本人也將陷入「竄改實錄」的巨大漩渦。這在史官眼中，是比任何罪名都更為惡劣的行徑，是動搖國本的罪惡。

而若是不呈上此物，韓忠彥今日必將大勝，曾布顏面掃地，日後必視自己為何黨之人，從此仕途坎坷，甚至可能招來禍端。他只是個檢正五房公事，在宰執的權力鬥爭中，不過是一枚微不足道的棋子，卻被推到了這等進退維谷的絕境。

他的腦海中，飛速權衡著利弊。雨聲漸大，打在窗戶上，發出「噼啪」的聲響，猶如戰鼓擂動。廳外雷聲已然近在咫尺，震得整座庫房都微微顫動。

何洵深吸一口氣，指尖撫過那張薄薄的紙頁，感受著其上墨跡的微凸。他腦中靈光一閃，一個大膽而危險的念頭驀然浮現。

他將那份成案輕輕放下，深吸一口氣，佯裝不經意地翻了幾頁。隨後，他用戴著手套的指尖，小心翼翼地將那份夾在中間、帶有曾布簽押的劄子，從卷宗中抽了出來，悄無聲息地藏入袖中。隨後，他將那份記載了哲宗皇帝批示的成案，只取了首尾兩頁——即標明案由與最終批示的關鍵頁面——輕輕撕下。這樣，既保留了哲宗皇帝的明確批示，又隱去了中間可能引起爭議的、關於《實錄》修訂的細節，以及那張致命的曾布親筆簽押。

他的心臟仍在狂跳，手心滲出冷汗，卻竭力保持著面上的平靜。他將撕下的兩頁紙小心地折疊好，藏入袖中。隨後，他將剩餘的殘卷放回原處，又隨手翻了幾份其他的卷宗，以掩人耳目。

「張老，元豐年間的案卷甚夥，下官尋到了幾份有關的，但皆語焉不詳。」何洵故作疲憊地走到張庫吏身邊，低聲道：「下官還需前往樞密院一趟，或許那裡有更確鑿的證據。」

張庫吏點點頭，沒有多想，只道：「去吧，去吧。這雷雨將至，路上小心些。」

何洵匆匆走出中書省典籍庫，冒著愈發密集的雨點，朝樞密院的方向疾步走去。他需要時間讓自己的心緒平復，也需要讓自己的行為看起來更加「合理」。一路上，雨水打濕了他的幞頭與公服，泥濘的道路讓他的官靴沾滿了濕漉漉的泥漿。冰冷的雨水澆在他臉上，卻無法澆滅他內心的灼熱與恐懼。

他並未真的去樞密院。只是繞了一圈，等雨勢稍歇，待臉色恢復平靜後，他才重新回到政事堂西花廳。

廳內，曾布與韓忠彥的爭論仍在繼續，只是聲音已不再像之前那般劍拔弩張，卻多了一絲疲憊與僵持。他們各自回到案後，只是眼神依然犀利，不肯退讓半分。

「何洵，可曾尋到？」曾布見他進來，立刻問道。

何洵躬身，從袖中取出那兩頁紙，雙手呈上：「回稟曾相公，下官在中書省典籍庫中，尋得哲宗皇帝元符年間，重議王介甫配享太廟之成案。此乃其首尾二頁，載有哲宗皇帝親批之語。」

曾布接過紙頁，目光掃過，隨後遞給韓忠彥。韓忠彥將信將疑地接過，仔細閱讀。那兩頁紙上，的確清晰記載著哲宗皇帝「王安石功過，自有定論，其配享事宜，當從先帝遺志，且議者勿再紛擾」的批示。這批示，無疑是對王安石配享的有力支持。

韓忠彥的臉色越發陰沉。他當然知道哲宗皇帝晚年有撥亂反正之舉，但他沒料到曾布能如此迅速地拿出這般確鑿的證據。這兩頁紙，字字珠璣，宛如兩記響亮的耳光，重重地打在他的臉上。他將紙頁重重地拍在案上，發出「啪」的一聲脆響。

「哲宗之批示，亦可有不同解讀！」韓忠彥不甘示弱，強辯道：「彼時朝局複雜，陛下此言，亦有安撫新黨之意，非定論也！」

「安撫之意？韓相公莫非以為聖上金口玉言，亦可隨意解讀？」曾布冷笑一聲，語氣中帶著勝利者的嘲諷：「若如此，朝堂法度何在？典章何在？難道我大宋的《實錄》與聖旨，皆可任人塗抹臆測不成！」

兩人你來我往，爭論不休，但韓忠彥的氣勢明顯被壓了下去。何洵站在一旁，看著這一切，心中百味雜陳。他知道，自己剛才的舉動，或許保住了曾布一時，也保住了自己的性命與仕途。但那份被他藏入袖中的劄子，卻像一塊沉重的石頭，壓在他的心頭。他感覺到自己已經踏入了一個深不見底的漩渦，再也無法置身事外。

政事堂內的爭吵聲，伴隨著窗外漸歇的雨聲與遠去的雷鳴，顯得愈發疲憊而無力。兩相的權力鬥爭，已然徹底公開化，北宋最高行政中樞，此刻正陷入一種僵持不下的癱瘓狀態。

就在這僵持不下之際，廳門外突然響起一陣輕微的腳步聲。一名身著緋色官服的內侍中官，躬身立於門外，手中捧著一道明黃色的絲帛。

「聖上口諭，兩位相公有旨！」內侍中官尖細的嗓音，打破了廳中的沉寂。

曾布與韓忠彥聞言，皆暫時放下爭執，轉身面向內侍，躬身聆聽。何洵亦隨眾人一同躬身。

「聖上口諭：兩相各歸私第，配享之事暫寢。」內侍中官面無表情地宣讀著，語氣平淡，卻帶著不容置疑的皇權威嚴：「宣戶部侍郎蔡京明日垂拱殿便殿進對。」

「蔡京」二字，如同兩枚冰冷的鐵釘，瞬間釘入了廳中所有人的心頭。

曾布與韓忠彥的臉色，幾乎在同一時刻發生了劇烈的變化。方才的怒意、疲憊、爭執，此刻盡數化作一種難以置信的震驚與警惕。何洵亦是猛地抬頭，只見兩位宰執的目光，不約而同地望向對方，眼神中除了原有的敵意，更添了一抹深深的忌憚。

蔡京！這個名字，對於朝中任何一個官員來說，都絕不陌生。他曾為元祐舊黨所貶，後又因阿附章惇而得寵。他才華橫溢，書法出眾，然其人品卻備受爭議，以投機鑽營著稱。更重要的是，他並非任何一黨的嫡系，他的崛起，似乎意味著官家，這位年輕的徽宗皇帝，已然不滿於兩相的僵持，正謀求打破均勢的第三種力量。

廳中眾人，此刻皆陷入了死一般的沉寂，唯有雨滴從屋簷滑落，滴答作響。所有人的目光，都下意識地望向了彼此，又迅速移開，空氣中瀰漫著一股山雨欲來的沉重氣息。何洵的掌心，再次滲出冷汗，而袖中那張被他藏匿的曾布簽押，此刻卻彷彿燃起了灼熱的火焰，燙得他心驚肉跳。

本章時間設定為建中靖國元年八月二十日（1101年9月15日），此時宋徽宗剛剛即位，朝政由向太后垂簾，但實權逐漸轉移至徽宗。向太后於八月二十四日駕崩，本章設定在駕崩前四日，其遺旨對於朝政仍有影響力。史實中，建中靖國末期，左相曾布與右相韓忠彥由合作走向決裂，圍繞王安石配享神宗廟庭以及《神宗實錄》的修訂問題爆發了激烈的黨爭。曾布為新黨領袖，力主恢復新法及王安石的地位；韓忠彥則偏向舊黨，反對王安石配享，並質疑新法。徽宗皇帝對兩相的爭鬥感到厭煩，並在此後不久啟用蔡京，令其回京擔任戶部尚書，標誌著蔡京政治生涯的迅速崛起，並最終打破了朝堂的舊有格局。《續資治通鑑長編》記載了建中靖國年間，朝廷圍繞王安石配享問題的多次爭論，以及曾布與韓忠彥的矛盾激化。向太后臨終前確實有關於新法的遺言，成為韓忠彥攻擊新法的藉口。哲宗元符年間，曾對王安石配享問題有過重議，史實中曾布為維護新黨利益，確實參與過《神宗實錄》的編修，並有刪改之嫌。

**【待核事項】：**
1.  **《神宗實錄》異文具體細節：** 史料中關於《神宗實錄》在不同時期（元祐、紹聖、元符）的編修與刪改爭議非常複雜。本章虛構了樞密院與中書省典籍庫存在異文，以及哲宗朝議定配享的元豐原檔中夾帶曾布簽押的細節。需進一步考證不同版本《實錄》的具體差異是否能支持這種「異文」的存在，以及曾布參與刪改的具體證據或合理推演。
2.  **哲宗朝「元豐原檔」的具體內容與批示語氣：** 本章虛構了哲宗皇帝「王安石功過，自有定論，其配享事宜，當從先帝遺志，且議者勿再紛擾」的批示。此批示語氣是否符合史實中哲宗皇帝在元符年間對新舊黨爭的態度，需進一步查證。
3.  **官職細節與流轉：** 蔡京在建中靖國元年八月被召回京師，任戶部尚書，但本章末尾稱其為「戶部侍郎」，這是為了鋪墊其升遷。需確認其被召回京師時的具體職位，以及「戶部侍郎」到「戶部尚書」的銜接是否合理。此處設定為「戶部侍郎」是為了表現其被召回京，但尚未完全掌權的過渡狀態，與後文蔡京被重用為尚書相銜接。
4.  **戶部侍郎蔡京進對地點：** 垂拱殿便殿是否為戶部侍郎級別官員進對的常規地點，或是否具有特殊含義，需考證。

**【合理推演】：**
1.  **黨爭白熱化下的基層官員心態：** 在曾布與韓忠彥這等宰執級別的激烈黨爭中，中層官員如何洵，其生存壓力是巨大的。本章推演了何洵在重壓之下，為求自保而採取「隱匿」關鍵證據的策略。這種在夾縫中求生存，利用職權之便進行微妙操作，以期在政治風暴中全身而退的心機與抉擇，符合當時朝堂鬥爭的現實邏輯。
2.  **資訊傳播與文書管理：** 中書省與樞密院分掌政務與軍務，各自擁有典籍庫，但兩者對同一歷史事件的記錄可能因立場、編修者、傳抄者等因素而存在差異，這是合理的。何洵在兩庫之間虛晃一槍，實則在中書省典籍庫內完成操作，也符合當時公文處理流程與個人隱秘行為的推演。
3.  **皇帝對黨爭的厭煩與求變：** 徽宗皇帝初登大寶，面臨兩大宰執的激烈內鬥，長期僵持不下必然影響朝政效率與皇權威信。他召見蔡京，正是其厭倦現有局面，試圖引入第三方力量打破平衡的合理推演，也是史實中蔡京崛起的重要契機。

**【小說虛構】：**
1.  **人物何洵：** 中書省檢正五房公事何洵為小說虛構人物，其在兩相黨爭中被迫做出抉擇，並實施抽除簽押頁的具體情節為小說虛構。
2.  **曾布簽押的劄子內容：** 曾布曾與章惇在《神宗實錄》編修問題上有過妥協，但其具體內容與形式為「私下向章惇妥協、同意刪減神宗部分言論的親筆簽押」乃小說戲劇性虛構，旨在製造何洵的兩難困境。
3.  **微觀衝突與感官細節：** 廳內雷聲、雨聲、書卷氣味、官服材質、何洵的心理活動、汗珠、手抖等所有具體的感官細節和內心掙扎，皆為小說虛構與描寫。
4.  **兩相具體爭執台詞：** 曾布與韓忠彥的具體對話內容，尤其是在哲宗批示出現後的強辯與反駁，皆為根據史實背景進行的文學創作。

**【連續性變更】：**
1.  **曾布與韓忠彥的關係：** 本章之前，兩人尚有合作之態，但本章將兩人的矛盾徹底公開化、白熱化，標誌著他們之間的政治聯盟徹底破裂，轉為全面敵對。
2.  **何洵的個人狀態與政治立場：** 何洵從一個相對中立的基層官員，在巨大的政治壓力下，被迫做出了具備風險的「站隊」行為，雖然是以自保為目的，但其命運已然與曾布深度捆綁，且因隱匿文書而背負了沉重的心理壓力與潛在風險。
3.  **徽宗皇帝的政治姿態：** 徽宗皇帝不再滿足於旁觀兩相爭鬥，其召見蔡京的舉動，預示著他將主動介入朝政，打破現有權力格局，顯示出其政治手腕的初步展現。

**【後續銜接】：**
1.  **蔡京的崛起：** 本章結尾蔡京的登場，為下一章或後續章節蔡京回京、面聖、被重用、進而打破朝堂平衡埋下伏筆。他的介入將徹底改變曾布與韓忠彥的權力格局，並開啟宋徽宗朝「蔡京當國」的局面。
2.  **王安石配享之爭的後續：** 雖然配享之事暫寢，但其背後的黨爭並未結束，只是從檯面轉入暗中，或以其他形式繼續。這將是日後新舊黨爭的長期主線之一。
3.  **何洵的命運走向：** 何洵的自保之舉，為其未來的仕途埋下了不確定性。他所隱藏的曾布簽押，將成為他個人命運中的一顆定時炸彈，可能在未來的某個時刻引爆，影響他與曾布，乃至與其他政治勢力的關係。他的微觀命運將與宏觀歷史的走向緊密結合。
4.  **向太后駕崩的影響：** 本章發生在向太后駕崩前，她的遺旨是韓忠彥的重要論據。隨著她的駕崩，朝政將完全由徽宗皇帝掌握，其政治路線將更加明確，這將對後續朝局產生深遠影響。
