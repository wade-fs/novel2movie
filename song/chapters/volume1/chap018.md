# 第十八章　銷毀禁籍與告密風潮

崇寧三年的秋風，帶著一股不同尋常的蕭瑟，裹挾著自國子監書庫院天井深處升騰而起的濃煙，盤旋著、嘶鳴著，最終化為細密的灰燼，洋洋灑灑地落在汴京城那寬闊的青石板路上，也落在往來匆匆的行人肩頭。那灰燼，黑中帶白，輕盈如雪，卻沉重得足以壓垮任何一個識字讀書人的心。九月初三這日，天空低垂，鉛灰色雲層密佈，偶有幾縷微弱的日光勉強穿透，卻也很快被那翻滾的煙柱吞噬，使得整個國子監籠罩在一片晦暗的陰影之中。

杜子敬，這位四十六歲的國子監書庫主簿兼校理，此刻正站在天井邊緣，身形單薄而筆直，宛如一株經霜的古柏。他身上那件洗得發白的青色公服，在熱浪與寒風的交織中輕微顫抖，卻非因寒冷。他的目光，穿透了空氣中瀰漫的焦墨與木炭的刺鼻氣味，死死地盯著火堆。那不是尋常的柴火，而是由無數梨木雕版與宣紙文集堆疊而成的巨大柴薪。火焰貪婪地舔舐著，發出噼啪作響的爆裂聲，每一聲都像是一記重錘，敲擊在他的心房之上。

書庫院的地面上，堆滿了尚未付之一炬的書籍和雕版。一摞摞被繩索捆紮的文集，封面已然泛黃，書脊上用端正小楷寫著「東坡全集」、「山谷詩抄」、「淮海居士長短句」等字樣，如今卻像待宰的羔羊，靜靜地躺臥在塵土之中。這些曾被無數士子奉若圭臬的文化瑰寶，此刻正被一群面無表情的差役和監工粗暴地搬運著，扔進那熊熊燃燒的火舌。梨木雕版厚重，帶著油墨的殘漬，被丟入火中時，發出沉悶的聲響，繼而冒出濃郁的黑煙，那是松香與油墨混合燃燒的獨特氣味，帶著一絲苦澀，一絲不甘。

火光映照著杜子敬蒼白的臉龐，他的雙唇緊抿成一條直線，眼角堆積著細密的魚尾紋，此刻卻更顯深邃。他那雙原本應當飽讀詩書、見慣春秋的眼睛，此刻卻充滿了難以言喻的悲哀與憤怒。二十餘載光陰，他與這些書籍日夜為伴，校勘、整理、謄錄，為它們的存續傾注了半生心血。而今，他卻要親眼目睹它們被付之一炬，這無異於在割他的骨肉，焚他的魂魄。

兩名監火的朝廷命官，侍御史王黼與開封府推官趙良，正負手而立，距離火堆不遠。王黼，身著一襲深紫色官袍，胸前繡著獬豸補子，臉色陰沉，目光銳利如鷹隼。他時不時地掃視著四周，仿佛要從每一個在場的國子監吏員或差役臉上，搜羅出任何一絲不滿或遲疑的痕跡。趙良則相對年輕，但眉宇間卻也透著一股不近人情的冷酷，他手中握著一份卷宗，時不時地翻閱，似在核對清單。他們的存在，如兩座冰冷的石碑，壓抑著現場所有人的呼吸。

「杜主簿，清點如何了？尚餘多少未銷毀？」王黼的聲音帶著一絲不容置疑的威嚴，在火堆的爆裂聲中清晰可聞。他的目光落在杜子敬身上，帶著審視。

杜子敬深吸一口氣，壓下喉間湧上的乾澀與苦澀，拱手作揖：「回稟御史大人，書庫院所藏元祐黨人蘇軾、黃庭堅、秦觀、張耒諸公文集雕版及刊印成書，已盡數清點造冊，待毀者尚餘近百捆雕版，墨寶手稿五箱，刊本六大櫃。今日午時前，當可盡數付之一炬，不留分毫。」他的聲音平穩，沒有一絲波動，仿佛在陳述一件與自己毫不相關的公務。

「很好。」王黼淡淡地應了一聲，目光轉向火堆，嘴角勾起一抹難以察覺的冷笑，「朝廷禁令已頒，天下敢有藏元祐黨人詩文集者，並限百日毀棄，違者以違制論；告發者賞錢百貫，任官者遷一秩。此番焚書，不僅是銷毀逆黨思想，更是對天下士子以儆效尤，免得他們誤入歧途，為逆黨張目。」

趙良在一旁補充道：「自禁令頒布以來，開封府每日接獲告發案牘多達數十起。前日便有太學外舍生陳東，被其同舍生告發私藏黃庭堅墨寶殘卷，言辭鑿鑿，證物確鑿。此等逆黨餘孽，自當嚴懲不貸。」

杜子敬的心猛地一沉，仿佛被一塊巨石砸中。陳東！這個名字在腦海中炸開，激起萬丈波瀾。陳東是太學外舍生，年方二十，卻是個極有才氣的青年。他曾多次向杜子敬請教詩文，對黃庭堅的書法和詩作尤其推崇。杜子敬也曾憐其才華，偶爾指點一二，甚至借閱過一些珍藏的拓本給他。沒想到，告密之風竟已侵入太學，連同舍生之間也未能倖免。

告密！這個詞語在近來已成為汴京城上空最陰冷、最毒辣的烏雲。自從崇寧黨禁以來，朝廷為徹底清除元祐黨人的影響，不惜重金懸賞告發，並許以官職升遷。一時間，京師上下，風聲鶴唳，草木皆兵。市井百姓為了一百貫的巨額賞金，不惜告發鄰里；官僚士大夫之間，更有人為了一秩官位而羅織罪名，攻訐同僚。甚至有奴僕告發主人的案例，使得人倫綱常幾近崩潰。昔日親朋好友之間談詩論道的雅集，如今變成了人人自危的陷阱；曾經的師生情誼，也可能在一夜之間化為你死我活的仇敵。

杜子敬想起昨日夜裡，一名平日裡頗為機敏的書庫小吏悄悄向他稟報，說開封府已派人前來國子監書庫，要求核對一份名單，其中赫然列著陳東之名。那時他心頭便已湧起不祥預感，如今從趙良口中得到證實，這份沉重感便如鉛塊般壓得他喘不過氣來。

若包庇陳東，自己定會被查出，輕則罷官下獄，重則亦被列入「黨人餘孽」，仕途與性命將毀於一旦。他已是知天命的年歲，膝下尚有幼子，家中老母也需奉養，這個代價他萬萬承擔不起。可若坐視陳東被捕，這名年輕太學生的錦繡前程將戛然而止，其下場恐怕比自己更慘。他親眼見過那些被冠以「逆黨餘孽」罪名之人，如何被開封府的差役如拖死狗般押走，如何被投入御史台大獄，遭受非人的折磨，最終或流放，或充軍，甚至有不堪受辱而自縊者。陳東，一個才華橫溢、前途無量的年輕人，怎能就此葬送？

杜子敬的目光掃過堆積如山的書籍，又落向那熊熊燃燒的火堆。火光跳躍，將他的影子拉得頎長而扭曲，仿佛內心掙扎的寫照。他看見一名差役正將一捆捆未經拆封的《山谷全集》丟入火中，那些梨木雕版在火焰中迅速碳化，發出吱吱的哀鳴。一股難以忍受的劇痛，自他胸口深處蔓延開來。

他深知，這些書籍承載的不僅是文字，更是思想，是精神。焚書，焚的不是紙張，而是民族的記憶，是文化的血脈。他身為校理，職責便是守護這些珍貴的文化遺產，如今卻要親手將它們毀滅。這份職責與現實的巨大反差，讓他的心頭如同被萬千蟻蟲啃噬。

「杜主簿，為何發愣？」王黼的聲音再次響起，帶著一絲不悅。他注意到杜子敬臉上那一閃而逝的痛苦神情。

杜子敬猛地回過神來，臉上已恢復了平靜。他瞥了一眼身旁堆放著的「待銷毀」物品，其中有一隻半開的木箱，裡面雜亂地堆放著一些被搜繳上來的物件，有幾本書冊，幾幅字畫，還有一些零碎的筆墨紙硯。他知道，陳東的「罪證」極有可能就在其中。

他緩緩走到木箱旁，假裝清點，實則悄悄用腳撥開了箱子邊緣的幾塊木板，讓箱子內部露出一個縫隙。他的目光快速掃過，在一堆雜物中，他看到了一卷被粗麻繩隨意捆綁的紙軸，紙軸的邊緣已有些磨損，墨色卻是極好。他一眼便認出，這是黃庭堅的墨寶，他曾經在陳東處見過，雖非真跡，卻是極為精妙的手抄摹本，字跡間透著一股傲岸不羈的「山谷體」韻味。這就是趙良口中的「黃庭堅墨寶殘卷」！

他的心跳驟然加速，血液似乎在血管裡奔騰。他必須做出抉擇，而且必須是現在。

「御史大人，推官大人，這堆雕版堆積得太過緊密，恐難燃盡。不如讓下官親自去撥動柴薪，以助火勢。」杜子敬躬身說道，語氣恭敬，目光卻堅定地落在火堆之上。

王黼和趙良對視一眼，並未多想。杜子敬平日裡便以謹慎盡責著稱，此刻提出這點要求，也無甚可疑之處。王黼微微頷首：「可。務必盡速燒盡，不留後患。」

「下官領命。」杜子敬再次拱手，隨即從一名差役手中接過一把長長的鐵質火鉗。火鉗粗糙，握在手中沉甸甸的，散發著冰冷的鐵鏽味。

他緩步走向火堆，每一步都像踩在刀尖上。火焰的熱浪撲面而來，將他臉上的汗毛都烤得捲曲。他感到自己的額頭滲出細密的汗珠，順著鬢角滑落，然而他卻顧不得擦拭。

他小心翼翼地走到木箱旁，彎下腰，假裝用火鉗去撥動箱子底下的幾塊雕版，實則用袖子遮掩，右手迅速伸進箱子，手指精準地勾住了那卷黃庭堅的墨寶殘卷。那紙軸入手微涼，帶著紙張特有的細膩觸感。他幾乎沒有片刻猶豫，在火光與濃煙的掩護下，他猛地將那卷紙軸從箱子中抽出，繼而以迅雷不及掩耳之勢，將其塞進了火堆最旺盛的一處。

「嗤——」一聲輕微的聲響，紙張被火焰瞬間吞噬。墨跡在烈焰中扭曲、蒸發，化為幾縷青煙，隨即徹底消失。那曾被陳東奉若珍寶的墨寶，連同他可能被定罪的證據，就在這轉瞬之間，灰飛煙滅。

杜子敬的動作自然流暢，仿佛真的只是在調整柴薪。他甚至用火鉗輕輕捅了捅那處火焰，讓它燃燒得更加旺盛。做完這一切，他直起身，臉上依舊是那副沉靜而略帶疲憊的神情。

他轉身面向王黼和趙良，拱手道：「御史大人，推官大人，方才下官在清理廢紙時，發現了幾張字跡，筆法頗似黃山谷。但細看之下，墨跡新舊、紙張紋理皆與黃山谷真跡不符，應是太學舍生平日臨摹之作，偶然混入其中，並非逆黨真跡。下官已將其投入火中銷毀，以免有人妄作文章。」

王黼的眉頭微微一皺，目光落在杜子敬的臉上，試圖從中看出些什麼。他注意到杜子敬的額頭有些許汗珠，但這在火堆旁也屬正常。他的語氣依舊冰冷：「哦？杜主簿，你確定是臨摹之作，而非逆黨真跡？」

杜子敬語氣堅定，不卑不亢：「下官在國子監校理二十餘載，經手元祐諸公墨跡無數，對其筆法、紙質、印鑑等細節，自問尚能辨識。此乃校勘廢紙，非逆黨真跡，告密者誣妄圖賞耳。太學舍生年少輕狂，偶有慕古之癖，也屬正常。若因此便將其打為逆黨，未免冤枉。」

他這番話說得滴水不漏，既表明了自己的專業判斷，又暗示了告密者可能存在的私心，同時也為陳東開脫了一線生機。他知道，這番話若在平時，足以引發王黼的雷霆之怒。但此刻，在眾目睽睽之下，在這些「證據」已然銷毀之後，王黼若要追究，也無從查起。他深知這些御史最重「證據」，無證之罪，難以定奪。

王黼的目光在杜子敬身上停留了片刻，最終還是緩緩移開。他雖然心存疑慮，但杜子敬的身份和資歷，加上他剛才的果斷處理，讓他找不到任何破綻。他也不願在這種「小事」上過多糾纏，以免被人說他矯枉過正。

「既然杜主簿如此說，那便作罷。」王黼冷冷地道，語氣中帶著一絲不屑。他顯然不相信杜子敬的「臨摹之作」說法，但證據已毀，他又能如何？他轉身對趙良道：「趙推官，告密之事，仍需嚴查。但凡無憑無據，誣告之人，亦當嚴懲，以正朝綱。」這話一半是做給杜子敬看，一半也是警示那些過於熱衷告密卻又缺乏實證的人。

趙良躬身應道：「下官明白。」

王黼不再多言，他與趙良又監察了一陣，見火勢旺盛，銷毀工作進展順利，便在隨從的簇擁下，帶著一抹冷笑，徑直離去。他們的背影漸行漸遠，最終消失在書庫院的拱門之外。

杜子敬看著他們離去的方向，緊繃的神經終於緩緩鬆弛下來。他感到一陣脫力，雙腿幾乎有些站立不穩。他輕輕放下手中的火鉗，火鉗與地面碰撞，發出輕微的「哐當」一聲，在這片焚書的喧囂中，幾乎微不可聞。

他走到火堆邊緣，蹲下身，伸出手，在灰燼中輕輕撥弄。那灰燼溫熱，帶著一股令人窒息的焦糊味。他低頭搜尋，眼神專注而悲傷。終於，在一堆尚未完全燃盡的木炭與紙屑之中，他撿起了一片巴掌大小的殘頁。那殘頁的邊緣已然焦黑捲曲，大半字跡已無法辨識，但中央卻奇蹟般地殘留著半句墨跡，用瀟灑的行書寫就：

「人生如逆旅，我亦是行人。」

這正是東坡居士那篇《臨江仙·送錢穆父》中的名句。那字跡雖已殘破，卻依舊透著一股超然物外、豁達灑脫的氣韻。杜子敬輕輕摩挲著那片殘頁，指尖感受到紙張纖維的粗糙與焦糊，心頭湧起一股巨大的悲涼。他仿佛看見了蘇軾本人，在被貶謫的路上，在逆境之中，依舊保持著那份詩人的傲骨與情懷。而此刻，他身處這片焚書的火海，又何嘗不是一個「逆旅」中的「行人」？

這片殘頁，是這場文化浩劫中，僥倖存活下來的一縷微光。杜子敬將它小心翼翼地藏入荷包，如同藏匿著一份沉重的誓言。他知道，今日他所做的一切，不過是杯水車薪，無法挽回這場席捲天下的災難。思想與書籍的暴力禁絕，已然將整個士林文化推入了漫長的冰河期。年輕一代的太學生，在告密與恐懼的雙重壓迫下，正在悄然分化。一部分人，如陳東這般，內心的憤懣轉為地下潛藏，如同被壓抑的火山，蓄積著未來爆發的力量；而另一部分人，則徹底倒向了諂媚新貴，學習著如何在權力的陰影下生存，甚至以此為榮。

就在此時，書庫院的拱門外，傳來一陣沉悶而刺耳的聲響。那是鐵鏈拖地發出的「嘩啦啦」的聲響，混雜著粗暴的呵斥與低沉的啜泣。杜子敬抬頭望去，只見開封府的差役們正押解著又一批涉案士子，魚貫而入，他們大多是太學中的學生，面色慘白，雙手被繩索捆綁，神情絕望。他們的目光掃過火堆，掃過杜子敬，眼中充滿了驚恐與不解，最終被差役們粗暴地推搡著，一步步押向拱門之外，那裡通向御史台大獄的黑暗深淵。

杜子敬的目光追隨著那些年輕的背影，直到他們消失在視線盡頭。他知道，這場風暴還遠未結束，而他自己，也只是這場風暴中一個微不足道的參與者。他能做的，或許只有在灰燼中，盡力守護那微弱的火種，等待下一個春天。

本章的核心史實背景是崇寧三年（1104年）宋徽宗頒布的黨禁政策，即對蘇軾、黃庭堅等元祐黨人進行政治清算和文化壓制。根據《宋會要輯稿·崇儒》記載，朝廷嚴令銷毀元祐黨人文集雕版，並禁止天下私藏其詩文集，違者有罪，告發者可獲重賞。這一政策導致了全國範圍內的焚書與告密風潮，對當時的士林文化產生了毀滅性打擊。本章描寫的國子監書庫院焚書現場，以及侍御史王黼、開封府推官趙良的監察，均符合當時的歷史情境。告密之風盛行，賞錢百貫、遷官一秩的獎勵，亦有史料依據。章末提到的御史台大獄，是當時審理政治犯的場所。

**【待核事項】：**
1.  **王黼的官職與歷史活動：** 崇寧三年王黼是否已任侍御史，其在黨禁中的具體角色和表現，需進一步核查《宋史》相關記載。目前設定為侍御史，符合其後來權臣的形象與其心狠手辣的特質。
2.  **趙良的官職與歷史活動：** 開封府推官趙良是否為真實歷史人物，其在黨禁中的參與程度。若無此人，則應標註為虛構人物，或替換為其他符合官階的歷史人物。目前作為虛構人物處理。
3.  **國子監書庫院的具體佈局與焚書流程：** 史料中對焚書地點多有提及，但具體操作流程、監管人員配置、書庫建築格局等微觀細節較為匱乏，本章情節依據合理推演進行描寫。
4.  **蘇軾詩句的準確性：** 「人生如逆旅，我亦是行人。」出自《臨江仙·送錢穆父》，詩句本身無誤。

**【合理推演】：**
1.  **焚書現場的悲劇氛圍與感官細節：** 史料僅載焚書之令，但未詳述現場。本章推演了焚書時的感官體驗——焦墨與木炭的刺鼻氣味、梨木雕版燃燒的噼啪聲、秋風蕭瑟與濃煙滾滾的視覺衝擊，以及在場書吏內心的悲痛與麻木。
2.  **基層書吏的道德困境：** 杜子敬作為國子監書庫主簿兼校理，其職責與內心對文化的敬重，在焚書命令下產生激烈衝突。這種兩難境地是當時許多基層文人共通的遭遇。
3.  **告密風潮的滲透與影響：** 告密不獨發生在官場，更會滲透到太學、市井乃至家庭內部。太學生同舍生之間告密，奴僕告發主人，這些都是在極權統治下，為利所誘、人倫崩壞的合理推演。
4.  **杜子敬的「暗中庇護」行為：** 在嚴密的監管下，杜子敬要銷毀證據，必須藉助其職務之便，並選擇一個恰當的時機和理由。他以「調整柴薪」為由靠近火堆，並巧妙地將「臨摹之作」為藉口，將證據投入火中，並以其校理資歷堵住御史的質疑，符合當時官場的權變邏輯。
5.  **年輕士子的分化：** 在高壓政治下，年輕一代士子必然會出現不同的應對策略：一部分人憤懣轉為地下，另一部分人則選擇諂媚附和新貴，這符合人性在特殊歷史時期的表現。

**【小說虛構】：**
1.  **主要人物杜子敬：** 國子監書庫主簿兼校理杜子敬為虛構人物，其四十六歲的年齡、對書籍的深厚感情、以及在黨禁中掙扎求存並暗中庇護學生的情節，均為小說創作。
2.  **少年陳東：** 太學外舍生陳東為虛構人物，其私藏黃庭堅墨寶並被告發的情節，以及杜子敬對其的庇護，是本章的核心微觀衝突。陳東在此時初入太學，親歷黨禁酷烈，為其日後伏闕請願埋下性格根基，這也是為後續情節埋下的伏筆。
3.  **具體對話與心理描寫：** 杜子敬與王黼、趙良之間的對話，以及杜子敬內心的掙扎、恐懼與悲憤，均為小說虛構，旨在豐富人物形象和情節張力。
4.  **火場銷毀墨寶殘卷的具體操作：** 杜子敬將墨寶殘卷投入火中的動作細節，以及他為此提供的「校勘廢紙」解釋，是為推動情節發展而設計的戲劇性細節。

**【連續性變更】：**
1.  **杜子敬的人物狀態：** 本章結束後，杜子敬雖然成功掩護了陳東，但其內心對黨禁的恐懼與悲憤更深。他從一個單純的書籍守護者，變成了一個在暴政下掙扎求存、並偶爾施以援手的「逆旅行人」。他藏匿的半截東坡詩殘頁，成為他內心精神寄託的象徵。
2.  **士林文化氛圍：** 經此焚書與告密風潮，汴京士林文化陷入冰河期，學術探討與言論自由受到嚴重壓制，人們在公開場合談論詩文時將更加謹慎。
3.  **太學生群體的分化：** 年輕一代太學生在經歷此次黨禁後，其思想、行為方式將出現明顯分化，為後續小說中不同人物的政治立場和命運走向奠定基礎。
4.  **陳東的命運伏筆：** 陳東此次免於被捕，但他對黨禁的親身感受將極大影響其日後的性格發展與政治傾向，為其未來參與政治事件埋下伏筆。

**【後續銜接】：**
1.  **思想控制的持續影響：** 本章結束後，焚書禁言的陰影將繼續籠罩大宋。士子們轉為地下閱讀、私下傳抄，或轉向更加隱晦的文學創作，為後續章節中文化精英的應對方式提供背景。
2.  **告密之風的蔓延：** 告密機制一旦建立，其影響不會短期內消失，將在後續章節中繼續影響社會人際關係與政治氛圍，可能引發更多的人物衝突與悲劇。
3.  **北方邊情單元開啟：** 儘管本章聚焦於內政與文化層面，但「宋末」全書的第1卷作為鋪墊，本章的壓抑氛圍預示著北宋內部的動盪與危機，為接下來的「北方邊情」單元（第019-027章）做好了情緒與政治環境的鋪墊。內部的虛弱與紛亂，會使得北方面臨的外部威脅顯得更加嚴峻。同時，陳東作為太學生，他所經歷的黨禁，也為他日後對國家命運的關切與行動埋下伏筆，可能在未來與北方邊境的事件產生聯繫。
