# 第四十一章　禁書私藏與查抄搜檢

重和元年四月二十日，汴京城籠罩在陰鬱的春雨之中。自辰時起，細密的雨絲便無休止地從鉛灰色的天幕中灑落，將相國寺東夾道兩旁的青石板路浸潤得發亮，也將兩側書肆門楣上懸掛的招牌淋得濕漉漉的。往日裡，這條夾道總是人聲鼎沸，書商的吆喝聲、讀書人的高談闊論、孩童的嬉鬧聲此起彼伏，而今卻一片死寂，只有雨點敲打檐瓦、滴落街面的聲音，間或夾雜著遠處傳來的、令人心膽俱寒的巨響。

胡掌櫃的「翰墨齋」書肆，此刻前廳的門扉緊閉，厚重的杉木門板上，斑駁的朱漆在雨水中顯得黯淡。然而，這層薄薄的木板，此刻卻如同他顫抖的心臟般脆弱。遠處傳來的「砰！」「砰！」「砰！」的重擊聲越來越近，那是開封府與提點刑獄司的差役們，正用鐵尺或木棒粗暴地砸開一間間書肆的門。隨之而來的，是玻璃瓦被震碎的清脆響動，是驚恐的尖叫，是紙張被粗魯撕扯的「嘩啦」聲，以及官差們粗厲的呵斥。

胡掌櫃，一個年過五旬、身形略顯佝僂的男子，此刻正焦躁不安地踱步於書肆後院的密室之中。密室不大，四壁皆是書架，堆滿了線裝、板刻、手抄的經史子集。空氣中瀰漫著舊紙張與淡淡黴味交織的獨特氣息，混雜著窗外滲入的潮濕泥土味。儘管密室內有炭盆烘烤，卻依然擋不住那股自骨髓深處冒出的寒意。他那件褪色的青布襴衫被汗水浸濕，緊貼在背上，而額角卻因緊張而滲出冷汗。

方才，前院的小夥計胡小乙，他那尚未及冠的兒子，隔著厚門板，用一種被壓抑到極致的哭腔稟報：「爹！他們……他們已經到周家筆墨鋪了！周掌櫃被拖出來了，他家的書都被撕碎了，扔得滿街都是！差役們叫罵著『元祐黨人逆書，焚！焚！』」

「禁書私藏，告發者賞銀五十兩，知情不報者，與同罪，刺配沙門島，家產盡沒！」小乙的聲音因恐懼而變調，每一個字都像一柄冰冷的鐵錐，狠狠地扎進胡掌櫃的心窩。

五十兩白銀！那幾乎是尋常人家一輩子的積蓄，足以讓多少人利慾薰心，不惜骨肉相殘。而沙門島，那是比流放更恐怖的去處，傳聞去了那裡，便再無生還之望。

胡掌櫃死死地盯著密室裡唯一一扇緊閉的木門，門後是書肆的主體店堂。他能聽到從那邊傳來的，越來越清晰的嘈雜聲，那不祥的聲響如同死神的鐮刀，在門外磨礪。他的手下意識地摸向腰間懸掛的一串銅錢，那是他一生辛勞的印記，如今卻顯得如此微不足道。

他深吸一口氣，努力平復胸中狂跳的心臟。目光轉向密室中央，那裡堆疊著三隻包袱，用粗麻布細心包裹，形狀方正，顯然是書籍。這便是他此刻最大的禍患，也是他最珍視的寶貝。

那是三部宋初舊槧的蘇軾《東坡策論》。昨日清晨，一位面色青白、衣衫襤褸的太學落魄士子，步履蹣跚地來到翰墨齋。士子面帶菜色，卻雙目有神，懷抱著這三部策論，求胡掌櫃代為脫手。他說這是他祖上代代相傳的孤本，紙張已經泛黃，墨色卻依然清晰。士子言辭懇切，語調中帶著一種近乎絕望的堅韌：「胡掌櫃，此書非為錢財，實為保全先賢文章。亂世將至，士子凋零，朝廷禁錮言路，先賢文字恐將付之一炬。望掌櫃能尋一識貨有心之人，使此策論不至埋沒。」

胡掌櫃當時接過書卷，只覺入手沉甸甸，紙張雖然陳舊，卻有著一種古樸的溫潤感。他小心翼翼地翻開一頁，墨香中帶著歲月的氣息撲面而來，那是幾百年前大儒的筆觸，字字珠璣，透著清朗與坦蕩。此等舊槧孤本，價值連城，更何況是蘇文。他本打算將其暫時收下，待風頭略緩再做打算。誰料，朝廷的「搜禁私書令」竟在今日重和元年四月二十日，以雷霆之勢，降臨汴京。

這不是第一次。自元祐年間以來，朝廷對元祐黨人的學術與文集便屢次頒布禁令。從最初的刻板銷毀，到後來的凡坊刻元祐文字一律沒收銷毀，再到如今的重和元年，禁令更是嚴苛到令人髮指的地步。凡私藏者，皆以重罪論處。這三部《東坡策論》，便是那條紅線，將胡掌櫃一家人的性命，以及他一輩子守護的文化，都綁在了懸崖邊緣。

胡掌櫃伸出粗糙的手，輕輕撫摸著其中一個包袱。麻布之下，他似乎能感受到那古老紙張的紋理，感受到字裡行間蘊含的、不屈的文人風骨。若交出書本，自己或許能免罪，但這批士人泣血保留的原典，這些承載著先賢思想的文字，將在火光中化為灰燼，連同那太學士子最後的寄託。若匿而不報，一旦查獲，全家老小……刺配沙門島，家產盡沒。

他緊閉雙眼，腦海中浮現出妻子蒼老的容顏，小乙天真卻又帶著恐懼的眼神，還有他自己經營了三十餘年的翰墨齋，那些堆積如山的書籍，那些他親手刻印、裝幀的書冊。他這一輩子，都在與墨香、紙張、文字打交道。他見證了多少文人的喜怒哀樂，多少書籍的興衰沉浮。如今，他自己也成了這場文化浩劫中的一粒微塵。

「爹！他們已經到咱們巷口了！隔壁張家的門板都砸破了！」小乙的聲音帶著哭腔，從門縫裡鑽進來，像一道驚雷，徹底擊碎了胡掌櫃的猶豫。

他猛地睜開眼睛，眼中閃過一絲狠厲。不！不能讓這些書落入那些爪牙之手！這是文脈，是士子的命，也是他胡家的道義！

「小乙！你聽著！」胡掌櫃壓低聲音，聲音卻因決絕而顯得異常堅定，「你速去後院柴房，將那堆枯柴堆得高一些，然後用火鐮點燃！記住，不要燒得太猛，要讓煙大，火光要亮！然後你就大聲呼喊『走水了！走水了！』」

小乙在門外愣了一下，顯然沒料到父親會下這樣的命令。火，在這雨天裡，是個危險的字眼。
「爹！那……那會燒到屋子嗎？」他的聲音顫抖。
「照我說的做！這是唯一的機會！」胡掌櫃厲聲喝道，語氣中不容置疑。他知道，在這種情形下，必須速戰速決。官差們搜查違禁書籍，而火災，則是最能吸引他們注意力的意外。他們或許會因為火災而暫緩搜查，或者將重心轉移到救火上。

小乙不敢再問，只得應了一聲，腳步聲匆匆離去。

胡掌櫃不再耽擱，他迅速躬下身，抱起那三隻包袱。沉甸甸的重量，此刻卻成了他唯一的希望。他走向密室牆角，那裡有一塊不起眼的青石板。他用手摸索著石板邊緣，摸到一個隱蔽的鐵環，使勁一拉，青石板便緩緩挪開，露出一個漆黑的洞口。洞口下方，赫然是一口枯井，井壁上鑿有幾級簡陋的踏腳，顯然是經過精心改造的暗道。

這是胡家祖傳的秘密。當年靖康之變時，胡家先祖便是靠著這口枯井，才將家族珍藏的善本避過了金兵的劫掠。如今，這口枯井，又要再次承載起沉重的使命。

「砰！」一聲巨響，前院的書肆大門被差役們一腳踹開，木屑飛濺。緊接著是幾聲粗野的謾罵，以及書架被推倒的轟然巨響。胡掌櫃的身體猛地一僵，心臟幾乎要跳出胸腔。他知道，時間已經不多了。

他抱著書包，深吸一口氣，一咬牙，將其中一隻包袱遞入洞中，然後小心翼翼地踩上第一級踏腳。井壁濕滑，散發著一股陳年的泥土和腐爛葉片的氣味。他顧不得這些，將懷中的另兩隻包袱也塞入洞中，然後躬身，將自己肥胖的身軀也擠了進去。

枯井底部的空間不大，但足以容納一個人盤坐。泥濘的井底鋪著一層厚厚的枯草，用以吸潮。胡掌櫃將三隻包袱緊緊地抱在懷裡，生怕它們沾染到一絲一毫的水汽。他背靠著冰冷的井壁，透過青石板的縫隙，努力辨認外面的動靜。

從井口傳來的聲音變得混亂而嘈雜。前院店堂裡，差役們粗暴的翻檢聲、撕扯書頁的「嘩啦」聲，以及小夥計們被嚇得噤若寒蟬的低泣聲，清晰地傳入他的耳中。

「這些都是甚麼破爛玩意兒！《孟子》、《論語》？這些老掉牙的東西還有甚麼用！」一個粗野的聲音叫罵著。
「找那些『元祐』的！蘇黃秦蔡！這些才是要緊的！」另一個聲音附和道，伴隨著書本被扔在地上的沉悶響聲。

胡掌櫃的手緊緊地握著，指節因用力而泛白。那些被他們視為「破爛」的，是聖賢的智慧，是文明的基石！他閉上眼睛，強忍著衝出去與他們理論的衝動。他不能，他還有更重要的東西要守護。

就在此時，後院傳來一聲尖銳的喊叫：「走水了！走水了！柴房走水了！」是小乙的聲音，帶著恰到好處的驚恐與慌亂。

緊接著，一股濃煙順著風，從後院的方向飄了過來，帶著焦木的氣味，刺激著胡掌櫃的鼻腔。

「甚麼？！走水了？！」前院的差役們似乎也聽到了。
「他娘的！這當口還能走水！快去看看！」
「狗日的，要是燒了老子們的公文，看你們吃幾板子！」

一陣急促的腳步聲從前院向後院奔去，伴隨著呼喝聲。胡掌櫃聽到水桶被撞倒的聲音，以及差役們叫罵著讓小乙去打水的命令。他知道，他的計策奏效了。

他緊貼著井壁，努力讓自己的呼吸變得平穩。井底的黑暗與潮濕，此刻反而給了他一絲安全感。他能聽到頭頂的青石板上，有官差的腳步聲來回走動。他們似乎在討論著什麼，聲音模糊不清。

過了一炷香的時間，火勢似乎被控制住了。焦煙味漸淡，取而代之的是水澆在火上的「滋啦」聲，以及一陣陣的泥土腥氣。

「他娘的，一個柴火堆也敢點成這樣！」一個官差的聲音顯得不耐煩，「這般雨天，還能走水，真是見鬼了！」
「說不定是這廝故意的，想趁亂藏匿禁書！」另一個聲音充滿了警惕。
「搜！把這後院也給老子搜仔細了！看看還有甚麼機關！」

胡掌櫃的心又提到了嗓子眼。他屏住呼吸，連大氣都不敢出。他能聽到井口上方的青石板發出輕微的摩擦聲，似乎有人正用腳踩踏著，試圖尋找什麼。

「這塊石頭有些鬆動……」一個聲音低語。
胡掌櫃全身肌肉緊繃，冷汗再次滲出。他緊緊抱住懷中的書，彷彿那便是他身體的一部分。若此刻被發現，那一切都將前功盡棄。他甚至能聽到自己心臟在胸腔中劇烈跳動的聲音，在寂靜的井底顯得格外清晰。

「胡掌櫃！你他娘的給老子出來！」一個粗啞的聲音從井口上方傳來，帶著威脅。
胡掌櫃不敢應聲，他知道這是試探。

「別瞎折騰了！」另一個略顯沉穩的聲音響起，似乎是帶隊的開封府右巡使，「一個破柴火堆，雨水這麼大，燒也燒不起來！我看八成是這小子（指胡小乙）不小心。」
「大人，那這家書肆……」
「前頭都搜過了，除了這些《論語》《孟子》的酸腐書，沒見著什麼元祐逆書。想是這廝膽小，早便燒了或者藏了。這等小門小戶的，能有甚麼稀罕物？」右巡使的語氣帶著不屑。
「那這柴火錢，還有我等救火的辛苦錢……」一個差役搓著手，露出了貪婪的本性。

胡掌櫃從井底聽得清清楚楚。這是他們慣用的伎倆，藉著搜查的名義，訛詐錢財。他心中一陣肉痛，卻又鬆了口氣。只要書沒被發現，錢財便是小事。

「去，叫那胡掌櫃出來，讓他們家拿三十貫錢出來，算是給弟兄們的辛苦錢，再賠償周遭鄰里一些損失。否則，今日便將你們這書肆一把火燒了！」右巡使的聲音帶著威脅。

過了一會兒，胡掌櫃聽到小乙帶著哭腔，哀求著說父親不在。然後，他聽到一陣翻箱倒櫃的聲音，顯然是差役們在前院和後院搜刮財物。不多時，又聽到小乙委屈地說：「爹的錢匣子裡，只有三十貫零錢了……」

「哼！算你識相！」右巡使冷哼一聲，聲音漸遠，「走！去下一家！」

腳步聲、嘈雜聲、雨聲，漸漸遠去，直至完全消失。胡掌櫃在井底又等了一炷香的時間，直到確定外面再無任何動靜，他才敢緩緩地動了動身子。他的手臂因為長時間抱著書而發麻，雙腿也因為蜷縮而僵硬。井底的濕冷透過薄薄的衣衫，滲入骨髓。

他費力地抬起頭，透過青石板的縫隙，看到外面天色已然昏暗，雨依然淅淅瀝瀝地下著。他小心翼翼地推開井口的青石板，一股泥土和潮濕的空氣撲面而來。他探出頭，四下張望，確認後院空無一人。

然後，他將懷中的三隻包袱小心翼翼地放在井口，又用盡全身力氣，將自己肥胖的身軀從枯井中拔了出來。他的青布襴衫被井泥浸透，沾滿了黑色的泥漿，頭髮凌亂，臉上混雜著雨水、汗水和泥點，狼狽不堪。

他顧不得身上的泥污，第一時間抱起那三隻包袱。他小心翼翼地解開麻布，露出裡面的書籍。萬幸，紙張沒有被水打濕，墨跡依然清晰。他用顫抖的手，輕輕撫摸著《東坡策論》的封面，指骨慘白如雪。

濕冷的風吹過，胡掌櫃打了個寒顫。他抬頭望向陰沉的天空，雨幕中，遠處相國寺的飛檐輪廓模糊。他知道，今日所經歷的一切，不過是這場浩劫的開端。那些被撕碎的書頁，那些被焚毀的文字，那些被恐懼籠罩的人心，都將在漫長的歲月中，留下不可磨滅的印記。而他，一個小小的書肆掌櫃，在今日，用三十貫銅錢和一場精心策劃的火災，守住了這微弱的火種。他不知道未來還有多少這樣的日子，但他知道，只要他活著，只要翰墨齋還在，他就必須繼續守護這些文字，守護這片文脈。

## 章後工作紀錄

**【史實骨架】：**
本章的核心史實背景是宋徽宗朝對元祐黨人學術與文集的持續性禁錮與搜查沒收。根據《宋會要輯稿·崇儒》等文獻記載，自元符年間至宣和年間，朝廷多次頒布禁令，禁止坊刻和私藏元祐黨人的著作，尤其是蘇軾、黃庭堅等人的文章。重和元年（1118年）前後，對禁書的查禁尤為嚴厲，甚至發布了「搜禁私書令」，懸賞告發，並對私藏者處以重罰，如刺配沙門島。章中提及的開封府和提點刑獄司的差役聯合執法，以及對違禁書籍的當場銷毀，均有史料依據。賞銀五十兩的數額，在當時確屬巨額，足以引發告密風潮，體現了朝廷禁絕元祐學術的決心。

**【待核事項】：**
1.  **具體日期及事件細節**：本章將重和元年四月二十日（1118年5月12日，己卯日）作為查抄事件的具體發生日期。雖然史料記載了徽宗朝多次禁書，但並未精確到某年某月某日全國範圍的大規模查抄。此處的精確日期是為小說敘事服務，增加歷史現場感。
2.  **官職與權限**：開封府右巡使在查抄行動中的具體職權與提點刑獄司差役的協同模式，需進一步考證其在當時的實際操作流程與權限劃分。
3.  **枯井暗洞的普遍性**：宋代民居中設置枯井密室以避難藏物的普遍性與可行性，以及其構造細節。雖然靖康之變時民間藏匿財物、書籍的現象普遍存在，但具體形式需進一步考證。
4.  **火災引開查抄的可行性**：在官方嚴密查抄的背景下，一場人為的「火災」是否能有效分散官差注意力並成功讓其放棄深度搜查，尤其是在下雨天。這需要考慮當時官府對火災的重視程度與查禁禁書的優先級。

**【合理推演】：**
1.  **基層民眾的應對**：在嚴酷的文化專制下，普通書商如胡掌櫃，面對朝廷的禁書令，不可能坐以待斃。本章推演了其利用火災製造混亂、轉移官差注意力的策略，並結合其祖傳的枯井密洞進行藏匿。這反映了基層民眾在巨大壓力下的求生本能與智慧。
2.  **資訊傳播與民間反應**：禁書令的頒布與執行速度之快，導致許多書商措手不及。太學士子在禁令前夕託售舊槧，顯示了知識分子對文化傳承的憂慮與對朝廷政策的預感。胡掌櫃在收到消息後，迅速做出判斷並採取行動，也符合當時資訊傳播的特點（口耳相傳、快速蔓延的恐懼）。
3.  **官員的腐敗與勒索**：右巡使在未發現禁書後，仍以「辛苦錢」為由勒索三十貫私錢，這是對宋代官吏腐敗現象的合理推演。在嚴苛的政治氛圍下，基層官吏往往利用職權便利，敲詐勒索，以彌補自身利益。三十貫銅錢在當時雖非天文數字，但對一個書肆掌櫃而言，也是一筆不小的損失。

**【小說虛構】：**
1.  **主要人物**：胡掌櫃及其子胡小乙，均為虛構人物，用以代表在宋徽宗朝禁書背景下，掙扎求存的文化業者群體。
2.  **具體情節**：胡掌櫃利用柴火失火引開官差視線，以及跳入枯井暗洞藏匿《東坡策論》的具體行動，均為小說虛構的戲劇性細節。
3.  **特定書籍**：三部「宋初舊槧蘇軾《東坡策論》」的具體來源（太學落魄士子託售）和數量，是為強化情節衝突與人物動機而設計的。
4.  **平民護道群像**：胡掌櫃以身犯險保護禁書的行為，是虛構的「平民護道群像」的一個縮影，旨在展現民間力量在文化專制面前的堅守。

**【連續性變更】：**
1.  **胡掌櫃的狀態**：本章之前，胡掌櫃可能是一個相對安穩的書肆掌櫃。經歷此次事件後，他從一個恐懼、猶豫的狀態，轉變為一個堅定、決絕的文化守護者。他的身體受到井泥浸染，精神上則遭受了極大的創傷和考驗。
2.  **經濟狀況**：翰墨齋因被搜查而店堂受損，並被勒索三十貫私錢，其經濟狀況受到一定打擊。這筆錢對書肆而言是不小的損失。
3.  **藏書狀態**：之前在密室中的三十部蘇文、黃詩及《元祐實錄》手抄本，經過本章事件，已全部安全轉移入地窖，躲過查抄。這改變了翰墨齋的藏書風險等級。
4.  **心理影響**：此次事件在胡掌櫃及其家人心中種下了不可磨滅的恐懼與對朝廷的背叛感。小乙的恐懼也預示著他將在這種陰影下成長。

**【後續銜接】：**
1.  **地下抗衡的伏筆**：胡掌櫃成功匿藏禁書，預示著民間對禁書的渴求與官府的查禁將形成長期而隱蔽的地下抗衡。這為後續小說中文化傳承的艱難與地下文脈的延續埋下伏筆。
2.  **文化專制的深遠影響**：本章結尾胡掌櫃的疲憊與堅守，反映了文化專制對個體命運的深刻影響，以及其在城市市民與出版業者心中種下的恐懼。這將在後續章節中，通過其他人物的視角，繼續展現大時代風雲如何滲透並主宰市井小民的命運。
3.  **書籍的價值與未來**：這些被胡掌櫃冒死保護的書籍，將在未來的亂世中扮演重要角色，它們可能成為啟迪思想的火種，也可能成為引發新衝突的導火索。這為後續章節中對這些書籍的再次提及或其影響力的展現做了鋪墊。
