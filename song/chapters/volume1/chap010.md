# 第十章　建中調和的試探

建中靖國元年正月十五日，上元夜。

汴京宣德門外，百萬盞彩燈如潮水般湧動，將整個夜空映照得亮如白晝。鰲山彩燈高聳入雲，其上瓊樓玉宇，仙子弄影，流光溢彩，引得無數士民競相駐足。管弦絲竹之聲，伴隨著歡聲笑語，如浪濤般越過高聳的宮牆，隱約傳入深宮。然而，在這片盛世歡騰的背景下，垂拱殿東廡的宣敕房內，燭火搖曳，映照著一室如臨大敵的沉重氣氛。

崔文弼，中書舍人兼起居舍人，年過不惑，臉上已顯出歲月磨礪的痕跡。他身著一襲深紫色官袍，端坐在案前，身形挺拔卻略顯疲憊。桌案上堆疊著尺牘與筆墨，墨香與燈油的氣味混雜，在微冷的空氣中瀰漫。他的目光落在鋪陳開的素白詔紙上，其上寥寥數語，正是他今夜必須完成的「召還元祐舊臣恩詔」的開頭。

窗外雖有喧鬧，但此處卻是靜默得針落可聞。只有崔文弼筆尖在紙上輕輕劃過，偶爾發出沙沙聲。他時而蹙眉沉思，時而提筆欲書，卻又輕輕放下。這不是一份普通的詔書，它承載著新皇欲「建中靖國」、調和黨爭的期望，卻也暗藏著兩黨宰執之間最為尖銳的攻防。

自先帝哲宗駕崩，徽宗趙佶即位以來，朝中氣象便有了微妙的變化。向太后雖已撤簾，但其對元祐舊臣的憐恤之心人盡皆知。新皇趙佶年少登基，急於展現自己的治國方略，其親筆手詔上「建中無偏」四字，便是對崔文弼這等執筆者的最高旨意，也是最沉重的枷鎖。

“建中無偏……”崔文弼在心底默念這四個字，只覺其重如千鈞。何謂無偏？在黨爭撕裂朝野十數載的今日，任何一句話，任何一個字，都可能被解讀出偏向。

桌案右側，筆架上掛著數支狼毫，筆洗中積著殘墨。崔文弼拿起一支筆，蘸了蘸墨，又緩緩放下。他看著眼前這張白紙，仿佛能看到其上隱藏著無數雙眼睛——有太后的慈祥目光，有徽宗的年輕銳氣，更有曾布與韓忠彥兩位宰執審視的利刃。

曾布，新黨魁首，深諳政治權謀，執掌樞密院，其勢力不容小覷。韓忠彥，雖是舊黨出身，卻也深知朝局複雜，力主召還元祐舊臣，以求朝政清明。兩人雖同列宰執，政見卻南轅相徑，此番恩詔，便是兩人明爭暗鬥的焦點。

“舍人，韓相公處又來了條子。”

一個年輕的小吏，輕手輕腳地走進房內，將一張折疊得整整齊齊的紙條恭敬地放在崔文弼的案頭。小吏面色有些蒼白，顯然是從外面的寒風中趕來，衣領上還沾著細小的雪珠。他瞥了一眼崔文弼凝重的臉色，旋即低下頭，不敢多言。

崔文弼輕輕點頭，示意小吏退下。他拿起那張條子，展開。紙條上墨跡未乾，字跡清勁有力，顯然是韓忠彥的心腹親筆所書：“……元祐舊臣，如司馬光、范純仁、呂公著等先賢，皆國之棟樑，不應止於貶謫。宜盡數昭雪，復其官爵，以彰顯朝廷撥亂反正之心。蘇軾、蘇轍兄弟，文章蓋世，忠心可鑒，速召回京，委以重任……”

崔文弼的眉頭擰得更緊了。韓忠彥的意思，是要求詔書中明確肯定元祐諸臣的功績，甚至推翻對他們的定性。這幾乎是在直接挑戰先帝神宗的「紹述」之法，也必然會觸及曾布的底線。

他將條子放在一旁，目光重新回到詔紙上。他此前已擬了幾句開場白，旨在以平穩的語氣陳述徽宗登基，欲革新弊政的決心。但這幾句，遠不足以平息兩黨之爭。

片刻之後，房門再次被輕輕叩響。這次進來的是另一個年紀稍長的小吏，他遞上一張條子，臉上帶著幾分不易察覺的傲慢，低聲道：“舍人，曾相公有話。”

崔文弼知道，這是曾布的心腹，多半是樞密院的人。他接過條子，展開。上面的字跡則顯得遒勁鋒利，字裡行間透著不容置疑的堅決：“……先帝神宗之法，乃祖宗之法脈所繫，豈可輕言廢棄？元祐黨人，固然有其才學，但其亂政之實，亦不可掩。若專用舊人，即是毀謗先帝，動搖國本。詔書中務必強調‘紹述’，對元祐諸臣，可恤其勞苦，不可言其是非曲直，更不可全盤推翻前朝定論。”

這條子的內容，與韓忠彥的訴求幾乎是針鋒相對。曾布的立場非常明確：可以召回，可以給予一定補償，但絕不能承認他們是「正確」的，更不能否定神宗的改革。這「紹述」二字，便是新黨的命根子。

崔文弼閉上眼睛，深吸一口氣。他感到一陣陣的寒意從心底升起，並非來自上元夜的寒風，而是來自這無聲的政治刀光劍影。他想起多年前，新舊黨爭正酣時，多少官員因為站隊錯誤，或言辭不慎，而慘遭貶謫，甚至家破人亡。自己能穩坐中書舍人之位，靠的正是謹言慎行，以及在文字上求取最大公約數的能力。

此刻，他的命運，乃至於未來幾年朝廷的走向，都繫於他筆下這幾張薄薄的詔紙。若偏向韓忠彥，曾布掌管的樞密院日後定會阻礙其遷轉，甚至尋機報復；若偏向曾布，向太后雖已撤簾，但其餘威尚在，恐獲罪內廷，斷送仕途。而徽宗那句「建中無偏」，則像一把懸在頭頂的劍，逼迫他必須走出一個左右逢源的平衡之道。

他拿起狼毫筆，沾飽了墨。墨汁濃郁，帶著淡淡的松煙香。他凝視著詔紙，開始在心底默默構築句子。

首先，要肯定新皇登基的祥和氣象，以及其「建中靖國」的宏偉抱負。這是任何一方都無法反對的。
“朕惟皇帝嗣位以來，海宇清寧，萬物咸亨。夙夜孜孜，思所以廣德澤、睦人群者……”

然後，要提及先帝哲宗的德政，這是新黨的立場，也是必須尊重的。「紹述」的意味不能太強，但也不能沒有。
“追維先帝，廣開言路，勵精圖治，政績昭然，功德在民……”

接著，便是重頭戲，如何處理元祐舊臣。崔文弼的策略是「只敘遷謫勞苦，不言是非曲直」。這是一種春秋筆法，盡可能模糊化政治判斷，而將重點放在對個人遭遇的恤免上。

他筆走龍蛇，在紙上寫道：
“……然自時勢變遷，政事迭興，或有賢才宿學，因循流轉，久處邊陲，未得盡展所長。念及彼等，歷經風霜，老病侵尋，忠心未改，實為可憫。朕體恤萬民，不忍賢才埋沒，故思廣布恩澤，以彰仁恕之治。”

寫到這裡，他停頓下來，仔細審視。
「時勢變遷，政事迭興」，這句話很巧妙。它沒有指明是何種「變遷」，何種「政事」，既可以指元祐年間的政事，也可以指哲宗年間的政事。將其歸咎於「時勢」，則淡化了人為的過錯。
「賢才宿學，因循流轉，久處邊陲」，這說的是元祐舊臣的現狀，強調了他們的「才學」與「忠心」，又描述了他們的「勞苦」，這正是韓忠彥所要求的「恤其勞苦」。
「不忍賢才埋沒，故思廣布恩澤，以彰仁恕之治」，這則是從皇帝仁德的角度出發，顯示了新皇的寬宏大量，符合「建中無偏」的旨意。

但這還不夠。必須在不提及「元祐」二字的前提下，讓讀者心知肚明是指元祐舊臣。
他繼續寫道：
“……凡元祐以來，因事罷官、遠謫邊郡者，不論新舊，悉予寬宥。其官職年老者，可聽致仕，仍給俸祿。其尚可任事者，量才錄用，以充朝班。其已故者，追復官爵，其子孫若有賢才，亦可酌情錄用。”

「不論新舊」四字，是崔文弼深思熟慮後加上去的。這既照顧了新黨對「元祐黨人」標籤的敏感，又暗示了召回的對象主要就是那些被貶謫的舊黨官員。
「其官職年老者，可聽致仕，仍給俸祿」，這是在物質上給予補償，減少了他們重回朝堂可能帶來的政治衝擊。
「其尚可任事者，量才錄用，以充朝班」，則為蘇軾、蘇轍這些有聲望有能力的舊臣留下了復出的空間。
「其已故者，追復官爵，其子孫若有賢才，亦可酌情錄用」，則顯示了對已故元祐舊臣的追恤，這也是韓忠彥所要求的。

崔文弼讀罷，心頭稍定。這段文字，字字斟酌，句句推敲，看似平淡無奇，實則暗藏玄機。它沒有直接肯定元祐的政策，也沒有否定神宗的「紹述」，只是從皇帝的仁德出發，寬恤那些因「時勢變遷」而「勞苦」的官員。這應當是目前能找到的最大平衡點。

然而，他知道，這還遠未結束。恩詔的細節，尤其是針對具體人物的封爵定語，才是真正的戰場。

果然，又有小吏陸續送來數張條子。
“舍人，韓相公處問及蘇學士的定語，可否加上‘文章冠世，忠義炳然’？”
“舍人，曾相公處言，蘇軾曾有諷刺先帝詩作，不可過譽，務求平實。”
“舍人，韓相公處請示，對司馬光、范純仁等已故宰執，可否追贈太師、太傅？”
“舍人，曾相公處強調，追贈官爵不可逾制，且需考慮其生前功過……”

每一張條子，都像是一把利刃，刺向崔文弼心頭。他感覺頭痛欲裂。窗外傳來的喧鬧聲，此時聽來卻格外刺耳，仿佛在嘲笑這宮牆之內的爾虞我詐。

他知道，這些條子並非是宰執們親自寫的，而是他們的親信舍人或書記，根據宰執們的意圖，代為傳達。這些人，也都是為了自己的前程，在努力替主子爭取利益。

崔文弼放下筆，揉了揉發脹的太陽穴。他命人端來一盞清茶，熱氣騰騰的茶水，卻無法驅散他內心的寒意。他抬頭望向窗外，宮燈的光芒透過半透明的窗紙，將宣敕房內映照得影影綽綽。遠處，依稀能看到鰲山彩燈的頂部，在夜空中閃爍著迷人的光暈。

那是一個盛世的表象，而他此刻所處的，卻是盛世之下暗流湧動的漩渦。

他召來小吏，低聲吩咐：“去回稟韓相公處，恩詔旨在大體，具體謫官復職，當有後續細則條例，屆時再議定語。至於追贈，亦需依慣例，待朝議再定。”
他又吩咐另一位小吏：“去回稟曾相公處，恩詔旨在寬恤，非在褒貶。所有定語皆力求中和，不逾法度。追贈之事，亦將嚴循舊制。”

這一番話，說得滴水不漏。他將具體的人事定奪，推遲到恩詔頒布之後的「細則條例」與「朝議」，巧妙地避開了此刻的鋒芒。這既給了兩派一個模糊的承諾，又避免了在詔書正文中留下任何可能被攻擊的把柄。

然而，他心知肚明，這只是暫時的緩兵之計。真正的鬥爭，將在恩詔頒布後的朝堂上，以更加激烈的方式展開。而他，作為恩詔的起草者，也必然會受到各方的審視。

他再次拿起筆，將最後一段文字補齊：
“……朕願與天下士民，同心同德，共建昇平。凡我群臣，當體朕意，捐棄宿怨，戮力同心，以匡扶社稷，共致治平。”

這段結語，再次強調了「建中靖國」的總體目標，呼籲群臣放下黨爭，共同為國效力。

崔文弼仔細檢查了詔書的每一處文字，確保沒有任何遺漏或錯謬。墨跡已乾，字跡工整，整篇詔書讀來流暢自然，不偏不倚，仿佛真是一位超然物外、只為天下蒼生著想的皇帝所言。

他長舒一口氣，心頭的重擔卻並未完全卸下。這份詔書，能否真正達到「建中無偏」的效果，他沒有把握。他只知道，這是他窮盡心力，在刀尖上跳舞，所能寫出的最好答案。

他將詔書小心翼翼地捲起，用一條明黃色的絲帶輕輕繫好。然後，他起身，將詔書鄭重地交給一直等候在門外的內侍省小黃門。

“速呈入內東門，請官家御覽。”崔文弼沉聲道。

小黃門應了一聲“喏”，便捧著詔書，小跑著消失在昏暗的宮道盡頭。崔文弼看著他遠去的背影，聽著腳步聲漸漸微弱，最終消失，房內再次恢復了寂靜。

他重新坐回案前，疲憊地閉上眼睛。此刻已是深夜，窗外的喧鬧聲漸漸微弱，但遠處隱約傳來的幾聲爆竹，卻仍提醒著他，今夜是上元佳節。而他，卻在宮牆之內，經歷了一場無聲的戰役。

時間一分一秒地過去。半個時辰，仿佛一個世紀那麼漫長。崔文弼感到全身的力氣都像被抽乾了，他甚至不敢去喝那盞已經涼透的茶水。他知道，這半個時辰裡，這份詔書，正在決定著許多人的命運，也包括他自己的命運。

終於，急促的腳步聲再次響起，由遠及近。小黃門氣喘吁吁地跑回來，手中捧著那份詔書，臉色有些異樣。

“舍人……”小黃門的聲音有些發顫。

崔文弼的心猛地一沉。他知道，這不是一個好兆頭。他伸手接過詔書，展開。

詔書上，他親筆寫下的文字依舊工整，但卻在末尾處，多了一行用硃筆批寫的小字。那是官家的字跡，筆勢流暢，卻帶著幾分不羈的銳氣。

崔文弼定睛一看，那行小字赫然寫著：

**“文字雖順，氣象萎靡。朕聞杭州有蔡京者，才具練達，何以無人薦舉？”**

“轟隆”一聲，仿佛一道驚雷在崔文弼耳邊炸響。他手中的詔書幾乎拿捏不住，指尖都在顫抖。他感覺一股寒氣從腳底直衝天靈蓋，後背瞬間被冷汗浸透。

氣象萎靡？這四個字，分明是對他這番苦心孤詣、力求平衡的努力，最直接的否定。而更讓他感到心寒的，是那句突如其來的“杭州有蔡京者”。蔡京此時不過是知杭州，一個外放的地方官，論資歷、論聲望，都不足以與朝中宰執比肩。但官家此刻卻突然提起他，其用意何在？

崔文弼猛然想起，蔡京向來以善於逢迎、能言善辯著稱，且與內侍童貫交好。童貫此時正以供奉官身份在杭州採訪圖畫……

他感覺一陣暈眩。這份他耗盡心血、自以為周全的「建中調和」之詔，竟被官家批作「氣象萎靡」，更在字裡行間流露出對現有宰執的不滿，甚至暗示了對蔡京這樣一個不為兩黨所容之人的興趣。

這意味著什麼？意味著官家想要的，並非是溫吞的調和，而是更具魄力、更為決斷的手段。意味著他所做的所有平衡，在官家眼中，不過是畏首畏尾的表現。

崔文弼的視線落在詔書上，那硃批的字跡仿佛帶血，刺痛了他的雙眼。他意識到，自己自以為的「平衡」，或許從一開始就錯了。官家想要的，根本不是什麼「建中無偏」的左右逢源，而是獨斷專行、大權獨攬。而他，不過是被官家拿來試探朝野反應的一顆棋子罷了。

這個上元夜，宮牆之外是萬民同樂，而宮牆之內，卻是冰冷的權力遊戲。崔文弼看著那行硃批，只覺前路茫茫，心如死灰。

## 章後工作紀錄

### 【史實骨架】：
本章情節緊密圍繞建中靖國元年（1101年）正月十五日上元夜這一時間點展開。核心事件是徽宗即位後，在向太后與兩位宰執（曾布、韓忠彥）的影響下，試圖調和新舊黨爭，召還元祐舊臣的「恩詔」起草過程。
1.  **時間地點**：建中靖國元年正月十五日，汴京皇宮垂拱殿東廡宣敕房。
2.  **核心事件**：起草「召還元祐舊臣恩詔」。
3.  **主要人物**：徽宗趙佶（手詔「建中無偏」及硃批）、向太后（影響力）、曾布（新黨宰執）、韓忠彥（舊黨宰執）、蔡京（知杭州，欲謀起復）、童貫（供奉官，在杭州）。
4.  **歷史背景**：哲宗駕崩，徽宗即位，向太后垂簾雖退但餘威尚在。韓忠彥為舊黨代表，主張全盤昭雪元祐舊臣，召還蘇軾、蘇轍等。曾布為新黨代表，堅守「紹述神宗之法不可廢」，反對推翻前朝定論。
5.  **徽宗態度**：初登基時，徽宗確實有調和新舊黨爭的意圖，但其「建中無偏」的指示，既是期望，也反映了他對文臣掣肘的不耐，最終體現在對崔文弼詔草的硃批上。
6.  **蔡京與童貫**：史載蔡京此時確在杭州，並極力結交赴杭州採訪圖畫的供奉官童貫，謀求向徽宗及內廷進言，為自己起復鋪路。徽宗在詔草上的硃批，正是蔡京影響力初步顯現的徵兆。
（參考：《續資治通鑑長編》相關記載，尤其是建中靖國元年正月至二月間的政治動向和人物互動。）

### 【待核事項】：
1.  **宣敕房的具體職能與人員配置**：中書舍人起草詔書時，除了小吏協助傳遞條子外，是否有其他更高級別的官員在場？或僅為中書舍人單獨執筆？本章設定為中書舍人單獨執筆，小吏協助，以強化其個人壓力。
2.  **宰執傳遞「條子」的具體流程與頻率**：條子傳遞的頻繁程度、內容的詳細程度，以及是否由宰執親信直接送達，在本章中進行了合理推演，以增加緊張感。
3.  **恩詔的具體措辭慣例**：對於「元祐舊臣」的稱謂、貶謫理由的表述，以及召還、追贈的定語，如何做到「無偏」且符合當時制度？本章的措辭已盡力貼合「只敘遷謫勞苦，不言是非曲直」的原則。
4.  **徽宗硃批的習慣與風格**：徽宗是否習慣在詔草上直接批示，以及其批示的語氣和內容，本章的「氣象萎靡」和提及蔡京，符合其初登基時對朝政的掌控欲和對不同人才的關注。

### 【合理推演】：
1.  **中書舍人面臨的兩難**：在宰執權力鬥爭中，中書舍人作為執筆者，其個人仕途與安危繫於詔書的措辭。本章詳細展現了崔文弼在左右夾擊下的內心掙扎與求生欲，這是歷史邏輯下的必然。
2.  **基層資訊傳播與壓力**：宰執通過親信小吏不斷傳遞「條子」，實質上是對崔文弼施加實時、直接的政治壓力。這種微觀層面的資訊傳遞，構成了一種無形的政治角力場。
3.  **皇帝的「無偏」與「偏好」**：徽宗「建中無偏」的指示，看似要求公正，實則反映了他對現有格局的不滿。當文臣們試圖在既有框架內尋求平衡時，皇帝可能已經在尋求更具突破性、更符合自己意志的人選。硃批蔡京，便是皇帝這種隱藏偏好的突然展現。
4.  **上元夜的氛圍反差**：宮外歡騰與宮內緊張的對比，強化了政治鬥爭的冷酷無情，也烘托了崔文弼個人命運的孤獨與沉重。感官細節的描寫，如燭火、墨香、遠處的管弦聲，都旨在營造這種沉浸式氛圍。

### 【小說虛構】：
1.  **崔文弼其人**：崔文弼為本章的視角人物，其具體生平、性格、內心活動、對黨爭的看法、起草詔書時的思維過程與掙扎，均為小說虛構。但其官職（中書舍人兼起居舍人）是真實存在的。
2.  **「條子」的具體內容與傳遞情節**：宰執們傳遞「條子」施壓，以及崔文弼對其的回應，是根據史實背景合理虛構的戲劇細節，以展現微觀衝突。
3.  **恩詔的詳細措辭與修改過程**：本章所寫的詔書內容，是基於歷史背景和兩黨訴求進行的藝術創作，旨在體現「建中無偏」的春秋筆法。
4.  **徽宗硃批的具體文字**：雖然徽宗對蔡京的關注是史實，但「文字雖順，氣象萎靡。朕聞杭州有蔡京者，才具練達，何以無人薦舉？」這段硃批的具體內容是為劇情張力而虛構，用以直接揭示徽宗的潛在意圖。

### 【連續性變更】：
1.  **崔文弼的心理狀態**：從開始的謹慎、求穩，到最終的震驚、心灰意冷，他的個人政治判斷受到重創。這將使其在後續朝政中，對皇帝的意圖更加警惕，甚至可能變得更加保守或投機。
2.  **朝廷政治路線的預示**：原本「建中靖國」的調和嘗試，在本章末尾被徽宗的硃批打破，預示著單純的平衡策略將難以奏效。這標誌著徽宗在政治上將逐漸展現其獨斷的一面，為蔡京等新一代權臣的崛起埋下伏筆。
3.  **蔡京與童貫的影響力**：通過徽宗的硃批，蔡京的名字第一次在朝堂核心事件中被皇帝主動提及，預示著他和童貫的政治影響力開始浮現，並將在未來章節中迅速擴大。

### 【後續銜接】：
1.  **「建中調和」的失敗**：本章結尾的硃批，直接宣告了崔文弼式「建中調和」努力的失敗，為後續章節中新舊黨爭的持續、甚至新的權臣集團的崛起奠定基調。
2.  **蔡京的起復**：徽宗對蔡京的關注，將直接推動蔡京在後續章節中被召回京城，並迅速獲得重用，成為新政局的關鍵人物。
3.  **徽宗的政治傾向**：硃批也展現了徽宗不願受制於傳統文臣、渴望快速推動自己意志的傾向，這將是他未來統治風格的一個重要伏筆，也為他日後啟用像童貫、蔡京這樣的「能臣」埋下伏筆。
4.  **黨爭的演變**：雖然恩詔最終可能還是會頒布，但徽宗的態度將使得舊黨的復興受到限制，而新黨的曾布也未能完全掌握局面，朝局將進入一個更加複雜多變的階段，為《宋末》整體故事中政治腐敗與混亂的根源提供早期線索。
