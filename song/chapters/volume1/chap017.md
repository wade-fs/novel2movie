# 第十七章　端禮門前的元祐黨人碑

崇寧三年正月，汴京城被凍結在一片灰白色調中。正月二十八日，庚寅日，天未破曉，東方僅現一線魚肚白，皇城根下的寒風便已攜著細碎雪末，如同無數把鋒利的小刀，呼嘯著刮過端禮門前的廣場。積雪覆蓋了青磚路面，又被過往的車馬與行人踩踏成黑白相間的泥濘。空氣中瀰漫著濕冷的土腥與未散盡的炭火煙氣，鑽進人的骨縫裡，教人不由自主地佝僂身軀。

安民，翰林院石刻待詔，今年四十八歲，卻覺雙肩比往年更沉重，脊背也彎得更厲8害。他裹緊了身上粗布棉袍，頭上戴著羊毛氈帽，只露出被風霜刻蝕得溝壑縱橫的臉龐。清晨時分，他已隨同數名學徒兼助手，趕至端禮門旁的文華殿外。那裡，一座為官作坊臨時搭建的木棚，正籠罩在晨曦的微光與寒意之中。

棚下，一座巍峨的青石巨碑如同一座小山般矗立，其高足有數丈，寬亦數尺。碑身通體蒼勁，石質堅硬，乃是從河北深山運來的上等石料。此碑的頂端，碑額上赫然鐫刻著六個氣勢磅礴的大字：「元祐奸黨碑」。這六字蒼勁有力，筆鋒恣意，安民一眼便認出，這是當今聖上徽宗皇帝的御筆。天子親題，其分量重如泰山，壓得安民胸口發悶。

碑身之上，密密麻麻的墨跡，字字珠璣，秀麗挺拔，行楷之間隱含雷霆萬鈞之力。那是當朝太宰、尚書左僕射蔡京的手書。安民深知，蔡太宰的書法，海內推為獨步，其筆法之精妙，世間罕有。然而此刻，這些優美的字跡卻承載著最為惡毒的詛咒與最殘酷的判決。

碑前，已立著數名身著緋色官袍的監察官員，他們手籠暖袖，面色冷峻，在寒風中紋絲不動，身姿如松，卻散發著無形的壓迫感。為首的一位，是御史中丞劉安國的親信，名叫趙庸，年約四旬，面龐瘦削，兩眼深陷，眼神銳利如鷹隼。他身披一件厚重的錦袍，卻似乎感受不到寒意，只是不時地瞥一眼那塊巨大的石碑，眼神中充滿了一種近乎狂熱的堅定。在他身後，幾名佩刀的皇城禁軍，甲冑森然，手按刀柄，肅立兩旁，他們的呼吸在寒冷的空氣中凝結成白霧，又迅速消散。

「安待詔，時辰不早了。」趙庸的聲音低沉而平靜，卻帶著不容置疑的威嚴，在空曠的廣場上清晰可聞。「今日務必將這三百零九位『奸黨』名姓，悉數鐫刻完畢。聖上與太宰大人皆在等著這碑立起來，頒行天下。」

安民沒有回應，只是沉默地將隨身攜帶的鐵鑿與鐵錘從布袋中取出。鐵鑿在寒風中散發著冰冷的金屬光澤，錘柄因長年摩挲而呈現出幽深的油亮。他將工具一一擺放在鋪著麻布的石凳上，動作緩慢而鄭重，彷彿在進行某種儀式。他的學徒們則忙著生火取暖，並準備好熱水與擦拭石面的濕布。

他抬頭望向碑身。蔡京親書的底本早已被拓印在碑面上，墨色烏黑，字跡清晰可辨。從司馬光、文彥博、蘇軾、蘇轍、黃庭堅、秦觀，直到范祖禹，三百零九個名字，每一個都如同烙鐵般，深深地燙在他的心頭。這些名字，對於一個身處文化鼎盛之世的讀書人而言，無疑是如雷貫耳的賢相大儒，是文章道德的典範。

司馬相公，海內稱其忠直，編撰《資治通鑑》，功在社稷；蘇學士，文章滿天下，詩詞書畫，無一不精，其《赤壁賦》連販夫走卒亦能吟誦。黃庭堅，書法詩歌，開宗立派，引領風騷。這些人物，哪一個不是大宋的脊樑？而今，他們卻被冠以「奸黨」之名，要被永遠釘在歷史的恥辱柱上。

安民的手有些顫抖，不是因為寒冷，而是源自內心的激盪。他是一名石刻待詔，大宋天下第一的鐫石名手，他的技藝足以讓頑石煥發生命，讓文字永垂不朽。然而，此刻他所面對的，卻是將不朽的聲名化為永恆的污點，將忠直的賢者貶為奸邪的罪人。

他深吸一口氣，冰冷的空氣灌入肺腑，帶來一陣刺痛。他選了一柄最為鋒利的鐵鑿，小心翼翼地對準了碑文上「司馬光」三個字的筆畫。他的目光掃過這三個字，腦海中浮現出司馬光在洛陽獨樂園中，清茶淡飯，潛心著書的景象。那是多少士人嚮往的清高與超脫。

「叮——」第一鑿落下，清脆的聲響在寒風中傳開，帶著一種儀式感的沉重。碎石屑崩飛，落在他的麻布鞋面上。他的手藝極為精湛，一鑿下去，筆畫的深淺、寬窄，皆能精準控制，力道拿捏得恰到好處，務求字跡與底本毫釐不差。每一個筆畫都如同有生命般，在他的鐵鑿下逐漸成形。

時間一分一秒地流逝，太陽終於掙脫了雲層的束縛，將一抹慘淡的光線投射在碑面上。光線移動，碑上的字跡時而清晰，時而隱沒在陰影之中。安民的手臂漸漸感到痠痛，但他的動作卻始終保持著一種機械般的穩定。他刻下了司馬光，刻下了文彥博，又刻下了蘇軾。每刻一個名字，他的心就沉重一分。他彷彿能聽到那些名字背後，無數士子的嘆息與扼腕，亦或是憤怒與不甘。

期間，趙庸會不時走過來，近距離審視安民的進度，他的目光如炬，彷彿要將每一個筆畫都刻進自己的腦海。他甚至會伸手觸摸一下碑石，感受其表面是否光滑，筆畫是否深淺一致。安民始終低著頭，專注於手中的活計，沒有與他對視。他知道，今日的趙庸，代表的是蔡京的意志，是朝廷的最高權力，是任何人都無法違逆的洪流。

午時已過，寒意卻絲毫沒有減退。幾個學徒小心翼翼地送來了熱騰騰的薑湯，安民接過，卻顧不上喝，只是用粗糙的布巾擦了擦額頭滲出的汗珠。他的雙手已經凍得有些僵硬，指節發白，但手中的鐵鑿與鐵錘卻彷彿與他融為一體。

當他刻到黃庭堅的名字時，手腕不經意間一顫，一小塊碎石崩得遠了一些，險些砸到趙庸的袍角。趙庸眉頭微皺，卻沒有發作，只是冷哼一聲，轉身走到一旁。安民心中一凜，知道自己心緒不寧，再這般下去，恐怕會出差錯。他閉了閉眼，深吸一口氣，努力將雜念驅散，重新將注意力集中到手中的鑿子上。

直到日頭偏西，夕陽將端禮門的輪廓拉得極長，三百零九個名字，終於在安民近乎麻木的雕琢下，悉數鐫刻完畢。他放下鐵鑿，長舒一口氣，只覺得全身的力氣都被抽空了。這些字跡，每一個都如同他的骨血一般，深深地印在了碑石上，也印在了他的心上。

趙庸緩步上前，仔細地檢查了一遍碑文。他的眼神在每個名字上停留片刻，最終滿意地點了點頭。

「安待詔，不愧是天下第一鐫石名手。」趙庸的語氣中帶著一絲不易察覺的讚許，卻又很快被冰冷的公事公辦所取代。「按旨意，此碑陰下角，須鐫刻『翰林石工安民刻字』，以傳後世。這亦是對你技藝的認可。」

這句話如同晴天霹靂，擊中了安民。他僵在原地，雙唇顫抖，半晌說不出話來。傳後世？傳什麼後世？傳他安民參與了這場對賢者的侮辱，傳他親手將這些「奸黨」之名刻在石碑上，成為千古罪人？

他緩緩跪下，膝蓋撞擊在冰冷的青磚地上，發出沉悶的聲響。寒風吹過，吹散了他眼角的淚珠，又迅速凝結成冰。

「小人……小人賤工，不知朝廷是非。」安民的聲音沙啞而顫抖，幾乎聽不清。「然……然司馬相公海內稱忠直，蘇學士文章滿天下，今指為奸邪，小人……小人實不忍鐫其名！」

他抬起頭，淚水已模糊了雙眼，但眼神中卻透出一股前所未有的堅決：「若必欲勒石，乞免刻安民姓名，恐玷污後代！小人寧願……寧願不傳此名於世！」

這一番話，如同一聲驚雷，在端禮門前炸響。趙庸的臉色驟然變了，原先的讚許消失殆盡，取而代之的是極度的震怒。他本以為安民會欣然接受這份「殊榮」，卻沒想到這個賤工竟然敢在天子御碑前，公然質疑朝廷的決斷！

「放肆！」趙庸厲聲喝道，聲如洪鐘，震得周圍禁軍都為之一顫。「你這賤民，竟敢妄議朝政，公然違抗聖旨！當斬！」

他猛地拔出腰間佩刀，「鏘」的一聲，刀刃在夕陽下閃爍著刺目的寒光。刀鋒直指安民的咽喉，凜冽的殺氣瞬間籠罩了整個碑坊。周圍的學徒們嚇得面無人色，紛紛跪倒在地，噤若寒蟬。禁軍士兵們也迅速上前，將安民團團圍住。

安民卻沒有絲毫躲閃，他只是仰著頭，任憑刀鋒的寒氣刮過他的皮膚。他的心頭湧起一種奇異的平靜，彷彿死亡的威脅，反而讓他從長久的壓抑中解脫出來。

就在刀刃即將落下之際，一個急促的腳步聲傳來。一名身著紫色官袍的官員，鬢髮微白，面容清癯，卻步伐矯健，急步上前，伸出手，堪堪攔住了趙庸的刀刃。

「趙中丞且慢！」來者正是知制誥劉逵，他目光清澈而銳利，語氣冷靜，卻帶著不容置疑的力度。「石工猶知是非，若斬之，反彰朝廷殺義士！此事若傳開去，天下士子將如何看待我朝廷？莫要因此，反倒讓那些奸黨得了聲名！」

趙庸的刀尖懸在安民頸側，距離不過寸許。他轉頭看向劉逵，眼神中帶著一絲不解與慍怒。劉逵的官職雖不及他，但知制誥乃是為皇帝起草詔令的近臣，地位超然，且素來以清正聞名。

「劉學士，此賤民公然質疑朝廷，其心可誅！」趙庸沉聲道，刀刃仍未收回。

劉逵輕輕一笑，笑容中帶著一絲諷刺：「他不過一介石工，何來『質疑』朝廷之權？不過是出於工匠之愚見，不忍玷污其手藝罷了。若因此而斬殺，豈非正中奸黨下懷，讓他們得了個『為賢者而死』的名頭？蔡太宰行事，素來求一個名正言順。依我看，免其題名便是，讓他這等賤工，無名無姓，湮沒於世，豈不更顯朝廷之威嚴？」

趙庸聞言，目光閃爍，仔細權衡了片刻。劉逵的話，雖是為安民解圍，卻也將安民貶低到了塵埃裡，更將其行為定義為「愚見」，而非「質疑」。這確實比斬殺一個「義士」更能維護朝廷的顏面。況且，蔡太宰確實曾叮囑過他，處理黨人碑之事，務必做到滴水不漏，不給天下士人留下任何口實。

他冷哼一聲，緩緩收回佩刀，刀刃歸鞘，發出清脆的聲響。

「哼！算你命大！」趙庸瞪了一眼安民，又轉向劉逵，拱手道：「既然劉學士有此見，那便依學士所言。免去這賤工題名便是。不過，此事仍需上報太宰大人定奪。」

劉逵微微頷首，沒有多言。

安民依舊跪在原地，雙眼通紅，淚水與汗水混雜在一起，流淌在他的臉上。他知道自己僥倖逃過一劫，卻也明白，自己的名字，將從此在所有官方文獻中被抹去，永不見光。然而，此刻他心中卻沒有恐懼，只有一種莫名的悲哀。

他緩緩地，顫抖著伸出手，重新執起那柄冰冷的鐵鑿。夕陽的餘暉灑在他的手上，將他指尖的鮮血映照得觸目驚心。他低頭看向碑身，目光落在「蘇軾」二字之間，那裡，正是他方才心緒不寧，鑿偏了一點的位置。

「叮——」他再次揮動鐵錘，鑿下了那塊多餘的碎石。指尖的血珠，終於禁不住重力，滴落在碑石上，殷紅的液體滲入石材的紋理，在「蘇軾」二字之間，留下了一個觸目驚心的血點。

寒風依舊呼嘯，彷彿在為這場無聲的悲劇而嗚咽。安民的雙手在劇烈地顫抖，每鑿下一塊碎石，都彷彿從他心上割下了一塊肉。他知道，這塊碑，不僅僅是三百零九位「奸黨」的罪證，更是大宋士人政治倫理徹底沉淪的標誌，也是他安民此生無法磨滅的恥辱。他無力改變這一切，只能用自己的雙手，將這份恥辱，連同他的血淚，永遠地銘刻在歷史的頑石之上。

## 章後工作紀錄

**【史實骨架】：**
本章的核心事件為崇寧三年（1104年）正月，徽宗下詔重定「元祐黨人」名單，共三百零九人，命蔡京親書碑文，徽宗題額「元祐奸黨碑」，立於汴京端禮門外，並頒其墨本於天下各州縣立石。主要依據《宋史·蔡京傳》：「崇寧三年正月，又定為『元祐奸黨』，凡三百九人，命京書碑，石刻於端禮門。制曰：『朕惟政體一也，而人情萬殊。自元祐以來，邪正混淆，士大夫不知所守，以至政事日壞，民不聊生。今特命書黨人姓名於碑，立於端禮門，以示天下，使知邪正之分。』」以及《東坡志林》或明清筆記所引：「翰林石工安民請免鐫姓名，稱：『司馬光等海內共知其賢，不忍刻也。』」本章將安民的請辭和官員的反應具體化為小說情節。

**【待核事項】：**
1.  **具體日期：** 崇寧三年正月二十八日（1104年2月26日）是庚寅日，符合農曆。但頒布詔書與實際刻碑完成並豎立的具體日期，史料未載確切。本章將鐫刻完成日設定為此日，以強化時間節點。
2.  **碑坊位置：** 「文華殿旁官作碑坊」是基於端禮門靠近文華殿的地理位置，推測臨時工作坊的設置地點。
3.  **劉逵的官職與行為：** 劉逵在宋徽宗時期曾任知制誥，以正直敢言著稱。史料未載他直接干預黨人碑事件，本章為小說虛構其出面解圍，以合理化安民的免死與免題名，並為小說增添戲劇性衝突。
4.  **監察官員具體名諱：** 監察官員趙庸為虛構人物，但其職責與行為符合當時蔡京集團對黨人碑事件的嚴密監控。
5.  **「元祐黨人」三百零九人名單的具體排列順序：** 史料未載碑上名單的精確排列，本章採用從著名人物（如司馬光、蘇軾）開始的寫法，符合重要人物優先的常理。

**【合理推演】：**
1.  **端禮門立碑的嚴寒氣氛：** 結合崇寧三年正月的天氣特點（農曆正月下旬，北方寒冬），推演碑坊周圍的寒冷、風雪、泥濘等感官細節，以烘托事件的肅殺與沉重。
2.  **工匠安民的內心絕望與掙扎：** 作為「天下第一鐫石名手」，安民對傳統儒家賢士的景仰與對手藝的珍視，與被迫鐫刻「奸黨」碑文之間的巨大衝突，是合理的人性推演。他不可能對此毫無感觸，其內心的掙扎、對「玷污後代」的恐懼，是其請免題名的深層動機。
3.  **基層資訊傳播與士人反應：** 安民能夠知曉司馬光、蘇軾等人的聲名，反映了當時士大夫階層的評價與民間輿論對其的認知，即使是工匠階層，亦能接觸到這些文化資訊。
4.  **劉逵解圍的邏輯：** 劉逵作為知制誥，其言行需符合其身份和當時的政治環境。他出面並非直接反對蔡京，而是從維護「朝廷顏面」和避免「為奸黨樹立義士」的角度來勸說趙庸，這既合情合理，也符合當時高層官員在極權政治下為求自保而採取的策略。

**【小說虛構】：**
