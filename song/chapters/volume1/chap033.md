# 第三十三章　萬歲山初奠與祥瑞進奉

政和七年五月十二日，甲辰日，天光方才微亮，汴京東北隅的萬歲山營造總指揮大營便已亂成一鍋粥。李質，年屆四十二，身兼將作監丞與艮嶽修葺所主事，此時正立於一堆混著泥漿的碎石之上，渾身濕透，臉色煞白如紙。昨夜一場傾盆大雨，將這座平地拔起的「人間仙境」沖刷得面目全非，而最要命的，莫過於萬歲峰西側山體的滑坡。

泥漿如瀑布般從山腰傾瀉而下，裹挾著數十萬斤的太湖巨石，轟然砸向新落成的御覽宮殿。那宮殿昨日傍晚尚在琉璃瓦下閃爍著微光，此刻卻已成了瓦礫木屑與泥土的廢墟。兩間方才鋪設了精緻地磚的殿宇，連同裡頭來不及撤出的二十餘名廂兵匠役，一同被巨石與泥土深埋。空氣中除了濕泥的腥氣，更混雜著一股淡淡的血腥與死亡的腐敗。

「快！快！都給某動起來！」李質嘶啞著嗓子吼道，聲音在晨曦中顯得格外刺耳。他的雙腳深陷在泥濘中，官靴早已不堪重負，只覺冰冷的泥水浸透襪子，直透骨髓。濕重的官服緊貼在身上，黏膩得令人發狂，可他顧不得這些。豆大的汗珠與雨水混雜，順著他蒼白的臉頰往下淌，將官帽上的汗巾都浸濕了。

遠處，負責傳遞消息的總管太監王福，肥胖的身軀在泥濘中跌跌撞撞，他尖細的嗓音劃破清晨的寂靜：「李主事！李主事！官家駕臨的時辰已定！林真人與童大官也已隨駕！半個時辰！至多半個時辰便要入山了！」

半個時辰！李質心臟猛地一抽，如同被一隻無形的手緊緊攥住。汗毛倒豎，一股寒意從腳底直竄腦門。半個時辰，足夠將作監上下數十號人盡數拖往菜市口，身首異處。這萬歲山，名曰萬歲，實則葬送了無數人的性命與前程。

「快！都給某聽好了！」李質發瘋似的吼道，聲音幾乎變了調，脖子上的青筋暴起，「張監事！李押班！你們速速召集所有能動的廂兵與匠役，將這裡的屍首，全部，全部拋入東邊的洗心池！越深越好！務必在官家入山前，連一絲痕跡都不能留下！」

張監事是將作監的從八品官，臉色比李質更難看，他哆嗦著嘴唇道：「主事，洗心池……那池水尚未引滿，池底尚淺，且……且是將來官家清修之所，拋入屍首，恐……」

「恐什麼恐！」李質猛地一把揪住張監事的衣領，泥水濺了他一臉，腥臭的氣味撲鼻而來。他一雙布滿血絲的眼睛死死盯著對方，聲音壓得極低，卻字字帶血：「你若不想被亂刀分屍，就給某把他們餵了魚！便是將來池水引滿，魚蝦啃食殆盡，也總好過官家親眼看見祥瑞之地成了亂葬崗！若事敗，你我連同所有參與者，都將以『沮壞風水祥瑞，驚擾聖駕』之罪，斬首示眾！株連九族！」

張監事被李質眼中的殺意震懾，肥胖的身軀劇烈地顫抖了一下，連連點頭：「是，是！下官這便去辦！」說罷，他如蒙大赦般，連滾帶爬地衝向東側。

李質鬆開手，只覺掌心黏膩，不知是雨水、泥漿還是張監事嚇出的冷汗。他環顧四周，滑坡的山體如同被撕裂的血肉，裸露的黃土、碎石、斷裂的樹根混雜在一起，泥漿還在緩緩下淌，毀去的宮殿如同被踩扁的蟲豸，觸目驚心。這景象若被徽宗看見，萬歲山便不再是延年益壽的祥瑞，而是天降不祥的災禍，那后果，李質不敢想。

「王押班！」他又點了一名負責料作的押班官，指著山體滑坡處，聲音中帶著不容置疑的命令，「速速調集所有黃綠絹帛，不計成本！將這整個山體，從上到下，全部給某覆蓋起來！再調集所有存活的翠竹，越大越好，越多越好！插滿山坡，務必給某遮蔽得嚴嚴實實！」

王押班也是一臉慘白，但見李質那副要吃人的模樣，也不敢多言，只得躬身領命，指揮著一眾廂兵匠役，朝料作庫房狂奔而去。

李質深吸一口氣，冰冷的空氣帶著泥土與血腥味，刺激得他肺部生疼。他的目光越過正在忙亂的營地，投向遠處層層疊疊的奇峰怪石。這座萬歲山，方圓十餘里，人工開鑿的景龍江蜿蜒環繞，引江南運來的奇峰怪石堆疊成崇山峻嶺，上植羅漢松、枇杷、古梅，奇禽異獸出沒其間，宛若人間仙境。然而，這一切都是用無數的金銀，無數的性命堆砌而成。

他清楚記得，數月前，將作監曾經向童貫遞呈過一份劄子，言及萬歲山初奠山形，地基堆土未實，難以承受數十萬斤巨石的疊壓，尤其江南太湖石，質地雖奇，卻重逾千鈞，若再遇暴雨，恐有坍塌之虞。然而，那份劄子如同石沉大海，童貫只回了一句：「官家龍心甚悅，祥瑞之地，豈有不堅之理？爾等匠作，只管依旨營造，休得多言！」

如今看來，這句「休得多言」，便是斷送他們性命的催命符。

李質揉了揉劇烈跳動的太陽穴，腦海中飛速盤算著。掩蓋屍首、遮蔽山體，這些都是權宜之計，瞞得了眼，瞞不過心。尤其徽宗身邊，還跟著那位深得聖寵的林靈素真人。這位道士，以神霄派道法蠱惑聖聽，自稱能役使鬼神，呼風喚雨。若他看破端倪，隨意一句「此處陰氣盤旋，恐有不祥」，那所有人的努力都將功虧一簣。

他轉身，目光鎖定在不遠處一頂臨時搭建的帳篷上。那是林靈素在山中的暫居之所，帳篷前有兩名身著道袍的小道童守衛。李質深吸一口氣，泥水濺濕的官袍在風中獵獵作響，他邁開沉重的步伐，朝帳篷走去。

帳篷內，檀香繚繞，與外面的泥腥味形成鮮明對比。林靈素盤膝而坐於蒲團之上，身著紫金道袍，頭戴五嶽冠，雙目微閉，面色紅潤，一副得道高人的模樣。他身邊的小道童正小心翼翼地為他續上一盞熱茶。

「李主事，如此狼狽，所為何事？」林靈素緩緩睜開眼，目光落在李質濕漉漉的官服上，嘴角勾起一抹意味不明的笑意。他的聲音不高，卻帶著一種穿透人心的力量，讓李質本就緊張的神經繃得更緊。

李質躬身行禮，盡量讓自己的語氣保持平穩，不露絲毫慌亂：「下官參見林真人。真人修仙悟道，想必已窺天機，知曉昨夜山中變故。下官此來，正是為此請真人指點迷津。」

他從袖中取出一個用油紙包裹得嚴嚴實實的銀鋌，悄無聲息地塞到林靈素身邊的小几上。銀鋌入手沉甸，估計有五十兩之重，表面打磨得光滑，在帳篷內微弱的燭光下泛著幽暗的光澤。這是他多年來小心翼翼積攢下的俸祿與賞賜，如今卻要一股腦地送出去。

林靈素的目光掃過那銀鋌，眼底掠過一絲不易察覺的滿意，但臉上卻不動聲色。他端起茶盞，輕輕吹了吹熱氣，慢悠悠地說道：「哦？本真人夜觀星象，昨夜確實見太白星黯淡，紫微星動盪，似有小劫。卻不知李主事所指何事？」

李質心知肚明，這位真人哪裡是什麼夜觀星象，不過是想聽他親口道出詳情，好拿捏他的把柄罷了。他跪倒在地，聲音壓得更低，帶著幾分哀求：「真人明鑒！昨夜暴雨，萬歲峰西側山體滑坡，毀去宮殿兩間，傷亡匠役數十人。如今官家御駕將至，下官已命人盡力掩飾，然天威難測，人命關天……若官家見此不祥之兆，下官等一眾營造官員，皆將萬劫不復！」

他抬起頭，目光懇切：「下官懇請真人，念在萬歲山營建不易，耗費官家無數心血，為聖上千秋萬代之基業，能……能為下官等遮掩一二。若真人能替下官等圓說，將此變故解釋為祥瑞之兆，下官必當銘記真人恩德，日後必有重報！」

林靈素放下茶盞，輕捋長鬚，臉上露出一絲高深莫測的笑容：「你說的，卻是難辦。山體滑坡，宮殿被毀，人命傷亡，此乃煞氣也。如何能化為祥瑞？」

李質知道，這是在討價還價。他咬了咬牙，從懷中又掏出一張用絲綢包裹的牙帖，這是他準備好的私產憑證，上面記錄著他在汴京城外的一處良田，約有百畝。他將牙帖雙手奉上：「真人！此乃下官在城郊薄田百畝之契，權作微薄孝敬，請真人笑納！若真人能助下官渡過此劫，下官願將所有家產盡數奉上，只求保得一條性命！」

林靈素終於拿起那張牙帖，略微掃了一眼，臉上的笑容終於多了一絲真誠。他將牙帖與銀鋌一併收入袖中，閉上眼睛，沉吟片刻，才緩緩開口：「嗯……你說的，倒也並非無解。本真人曾聞，太古之時，青龍出海，常引動地脈震盪，吐翠生祥。這萬歲峰西側，恰逢卯位，青龍之位也。或許，這並非地基不實，而是青龍感應聖德，欲吐瑞氣，卻因靈氣太盛，地脈承受不住，故而略有震盪耳。」

李質聞言，如聞天籟，猛地抬頭，眼中閃爍著劫後餘生的狂喜：「真人妙計！妙計啊！青龍吐翠，地脈生祥！正是如此！正是如此！」

林靈素擺了擺手，示意他稍安勿躁：「不過，這瑞氣吐出，需得有物承接。你且命人在那滑坡之地，多插翠竹，點燃數十支上好的沉香，以香氣引導瑞氣，再在山間各處，多放幾隻仙鶴。本真人自會設法，引導紫氣東來，為官家呈現祥瑞之景。」

李質連連叩頭：「多謝真人！多謝真人指點！下官這便去辦！」他知道，所謂的「引導紫氣東來」，不過是林靈素故弄玄虛，暗中燃燒熏香，製造煙霧罷了。但此刻，這卻是他唯一的生路。

他從帳篷中衝出，顧不得滿身的泥濘與疲憊，重新回到萬歲峰西側。此時，廂兵與匠役們已將那些死傷者的屍首，或拖或抬，盡數拋入尚未引滿的洗心池中。池水淺淺，尚能見到底下模糊的人影，但他不敢多看，只是催促著道：「快！快將池邊的青石板鋪好！不許留下任何痕跡！」

數百匹黃綠絹帛被廂兵們從料作庫房中抬出，如同流水般覆蓋在滑坡的山體上。這些上好的絲綢，原本是為了裝飾宮殿內部而準備的，如今卻成了遮掩罪惡的裹屍布。在雨水的沖刷下，絲綢緊貼著泥土，呈現出一種詭異的柔順。而一隊隊匠役則扛著連夜從山下移栽來的翠竹，密密麻麻地插在絹帛之上，企圖以這鮮活的綠意，掩蓋其下腐朽的死亡。

遠處，汴京城方向，隱約傳來鑾駕行進的聲響。鐘鼓齊鳴，仙樂繚繞，昭示著當今聖上「教主道君皇帝」的御駕即將抵達。

李質站在泥濘中，看著眼前的「傑作」。黃綠相間的絲綢覆蓋著山體，翠竹如劍般直插雲霄，一眼望去，倒也顯得生機勃勃。只是他鼻端，卻仍能嗅到那股若有似無的血腥氣，以及泥土深處，隱隱傳來的腐朽之味。他知道，那不是錯覺，那是數十條鮮活的生命，被掩埋在這座虛假的仙山之下。

林靈素的道童們，也開始在山間各處點燃沉香，裊裊的煙氣隨風飄散，將空氣中的泥土與血腥味沖淡了幾分。幾隻圈養的仙鶴被放了出來，在山谷間盤旋飛舞，發出幾聲清亮的鶴鳴。這一切，都為這座人工山林增添了幾分「仙氣」。

不多時，浩浩蕩蕩的御駕隊伍便已抵達山門。徽宗趙佶身著一襲繡有金絲太極八卦圖案的道袍，頭戴純金九梁冠，神采奕奕。他乘坐著一頂由八名內侍抬著的道轎，兩側是身形魁梧的童貫，以及面色紅潤的林靈素。蔡京、高俅等一眾朝中重臣，則步行隨侍在後，個個噤若寒蟬，不敢發出半點聲響。

李質與將作監的一眾官員，早已跪伏於地，大氣不敢出。

「平身。」徽宗的聲音帶著一種帝王特有的威嚴，卻又透著幾分閒散與愉悅。

李質顫顫巍巍地起身，目光不敢直視聖顏，只敢低頭看著自己官靴上的泥濘。

徽宗的道轎穩穩地停在萬歲峰下，他抬頭仰望，只見眼前山勢連綿，綠意盎然。在林靈素的指引下，他的目光投向了西側山體。那裡，黃綠絹帛與翠竹交織，在晨光的映照下，顯得格外鮮亮。遠處，幾隻仙鶴恰巧飛過，清亮的鶴鳴在山谷間迴盪。而林靈素暗中點燃的沉香，此時也化作縷縷青煙，隨風而上，在山巔繚繞，如同紫氣。

「妙哉！妙哉！」徽宗龍顏大悅，他看向林靈素，眼中滿是讚賞，「真人所言不虛，此處果真有青龍吐翠之相！你看那山體，鬱鬱蔥蔥，生機勃勃，便似有龍氣從地底噴薄而出，匯聚成祥！」

林靈素躬身笑道：「聖上聖德感天，故而祥瑞自生。此乃青龍應瑞，為聖上延億萬年之祚也！」

徽宗撫掌大笑，心情顯得極為暢快。他命人將道轎抬至山頂，欲登臨絕頂，極目遠眺。李質與一眾官員連忙引導聖駕，步步小心。每一步，李質都走得心驚膽戰，生怕腳下泥土鬆動，露出絲毫破綻。

來到山巔，徽宗放眼望去，整個汴京城盡收眼底。煙波浩渺的景龍江，蜿蜒盤旋，如同玉帶環繞。山間奇石嶙峋，古樹參天，仙鶴翔集，紫氣蒸騰。在林靈素的「道法」加持下，整個萬歲山，此刻真正成了他夢想中的仙境。

徽宗拂袖而立，身姿挺拔，意氣風發。他轉過身，看向身邊的蔡京，笑謂道：「今日方知為天子之樂！此山可名艮嶽，為朕延億萬年之祚！」

蔡京慌忙躬身，臉上堆滿了諂媚的笑容：「恭喜聖上，賀喜聖上！艮嶽之名，正合天地之數，聖上萬壽無疆！」

李質跪伏於地，頭深深埋入臂彎。他聽著徽宗與眾臣的歡聲笑語，聽著林靈素高聲吟誦的道家經文，只覺耳膜嗡鳴。鼻端，那股若有似無的腐血腥味，卻在此刻變得格外清晰。它從他腳下的泥土深處滲出，穿透了濕冷的空氣，直達他的心肺。這股味道，如同無數冤魂的低語，嘲諷著眼前這一切虛假的繁華與祥瑞。他知道，他活下來了，但他的良心，卻被永遠地埋葬在了這座名為「艮嶽」的萬歲山之下。

本章時間點設定在政和七年（1117年），此時徽宗自稱「教主道君皇帝」，對道教的痴迷達到巔峰，並開始大規模營建艮嶽（初名萬歲山，宣和四年落成），以求長生與個人美學的實現。艮嶽的營建確系廣採天下奇花異石，動用數十萬工匠，耗費鉅資，極盡奢靡，這些在《宋史·地理志·艮嶽記》及相關史料中均有記載。章中提及的林靈素深得徽宗信任，道教神霄派在京師大盛，排斥佛教，朝政愈發荒誕，此為當時的真實歷史背景。蔡京、童貫作為徽宗寵臣，參與其事，亦符合史實。徽宗最終將萬歲山命名為「艮嶽」，取「萬物所成終，萬物所成始」之意，寄託長生永壽的願望，也與史實相符。

**【待核事項】：**
1.  **具體宮殿名稱與位置：** 章中提及「御覽宮殿」，此為虛構名稱，用於方便敘事。艮嶽內宮殿眾多，但具體哪一座宮殿位於萬歲峰西側、且在營建初期便遭滑坡，史料未詳載。此處取其功能性而非具體史料名稱。
2.  **洗心池的具體位置與營建進度：** 洗心池為艮嶽內景點之一，但其具體位置與營建時序，史料無詳細記載。章中設定為尚未完全引滿水，池底尚淺，以合理化李質拋屍的行為。
3.  **廂兵與匠役的具體傷亡數字：** 史料對艮嶽營建期間的具體傷亡數字語焉不詳，只籠統提及動用數十萬工匠與民夫。章中設定為二十餘人，為小說虛構，旨在具體化微觀衝突。
4.  **銀鋌、牙帖的具體價值：** 五十兩銀鋌與百畝良田的價值，在北宋時期屬於鉅款。需進一步考證當時汴京地區的田價與白銀購買力，以確保其作為賄賂的合理性與李質獻出家產的巨大代價。

**【合理推演】：**
1.  **地基塌陷與掩飾：** 萬歲山在平地起山，工程浩大且工期倉促，地基堆土不實導致山體滑坡是極其合理的工程事故。在皇帝對工程進度與「祥瑞」有極高期待的情況下，基層官員為保性命而掩飾事故，甚至不惜拋屍滅跡，是基於極端政治壓力下的人性推演。這種「報喜不報憂」的官場文化，在歷代王朝均有體現，尤其在北宋末年徽宗的統治下，更是變本加厲。
2.  **賄賂林靈素：** 林靈素作為徽宗身邊的紅人，其言行對徽宗的判斷有著決定性影響。李質選擇賄賂林靈素，請其將災難解釋為祥瑞，是基於當時朝廷道士、宦官專權的政治生態的合理推演。林靈素利用其影響力，將自然災害包裝成「青龍吐翠」的道教祥瑞，既迎合了徽宗的道教痴迷，又為自己謀取了私利，符合其人物性格與當時的政治氛圍。
3.  **謊言共同體：** 從營造官員的掩飾，到林靈素的圓說，再到蔡京等大臣的附和，整個朝廷形成了一個用謊言編織的虛妄盛世共同體。這種共同體脫離帝國現實，僅圍繞皇帝的個人意志和美學追求運轉，最終導致了北宋末年的政治腐敗和國力衰弱，是本章對宏觀歷史的微觀映射。

**【小說虛構】：**
1.  **李質的人物設定與具體行動：** 李質作為將作監丞兼艮嶽修葺所主事，其姓名、年齡、官職以及他在面臨危機時的具體心理活動、下達的拋屍、覆絹、插竹、行賄等指令，均為小說虛構。這些細節旨在構築一個在巨大壓力下求生的小人物形象，並推動情節發展。
2.  **太湖疊石傾覆與宮殿毀壞、人員傷亡的具體情節：** 史料僅載艮嶽營建奢靡，但並無明確記載初期有如此大規模的工程事故。本章虛構了具體的滑坡、宮殿毀壞、二十餘名廂兵匠役死亡的細節，以製造核心衝突。
3.  **黃綠絹帛覆蓋山體與翠竹遮蔽的視覺化描寫：** 這種具體的掩飾手段，是為小說戲劇性效果而設計。
4.  **林靈素「青龍吐翠」的解釋與暗放香煙的細節：** 雖然林靈素善於蠱惑聖聽，但「青龍吐翠」的具體說辭和利用香煙製造「紫氣」的手段是小說虛構，用於展現其欺騙性與徽宗的盲信。

**【連續性變更】：**
1.  **李質的人物狀態：** 從前文可能較為謹慎的官僚，變為在本章中為了保命而被迫突破道德底線，親手製造並掩蓋血腥罪行。他的內心將因此留下深刻的烙印，對朝廷的虛偽與殘酷有更深的認識。
2.  **艮嶽的「基礎」：** 艮嶽在徽宗眼中是「祥瑞之地」，但在李質和其他知情者眼中，它將永遠是一座建立在屍骨與謊言之上的虛假仙山。這種對比將貫穿後續對艮嶽的描寫。
3.  **林靈素與李質的關係：** 此次行賄，使林靈素對李質有了把柄，李質也成為了林靈素維持其虛假「神蹟」的共犯。兩人的關係將帶有一種共謀的色彩，李質可能在未來會被林靈素利用。
4.  **朝廷氛圍的固化：** 本章進一步固化了北宋末年朝廷上下瀰漫的「報喜不報憂」、逢迎聖意的氛圍，為後續更嚴重的政治腐敗和決策失誤埋下伏筆。

**【後續銜接】：**
本章結尾，徽宗對艮嶽的命名和對「天子之樂」的感嘆，標誌著他對道教長生與個人美學烏托邦的沉溺達到了巔峰。這將直接銜接後續艮嶽工程的進一步擴大與奢靡，以及對天下奇花異石的無度索取（如花石綱）。李質的內心創傷和對朝廷黑暗的認知，也為他未來在更廣闊的歷史變革中可能做出的抉擇埋下伏筆。同時，林靈素在徽宗心中的地位得到進一步鞏固，將影響後續朝政中道教對佛教的排斥，以及更荒誕的政策出台。這一切都指向北宋王朝在盛世表象下的日益衰敗，為「宋末」的大背景鋪墊。下一章可以從花石綱的組織、或林靈素在朝中權勢的擴張方面展開。
