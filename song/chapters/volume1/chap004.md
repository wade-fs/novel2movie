# 第四章　修內司的琉璃與泥瓦

元符三年，三月十五日，辰時未至，汴京城天波門外的將作監修內司窯作，便已籠罩在一片灰黑的煙塵之中。窯火日夜不絕，高聳的煙囪吐出嗆人的煤煙，彌漫在早春尚未完全消散的濕冷空氣裡，將周遭的屋脊、樹梢染上一層厚重的煤灰。

周大興，將作監修內司泥瓦匠頭目，四十五歲，此刻正佝僂著身子，在窯作最深處的陰影裡，藉著窯爐餘火的微弱光線，用一截燒得焦黑的木棍，撥弄著爐膛裡幾塊熄滅的石炭殘渣。他的臉被火光映得紅一陣、黑一陣，額頭上的汗珠混著煤灰，在溝壑縱橫的皮膚上劃出幾道黑色的泥痕。他身上那件原是青色的短褐，早已被泥土、灰燼、汗水浸染得看不出本色，袖口和衣襬處磨損得露出棉絮。

這是哲宗皇帝駕崩後的第三個月。聖駕歸葬永泰陵的營建工程，如同一座無形的山巒，沉重地壓在汴京城內所有與將作監相關的作坊肩上。從明器、山陵瓦窯到法駕器用，每一處都如熱鍋上的螞蟻，日夜趕造。修內司的工匠與廂兵們更是首當其衝，自開春以來，便被釘死在作坊裡，皮開肉綻是常事，日夜輪班，根本分不清白晝與黑夜。

「頭兒，還剩下兩千七百件青瓦，都塗上了，再回爐烘烤兩炷香的功夫，就能出窯了！」身後傳來學徒小石頭沙啞的聲音，他臉色蒼白，雙眼佈滿血絲，顯然已是熬了幾夜。小石頭是從開封府鄉下徵來的廂軍工匠，年紀不過十七八歲，卻已能獨當一面，只是這幾個月下來，原本精壯的身板，也瘦削得只剩一把骨頭。

周大興緩緩站起身，活動了一下痠痛僵硬的腰背，發出幾聲骨節摩擦的輕響。他走到窯爐前，透過爐門的縫隙，望向裡面微微發紅的瓦片。那不是正常的青瓦色澤。原本應當溫潤如玉、青中泛灰的祭奠素瓦，因冬季配給的石炭不足，窯溫始終無法達到應有的火候，導致大批瓦件燒結不實，成色暗黑，甚至有些發白，指甲輕輕一劃，便能刮下細密的粉末。這樣的瓦，用在尋常民宅尚可，但若用於皇帝陵寢，一旦經風霜雨雪而瓦裂，便是「謀逆大不敬」的死罪。

八千件祭奠青瓷素瓦，這是工部下達的死命令。然而，自入冬以來，修內司主事官李大人便以「戶部撥款不及，燃料緊缺」為由，剋扣了將作監配給修內司近半的石炭。那些原本堆滿半個庫房的烏黑石炭，不知怎的，便偷偷運出了天波門，轉手在市井高價販賣。周大興曾壯著膽子，在例行報備時，向李主事稟報過燃料短缺之事，卻被李主事瞪了一眼，冷冰冰地說：「周大興，莫以為老夫不知爾等工匠慣會偷懶，燒窯火候不足，隻會賴在燃料頭上！你等只管把活計做好，莫要生事！」

周大興知道，若真把石炭短缺之事鬧大，最終只會被主事官吏誣陷成「工匠怠惰偷安，延誤工程」，屆時不僅瓦作上下數百口人要受罰，他這個匠頭更是逃不過板子和牢獄之災。而若直接呈驗次品，一旦陵寢瓦裂，那便是砍頭滅族的大罪。

他無路可退。

數日前，當他看到那批燒結不實的青瓦從窯中取出時，手腳冰涼，一夜未眠。次日，工部催役的文書一日三至，公文上蓋著明晃晃的朱印，白紙黑字，赫然寫著：「逾期一日，當事匠作頭目受杖六十，工匠追奪工糧，情節嚴重者，按《刑統》論處！」那“按《刑統》論處”幾個字，猶如冰冷的刀刃，直抵心窩。

在絕望之中，他腦海裡閃過一個被前輩匠人稱為「下作」的法子。那便是用油。尋常百姓家的麻油，在火上熬煮後，塗抹在粗糙的陶器表面，能使其色澤油亮，略顯光澤。而熟桐油，更是能滲透瓦面，使其短時間內看來堅固潤澤。這法子，騙得了尋常人，卻騙不過真正的行家。可眼下，還有何選擇？

周大興咬牙，將自己這些年攢下的幾貫折二錢，又向相熟的幾個老匠頭借了些，湊了足足一兩多的散碎銀子。他讓小石頭偷偷潛入城內，從相熟的油坊裡，買來數十斤熬煮過的麻油渣，又從一些修補船隻的作坊裡，高價收購了兩大桶熟桐油。那些油渣與桐油，散發著刺鼻的氣味，但對於他來說，卻是救命的稻草。

“快！都快些！油塗得薄厚要均勻，莫要留下痕跡！”周大興的聲音沙啞而急促，他親自挽起袖子，拿起一塊夾生的青瓦，用棉布沾滿了黑乎乎的麻油渣，細緻地塗抹在瓦面上。那些油渣混雜著炭灰，塗抹上去，青瓦的暗色立刻被掩蓋，顯出一層油亮的烏光。

作坊裡數十名工匠，無論是老匠人還是半大孩子，都默默地彎著腰，在昏黃的燈光下，重複著這個動作。他們的手指被油料浸泡得發白浮腫，又被回爐的急火烤得紅腫開裂。空氣中瀰漫著麻油與桐油混雜的焦糊味，以及汗水和泥土的鹹濕氣息。每個人都清楚，這是他們唯一的生路。若事情敗露，他們這些底層的匠人，便是替罪羊。

爐火正旺，這一次，他們不惜代價，將從市井購來的木柴與草料，一股腦地塞進了爐膛，只為讓瓦面能迅速吸收油分，呈現出那種「光可鑑人」的假象。火焰舔舐著瓦片，油漬被高溫催化，發出吱吱的聲響，一股股黑色的濃煙，順著窯頂的排氣口，直衝天際。

“頭兒，這批要出窯了！”小石頭喊道。

周大興走上前，戴上厚厚的棉麻手套，小心翼翼地從爐膛裡夾出一塊青瓦。熱氣撲面而來，他顧不得燙，仔細觀察。瓦面烏黑髮亮，光澤內斂，雖不如上品青瓷那般通透，卻也遠勝於之前的黯淡無光。他用指甲輕輕刮了一下，瓦面沒有掉粉。他鬆了口氣，又迅速緊張起來。這只是表面功夫，騙得了一時，騙不了一世。但眼下，只要能騙過工部官員的眼睛，便是勝利。

將作監裡的工匠，多數是從廂軍中抽調而來，服役期滿後，便持有將作監頒發的「度牒」，成為正式工匠，享受一份薄俸。他們世代相傳手藝，卻始終擺脫不了軍籍的底色，身份介於兵民之間，進退兩難。周大興亦是如此，他四十年前從軍，隨後被編入工匠營，在將作監裡從學徒做起，一步步熬到了匠頭。他深知這些人的苦楚，也知道他們上有老下有小，一旦追奪工糧，便是全家斷炊。所以，無論如何，他都要把這件事扛下來。

日頭漸高，城內方向傳來一陣稀疏的馬蹄聲。周大興心頭一緊，知道工部來人了。他立刻讓所有工匠放下手頭的活計，將還未塗抹的次品瓦片全部搬入內庫，又吩咐人將作坊裡散落的麻油渣和桐油桶藏匿起來，將地面清掃乾淨，只留下那些已“處理”好的青瓦，整齊地碼放在作坊中央的空地上。

一隊人馬，約莫十餘騎，在修內司主事李大人的引導下，緩緩駛入院中。為首的是一位身著綠色官袍的官員，頭戴烏紗帽，面容清瘦，下巴留著三縷短鬚，眉宇間帶著幾分不耐。此人正是工部屯田司的員外郎，姓趙。他騎在馬上，居高臨下地掃視著作坊內的景象。

趙員外郎身後，跟著幾名書吏和隨從，個個衣冠楚楚，與作坊內灰頭土臉的工匠們形成鮮明對比。他們捂著鼻子，顯然對此地的煙塵和油漆味極為厭惡。

“趙員外，這便是修內司瓦石作坊，為哲宗皇帝山陵所趕造的祭奠青瓷素瓦，都在這裡了。”李主事滿臉堆笑，指著地面上碼放整齊的青瓦，又轉頭對周大興喝道：“周大興，還不快過來拜見趙員外！”

周大興立刻躬身向前，雙膝跪地，頭幾乎要磕到泥水裡，沙啞地應道：“小人周大興，拜見趙員外！”

趙員外郎只是輕輕“嗯”了一聲，連眼皮都未抬，目光只在那些瓦片上掃了一眼。他沒有下馬，也沒有仔細檢視，甚至沒有讓隨從上前查看。或許是此地瀰漫的油煙氣味讓他感到不適，又或許是連日的奔波讓他感到疲憊，他只是在馬背上，遙遙地望了一眼，便收回了目光。

“嗯，瓦光可鑑，色澤沉穩，勝於先朝所製。修內司這次辦得不錯。”趙員外郎語氣平淡，卻帶著一股不容置疑的威嚴。他頓了頓，又道：“本官近日巡查，見端王舊邸，也就是如今的端命殿，內閣修葺尚缺一批此等成色的素瓦。既然此處瓦件充足，便將剩餘的桐油瓦式，全數撥送端命殿，以為修葺之用吧。”

這話一出，李主事臉上立刻笑開了花，連連稱是。周大興跪在泥水中，心裡卻是一沉。他原以為，只要這批瓦件能應付永泰陵的點驗便已是萬幸，卻沒想到，趙員外郎隨口一句，竟讓這些「油瓦」直接進入了端命殿。端王，便是如今的皇帝官家，趙佶。他素來喜好奇巧之物，對宮室營造更是極為講究。這些油瓦，用在陵寢之上，或許能撐過數年，但在端命殿，長期暴露在宮室之內，又如何能瞞天過海？一旦被識破，那罪責，恐怕更甚於永泰陵的次品瓦。

但此刻，他能說什麼？他一個泥瓦匠頭目，又如何能質疑工部員外郎的決定？

“謝趙員外明察！小人等定當竭力為官家效命！”周大興只能將頭磕得更低，聲音裡帶著幾不可聞的顫抖。

趙員外郎沒有再多說什麼，他掉轉馬頭，在李主事的陪同下，緩緩離開了窯作。只留下周大興，以及身後那些面面相覷的工匠們，跪在泥濘之中。

周大興緩緩撐起身子，感覺手心傳來一陣火辣辣的刺痛。他低頭看去，原本被油漬浸泡、又被爐火灼燒的手掌，此刻已是皮開肉綻，爛皮翻起，露出紅腫的嫩肉。但他卻感覺不到疼痛，只是眼神空洞地望著那些碼放整齊的青瓦。瓦面油亮，反射著正午的陽光，顯得那樣的光鮮，那樣的諷刺。

大宋朝龐大的營造機制，表面上光鮮亮麗，莊嚴宏大，而底層，卻全靠著他們這些工匠，用瞞哄、盤剝、血汗，甚至性命，來勉強支撐。而他，周大興，不過是這巨大機器下，一粒微不足道的泥沙。

## 章後工作紀錄

**【史實骨架】：**
本章的核心歷史背景是哲宗駕崩後，元符三年（1100年）永泰陵的營建。宋代將作監下設多個司，其中修內司主要負責宮室、陵寢的營建和修繕。工部作為中央行政機構，負責國家工程事務，其下屬屯田司員外郎有巡察監管之責。宋代工匠多由廂軍抽調，身份特殊，稱為「廂軍工匠」，他們承擔著繁重的徭役，待遇低下，物料剋扣、貪腐現象在官場中屢見不鮮，尤其在大型營建工程中更為突出。李誡此時確在將作少監任上，正著手整理修訂《營造法式》，其書中對各類建築材料、工藝流程有詳盡記載，間接反映了當時營造制度的嚴謹與實際操作中的種種弊端。章中提及的“逾期一人受杖六十，工匠追奪工糧”以及“按《刑統》論處”，均是宋代對官役工匠懲罰的常見方式，體現了制度的嚴苛。哲宗歸葬永泰陵的確切時間是元符三年九月，三月十五日正值準備階段。

**【待核事項】：**
1.  **官職細節：** 工部屯田司員外郎在巡察將作監時，其權限與具體職責是否精確？例如，是否有權直接調撥將作監為陵寢準備的物資至其他宮室？（此處為小說情節需要，推演其權力影響力）
2.  **物資剋扣流程：** 從戶部撥款到修內司燃料具體發放的完整流程，以及主事官員剋扣物料的具體操作手段，如何瞞過上級檢查？（小說中簡化為「剋扣轉賣」，需考慮實際操作的複雜性）
3.  **桐油烤瓦的真實性：** 宋代是否真有使用麻油渣或熟桐油塗抹瓦片以掩蓋瑕疵的工藝？這種做法對瓦片壽命的實際影響如何？（此為小說虛構的核心情節，基於合理性推演）
4.  **端王舊邸改稱端命殿的時間：** 端王趙佶在元符三年即位為徽宗，其舊邸改稱端命殿的具體時間點是否在三月十五日之前或之後不久？（小說中假定已改稱，以強化其身份轉變）

**【合理推演】：**
1.  **物料剋扣與底層應對：** 宋代官僚體系中，基層官吏利用職權剋扣物資、中飽私囊是常態，尤其在大型耗費甚鉅的工程中，油水更豐。周大興作為匠頭，深知向上申報的風險，不僅無法解決問題，反而會引火燒身。因此，他選擇私下籌措資金，尋找民間偏方，以「瞞天過海」的方式應對，是符合歷史語境下，底層工匠在官僚壓榨與生存壓力下的無奈且合理的選擇。
2.  **官員視察的敷衍：** 工部員外郎趙大人身居高位，對基層工藝細節不甚了解，加之對窯作環境的厭惡，以及趕工期、公務繁忙等因素，其視察流於形式、走馬觀花是極為現實的。他對「瓦光可鑑」的讚賞，反映了他對外觀的重視，而非對實質品質的深究。
3.  **物資調撥的隨意性：** 趙員外郎將「剩餘桐油瓦式」直接調撥給端命殿，體現了宋代官員在一定權限內對物資的支配權，尤其涉及到皇家工程，其決策往往更為迅速且不容置疑。這也暗示了新即位的徽宗對宮殿修繕的熱衷，使得這類需求具有高優先級。

**【小說虛構】：**
1.  **周大興其人：** 泥瓦匠頭目周大興是完全虛構的人物，其年齡、經歷、性格及在修內司的具體職位與人際關係均為小說創作。
2.  **桐油烤瓦情節：** 使用麻油渣與熟桐油塗抹青瓦，再回爐急火烘烤以掩蓋燒結瑕疵的具體情節，是為本章核心衝突與人物抉擇而設計的虛構細節。儘管其物理原理（油漆光澤）有一定合理性，但其在宋代官窯中的普遍應用及效果，無史料直接記載。
3.  **小石頭的角色：** 學徒小石頭是虛構人物，用以襯托周大興的匠頭身份，並作為基層工匠的代表。
4.  **李主事與趙員外郎：** 修內司主事李大人和工部屯田司員外郎趙大人，其姓名及具體行為均為虛構，但其官職設定與職權範圍符合宋代官制。

**【連續性變更】：**
