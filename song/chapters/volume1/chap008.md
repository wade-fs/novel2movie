# 第八章　太學外舍的策問抄本

元符三年十月初十日，汴京城南，朱雀門外，國子監太學外舍的齋舍中，數百名士子正伏案疾書。深秋的陽光透過高窗灑落，卻難以驅散屋內瀰漫的墨香與筆尖摩擦紙張的沙沙聲。空氣中凝結著一股令人窒息的緊張，每個人的眉頭都緊鎖著，仿佛肩負著社稷興衰的重擔。這不僅僅是一場尋常的月試，更是外舍生晉升內舍的關鍵一搏。

黃時，一名來自應天府的寄祿生，此刻正襟危坐於書案前，指尖緊握著一支狼毫，卻遲遲未能落筆。他二十有二，面容清瘦，眼窩深陷，顯是長年苦讀所致。他的目光掃過身前攤開的試卷，那上面的題目，墨跡猶新，卻沉甸甸地壓在他的心頭：

《論天下財賦出入與元豐法度》

「元豐法度」四字，如同一柄懸在頭頂的利劍，寒光閃爍。自哲宗皇帝駕崩，年僅十八的端王趙佶即位，向太后垂簾聽政，朝堂上的風向便一日數變。是沿襲元祐舊黨之政，恢復司馬光、呂公著等人力主之「祖宗法度」？抑或是堅守哲宗親政後所推行的「紹述」之旨，繼續奉行王安石、章惇、曾布等人之「元豐新法」？這道策問，看似尋常，實則是一道深不見底的鴻溝，稍有不慎，便會跌入萬劫不復的深淵。

黃時深吸一口氣，試圖平復胸中翻騰的焦慮。窗外偶有秋風拂過，發出嗚咽的聲響，將遠處市井的喧囂聲模糊地送入耳中。朱雀門外，攤販的叫賣聲、挑夫的吆喝聲，以及車馬轆轆的雜音，無一不提醒著他，他此刻身處的，是大宋的都城，是天下政局的中心，而他，一個微不足道的太學生，卻被迫成為這場政治博弈的棋子。

自從他背負著鄉里族人籌措的十萬銅錢盤纏，從應天府一路北上，來到這汴京太學求學，每一步都走得如履薄冰。那十萬銅錢，並非尋常之數，是鄉親們將田地抵押給富賈，或是變賣傳家之物，才一點一滴湊出來的。這筆錢，足夠一個尋常農戶數年之用，在汴京也夠他外舍寄祿生三五年的膏火之費。他知道，那不只是一筆錢，更是數十雙飽含期盼的眼睛，寄託著整個宗族的榮耀與希望。若他不能金榜題名，光耀門楣，那筆錢便如同一道催命符，將他壓得喘不過氣。

太學三舍法，本是王安石變法時所創，意在選拔真才實學之士。外舍生，每月有月試，表現優異者可升入內舍；內舍生則可直接參與科舉，甚至有機會被薦舉入仕。這一次的外舍升內舍試，便是他改變命運的絕佳機會。然而，眼前這道策問，卻將他推進了兩難的境地。

「元豐法度……」黃時在心中默念。元豐年間，神宗皇帝重用王安石，推行青苗、免役、市易、均輸等新法。這些新法，初衷是「理財」「富國」，卻在實施中引發了巨大的爭議。舊黨認為其「與民爭利」，傷及根本；新黨則堅稱其為富國強兵之基石。哲宗親政後，一度力推「紹述」，將新法奉為圭臬，貶斥舊黨。如今哲宗駕崩，向太后垂簾，朝中韓忠彥等舊黨大臣漸受重用，但章惇、曾布等新法重臣依然盤踞要津，權勢未減。朝廷的風向，如十月汴河上的浮萍，捉摸不定。

他想起前幾日，太學博士林自，私下在校外酒肆與士子們談論時局，言及新帝即位，雖有向太后調和之意，但「紹述」之政仍是主調，士子們不可輕忽。當時便有心急者，求取林博士的「紹述密題題解」，一時之間，太學內外頗為流傳。

黃時的目光不經意間瞥向鄰座。他的同舍好友陳子業，此刻正低著頭，右手看似握筆疾書，左手卻悄悄地從寬袖中抽出一張摺疊得極小的紙條。那紙條上，墨跡細如蚊蠅，密密麻麻地寫滿了字。黃時認得，那便是市面上流傳的「紹述密題題解」。

陳子業是個性情活躍的士子，出身汴京城內一戶殷實之家，平日裡穿著講究，腰間常佩一塊上好的羊脂玉。他與黃時交好，卻不似黃時那般小心謹慎。此刻，陳子業的目光極快地掃了一眼監考的學官，見其正踱步至齋舍另一側，便猛地將紙條攤開一角，只露出最關鍵的幾行字。他微微側過身子，用肩膀擋住學官的視線，同時用眼神示意黃時。

黃時的心臟猛地一抽。他看見那紙條上赫然寫著「……元豐新法，其利國利民之本意，不可不察。雖施行有弊，然其宏旨，實為社稷長久計……」等字樣。這正是林博士在酒肆中，所言「紹述」的調子，強調新法本意之良善。

陳子業又將紙條向黃時的方向推了推，壓低聲音，幾乎聽不見地輕喚了一聲：「黃兄……」

黃時的筆尖不由自主地顫抖了一下，險些將墨汁滴落。他知道陳子業是好意，想助他一臂之力。若依照這「題解」的思路來寫，無疑是最穩妥的選擇，因為這代表了當時太學內部，甚至某種程度上，朝廷中新黨勢力所希望看到的答案。

然而，一旦作弊被查，後果不堪設想。太學規矩森嚴，作弊者，輕則絀落除籍，重則終身不錄，斷絕仕途。他背負著族人十萬盤纏的重擔，根本賭不起。那將意味著，他不僅將辜負所有人的期望，更會將家族拖入萬劫不復的境地。那十萬銅錢的債務，或許將成為壓垮他家鄉父老的最後一根稻草。

黃時的眼神從那紙條上移開，重新落回自己的試卷。他深吸一口氣，在心中默默對陳子業說了一聲「謝了」。他不能看。他必須自己寫。

可是，如何寫？全盤肯定元豐新法，會不會觸怒向太后與漸受重用的舊黨？若全盤否定，又會不會被視為「非議祖宗法度」，得罪章惇、曾布等權臣？

他閉上眼睛，腦海中飛速地檢索著平日所讀的經義與史論。王安石的《字說》、司馬光的《資治通鑑》、程頤、張載等大儒的言論，如潮水般湧現。

王安石在《字說》中，曾言：「夫天地之化，萬物之生，皆有其自然之理。國家理財，亦應順其自然，興利除弊，以養天下。」這無疑是對新法「興利」思想的最好註腳。而司馬光在《資治通鑑》中，論及漢武帝時，亦曾寫道：「夫天地之間，物產有限，取之有時，用之有節。國家之政，當以寬仁為本，輕徭薄賦，使民休養生息，方為長久之道。」這與王安石的積極干預，顯然是兩種截然不同的思路。

黃時的指尖輕輕敲擊著桌面，發出極為輕微的叩擊聲。他想起向太后此次垂簾，曾下詔求直言，並已著手起用韓忠彥等舊黨大臣，同時又未罷黜章惇、曾布，顯然是希望調和新舊。這是否意味著，朝廷希望看到一種「中和」的論調？

他猛地睜開眼睛，心中已有了腹稿。他決定不走極端，不偏廢任何一方。他要寫一篇看似迎合「紹述」之旨，卻又暗合向太后調和之意的策論。

筆尖蘸飽了墨，墨汁烏黑發亮，散發著微苦的氣味。黃時開始動筆，起手便是對「元豐法度」的肯定，但這種肯定，卻巧妙地避開了具體措施的爭議，轉而強調其「富國強兵」的「本意」。

「臣聞國家興衰，財賦為本。元豐年間，神宗皇帝肇興新法，以圖理財強兵，其本意實為社稷長久計，非為私利也。」

他寫得沉穩而緩慢，每一個字都力求精準，字跡清秀而有力。這是他多年苦讀的功底，也是他唯一能倚仗的武器。

接著，他筆鋒一轉，開始引用王安石《字說》中的語句，闡述國家「興利」之必要，將其與天地萬物「自然之理」相結合，顯得高深而充滿哲思。

「夫天地之化，萬物之生，皆有其自然之理。國家興利除弊，以養天下，此亦因時制宜，順應天道之舉也。若坐視財用困窘，國力衰微，則何以立國，何以安民？」

寫到這裡，他停頓了一下，抬頭看了一眼監考的學官。學官正背著手，緩緩地從齋舍中間踱過，目光銳利地掃視著每一個士子。黃時趕緊垂下頭，心跳如鼓。他知道，這段話，足以讓那些堅持「紹述」的太學博士們頷首稱讚。

然而，僅僅如此還不夠。他必須為自己留下後路，為可能到來的「元祐之政」埋下伏筆。

他筆鋒再轉，開始論述「興利」之外，更重要的「節用」與「恤民」。他巧妙地將司馬光《資治通鑑》中對「民力」的重視，融入自己的論述。

「然興利之術，雖為國本，亦當慎之又慎。蓋天地之間，物產有限，民力有窮，國家取之於民，當如取之於井，取者不竭，則井水長流；取之太甚，則井涸民枯矣。故《資治通鑑》有言：『夫天地之間，物產有限，取之有時，用之有節。國家之政，當以寬仁為本，輕徭薄賦，使民休養生息，方為長久之道。』」

他將王安石的「興利」與司馬光的「節用恤民」熔接起來，試圖構築一個看似全面的論點。他強調，元豐法度雖有其「宏旨」，但在實際施行中，亦需「因時損益」，「體察民情」，以達「上下交泰，內外和合」之境。

他小心翼翼地措辭，避免直接批評新法，而是將其歸結為「施行之弊」，而非「法度之失」。他引申說，即便良法，若執行不當，亦會傷民。這是他能想到的，在當前晦暗不明的局勢下，最為穩妥的表達方式。既肯定了新法的合理性，又給舊黨的觀點留下了空間，還暗合了向太后調和新舊的意圖。

時間一點一滴地流逝，齋舍內只有筆尖的沙沙聲和偶爾的咳嗽聲。黃時感到自己的手腕有些發酸，額角也沁出了細密的汗珠。他不斷地審視著自己寫下的每一個字，每一個句子，唯恐有一絲一毫的偏差。這不是一篇學術論文，而是一場政治賭博，賭注是他整個家族的未來。

他寫到國家財賦的出入，應當「量入為出，不致匱乏」，又當「取之有道，不傷民力」。他引用了《周禮》中的「九府圜法」之說，以示其論有古法之依據。最後，他總結道，當今之世，首重「安民」，「元豐法度」亦當以「安民」為歸。若能如此，則天下幸甚，社稷幸甚。

整篇策論，行雲流水，論證嚴謹，足足寫了近千字。黃時放下筆，長長地舒了一口氣。他再次從頭到尾審視了一遍，確認沒有錯別字，也沒有任何可能被抓住把柄的激進言辭。這是一篇「兩面討好」的策論，他將王安石的《字說》引語與司馬光的《資治通鑑》史論巧妙熔接，試圖在矛盾的政治主張之間找到一個平衡點。

或許，這並不是一篇能讓他一鳴驚人的文章，但他相信，這至少能讓他在這場外舍升內舍的考試中，穩穩地通過。他的目標不是拔得頭籌，而是穩妥晉升。

考時將盡，監考學官提醒眾士子，只剩半刻鐘。黃時將試卷整理妥當，小心翼翼地將其疊好，起身，將其呈交給收卷的學官。那一刻，他感到前所未有的輕鬆，仿佛壓在心頭的巨石終於被卸下。

他回到自己的書案前，收拾筆墨紙硯。陳子業也已交卷，此刻正伸著懶腰，疲憊地揉著太陽穴。見黃時回來，他壓低聲音問道：「黃兄，你可看那題解了？我方才將它推與你，你怎地不看？」

黃時搖了搖頭，苦笑道：「我不敢看。此番凶險，全憑自知。子業，你可順利？」

陳子業撇了撇嘴，道：「我將林博士的題解化用了一二，通篇盡頌元豐之法，想來不會有失。如今章相公、曾相公依然居於中樞，新帝即位，雖有調和之意，然紹述仍是主調，吾輩不可不察啊。」他壓低聲音，一副胸有成竹的樣子。

黃時心中一動，他方才的策論，雖然也肯定了元豐新法，但卻留了後路，並非一味歌頌。與陳子業的一味「盡頌」相比，他的策略是否太過保守，以至於會被認為立場不夠鮮明？他心頭剛卸下的石頭，又悄然懸起。

就在黃時心中揣度之際，齋舍的門突然被猛地推開，發出一聲沉悶的撞擊聲。門外，一名內舍的學長，面色焦急，氣喘吁吁地奔入齋舍。他顧不得監考學官的呵斥，徑直跑到齋舍中央，壓低聲音，卻難掩激動地對周圍幾個交卷的士子耳語。

「諸位，大事！天大的事！」學長聲音急促而低沉，卻如一道驚雷，猛地在黃時耳邊炸響。

「方才從省院傳來消息……」學長喘息著說道，目光掃過周圍，見無學官注意，才又壓低聲音道：「章相公罷相了！出知越州！」

齋舍內，原本的竊竊私語和收拾物品的聲音，瞬間凝固。所有人的目光，齊刷刷地投向那學長。章惇，當朝宰相，鐵腕推行新法，權傾朝野，竟被罷相？這消息，無異於平地一聲驚雷！

學長見眾人震驚，又壓低聲音補充道：「不僅如此，韓忠彥韓相公，已拜右相！曾布曾相公，拜左相！」

黃時只覺腦中嗡的一聲。章惇罷相，意味著新黨的頭號人物倒台。韓忠彥拜右相，這是舊黨的勝利！而曾布，雖然也是新黨舊人，卻在韓忠彥這個舊黨人物之下，擔任左相，這明顯是向太后調和新舊的姿態。

「還有……」學長繼續說道，聲音中帶著一絲興奮：「朝廷改元之議已定！聽聞，將改元為『建中靖國』！」

「建中靖國」！這四字一出，黃時的臉色瞬間慘白如紙。建中，意為建立中正之道；靖國，意為安定國家。這分明是向太后力主調和，意圖徹底結束新舊黨爭，恢復中庸之道的明確信號！

黃時僵硬地轉過頭，目光落在自己剛剛交出去的試卷方向。他的腦海中，清晰地回放著自己方才寫下的每一個字：通篇引述王安石新學的《字說》，雖然後來又巧妙地嫁接了司馬光的《資治通鑑》史論，試圖做到兩面討好。但他開篇對「元豐法度」的肯定，以及對王安石「興利」思想的闡述，無疑都帶有濃重的新黨色彩。

如果章惇還在相位，如果「紹述」依然是主旋律，他的策論或許會被認為是穩妥之作。但此刻，章惇已經罷相，韓忠彥上位，朝廷已經決定改元，新的政治格局已然形成！這意味著，他那篇小心翼翼、試圖兩面討好的策論，此刻看來，卻是那麼的……尷尬而錯誤。

他彷彿看見自己的試卷，在那堆積如山的考卷中，被學官輕輕拿起，然後又輕輕放下，隨後，他的名字將被默默地劃去。十萬銅錢的盤纏，鄉親們的期盼，他自己的前程……一切都如同手中的墨汁，在白紙上暈開，最終化作一片觸目驚心的污漬。

黃時的嘴唇翕動，卻發不出任何聲音。他只覺得渾身冰涼，如同置身於嚴冬的汴河之中。他努力想要呼吸，卻發現周圍的空氣，此刻也變得如同鉛塊般沉重，壓得他幾乎窒息。

本章時間設定為元符三年十月初十日（1100年11月13日）。此時，哲宗皇帝駕崩不久，徽宗即位，向太后垂簾聽政。歷史上，元符三年九月，章惇因與向太后意見不合，被罷相，出知越州；十月，韓忠彥（舊黨代表人物）被任命為右相，曾布（新黨骨幹，但立場相對溫和，且與章惇有隙）則被任命為左相。這是向太后試圖調和新舊黨爭的重要舉措。同時，徽宗即位後確實有改元之議，最終於元符三年十一月確定改元為「建中靖國」。太學「三舍法」是王安石變法時創立的教育選拔制度，分為外舍、內舍、上舍，並與科舉掛鉤，是當時士子晉身的重要途徑。章綱中提到的「林自」為虛構太學博士，但其所傳遞的「紹述」訊息，反映了哲宗後期新黨主導政局下，太學內部的學術風氣與政治傾向。

**【待核事項】：**
1.  **太學外舍月試的具體時間與頻率：** 章綱中提及為「月考」，本章依此設定，但需進一步考證宋代太學月試的確切制度與頻率。
2.  **太學內部對策問作弊的處罰條例：** 本章設定為「絀落除籍，終身不錄」，需核實宋代太學對此類行為的具體處罰細則。
3.  **寄祿生與外舍生津貼及盤纏價值：** 十萬銅錢在當時的購買力及對應的銀兩、金錢換算，是否足以支撐數年汴京生活及學費，以及其對應的社會階層與家族負擔。
4.  **「紹述密題題解」的實際存在形式：** 本章虛構了林博士私下兜售的題解，需考證宋代是否存在類似的考前輔導或洩題現象，以及其流傳方式。

**【合理推演】：**
1.  **太學生對政治風向的敏感與押寶：** 在新舊黨爭激烈的時期，太學作為選拔人才的場所，必然會受到朝政變動的直接影響。士子們在策論考試中揣摩上意、押寶政治立場是符合情理的。本章黃時的掙扎與選擇，正是這種微觀層面政治影響的合理推演。
2.  **基層資訊傳播的滯後性與不確定性：** 章惇罷相、韓忠彥拜相等重大朝政變動，從朝廷發布到消息傳遍都城乃至太學，需要一定的時間。黃時在交卷後才得知消息，體現了資訊傳播的延遲與不對稱，也放大了其決策的風險性。學長急匆匆傳遞消息，也是當時資訊傳播的常見方式。
3.  **士子間的互助與作弊誘惑：** 在升學壓力巨大的背景下，士子之間存在互相幫助甚至作弊的現象是合理的。陳子業的行為反映了這種現實，而黃時的拒絕則凸顯了他的原則與對風險的考量。
4.  **對「元豐法度」與「紹述」的理解偏差：** 哲宗後期，「紹述」之政讓王安石新法成為主流。但在新帝即位、向太后垂簾的過渡期，這種「紹述」的「度」和「方向」變得模糊，使得士子對策論題目的判斷更為困難。黃時試圖「兩面討好」的策論，正是在這種模糊政治空氣下的合理應對。

**【小說虛構】：**
1.  **黃時及其家族背景：** 黃時作為應天府的寄祿生，其背負族人十萬盤纏的設定，以及他為此所承受的巨大精神壓力，均為小說虛構。
2.  **陳子業及其「紹述密題題解」：** 黃時的同舍好友陳子業，以及他私下夾帶、並試圖與黃時分享「紹述密題題解」的細節，均為小說虛構，用以塑造微觀衝突和人物抉擇。
3.  **黃時策論的具體內容與熔接策略：** 黃時在策論中將王安石的《字說》引語與司馬光的《資治通鑑》史論巧妙熔接的具體論述方式，是為了展現其在政治壓力下的學術應變能力，屬於小說虛構的戲劇細節。
4.  **太學博士林自私下兜售「題解」：** 林自此人物及其行為是為情節服務的虛構。

**【連續性變更】：**
1.  **黃時的心理狀態：** 本章開始時，黃時處於焦慮與謹慎之中，寫作過程中經歷了掙扎與自我說服，提交試卷後略感輕鬆。章末，因突如其來的政治變動，其心理狀態急轉直下，陷入巨大的恐懼與絕望，對前途感到迷茫。
2.  **黃時對朝政的認知：** 本章前段，黃時對朝政風向的判斷是晦暗不明，他試圖在「紹述」與「調和」之間尋找平衡。章末，章惇罷相，韓忠彥拜相，改元「建中靖國」等消息，徹底改變了他對朝政走向的認知，使其意識到自己之前的判斷可能已完全錯誤。
3.  **與陳子業的關係：** 兩人的關係在本章中展現了同窗好友間
