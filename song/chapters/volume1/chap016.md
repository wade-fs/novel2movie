# 第十六章　當十錢出籠與物價騰躍

崇寧二年六月十二日，酷熱如蒸籠。汴京內城，州橋藥鋪街，正午的日頭毒辣辣地烘烤著青石板路，熱氣從地上蒸騰而起，將遠處的牌坊、近處的店招都扭曲成模糊的幻影。空氣中瀰漫著一股混雜的氣味：藥鋪裡散逸出的川芎、當歸的辛辣，酒肆裡蒸騰的酸腐酒糟，腳夫們汗臭和著街邊泔水溝的腥臭，以及一股隱約的焦糊味——那是太陽炙烤著一切有機物，將它們的水分榨乾，釋放出最後的微弱生命氣息。

顧明道，汴京州橋生藥鋪的東主，亦是太醫局兼職的生藥行首，年屆五十，此刻正襟危坐在他那間不大不小的鋪子裡。他身著一件半舊的湖藍色絲綢長袍，汗水浸透了背心，緊貼著皮膚，黏膩得難受。他沒有搖扇，只是端坐著，雙眼微闔，耳廓卻像兩扇張開的蒲扇，將街市上紛亂的聲響一點不落地收入耳中。

自從半個月前，寶豐鑄錢務外那高聳的熔爐日夜不停地吐出烏煙，大宋官家下旨鑄造新錢「崇寧重寶」以來，汴京城就陷入了一種古怪的喧囂。起初是好奇，是觀望，繼而是疑惑，是拒絕，到了今日，已徹底變成了混亂、叫罵與哭喊。

「一斤羊肉三貫錢！去歲不過八百文！這不是搶劫嗎！」
「我家婆子拿了十個大錢，只換得一升糜子，平日裡能買三升半啊！」
「這錢是鉛鐵！是鉛鐵！不是銅！」
「閉嘴！誰敢說這重寶是鉛鐵？朝廷新鑄！當十錢！當十錢！」

顧明道聽著這些從街頭巷尾傳來的嘶吼，心頭如同被一塊燒紅的烙鐵緩緩壓下。他知道，這「崇寧重寶」根本不是什麼寶。他曾親手掂量過，那錢體粗糙，邊緣毛刺未去，錢文模糊不清，銅色發暗，隱隱透著鉛錫的灰白。錢爐的火候不足，鑄造敷衍，含銅量不足三成，比當年的折二錢還要不堪。可官府卻強行規定，一枚此等劣幣，面值竟等同於十枚足色小銅錢。這簡直是把天下百姓當成了三歲稚童。

「阿爹，隔壁米鋪的王掌櫃把鋪門半掩著，只在門縫裡給熟客過秤。」顧明道的獨子顧小乙，一個二十出頭的精壯後生，從門外探頭進來，臉上汗津津的，眉頭緊鎖。「他說，今日已有三家米鋪被差役砸了，掌櫃的都被枷了出去，說是『敢拒收大錢者，徒二年；敢閉門者籍沒家產』。」

顧明道緩緩睜開眼，他的目光掃過自家鋪子裡那些從川蜀、嶺南遠道而來的藥材，它們靜靜地躺在藥櫃裡，散發著微苦而又沉靜的氣息。那上好的川產人參，根鬚飽滿，紋理清晰；那色澤純正的川芎，藥力十足，香氣撲鼻。這些都是他顧家藥鋪百年聲譽的基石，是他與那些跋山涉水、冒死販運的客商們一點一滴建立起來的信任。那些客商，只認足色的金銀鋌子，只認光潔飽滿的舊小錢。誰會收這些黑沉沉、輕飄飄、連銅鏽都發不出正常青綠色的「當十錢」？

「知道了。」顧明道聲音沙啞，卻透著一股壓抑的沉重。「去把櫃檯裡的那幾張公券收好，還有那匣子裡存的舊錢，都收去後院，小心看管。」

顧小乙應了一聲，轉身去辦。顧明道則又閉上眼，腦海中飛快地盤算著。藥鋪的庫存還能支撐多久？上個月從蜀中來的客商，臨走時還催促著下一批貨的訂金。如今市價已經亂了套，原本一枚小錢能買一隻燙手的燒餅，現在街上傳言，三枚當十錢才能換到同樣的一隻，折算下來，等於三十文舊錢！這意味著物價在短短幾日之內，暴漲了五倍不止。這不是市價，這是掠奪！這是生生將百姓的血肉從骨頭上刮下來！

他聽見街上傳來一陣急促的腳步聲，夾雜著金屬撞擊的清脆。那是差役們腰間的鐵鎖和佩刀。他知道，今日的劫難，終於要臨到他這間藥鋪了。

果然，腳步聲越來越近，最終停在了他的鋪門前。陽光被幾道高大的身影遮住，店堂裡陡然暗了下來。一股汗臭和著廉價皮甲的酸味衝入鼻腔。

「顧掌櫃！」一個粗啞的聲音在門口炸響，帶著官差特有的蠻橫與不耐。

顧明道緩緩睜開眼，看到門口立著三名開封府的差役，領頭的那個身材魁梧，臉上有一道從額角斜劃到下頜的疤痕，此刻正用一雙渾濁的眼睛掃視著鋪子裡的藥材。他腰間挎著一把形制簡陋的佩刀，手裡則握著一根碗口粗的漆木棍，棍頭敲在門檻上，發出沉悶的聲響。他身後跟著兩個小吏，一個捧著一本厚厚的公文，一個則提著一個沉甸甸的布袋。

「趙差頭，有失遠迎。」顧明道掙扎著站起身，儘量讓自己的聲音聽起來平靜而恭敬。他認得這個趙差頭，是開封府的老油子，為人粗蠻，卻也深諳官場門道。

「哼！顧掌櫃，你這鋪子今日為何不關門？」趙差頭獰笑一聲，露出兩排發黃的牙齒。「難道你不知道，奉朝廷旨意，所有店鋪都必須開門營業，收受新錢嗎？還是顧掌櫃自恃是太醫局的行首，便能藐視朝廷法令？」

顧明道心頭一顫。他之所以沒有關門，正是因為關門的代價更大——籍沒家產。他本想著，或許憑著自己太醫局行首的身份，能讓這些差役有所忌憚，沒想到反而被趙差頭拿來敲打。

「趙差頭說笑了。小老兒不過一介藥商，怎敢藐視朝廷？只是這幾日店中生意清淡，來客稀少，故而門庭冷清了些。」顧明道拱手作揖，姿態放得很低。

趙差頭不為所動，他大步跨入店中，身後的兩名小吏也跟了進來。那捧公文的小吏將厚厚的冊子「啪」地一聲拍在櫃檯上，發出刺耳的聲響。

「少廢話！顧掌櫃，朝廷如今正在籌備西北邊軍的藥材，急需一批上等遼東野山參和川芎。你們這些藥鋪，理應為國效力！」趙差頭的目光落在藥櫃最顯眼處，那裡擺放著兩支用紅絲綢小心包裹的「上品」野山參，根鬚纏繞，形似人形，是他店裡的鎮店之寶，市價值三十貫小錢。

顧明道心臟猛地一縮。這兩支參是他半年前費盡心思才從遼東客商手中購得，本是為等待一位重病的大官而準備。三十貫小錢，這幾乎是他這鋪子半年的淨利了。

「趙差頭，這兩支野山參，乃是小老兒店中僅有的上品，尋常病人是斷然用不起的……」顧明道試圖解釋，聲音卻有些發顫。

「用不起？你以為是給你家親戚用嗎？」趙差頭惡狠狠地打斷了他，語氣中帶著不容置疑的威脅。「這是為大宋將士所備！你敢說邊軍將士用不起？還是你覺得，這參不值得！」

說罷，他朝身後提著布袋的小吏使了個眼色。那小吏立刻從布袋裡掏出一把沉甸甸的銅錢，徑直扔在了藥櫃上。「叮叮噹噹」一陣亂響，二十枚黑黢黢、形狀不一的「崇寧重寶」散落在顧明道面前。它們沒有舊錢的光澤，反而帶著一種不祥的暗啞。

「二十枚『崇寧重寶』，每枚當十。這便是你這兩支野山參的價錢了！」趙差頭的聲音冰冷，不帶絲毫商量餘地。

顧明道看著那二十枚劣幣，如同看著二十塊烙鐵。二十枚當十錢，面值上是兩百文，而這兩支野山參的市價是三十貫，也就是三萬文舊錢！這哪裡是買賣？這是明搶！若他收下，他顧家藥鋪百年基業，立刻便要虧空大半，無立錐之地。

他深吸一口氣，強忍住心中的怒火與悲憤，雙膝一軟，噗通一聲跪在了冰冷的青石板上。

「趙差頭！趙差頭！您行行好，小老兒這鋪子，全靠這點本錢周轉啊！這兩支參，是小老兒的命根子！您便是看在小老兒平日裡也為太醫局辦事的份上，給個方便吧！這二十枚大錢，連買一支尋常的川芎都不夠啊！」顧明道帶著哭腔，額頭幾乎要磕到地面。

趙差頭居高臨下地看著他，臉上沒有半分憐憫，反而露出殘忍的笑容。
「顧掌櫃，你這是公然抗旨嗎？還是說，你覺得這『崇寧重寶』是假錢？是劣幣？」他聲音陡然拔高，語氣森然，每個字都像一顆石頭，砸在顧明道的心頭。「你可知抗旨不遵的下場？枷示市肆，全家充軍！籍沒家產，連你這鋪子裡的藥渣都得充公！」

一旁的小吏也配合著，將那本公文翻開，指著上面密密麻麻的文字，大聲念道：「『崇寧二年六月初一，奉聖旨，京師及陝西諸路，一體通行崇寧重寶當十錢，不得拒絕。有敢以輕重多寡較量者，處以徒二年之刑；有敢閉門罷市者，籍沒家產，充軍邊遠！欽此！』顧掌櫃，你可聽清了？」

顧明道渾身冰冷，如同墜入冰窟。他知道，今日無論如何哀求，都已無濟於事。他抬頭，看到趙差頭眼中那森冷的殺意，那是一種被官府權力徹底馴服、以至於完全漠視他人性命的眼神。

他緩緩閉上眼，腦海中閃過一個瘋狂的念頭。

「趙差頭說的是，說的是……小老兒糊塗了。」顧明道重新睜開眼，臉上擠出一個比哭還難看的笑容，語氣卻透出了一絲詭異的平靜。「這兩支野山參，能為邊軍將士效力，是它們的福分，也是小老兒的榮幸。」

他顫顫巍巍地站起身，走到藥櫃前。他的目光在那兩支真正的遼東野山參上停留了片刻，眼中閃過一絲不捨與痛苦。然而，他的手卻伸向了藥櫃深處，一個不甚起眼的木盒。

「只是……趙差頭，這兩支參，是小老兒珍藏多年的極品，怕是藥力太猛，尋常人難以承受。且邊軍將士多是血氣方剛之輩，猛藥進補反倒不美。小老兒這裡，還有一對『老山參』，藥性溫和，延年益壽，最是滋補，且效力不輸遼東野參。」顧明道邊說，邊從木盒裡取出兩支被厚厚油紙包裹著的「人參」。

他小心翼翼地解開油紙，露出「人參」的真容。那兩支參，形狀也極似人形，根鬚飽滿，紋理清晰，甚至散發著一種淡淡的藥香。然而，顧明道卻知道，這根本不是什麼人參，而是他多年前為了應付那些不懂藥理卻又貪圖「野山參」名頭的富商，用上好桔梗偽製的「假參」。他費盡心思，用藥汁浸泡，用炭火烘烤，再用蜂蠟定型，又用黃土培植了數年，才做出這等足以亂真的「藝術品」。

趙差頭狐疑地看了一眼，又嗅了嗅，見那「人參」確實有藥香，且形制與真參無異，便不耐煩地擺了擺手：「少囉嗦！都是參，有什麼區別？快快包好！耽誤了邊軍用藥，拿你問罪！」

顧明道心頭一鬆，幾乎要癱軟下來。他知道，自己這條命，這間鋪子，暫時算是保住了。他恭恭敬敬地將那兩支「假參」用紅絲綢重新包裹好，然後遞給趙差頭。

趙差頭接過，隨手扔給身後的小吏。小吏將其放入一個準備好的木箱中。

「好了，二十枚當十錢，你收好！顧掌櫃，你這次還算識相！」趙差頭語氣轉緩，卻仍帶著一股勝利者的蔑視。「記住，日後再有官府徵用，休要再耍花招！否則，有你好看！」

說罷，趙差頭和兩名小吏轉身，大搖大擺地朝門外走去。那二十枚黑黢黢的「崇寧重寶」仍舊散落在櫃檯上，在陽光下泛著一層詭異的暗光。

顧明道跪在地上，看著他們的身影消失在門口，直到街上的喧囂聲再度清晰起來，他才緩緩地吐出一口濁氣。冷汗順著他的鬢角流下，浸濕了衣領。他感覺自己的後背像被抽空了力氣，雙腿發軟，幾乎無法站立。

「阿爹！」顧小乙從後院跑了出來，臉色發白，顯然已經聽到了外面的動靜。他看到櫃檯上那堆劣幣，又看了看顧明道慘白的臉色，眼中滿是憤怒與焦慮。

「別管這些廢銅爛鐵了！」顧明道猛地站起身，語氣急促而堅定。「快！把你藏好的那些真錢，還有櫃底下的足色小錢，全都拿出來！連夜，全都裝進那幾個密封的藥罐裡，埋入後院地窖最深處！記住，埋得越深越好，用土石壓實，再用雜物掩蓋，不許留下任何痕跡！」

「阿爹，這是為何？」顧小乙不解地問道。

「蠢材！你難道沒看清今日的情形嗎？」顧明道語氣嚴厲，卻帶著深深的憂慮。「這些劣幣，朝廷強推，市面混亂，物價狂漲，早晚要出大亂子！這些真錢，是咱們顧家最後的血脈，是咱們將來進貨的根本！一旦朝廷徹底撕破臉皮，連這些僅存的舊錢都要收繳，那咱們就真的一無所有了！」

顧小乙聞言，臉色陡然一變，他立刻明白了事態的嚴重性。他看著顧明道眼中那種深沉的絕望與孤注一擲，心中也湧起一股巨大的恐懼。他不敢再耽擱，立刻轉身衝進了後院。

顧明道癱坐在椅子上，他的目光掃過空蕩蕩的藥櫃，又落在櫃檯上那堆毫無價值的「崇寧重寶」。他知道，今天他雖然保住了性命，保住了鋪子，卻也付出了巨大的代價——他親手用欺瞞的方式，踐踏了自己作為藥商的誠信，也見證了朝廷對整個城市工商業階層的信任紐帶，被這劣幣徹底撕裂。

這汴京城，怕是真的要變天了。

他正思量著，忽然，門外傳來一陣更加劇烈的喧囂。

「還我血汗錢！」
「這狗屁當十錢，買不到一升糜子！老子不活了！」
「你們這群狗官！老子今日跟你們拼了！」

緊接著，是木棍與人體撞擊的沉悶聲，刀劍出鞘的摩擦聲，以及此起彼伏的慘叫與哭號。

顧明道猛地抬頭。他聽清了，那是汴河縴夫們粗獷的嗓音。他們大多是底層百姓，靠著在汴河上拉縴為生，每日的腳錢都是當日結清。如今，他們領到的怕也是那些如同廢鐵般的「崇寧重寶」。

他衝到門口，只見趙差頭和他的兩名小吏剛跨出藥鋪門檻，還未來得及走遠。此刻，他們正被七八個身著破爛麻衣的縴夫圍住。那些縴夫們個個面色黝黑，肌肉賁張，眼中燃燒著絕望的怒火。領頭的縴夫手裡奪過一根木棍，對準趙差頭的頭部便狠狠砸下。

趙差頭顯然沒料到這些平日裡逆來順受的賤民會如此暴烈，他猝不及防，只來得及用佩刀格擋。木棍與刀身發出刺耳的摩擦聲，火星四濺。更多的縴夫衝上前去，有人抱住了小吏的腰，有人奪走了他們的鐵鎖。街頭頓時血肉橫飛，哭號震天。

顧明道僵立在門口，看著這突如其來的街頭混戰。熾熱的陽光下，塵土飛揚，鮮血濺上了青石板。他感覺到一股徹骨的寒意，從腳底直竄頭頂。這不再是單純的物價騰躍，這已是民怨沸騰，是百姓與官府之間，最後一絲遮羞布被徹底撕開的徵兆。

## 章後工作紀錄

**【史實骨架】**
本章的核心史實是北宋崇寧二年（1103年）宋徽宗時期鑄造「崇寧重寶」當十錢，並強行推行。根據《續資治通鑑長編》記載，此錢因含銅量不足，多鉛錫，質量低劣，但面值卻定為舊錢十文，導致民間普遍拒收。為推行此劣幣，朝廷數次下詔嚴懲拒收者，甚至規定「一人敢拒收大錢者，徒二年；敢閉門者籍沒家產」，並廣布京師及陝西地區。惡劣的貨幣政策迅速引發惡性通貨膨脹，物價飛漲，民間交易停滯，社會信用體系崩潰。章末縴夫因劣幣無法購買生活必需品而與官差衝突，也反映了當時底層民眾的困境和由此引發的社會動盪。汴京作為當時的首都，其市井百態和官府的強硬推行政策，是本章的歷史背景。

**【待核事項】**
1.  **具體物價漲幅數據：** 章中提到「物價暴漲五倍，原本一枚小錢可買一隻燒餅，此刻需三枚當十錢（折合三十文舊錢）」。此處的五倍漲幅是基於史料中「物價狂飆」的合理推演，但具體到燒餅等民生物資的漲幅，屬於小說創作。需核實當時一枚小錢實際能購買的燒餅或類似食物的價值，以確保「三枚當十錢買一隻燒餅」的合理性。
2.  **官府徵用藥材的背景：** 章中趙差頭稱藥材為「西北邊軍的藥材」而徵用。需核實崇寧二年此時期西北邊境是否有大規模軍事行動或藥材緊缺的記載，以增加徵用行為的歷史合理性。
3.  **「桔梗偽製人參」的技術可行性與歷史記載：** 本章虛構了顧明道以桔梗偽製人參應付官差的情節。需考證在宋代是否有類似的以其他植物冒充人參的造假技術和方法。
4.  **「當十錢」在京師及陝西諸路使用的具體時間限制：** 史料提及朝廷後被迫限定當十錢只在京師及陝西使用。本章發生在崇寧二年六月，此限定是否已出台或正在醞釀，需要進一步精確時間點。

**【合理推演】**
1.  **商人的自保行為：** 在劣幣驅逐良幣的惡劣環境下，商人為保住自身財產，必然會採取各種自保手段。拒收、閉門罷市、囤積良幣是直接反應，而像顧明道這樣以假貨應付官府徵用，並暗中藏匿舊錢，是基於其專業知識和對時局判斷的合理推演。這種「陽奉陰違」的策略，是底層人民在面對國家暴力時的無奈反抗。
2.  **基層官吏的行為模式：** 趙差頭等開封府差役的粗暴、蠻橫，以及對百姓生計的漠視，符合當時基層吏治敗壞、官府憑藉權力胡作非為的社會現實。他們利用朝廷法令，不僅推行劣幣，也趁機中飽私囊，勒索商家。
3.  **底層民眾的反應：** 汴河縴夫因收入變成廢錢而無法購買基本生活物資，最終爆發暴力衝突，是極度壓榨下民怨的必然結果。它反映了貨幣政策對社會底層的直接衝擊，以及在生存面前，民眾可能採取的極端反抗。
4.  **資訊傳播：** 物價飛漲、朝廷嚴令拒收劣幣的訊息，在汴京城內會迅速通過市井口耳相傳、官府張貼告示等方式傳播。顧明道作為藥鋪東主，其消息來源會更廣泛，對局勢的判斷也更為敏銳。

**【小說虛構】**
1.  **視角人物顧明道及其家庭：** 顧明道及其子顧小乙均為虛構人物，其藥鋪「州橋生藥鋪」亦為虛構。他們的存在是為了具體化當時汴京城中商人的群體形象和遭遇。
2.  **桔梗偽製人參情節：** 顧明道以精心偽製的桔梗冒充遼東野山參應付官差，是本章的核心戲劇衝突點之一。這一情節雖然有其合理性推演，但具體實施和效果是小說創作。
3.  **微觀衝突與對話：** 顧明道與趙差頭的對話、顧明道跪地求情、顧小乙藏匿錢幣等細節，以及縴夫與差役的街頭衝突，均是為展現歷史背景下的個體命運和社會矛盾而虛構。
4.  **具體感官細節：** 章中所有關於聲音、氣味、光線、服飾、道路、市井叫賣、兵刃質感等描寫，均為小說家為營造沉浸感而虛構的細節。

**【連續性變更】**
1.  **顧明道的人物狀態：** 從一個謹慎持重、聲譽良好的藥鋪東主，被迫淪為用假貨應付官府、藏匿財產以求生存的商人。他的內心受到巨大衝擊，對朝廷的信任徹底破裂，對未來充滿絕望。
2.  **藥鋪物資與財產：** 店中珍貴的遼東野山參被「徵用」，但實際被假參替換，避免了直接損失，但仍損失了偽製假參的成本和精力。店內足色小錢被全部藏匿，以備後用，但同時也意味著短期內流動資金的枯竭，進貨面臨巨大困難。
3.  **人物關係：** 顧明道與其子顧小乙的關係，在共同面對危機、藏匿錢幣的過程中，父子之間的信任和依賴進一步加深，但也承載了更沉重的生存壓力。顧明道與官府（以趙差頭為代表）的關係從原有的「應付」轉變為「對抗」（雖是隱性對抗），信任徹底斷裂。
4.  **汴京市井氣氛：** 從之前的喧囂中帶著秩序，變為全面失序、物價飛漲、民怨沸騰、隨時可能爆發暴力衝突的極度緊張狀態。

**【後續銜接】**
本章以街頭暴力衝突作結，預示著崇寧年間因劣幣政策引發的社會動盪將會進一步加劇。顧明道作為城市中產階級的代表，其財產的藏匿和對朝廷信心的喪失，預示著更多商賈將會採取類似的自保措施，導致市場信用進一步崩潰。
1.  **宏觀歷史銜接：** 此次「當十錢」事件是北宋末年社會矛盾激化、官民離心離德的一個重要標誌。它將引發後續一系列的經濟、社會危機，為北宋的衰落埋下伏筆。朝廷的強硬政策最終會引發更大的反彈，甚至可能觸發大規模的民變。
