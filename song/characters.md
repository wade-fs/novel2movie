# **《宋末》人物分級與角色管理表（characters.md）**

> **原則宣告**：本表角色劃分以《宋末》全書結構為經緯。一級人物必須承載跨卷因果，二級人物撐起特定戰線與朝野網絡，三級人物與虛構人物則作為社會史與制度落地的透鏡。所有人物的官職、生卒年與政權歸屬皆已與前列年代、戰役、官制表交叉校對。

## **一、一級人物（全書主幹角色卡）**

### **1\. 宋徽宗 趙佶（北宋末年皇權與文化中心）**

* **生卒年**：1082年5月13日－1135年6月4日（享年54歲／周53）  
* **籍貫**：開封府人（出生於開國公邸）  
* **官職／軍職**：皇帝（1100–1126內禪）、太上皇（1126–1127）、昏德公（1127–1135金封）  
* **派系網絡**：舊黨清剿與新黨蔡京派；崇信道教（自稱「教主道君皇帝」）；宮廷藝術圈（宣和畫院）  
* **核心行蹤**：1100年登極 ➔ 1105年花石綱 ➔ 1115–1120海上之盟 ➔ 1125年底禪位太子趙桓 ➔ 1126年南逃毫州復歸 ➔ 1127年四月被俘北遷 ➔ 1128年經韓州發配五國城 ➔ 1135年卒於五國城。  
* **史料分歧與防雷**：避免將其寫成純粹無能的昏君。他在位期間的政治經濟改革（如崇寧變法、幣制改革）對北宋財政造成毀滅性打擊，但其在書法（瘦金體）與繪畫上的造詣及對宮廷文化的重塑，是理解北宋末年物質文明達到巔峰卻迅速崩塌的關鍵對照。

### **2\. 宋欽宗 趙桓（靖康危機中的在位君主）**

* **生卒年**：1100年－1156年（享年57歲／周56）  
* **官職**：皇太子（1102–1125）、皇帝（1126–1127）、重昏侯（1127–1156金封）  
* **派系網絡**：東宮僚屬（耿南仲、聶昌等主和派）；與太上皇徽宗之政治冷戰  
* **核心行蹤**：1126年正月初即位 ➔ 歷經第一、二次汴京保衛戰 ➔ 1127年初兩赴金營議和被扣 ➔ 三月被廢為庶人 ➔ 四月北遷 ➔ 1156年在燕京逝世（消息1161年始傳回南宋）。  
* **史料分歧與防雷**：性格極度懦弱、多疑且反覆無常。靖康年間頻繁更迭將相（如首用李綱隨即罷免、罷免後又因民意復用）、輕信神棍郭京，是導致汴京防線徹底瓦解的主因。

### **3\. 李綱（北宋末至南宋初軍政防禦中流砥柱）**

* **生卒年**：1083年－1140年（享年58歲／周57）  
* **籍貫**：福建邵武人  
* **官職**：兵部侍郎、尚書右丞（1126）、參知政事、湖北京西路宣撫使（1127）  
* **派系網絡**：主戰派文官核心；與种師道、宗澤互為聲援；遭黃潛善、汪伯彥、秦檜排擠  
* **核心行蹤**：1126年第一次保衛戰督師擊退金軍 ➔ 遭主和派排擠罷官 ➔ 靖康二年初短暫復起 ➔ 1127年五月佐高宗即位首任宰相（在位僅75日） ➔ 因力主還京開封遭黃潛善罷黜 ➔ 終生遭南宋朝廷閒置貶謫。  
* **史料分歧與防雷**：學界常視其為北宋末年唯一的力挽狂瀾者。寫作時需注意其戰略侷限：他擅長守城與激勵士氣，但在面對全面崩潰的財政與金軍機動騎兵時，其主張的「立刻還京」在軍事後勤上存在嚴重空想。

### **4\. 金太宗 完顏晟（金國擴張期最高統治者）**

* **生卒年**：1075年－1135年（享年61歲／周60）  
* **官職**：金國第二代皇帝（天會年間，1123–1135）  
* **派系網絡**：完顏阿骨打之弟；與完顏宗翰、完顏宗望等宗室軍事貴族共同決策  
* **核心行蹤**：1123年繼位 ➔ 主導滅遼與1125–1127年兩路伐宋、靖康之變 ➔ 冊立偽齊劉豫 ➔ 1135年病逝。  
* **史料分歧與防雷**：決策果斷，充分利用北宋朝廷的黨爭與軍事腐敗；其在位期間確立了金國由女真部落聯盟向帝制官僚機構過渡的體制。

### **5\. 完顏宗望、完顏宗翰（金軍南下與靖康核心將領）**

* **生卒年**：宗望（？－1127，約四十餘歲）；宗翰（粘罕，1080–1137，享年58歲）  
* **官職**：東路軍副元帥（宗望）、西路軍左副元帥（宗翰）  
* **派系網絡**：金國勃極烈會議核心成員；宗翰長期把持西京（大同）與雲中兵權  
* **核心行蹤**：1125年分別自平州與大同東、西夾擊北宋 ➔ 1126年宗望率先抵汴京逼和 ➔ 1126–1127年兩路會師破汴京、俘獲二帝 ➔ 宗望於1127年中暑暴卒，宗翰則持續主導對南宋的富平之戰與建立偽齊。  
* **史料分歧與防雷**：宗望擅長外交與速戰速決；宗翰則具備極強的戰略眼光與政治野心（後因支持完顏昌和議遭金兀朮清洗）。

### **6\. 宋高宗 趙構（南宋政權創建與皇權集中核心）**

* **生卒年**：1107年6月21日－1187年11月9日（享年81歲／周80）  
* **籍貫**：開封府人（徽宗第九子，康王）  
* **官職**：兵馬大元帥（1126年末）、南宋皇帝（1127–1162）、太上皇（1162–1187）  
* **派系網絡**：早期依賴黃潛善、汪伯彥；中期重用呂頤浩、張浚；後期與秦檜長期勾結共謀和議  
* **核心行蹤**：1126年使金歸來開大元帥府於相州 ➔ 1127年五月於應天府即位 ➔ 1129年維揚之變與苗劉兵變 ➔ 1129–1130年海上漂泊與黃天蕩危機 ➔ 1138–1141年定都臨安並與金議和、收三大將兵權、殺岳飛 ➔ 1162年內禪孝宗。  
* **史料分歧與防雷**：高宗是南宋政權的拯救者，也是政治謀略極深的高手。寫作時切忌將其描寫為全然懦弱無能的逃跑皇帝；他在極端動盪中展現出高超的權力平衡術，透過犧牲岳飛與領土妥協，換取了南宋半壁江山的長治久安。

### **7\. 岳飛（南宋初年中興名將、抗金精神象徵）**

* **生卒年**：1103年3月24日－1142年1月27日（享年39歲／周38）  
* **籍貫**：相州湯陰人（今河南湯陰）  
* **官職**：荊湖南北路襄陽府路宣撫使、少保、樞密副使  
* **派系網絡**：岳家軍核心（王貴、張憲、岳雲、董先、楊再興）；與主戰派張浚、趙鼎相合；與秦檜、張俊、高宗政見水火不容  
* **核心行蹤**：1126–1127年投宗澤部入伍 ➔ 1130年牛頭山之戰與建康大捷 ➔ 1134年第一次北伐收復襄陽六郡 ➔ 1135年平定楊么水軍 ➔ 1140年第四次北伐（郾城、潁昌大捷）至朱仙鎮被十二金牌召回 ➔ 1141年交出兵權下獄 ➔ 1142年初除夕夜遇害。  
* **史料分歧與防雷**：必須將岳飛置於當時的「軍閥化朝廷與皇權防範武將」的制度脈絡中。他擁有極高聲望與十萬精銳「岳家軍」，且在1137年曾觸碰儲位敏感話題（言及立儲），是高宗與秦檜必欲除之的根本政治原因。

### **8\. 秦檜（紹興和議與岳飛案核心宰相）**

* **生卒年**：1091年－1155年（享年65歲／周64）  
* **籍貫**：江寧句容人（出生於內黃）  
* **官職**：尚書右僕射、左僕射同中書門下平章事兼樞密使、太師、秦國公  
* **派系網絡**：秦黨（萬俟卨、王次翁等）；與金國主和派（完顏昌）長期保持密信聯繫  
* **核心行蹤**：1127年隨欽宗北遷 ➔ 1130年自金營「奇跡般」南歸 ➔ 1138年拜相主導第一次和議 ➔ 1141年配合高宗收兵權、製造岳飛冤案 ➔ 獨相十八年（1138–1155），實行文字獄與清洗主戰派。  
* **史料分歧與防雷**：切忌將秦檜單純臉譜化為「純粹漢奸」。他在南宋建立後透過制度化吏治、稅收與整肅官場，協助高宗建立了一套穩固的官僚體系；其投降與迫害岳飛是基於「貫徹高宗意志」的政治分工。

### **9\. 韓世忠、張俊、劉光世（南宋初年三大將／中興四將之三）**

* **生卒年**：韓世忠（1090–1151，享年62歲）；張俊（1086–1154，享年69歲）；劉光世（1089–1142，享年54歲）  
* **官職**：樞密使（韓、張）、太保（劉）  
* **派系網絡**：三大軍事集團首腦；韓世忠早期抗金（黃天蕩）功高；張俊資歷深厚且晚期投靠秦檜；劉光世出身將門但治軍鬆散。  
* **核心行蹤**：1129年平定苗劉兵變立大功 ➔ 1130年韓世忠黃天蕩抗金、張俊轉戰江浙 ➔ 1137年劉光世因淮西兵變被罷兵權 ➔ 1141年韓、張與岳飛同時被解除兵權轉任樞密使 ➔ 岳飛死後韓世忠閉門謝客、郁郁而終，張俊則積極迎合秦檜。

### **10\. 金世宗完顏雍、完顏宗弼（金國中期軍政巨擘）**

* **生卒年**：宗弼（兀朮，？–1148）；完顏雍（金世宗，1123–1189，在位1161–1189）  
* **派系網絡**：宗弼為金太祖四子，歷任都元帥、左丞相；世宗為海陵王死後擁立之明君（行「小堯舜」之治）  
* **核心行蹤**：宗弼主導1140年對岳飛戰爭及1141年紹興和議；世宗則於1161–1164年結束海陵王南侵荒政，與南宋簽訂隆興和議，開啟金宋四十年間的黃金和平。

### **11\. 宋孝宗 趙昚（南宋中期明君與北伐記憶）**

* **生卒年**：1127年－1194年（享年68歲／周67）  
* **籍貫**：秀州嘉興人（太祖七世孫）  
* **官職**：皇太子（1160–1162）、南宋皇帝（1162–1189）、太上皇（1189–1194）  
* **派系網絡**：孝宗朝主戰／北伐派（虞允文、張浚）；乾道年間乾道閣臣  
* **核心行蹤**：1162年受高宗內禪即位 ➔ 積極平反岳飛冤案、追封鄂王 ➔ 1163年發動隆興北伐（符離之敗） ➔ 1164年簽訂隆興和議（叔姪之國） ➔ 1189年內禪。

### **12\. 成吉思汗、窩闊台、蒙哥、忽必烈（蒙古帝國四代核心）**

* **生卒年**：成吉思汗（1162–1227）；窩闊台（1186–1241）；蒙哥（1209–1259）；忽必烈（1215–1294）  
* **核心行蹤**：1206年成吉思汗建國 ➔ 1211–1234年蒙金戰爭（1234聯宋滅金） ➔ 1235–1241年窩闊台第一次全面攻宋 ➔ 1258–1259年蒙哥親征四川釣魚城陣亡 ➔ 1260年忽必烈稱汗並於1271年建國號大元、1279年滅南宋。

### **13\. 賈似道（南宋末年爭議性政治核心）**

* **生卒年**：1213年－1275年（享年63歲／周62）  
* **籍貫**：台州天台人（賈涉之子，理宗貴妃異母弟）  
* **官職**：平章軍國重事（南宋末年實質獨相）、太師  
* **派系網絡**：賈黨（翁重淵等）；提拔劉整、高達等前線將領；與台諫官僚及江浙地主階層對立  
* **核心行蹤**：1259年鄂州之戰力挽狂瀾、擁立度宗 ➔ 1260年代推行「打算法」整肅財政與「公田法」限制兼併 ➔ 1261年逼反劉整 ➔ 1267–1273年錯判襄陽戰局 ➔ 1275年丁家洲決戰潰敗，八月被貶途中遭鄭虎臣處死。  
* **史料分歧與防雷**：傳統史書將其歸入奸臣傳，但現代史學揭示其並非無能，他在鄂州危機中展現出色的臨危應變能力，其「公田法」亦是為了救亡圖存而對江南大姓資本的強行掠奪，卻因此遭到士大夫階層的反撲與徹底抹黑。

### **14\. 文天祥（南宋末年抗元忠義記憶與流亡核心）**

* **生卒年**：1236年6月6日－1283年1月9日（享年48歲／周46）  
* **籍貫**：吉州廬陵人（今江西吉安）  
* **官職**：寶祐四年進士、右丞相兼樞密使、開府儀同三司  
* **派系網絡**：江西士大夫勤王網絡（趙時賞、劉子俊）；與陸秀夫、張世傑並稱宋末三傑  
* **核心行蹤**：1275年散盡家財起兵勤王 ➔ 1276年赴元營交涉被扣、夜遁南下 ➔ 1277年江西反攻、空坑之敗 ➔ 1278年底廣東五坡嶺被俘 ➔ 1279–1282年囚於大都土室三年餘（作《正氣歌》） ➔ 1283年1月9日於柴市口就義。  
* **史料分歧與防雷**：文天祥不僅是忠臣，更是傑出的愛國詩人與政治思想家。寫作時需展現其由書生轉為軍事統帥的艱難心路歷程，以及被俘後與忽方的多次正面交鋒。

### **15\. 陸秀夫、張世傑（南宋末年流亡政權雙柱石）**

* **生卒年**：陸秀夫（1236–1279，享年44歲）；張世傑（？–1279，溺死於崖山）  
* **官職**：左丞相（陸秀夫）、少保／樞密副使（張世傑）  
* **核心行蹤**：陸秀夫為1256年同榜進士，長期輔佐李庭芝與流亡朝廷 ➔ 1278年在碙州端宗崩逝後力排眾議擁立衛王趙昺 ➔ 1279年崖山海戰失敗，背負幼帝趙昺跳海殉國；張世傑統率海上水軍轉戰四年，崖山戰敗後遇颶風溺死。

### **16\. 恭帝趙㬎、端宗趙昰、帝昺趙昺（南宋末代三幼主）**

* **生卒年**：恭帝（1271–1323，活到元代）；端宗（1269–1278，享年10歲）；帝昺（1272–1279，享年8歲）  
* **行蹤**：恭帝4歲即位（1274），1276年臨安投降北上；端宗8歲即位（1276），海上漂泊兩年病逝；帝昺7歲即位（1278），崖山殉國。三人命運象徵南宋皇統在蒙古鐵騎下的斷裂與悲劇。

### **17\. 伯顏（元軍滅宋統帥）**

* **生卒年**：1236年－1295年（享年60歲／周59）  
* **身分**：蒙古巴嚕剌斯部人（速不台之孫）  
* **官職**：元軍中書右丞相、統帥  
* **核心行蹤**：1274年統領二十萬大軍順江東下 ➔ 1276年正月於皋亭山接受謝太后與恭帝投降 ➔ 1277–1278年平定北方宗王叛亂。其軍事風格兼具蒙古騎兵的迅猛與漢地兵法的高度組織力。

## **二、二級人物（分卷與功能精選清單）**

### **1\. 北宋末、靖康與北方社會**

* **蔡京（1047–1126）**：崇寧、大觀年間權相，四度罷相，1126年貶死道上，象徵新法集團的腐化。  
* **童貫（1054–1126）**：權宦，掌控西軍二十年，兼領樞密院，聯金攻遼與收復燕京的最高軍事負責人。  
* **王黼（1079–1126）**：主導海上之盟與聯金的少宰，靖康元年被民憤殺死。  
* **宗澤（1060–1128）**：北宋末抗金名將，東京留守，以七旬高齡連上二十四表請還京，憂憤病逝。  
* **李清照（1084–1155）與趙明誠（1081–1129）**：北宋至南宋之際的文人夫婦，其經歷展現了金兵南下、金石文物散失與顛沛流離的士人文化記憶。

### **2\. 南宋初、岳飛與宋金戰爭**

* **吳玠（1093–1139）與吳璘（1102–1167）**：川陝防線名將，和尚原與仙人關之戰的英雄，保住四川盆地。  
* **劉錡（1098–1162）**：順昌之戰大破金兀朮的智將，采石磯戰役的高齡主帥。  
* **岳雲（1119–1142）與張憲（？–1142）**：岳飛長子與得力部將，與岳飛同日被害。  
* **完顏昌（撻懶，？–1139）**：金國主和派代表，主導天眷和議並暗中與秦檜通信，後被完顏宗弼政變誅殺。

### **3\. 南宋中期、蒙古崛起與末期**

* **余玠（？–1253）**：淳祐年間四川制置使，首創山城防禦體系（釣魚城）。  
* **王堅（？–1264）**：合州釣魚城守將，力拒蒙哥汗大軍。  
* **呂文煥（？–1286後）**：襄陽守將，苦守六年後降元，成為元軍滅宋前導。  
* **李庭芝（1219–1276）**：揚州守將，臨安降後孤守孤城至死不屈。  
* **謝道清（謝太后，1210–1283）**：理宗皇后、恭帝祖母，以明智決斷開城投降保全江南百姓。  
* **蒲壽庚（約1205–1290）**：泉州市舶司阿拉伯裔海商，屠殺宗室降元，切斷南宋海上命脈。

## **三、三級人物與虛構人物配置規範**

為確保小說或歷史敘事不流於高層將相的空中樓閣，三級與虛構人物必須落實在七條社會生活線中：

1. **漕運／船戶家庭**：如「船老大老林一家」，見證汴河枯竭、運河斷流、江南車船建造與崖山逃亡。  
2. **軍戶／軍需工匠家庭**：如「鐵匠老趙與其子趙小七」，呈現神臂弓改良、火藥霹靂砲配方研製與襄陽回回砲轟擊下的軍械日常。  
3. **地方士人／小吏**：如「州縣書吏陳生」，經歷新舊黨爭、金兵南下時的文移潰散、公文交接與改朝換代。  
4. **農戶／佃戶家庭**：如「淮南農夫阿牛」，經歷杜充決河後的黃泛區洪災、流民逃荒與公田法下的租佃剝削。  
5. **商人／手工業者**：如「臨安茶坊掌櫃陸三」，見證交子與會子貶值、通膨暴漲與臨安投降前的恐慌。  
6. **醫者／僧侶網絡**：如「靈隱寺僧慧明」，戰亂中收容傷兵、抄寫流亡士人手稿與民間救濟。  
7. **女性視角**：如「紡織女工阿香」，經歷戰亂中家庭離散、攜幼逃荒及在紡織業中支撐生計的韌性。  
* **虛構人物角色卡強制欄位**：姓名與年齡範圍、籍貫、家庭成員、掌握技能、可用資源、現實限制、所知歷史情報範圍、所屬社會網絡、跨卷命運與結局。**嚴禁讓虛構人物代替史實人物完成任何記載在案的重大歷史事件。**

## **四、每位一、二級人物必備「角色卡」檢核清單（寫作前置對照）**

當你在正文動筆寫任一歷史人物登場時，其卡片必須包含以下十欄（可在大綱檔案中建立）：

1. **姓名、異名、字／號**（如：岳飛，字鵬舉）。  
2. **生卒年及確定程度**（如：1103–1142，史料確鑿）。  
3. **籍貫、家世與教育背景**（如：相州湯陰農家，曾受兵法於周同）。  
4. **官職／軍職與任免日期**（如：紹興十年授潭州觀察使、荊湖南北路宣撫使）。  
5. **所屬政權、派系或軍事網絡**（如：南宋主戰派、岳家軍統帥）。  
6. **重要事件與可考行蹤**（如：1140年郾城大捷、朱仙鎮前鋒）。  
7. **可確認的行動、言論與作品**（如：《滿江紅·怒髮衝冠》\[註：後世擬作爭議\]、《岳武穆遺文》）。  
8. **史料分歧與後世形象**（如：從忠義化身到晚期政治涉入之歷史評價）。  
9. **與其他人物的關係**（如：與高宗為君臣猜忌關係、與秦檜為死敵）。  
10. **本書功能、出場卷次、退場方式**（如：一級主幹人物，卷二至卷三核心，卷三末悲劇退場）。


## 五、維護規則

人物分級按跨卷敘事功能而定，不代表道德評價。每當新增人物或調整層級，須同步更新出場卷次、人物行蹤表、關係表與史料狀態。角色卡中，史實、推演、虛構關係應分欄記錄。
