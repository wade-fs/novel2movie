# chapter_ledger.md
## 《長安秋暮》與《中原風雲》——逐章管理與跨卷連續性規範

---

## 一、文件目的

本文件負責管理全系列十六卷的逐章規劃、人物連續性、歷史事件、區域敘事及實驗室支線。

本系列時間跨度為 875—979 年，涵蓋晚唐、五代十國與北宋初期。

全系列以歷史人物、制度變化、地方社會與普通人的生活為主體；實驗室支線則提供不同維度的觀察視角。

本文件的目的，是避免長篇創作過程中出現：

- 年代錯置。
- 人物年齡錯誤。
- 人物突然出現或消失。
- 人物關係前後矛盾。
- 同一事件跨卷重複或遺漏。
- 區域敘事失衡。
- 南方諸國被簡化成中原統一的背景。
- 實驗室研究者提前知道歷史結果。
- 實驗室研究假設反過來改寫歷史。
- 實驗室對話與歷史正文失去關聯。

### 1.1 文件管理原則

歷史正文與實驗室支線分別管理，但必須能夠相互對照。

歷史資料與年代以 `timeline_audit.md` 為準。

人物生命歷程以 `character_lifecycle.md` 為準。

各卷歷史安排以 `volumes.md` 為準。

實驗室規則以 `laboratory.md` 為準。

各卷研究問題以 `laboratory_volume_map.md` 為準。

本文件負責將上述設定落實到章節層級。

---

## 二、全系列章節管理原則

### 2.1 章節的基本任務

每章至少應完成下列一項任務：

1. 推進歷史事件。
2. 呈現人物選擇。
3. 建立或改變人物關係。
4. 呈現制度與政治變化。
5. 呈現地方社會與日常生活。
6. 補足歷史事件之間的因果關係。
7. 呈現不同區域之間的互動。
8. 推進虛構人物的生命歷程。
9. 在適當位置推進實驗室研究問題。

一章可以同時完成多項任務，但不能只有歷史資料的堆疊，也不能只為了安排實驗室對話而存在。

### 2.2 歷史連續性

章節安排必須注意：

- 前一章與下一章的時間關係。
- 人物年齡與實際經歷。
- 人物移動所需的合理時間。
- 事件發生地點與人物所在地。
- 同一事件是否已在其他章節呈現。
- 不同區域的事件是否具有相互影響的條件。

不得為了方便敘事而讓人物瞬間跨越不合理的地理距離。

### 2.3 章節不必平均分配年代

每卷的章節數量與年代跨度，不必按照年份平均分配。

事件密集的時期可以細寫。

歷史變化較緩慢的時期，可以透過人物生活、制度變化、地方社會與跨區域關係呈現。

不應為了填滿章數而重複事件，也不應為了趕上卷末年份而跳過重要人物的生命歷程。

## 三、單章資料格式

每章應依照以下格式建立紀錄。

### 3.1 歷史章節

```yaml
chapter_id: V01-C001
volume: 1
chapter_number: 1
chapter_title: 章名

date:
  year: 875
  month: null
  day: null
  precision: year
  historical_status: verified

location:
  primary: 地點
  secondary: []

viewpoint:
  characters:
    - 人物姓名
  narrative_scope: 個人／群體／地方／制度

historical_events:
  - event_id: E001
    description: 事件簡述
    status: historical_fact

characters:
  - name: 人物姓名
    age: 年齡
    status: active
    tier: 一级
    role_in_chapter: 本章作用

regional_axis:
  - 中原
  - 河東與北方
  - 南方諸國

chapter_function:
  - 歷史事件
  - 人物關係
  - 制度變化
  - 日常生活

fictional_elements:
  - description: 虛構內容
    classification: 合理推演

continuity_notes:
  - 前後章節需要銜接的事項

historical_verification:
  status: pending
  sources: []

laboratory:
  included: false
  research_phase: null
  research_question: null
  groups: []
  dialogue_function: null
  knowledge_boundary: null
  relation_to_human_chapter: null
```

以上是欄位範例，不代表所有章節都必須填入所有欄位。

沒有發生的事項可以留空，不得為了格式完整而虛構資料。

### 3.2 年代精度

歷史日期應保留史料實際能支持的精度。

| 精度 | 使用方式 |
|---|---|
| 年 | 只能確認年份 |
| 月 | 可以確認年份與月份 |
| 日 | 可以確認具體日期 |
| 時段 | 只能確認某段期間 |
| 約略 | 史料存在不同說法或時間不明 |

不得將只有年份的史料自行補成某月某日。

如果不同史料存在日期差異，應在校核欄位中保留說明。

## 四、人物生命歷程管理

### 4.1 人物基本資料

每位重要人物應建立獨立人物紀錄。

基本欄位包括：

- 姓名與異名。
- 出生年份或推定出生年份。
- 出身與家庭背景。
- 主要活動地區。
- 官職與政治身分。
- 所屬勢力及其變化。
- 重要人際關係。
- 主要歷史事件。
- 出場與退場時間。
- 死亡年份與史料可信程度。

### 4.2 年齡計算

人物年齡必須採取一致的計算方式。

建議以傳統虛歲作為正文主要呈現方式，內部資料同時保留出生年份與周歲估算，以便校核。

如果人物出生年份本身不確定，不得將推算年齡當成確定事實。

### 4.3 人物出場與退場

人物應記錄：

- 首次出場。
- 首次參與重要事件。
- 身分或政治立場變化。
- 重要關係變化。
- 最後一次出場。
- 死亡或歷史活動結束。

人物退場不等於死亡。

如果人物只是離開主要敘事區域，仍須保留其後續歷史狀態。

### 4.4 跨卷人物

跨卷人物必須維持：

- 年齡連續。
- 官職與身分連續。
- 親屬與人際關係連續。
- 政治立場變化有合理過程。
- 重要事件與人物經歷不重複或錯置。

人物可以改變立場，但必須有可理解的歷史背景與利益條件。

## 五、歷史事件管理

### 5.1 事件編號

重要歷史事件應建立唯一編號。

例如：

```yaml
event_id: E001
event_name: 事件名稱
date: 875
location: 地點
participants:
  - 人物
historical_status: verified
source_notes:
  - 史料名稱
related_chapters:
  - V01-C001
```

同一事件即使涉及多個人物與地區，也應使用同一事件編號。

### 5.2 事件分類

| 類型 | 定義 |
|---|---|
| 政治事件 | 政權、官職、權力結構變化 |
| 社會事件 | 人口、地方秩序、民間生活變化 |
| 經濟事件 | 財政、稅收、物價、貿易與生產 |
| 軍事事件 | 戰爭、軍隊調動、軍事控制 |
| 文化事件 | 教育、宗教、思想、藝術與文化 |
| 外交事件 | 政權之間的往來與協議 |
| 制度事件 | 行政、法律、財政與組織變革 |

軍事事件可以作為歷史背景，但正文不以戰術與戰場描寫為主要內容。

### 5.3 事件的因果關係

每項重要事件應盡可能記錄：

- 前置條件。
- 直接誘因。
- 主要參與者。
- 當時可掌握的資訊。
- 不同群體的利益。
- 直接結果。
- 後續影響。
- 尚未確定的史實。

不得把後來的歷史結果當成當事人當時已經知道的事情。

## 六、區域敘事管理

本系列應維持三條主要地理敘事軸線。

### 6.1 中原

主要範圍：

- 唐朝中央政權。
- 藩鎮與地方勢力。
- 五代政權。
- 後周與北宋建立。
- 中原政治、行政與社會秩序。

觀察重點：

- 中央與地方的關係。
- 政權更替。
- 官僚與行政制度。
- 財政與人口。
- 政治正統與地方治理。

### 6.2 河東與北方

主要範圍：

- 河東政權。
- 沙陀勢力。
- 李克用、李存勗及相關政治人物。
- 契丹與北方政權。
- 北漢及其周邊關係。

觀察重點：

- 區域地理條件。
- 政治與組織傳統。
- 人口與社會結構。
- 與中原政權的互動。
- 北方外交與區域安全。

### 6.3 南方諸國

主要範圍：

- 吳。
- 南唐。
- 吳越。
- 前蜀與後蜀。
- 閩。
- 楚。
- 南漢。
- 荊南及其他相關政權。

觀察重點：

- 地方治理與行政制度。
- 經濟與生產方式。
- 人口、交通與地理條件。
- 對外貿易與區域交流。
- 文化、教育、宗教與藝術。
- 不同政權之間的外交與競爭。

南方諸國必須有自身完整的歷史敘事。

不能只在中原政權準備統一時，才安排南方諸國出場。

## 七、普通人與日常生活管理

每卷都應檢查是否呈現歷史變化對普通人的影響。

可觀察的生活面向包括：

- 糧食與物價。
- 稅收與徵發。
- 戶籍與土地。
- 家庭與婚姻。
- 交通與商業。
- 教育與識字。
- 宗教與地方信仰。
- 疾病與醫療。
- 人口遷徙。
- 難民與地方救濟。
- 官府與地方社會的關係。
- 城市、鄉村與市場的變化。

普通人不只是歷史事件的受害者，也會有自己的判斷、選擇、合作與利益。

虛構人物可以透過這些生活面向連接不同歷史事件，但不得取代歷史人物與歷史事件的真實位置。

## 八、虛構人物管理

### 8.1 虛構人物的定位

虛構人物主要負責：

- 連接不同歷史人物與事件。
- 呈現普通人的生活經驗。
- 補足史料未能呈現的日常細節。
- 展現制度變化如何影響不同階層。
- 讓不同區域與不同世代產生敘事連續性。

### 8.2 史實標記

虛構情節使用以下標記：

- 【史實骨架】：有史料支持的歷史事件或人物事實。
- 【合理推演】：依據歷史條件推導的合理情境。
- 【小說虛構】：為敘事需要創作的人物、事件或對話。

標記主要用於內部規劃與校核，不一定需要出現在小說正文。

### 8.3 虛構人物生命紀錄

每位主要虛構人物應建立：

- 出生年份。
- 家庭背景。
- 初次出場年齡。
- 活動地區。
- 主要經歷。
- 人際關係。
- 身分變化。
- 退場方式。
- 最後一次出場。

不得讓虛構人物為了方便而不合理地跨越數十年仍維持相同年齡與生活狀態。

## 九、實驗室支線管理

### 9.1 基本原則

實驗室支線是與人類世界不同維度的觀察敘事。

實驗室對話不應改變人類世界的歷史發展，也不應讓人類世界的人物自然知道研究者的存在。

實驗室研究問題以 `laboratory_volume_map.md` 為準。

實驗室基本規則以 `laboratory.md` 為準。

### 9.2 實驗室章節紀錄格式

實驗室對話出現時，使用以下欄位：

```yaml
laboratory:
  included: true
  dialogue_id: L-V01-01

  related_volume: 1
  research_phase: 1

  primary_group:
    - 秩序組

  participating_groups:
    - 認知組
    - 紀錄組

  research_question: >
    制度存在是否代表制度有效？

  dialogue_position: 卷首

  dialogue_function:
    - 提出研究問題
    - 建立初始假設

  observed_material:
    - 本卷已經呈現的歷史現象

  known_facts:
    - 研究者目前能夠確認的資料

  hypotheses:
    - 尚待驗證的解釋

  unknowns:
    - 目前資料不足的問題

  knowledge_boundary: >
    不得使用本卷尚未發生的歷史結果。

  relation_to_human_chapter: >
    對照本卷制度與地方治理的歷史主線。

  conclusion_status: open
```

如果實驗室沒有出場，應標記：

```yaml
laboratory:
  included: false
```

不必為每章強行安排實驗室對話。

### 9.3 實驗室對話的功能分類

| 功能 | 用途 |
|---|---|
| 問題提出 | 建立新的研究方向 |
| 觀察補充 | 補充已經取得的資料 |
| 假設建立 | 提出可能的解釋 |
| 假設質疑 | 指出既有解釋的不足 |
| 資料檢查 | 確認資料是否完整 |
| 模型修正 | 調整原有理解 |
| 研究轉向 | 將注意力轉向新的現象 |
| 階段回顧 | 檢查目前研究成果 |
| 未知保留 | 明確承認資料不足 |

### 9.4 研究者知識邊界

每次實驗室對話都必須檢查：

1. 研究者是否已經觀察到相關事件？
2. 研究者是否已經取得相關資料？
3. 研究者的推論是否超出現有證據？
4. 是否將後來的歷史結果提前帶入討論？
5. 是否將推論誤寫成確定事實？
6. 是否擅自改動實驗參數？
7. 是否讓研究者知道人類人物不可能被他們直接掌握的內心資訊？

研究者可以提出推測，但不能以全知視角呈現。

### 9.5 實驗室對話的篇幅

實驗室對話不必與歷史章節等長。

可以是數句簡短討論，也可以是較完整的研究過程。

每段對話必須具有明確功能。

如果只是重述正文已經完整呈現的歷史事件，應考慮刪除。

### 9.6 不使用編號代稱

不得使用研究者 A、研究者 B、研究員甲、研究員乙等代號。

研究者的稱呼應依照自然對話、研究組別、職務或後續確立的人物設定處理。

## 十、實驗室與人類世界的時間關係

### 10.1 不建立固定換算

人類世界與實驗室世界不需要固定時間比例。

本文件只管理敘事上的觀察先後，不管理兩個世界的精確時間換算。

### 10.2 研究資料的取得

研究者只能依照實際已經取得的觀察資料進行討論。

即使實驗室可以在相對短的時間內觀察較長的人類歷史，也不能讓研究者提前知道尚未觀察到的事件。

### 10.3 不得以章節順序推定世界時間

小說中的章節排列是敘事安排，不代表兩個世界必須按照相同速度或固定比例前進。

實驗室對話可以放在卷首、卷中或卷末，依研究問題需要安排。

### 10.4 不得任意重置

實驗室研究者不得因為觀察結果不符合預期，就任意重置、倒轉或改寫人類世界。

## 十一、跨卷連續性檢查

每卷完成後，必須檢查以下項目。

### 11.1 年代

- 本卷起始與結束年代是否正確？
- 重要事件是否有明確時間？
- 前後卷是否有重複或遺漏？
- 是否存在年代交界問題？
- 是否將推定日期誤寫成確定日期？

### 11.2 人物

- 人物年齡是否連續？
- 人物是否在正確時間出場？
- 人物是否在正確時間退場？
- 官職與身分是否符合歷史發展？
- 親屬與人際關係是否一致？
- 人物是否出現在不合理的地點？

### 11.3 區域

- 中原、河東與北方、南方諸國是否都有實質敘事？
- 區域之間是否有合理互動？
- 是否因中原主線而壓縮南方諸國的歷史？
- 地理、交通與人口移動是否合理？

### 11.4 日常生活

- 是否呈現政治變化對普通人的影響？
- 是否只有政治人物，缺少社會生活？
- 是否將普通人寫成沒有自主選擇的背景人物？

### 11.5 實驗室

- 研究問題是否符合本卷配置？
- 研究者是否只使用已取得的資料？
- 研究者是否提前知道歷史結果？
- 對話是否具有研究功能？
- 是否擅自改動實驗參數？
- 是否將實驗室結論當成歷史事實？
- 是否與前卷研究進度連續？

---

## 十二、單卷完成驗收表

每卷完成後，使用以下清單進行檢查：

### 歷史與人物

- [ ] 本卷年代與歷史事件已校核。
- [ ] 重要人物的出生、年齡與死亡年份已確認。
- [ ] 跨卷人物的身分與關係已檢查。
- [ ] 重要歷史事件沒有重複或遺漏。
- [ ] 三條區域軸線的配置合理。
- [ ] 普通人與日常生活具有足夠篇幅。
- [ ] 虛構人物沒有破壞史實骨架。

## 十四、文件使用方式

本文件是長篇創作期間持續更新的管理文件，不是一次填完的靜態規格。

建議使用以下流程：

1. 先完成各卷的歷史分卷規劃。
2. 核對 `timeline_audit.md`。
3. 建立主要歷史人物與虛構人物的生命紀錄。
4. 逐章建立歷史事件與人物資料。
5. 按照 `laboratory_volume_map.md` 安排實驗室對話。
6. 完成每章後進行局部校核。
7. 完成每卷後進行跨卷檢查。
8. 全系列完成後進行總驗收。

若發現史實錯誤，應先修正歷史資料，再同步調整章節與實驗室對話。

若發現實驗室假設不合理，應修正研究假設，而不是修改歷史。

**最終原則：歷史負責發生，人物負責生活，實驗室負責觀察；三者各自遵守自己的邏輯。**
