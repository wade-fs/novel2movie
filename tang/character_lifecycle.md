# 《唐末》人物生命歷程與跨卷追蹤：`character_lifecycle.md`

## 一、文件目的

本文件用來追蹤 875–979 年間的重要歷史人物，避免歷史小說在跨卷寫作時出現以下問題：

1. 人物突然出現，沒有交代前期經歷。
2. 人物跨卷後年齡不一致。
3. 人物在不同卷中職位、身份或政治立場不連貫。
4. 人物已經死亡，後續章節卻仍被當作在世人物。
5. 人物在某地活動，下一章卻無合理原因出現在另一個地區。
6. 人物因為卷界而被切斷生命歷程。
7. 南方人物只在中原政權需要征服南方時才出現。

**核心原則：人物生命歷程優先於分卷安排。**

---

# 二、人物年齡與年代計算規則

## 1. 年齡標示

小說正文原則上採用人物當時的實際年齡概念，內部檔案則必須明確記錄採用的計算方式。

- 若人物出生年份與事件年份均可考，先按出生年份推算。
- 若出生月份、日期不明，年齡應標示為約數或區間。
- 若生年本身有爭議，標記「生年待考」，不可自行選定一個年份當成確定史實。
- 若史料只記載某人某年已任官或已參與事件，不可單憑職位推算其確切年齡。

## 2. 虛歲與周歲

歷史文獻可能採用虛歲或其他傳統年齡表述。

本文件的內部年齡推算，統一先採出生年份與事件年份的差值，作為便於跨卷核對的「推算年齡」。

若正文需要使用虛歲，應另行標記，不能將兩種算法混用。

## 3. 生卒年可信度標記

- **A：較可靠**——有較明確史料依據，且不同資料大致一致。
- **B：常見記載**——通行資料採用，但仍應進一步核對原始史料。
- **C：有爭議**——生卒年、月份或身份有不同說法。
- **D：不詳**——無法可靠推算。

以上等級是本書的工作標記，不代表史料本身的絕對可信度。

# 九、史實與小說推演的分界

人物檔案必須使用以下標記：

- **【史實骨架】**：生卒年、官職、政權、事件、親屬關係等有史料依據的內容。
- **【合理推演】**：人物在史料沒有明確記載的日常活動、心理反應、交往細節等。
- **【小說虛構】**：完全創作的人物、事件、對話與情節。

不得將合理推演或小說虛構內容寫入人物史實欄位。

# 十、版本維護原則

本文件不是一次完成的靜態人物百科。

每當以下情況發生時，必須同步更新：

1. 新增人物。
2. 修正人物生卒年。
3. 調整分卷年份。
4. 新增人物首次登場或退場章節。
5. 發現人物移動、年齡或官職矛盾。
6. 發現人物與政權的關係需要重新核對。

如果史實核驗發現人物年齡與既有分卷安排不合，應先檢討分卷，而不是修改人物年齡來配合原本的卷界。

**最終原則：十六卷是敘事安排，人物生命才是歷史本身。**
