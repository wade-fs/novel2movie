# **outline.md**

# **《唐末》——兩個世界的整體架構**

## **一、作品定位**

本作以唐朝晚期至五代十國為歷史主體，採取兩個世界交錯敘事：

1. **人類世界**：唐朝由盛轉衰、中央秩序瓦解、藩鎮割據、唐朝滅亡，以及五代十國政權更迭，直到宋朝建立與北漢滅亡。  
2. **外星實驗室世界**：外星文明成立人類文明觀測實驗，由不同研究組別觀察、分析、討論與評估人類歷史。

兩個世界各自具有完整的敘事脈絡。

人類世界不會知道外星實驗室的存在；外星研究者也不能任意改寫人類歷史。兩個世界的聯繫由讀者自行理解。

### **核心創作原則**

* 歷史是正文，外星實驗室是導讀與觀測視角。  
* 不寫成戰爭戰術小說，著重制度、政治、人文、地理與普通人的生活。  
* 不以唐朝滅亡作為必然結局，人物只能根據當時掌握的資訊作出判斷。  
* 不將五代十國簡化為唐朝滅亡後的混亂插曲，而是呈現不同政權各自的生存、治理與發展。  
* 不預設宋朝必然代表文明進步，也不將其他政權簡單定義為失敗者。  
* 外星研究者各有研究立場，但不代表絕對正確的答案。  
* 不讓作者的全知視角干擾外星實驗室的觀測參數。

## **二、人類世界：唐末至五代十國**

### **1\. 歷史範圍**

暫定時間：875—979年。

| 時間 | 歷史階段 | 主要內容 |
| ----- | ----- | ----- |
| 875—884 | 黃巢之亂 | 唐朝中央權威受到嚴重打擊，地方軍事力量擴張 |
| 884—907 | 晚唐餘局 | 藩鎮勢力、宦官、朝廷與地方軍政人物之間的權力競逐 |
| 907—923 | 後梁 | 唐亡，朱溫建立後梁，中原政權更替 |
| 923—936 | 後唐 | 李存勗建立後唐，李嗣源、李從厚、李從珂等人的政治局勢 |
| 936—947 | 後晉 | 石敬瑭建立後晉，契丹勢力介入中原政局 |
| 947—951 | 後漢 | 劉知遠建立後漢，政權短暫而迅速更替 |
| 951—960 | 後周 | 郭威、柴榮、郭宗訓，中央政權再度整合 |
| 960—979 | 宋初與十國終局 | 宋朝建立，南方政權陸續歸併，北漢於979年滅亡 |

五代十國並非同時存在、彼此平行的十個國家。各政權建立、滅亡與相互影響的時間不同，必須依照實際年代交錯敘述。

### **2\. 人類世界的主要敘事主軸**

#### **A. 唐朝中央與政治秩序**

觀察重點：

* 皇帝、宦官、朝臣之間的權力關係。  
* 中央財政、軍政制度與地方控制能力。  
* 藩鎮的形成、擴張及其與朝廷的關係。  
* 科舉、官僚體系與士人階層。  
* 唐朝政治正統性如何逐漸失去實際控制力。

主要歷史人物：

* 唐僖宗  
* 唐昭宗  
* 唐哀帝  
* 田令孜  
* 李克用  
* 朱溫  
* 崔胤  
* 其他晚唐中央與地方重要人物。

#### **B. 中原軍政勢力**

觀察重點：

* 藩鎮如何從地方軍事力量轉變為政權。  
* 軍事首領如何建立行政、財政與人事制度。  
* 政權繼承、家族關係與政治聯盟。  
* 地方治理與中央名義上的正統性之間的矛盾。  
* 五代政權更替背後的制度延續與變化。

主要政權：

* 後梁  
* 後唐  
* 後晉  
* 後漢  
* 後周

#### **C. 南方十國與地方發展**

不能只以中原政權為中心，把南方視為等待統一的地方。

觀察重點：

* 吳、南唐、吳越、閩、楚、南漢、前蜀、後蜀、荊南、北漢等政權的形成與發展。  
* 各地的地理條件、經濟結構與政治制度。  
* 江南水運、商業、農業與城市發展。  
* 地方政權如何維持統治、處理外交與軍事壓力。  
* 南方政權之間的競爭、合作、婚姻與外交關係。  
* 北方戰亂對南方人口、商業與文化的影響。

#### **D. 普通人的生活**

本作不只記錄帝王將相，也要呈現政權更迭如何改變普通人的生活。

主要觀察對象：

* 農民、佃戶與地主。  
* 商人、船戶與手工業者。  
* 士人、官吏與地方豪族。  
* 軍人、家屬與流動人口。  
* 僧侶、道士與宗教團體。  
* 婦女、兒童與失去家庭依靠的人。

生活議題：

* 戶籍與賦稅。  
* 兵役、徵發與地方軍事負擔。  
* 糧價、土地與農業生產。  
* 交通、商業與貨幣。  
* 戰亂、遷徙與人口流動。  
* 家庭、婚姻、教育與宗教。  
* 城市、鄉村與地方社會的變化。

### **3\. 人類世界的歷史敘事原則**

不以「唐朝滅亡—五代混亂—宋朝統一」作為單線進步史觀。

應該同時觀察：

* 唐朝留下了什麼？  
* 五代各政權承接了什麼？  
* 十國如何建立自己的政治與社會秩序？  
* 哪些制度被保留、修改或廢棄？  
* 哪些地方在政治分裂期間反而獲得發展？  
* 宋朝建立後，哪些問題得到解決，哪些問題只是換了一種形式？

歷史人物必須依據當時能取得的資訊行動，不可用後世結果替他們預先判定選擇。

## **三、外星實驗室世界**

### **1\. 基本設定**

外星文明成立人類文明實驗。

故事開始時，外星文明正在觀測唐朝末年人類已經發展出成熟的國家、文字、宗教、政治制度與文明傳承，針對人類文明進行研究。

### **2\. 文明與研究組別的關係**

必須區分：

* **外星文明**：實驗室的發起者。  
* **研究組別**：實驗室內的研究分工。  
* **研究者**：各文明派遣或指派參與實驗的人員。

研究組別不限制數量，人員非固定，一律以組別名稱來指代研究人員，未來可以依照研究需求增設。

### **3\. 初步研究組別**

#### **A. 秩序組**

研究方向：

* 政權與制度。  
* 中央與地方關係。  
* 權力分配與治理。  
* 社會秩序與制度穩定性。

核心研究問題：

人類能否建立一套不依賴個別統治者能力的長期治理制度？

#### **B. 學習組**

研究方向：

* 智慧與知識累積。  
* 教育與技術傳承。  
* 歷史經驗的吸收。  
* 錯誤修正與認知成長。

核心研究問題：

人類是否能夠從過去的錯誤中學習，並避免重複犯錯？

#### **C. 共存組**

研究方向：

* 道德與倫理。  
* 信仰與共同認同。  
* 群體合作與社會信任。  
* 不同利益群體之間的關係。

核心研究問題：

當不同群體具有不同利益時，人類是否仍能維持合作與共同生活？

#### **D. 競存組**

研究方向：

* 生存競爭。  
* 自然選擇與適應能力。  
* 資源分配與淘汰。  
* 個體、制度與文明的存續。

核心研究問題：

無法適應環境的個體、制度與文明，是否應該被淘汰？

研究組不能只用強弱判斷適者生存，也必須觀察環境變化、資源條件與適應方式。

#### **E. 紀錄組**

研究方向：

* 歷史文獻。  
* 資料保存與證據管理。  
* 集體記憶與文化傳承。  
* 歷史記載的失真、遺漏與篡改。

核心研究問題：

人類能否忠實保存自身經歷，讓後代真正知道曾經發生過什麼？

紀錄組負責保存觀測資料，但不必然負責解釋歷史。

#### **F. 認知組**

研究方向：

* 人類思維與判斷。  
* 理性、偏見與情緒。  
* 群體心理與政治認知。  
* 人類如何理解自己與外部世界。

核心研究問題：

人類究竟是依據事實作出判斷，還是依據自己相信的事實作出判斷？

#### **G. 創造組**

研究方向：

* 技術與發明。  
* 藝術、文學與想像。  
* 制度創新。  
* 新思想與新文化的形成。

核心研究問題：

人類的創造力是否能突破既有環境與制度的限制？

#### **H. 干預組**

研究方向：

* 外部刺激。  
* 實驗變數控制。  
* 介入效果與因果關係。  
* 人為改變對文明發展的影響。

核心研究問題：

外部介入能否改變人類文明的發展方向？介入是否會產生預期之外的結果？

### **4\. 研究組別的運作原則**

* 各組有自己的研究假說與觀測指標。  
* 不同研究組可以觀察同一事件。  
* 各組不必對同一事件得出相同結論。  
* 研究組內部也允許不同意見。  
* 不將研究組設定為善惡陣營。  
* 不要求所有組別在每一階段都發言。  
* 研究組可以隨實驗進度成立、合併、拆分或調整研究方向。

## **四、兩個世界的交錯敘事**

### **1\. 人類世界是主要正文**

歷史人物、政治變化、社會生活與地方環境構成小說的主要篇幅。

不因為外星實驗室的存在而縮短歷史敘事。

### **2\. 外星實驗室是短篇觀測對話**

外星實驗室不採取長篇說明，也不需要每次都完整交代研究背景。

主要呈現：

* 對某個歷史現象的觀察。  
* 不同研究組的假說衝突。  
* 對實驗結果的質疑。  
* 是否需要增加觀測項目。  
* 是否需要調整實驗條件。  
* 對既有研究結論的重新評估。

對話應該簡短、自然，具有研究討論的感覺。

不使用詩句作為固定章首裝飾，也不額外建立第三種詩文敘事層。

### **3\. 交錯方式**

暫定採用以下結構：

* 每章是人類世界的一個歷史敘事單位。  
* 部分章節之前或之後插入實驗室短對話。  
* 每一段歷史發展可以形成一個研究觀測節點。  
* 每一卷結束時，實驗室可以出現一次階段性討論。  
* 不強制每章都有實驗室對話。  
* 不讓實驗室對話重述正文已經交代過的歷史。

### **4\. 兩個世界的資訊邊界**

人類世界：

* 人物只知道當時能夠取得的資訊。  
* 不知道後世歷史結果。  
* 不知道外星研究者的存在。  
* 不會因為外星研究者的討論而改變行動。

外星實驗室：

* 可以觀察人類歷史資料。  
* 可以比較不同時期與不同政權。  
* 可以提出假說，但假說不等於事實。  
* 可以對人類行為感到困惑。  
* 不應以研究者的結論直接代替歷史解釋。

## **五、整體歷史階段與實驗室研究節點**

以下是兩個世界可以互相呼應的初步分段，不代表最終分卷。

| 歷史階段 | 人類世界的主要內容 | 實驗室可能關注的問題 |
| ----- | ----- | ----- |
| 晚唐危機 | 黃巢之亂、中央失控、地方勢力擴張 | 一個大型制度如何失去控制能力？ |
| 唐朝終局 | 唐昭宗、朱溫、唐哀帝、唐亡 | 政權滅亡是否等於制度消失？ |
| 後梁與後唐 | 新政權建立、正統性與統治能力 | 新政權如何證明自己比舊政權更有能力？ |
| 後晉與契丹 | 外部勢力介入、中原政權變動 | 外部力量如何改變內部政治選擇？ |
| 後漢與後周 | 短期政權更替、制度延續 | 政權更迭頻繁時，哪些制度仍能存續？ |
| 南方十國 | 地方政權治理、經濟與文化發展 | 政治分裂是否必然阻礙文明發展？ |
| 宋朝建立 | 中原政權重新整合 | 統一是否代表治理問題已經解決？ |
| 十國終局 | 南方歸併、北漢滅亡 | 文明整合與政治征服有何不同？ |

## **六、全書核心議題**

### **人類世界**

1. 一個曾經強盛的帝國，為什麼無法維持原有制度？  
2. 地方勢力取得權力後，是否必然走向割據？  
3. 政權的正統性與實際治理能力是否一致？  
4. 戰亂與分裂是否只帶來破壞？  
5. 南方地方政權是否具有獨立的歷史價值？  
6. 政權更替時，普通人的生活如何延續？  
7. 宋朝建立究竟解決了哪些問題，又留下了哪些問題？

### **外星實驗室**

1. 秩序是否是文明存續的必要條件？  
2. 人類是否真的能從歷史中學習？  
3. 道德與合作能否抵抗利益競爭？  
4. 適者生存是否等同於強者生存？  
5. 歷史紀錄是否足以讓後代避免錯誤？  
6. 理性是否能克服群體偏見？  
7. 創新是否能突破既有制度？  
8. 外部干預是否會讓實驗結果失去原本的意義？

## **七、寫作與歷史考證規範**

### **1\. 史實層次**

規劃與寫作時區分：

* 【史實骨架】：有史料支持的事件、人物、年代與制度。  
* 【合理推演】：依據當時環境、制度與人物關係所作的合理推論。  
* 【小說虛構】：為了敘事而創造的人物、事件與生活細節。

### **2\. 歷史考證**

各卷另行建立：

* timeline\_audit.md：年代與事件校核。  
* character\_network.md：人物關係與政治互動。  
* historical\_geography.md：歷史地理與交通空間。  
* institutions\_and\_daily\_life.md：制度與日常生活。  
* chapter\_ledger.md：章節安排與史實驗收。

### **3\. 人物塑造**

歷史人物依照歷史重要性與敘事功能分為一級、二級、三級人物。

不以正派、反派簡化歷史人物。

同一人物可以在不同時間、不同利益關係下展現不同選擇。

### **4\. 戰爭敘事**

不以戰術、陣法、攻城過程作為主要篇幅。

戰爭與軍事事件應著重：

* 徵兵與徵發。  
* 軍糧與財政。  
* 人口流動。  
* 地方秩序。  
* 官職與權力變動。  
* 家庭分離與生計困境。  
* 戰後治理與社會重建。

---

## **八、作品的最終方向**

本作不只是唐朝滅亡與宋朝建立的歷史小說，也不是單純的外星文明觀察故事。

人類世界呈現的是一個文明如何經歷衰敗、分裂、競爭、重組與延續。

外星實驗室呈現的是不同研究者如何試圖理解這個文明，並且逐漸發現：人類的行為未必符合任何一組研究者原先設定的假說。

兩個世界共同指向一個問題：

**如果文明可以被觀察、分析與評估，那麼究竟應該用什麼標準，判斷一個文明是否成功？**

全書不預設答案。

讓歷史人物用自己的選擇回答，讓外星研究者用自己的研究方法爭論，最後由讀者自行判斷。
