# volumes_lab_integration.md
## 《長安秋暮》與《中原風雲》——實驗室支線整合稿

### 一、整合原則

本文件用於將實驗室支線嵌入既有 `volumes.md`，不取代原有分卷綱要，也不重新分配歷史事件。

實驗室支線的任務，是觀察人類歷史中反覆出現的制度、認知、合作、競爭與適應現象。歷史正文負責呈現人物如何生活、選擇、承受後果；實驗室則透過研究者的討論，提出尚未獲得完整答案的問題。

#### 1. 不改動歷史骨架

- 不因實驗室提出某個假設，就改變歷史事件的發生順序。
- 不為配合研究結論，增減歷史人物的行為或動機。
- 不將歷史人物寫成實驗室研究者預先設定的樣本。
- 不讓研究者掌握尚未發生的歷史結果。
- 原有年代、人物年齡、事件及卷末落點，仍以 `volumes.md` 和 `timeline_audit.md` 為準。

#### 2. 每卷實驗室觀測的固定項目

每卷增加以下五項：

1. **研究問題**：本卷最值得觀察的現象。
2. **主要研究組別**：負責提出問題或分析資料的研究組。
3. **對話位置**：實驗室對話適合出現的位置，不強制固定章數。
4. **階段觀察**：研究者在本卷結束時能夠確認的現象，以及仍然無法解釋的部分。
5. **下一階段問題**：將研究問題帶入下一卷，但不預先宣告結果。

#### 3. 實驗室對話的篇幅

- 每卷安排一至兩次即可，不必每卷平均。
- 對話可以短至數句，也可以因研究議題較複雜而稍長。
- 不要求每個研究組都出場。
- 不要求研究者在每卷結尾達成共識。
- 不以研究者的話替讀者解釋剛讀完的歷史。
- 研究者可以修正假設，也可以承認目前資料不足。

#### 4. 研究組別

| 研究組 | 主要研究範圍 |
|---|---|
| 秩序組 | 制度、權力、治理、社會秩序 |
| 學習組 | 智慧、知識、教育、經驗與錯誤修正 |
| 共存組 | 道德、信念、合作、社會信任 |
| 競存組 | 競爭、適應、生存、資源與淘汰 |
| 紀錄組 | 歷史資料、集體記憶、記錄失真與遺漏 |
| 認知組 | 理性、偏見、情緒、群體心理與判斷 |
| 創造組 | 技術、發明、藝術、想像與制度創新 |
| 干預組 | 外部刺激、實驗變數、介入與因果關係 |

## 二、上冊《長安秋暮》

### 第一卷《黃塵初起》｜875—878

**研究問題：** 當一個既有制度仍然存在，卻逐漸無法處理地方問題時，人們會如何理解這種失效？

**主要研究組別：** 秩序組、認知組、紀錄組。

**對話位置：**
- 可安排在卷首，作為實驗室觀察問題的起點。
- 卷末可安排一次短對話，討論研究者最初的假設是否仍然成立。

**階段觀察：**

研究者開始注意到，制度的名義存在與制度的實際運作並不相同。

朝廷仍有官職、命令、法令與行政層級，但地方上的人們未必能從這些制度中獲得保護。當命令無法有效抵達地方，或者地方不再相信命令能解決問題，制度與社會之間便開始出現落差。

此時還不能認定制度已經崩潰。研究者需要區分局部失效、行政能力下降，以及整體秩序瓦解。

**下一階段問題：**

如果中央無法有效處理地方危機，地方勢力會填補空缺，還是進一步擴大混亂？

### 第二卷《南下風暴》｜879—881

**研究問題：** 當局部危機擴大並跨越地域，原本彼此分離的社會問題是否會形成連鎖反應？

**主要研究組別：** 競存組、共存組、干預組。

**對話位置：**
- 卷中，在地方危機逐漸擴大、不同區域開始相互影響時。
- 卷末，討論局部事件如何轉化為跨區域的社會衝擊。

**階段觀察：**

研究者發現，危機不一定按照行政區域或原有權力範圍發展。

人口移動、地方武裝、糧食供應、交通與地方利益，都可能使原本局部的事件擴大。不同群體對危機的反應也不一致：有人尋求保護，有人尋求利益，有人試圖維持原有生活。

研究者尚不能將這些反應歸納成單一的生存模式。

**下一階段問題：**

當人們離開原有秩序，新的群體關係與地方權力會如何形成？

### 第三卷《亂世歸人》｜882—884

**研究問題：** 當原有社會秩序失去穩定性，人們如何重新建立歸屬、信任與生活規則？

**主要研究組別：** 共存組、認知組、秩序組。

**對話位置：**
- 卷中，安排在人物經歷遷徙、依附或重新尋找生活秩序之後。
- 卷末，討論人們是否能在原有制度之外建立新的合作關係。

**階段觀察：**

研究者開始注意到，政治秩序與日常秩序並不完全相同。

即使中央權力衰弱，地方仍可能存在交易、互助、家族網絡、鄉里關係與其他維持生活的方式。這些關係未必能建立穩定政權，卻能讓部分社會活動繼續運作。

研究者需要避免把地方秩序直接等同於善意合作，也不能將所有依附關係視為單純的權力控制。

**下一階段問題：**

地方社會所形成的秩序，能否逐漸發展成具有持續治理能力的制度？

### 第四卷《餘燼未冷》｜885—888

**研究問題：** 一個曾經具有高度整合能力的政治中心，在遭受重大衝擊後，是否仍然具有恢復秩序的能力？

**主要研究組別：** 秩序組、紀錄組、學習組。

**對話位置：**
- 卷中，中央權力試圖恢復控制時。
- 卷末，討論制度復原與制度延續之間的差異。

**階段觀察：**

研究者開始區分「恢復原有機構」與「恢復原有功能」。

機構可以重新設置，官職可以重新任命，命令也可以再次發布；但行政網絡、地方信任、財政能力與人員忠誠，未必能同步恢復。

研究者也開始注意到，歷史記錄中對中央權力的描述，可能遠比地方實際運作完整。

**下一階段問題：**

如果中央無法重新建立完整控制，地方權力是否會形成長期化、制度化的競爭？

### 第五卷《藩鎮爭衡》｜889—895

**研究問題：** 當地方權力具有相對獨立的資源、組織與利益時，它們會如何與中央及其他地方勢力互動？

**主要研究組別：** 競存組、秩序組、共存組。

**對話位置：**
- 卷中，地方勢力的利益與中央政策出現明顯衝突時。
- 卷末，討論競爭是否必然導向全面破壞。

**階段觀察：**

研究者發現，地方勢力並非只有反抗中央一種行為模式。

它們可能尋求承認、交換利益、維持名義上的臣屬關係，也可能彼此結盟或競爭。地方統治者需要考慮自身權力、財政、人員、地方社會與外部威脅。

競爭並不必然使所有制度消失。有些地方可能在競爭中形成相對穩定的治理方式。

**下一階段問題：**

當地方競爭逐漸影響中央政權的存續，政治中心還能否維持名義與實質上的統一？

### 第六卷《帝國失序》｜896—900

**研究問題：** 當中央權力失去實際控制能力，政治合法性與行政能力是否會分離？

**主要研究組別：** 秩序組、認知組、紀錄組。

**對話位置：**
- 卷中，中央權力與地方實際控制出現明顯落差時。
- 卷末，討論名義上的統一是否仍具有實際作用。

**階段觀察：**

研究者開始觀察到，政治中心的象徵地位可能在實際控制能力衰退後繼續存在。

人們仍然可能使用原有年號、官職與政治名義，但實際決策、資源分配與地方安全，已經逐漸由不同權力中心掌握。

這使研究者必須重新思考：一個政權究竟是由制度、疆域、軍事能力、政治認同，還是日常治理所構成？

**下一階段問題：**

當中央權力成為不同勢力爭奪的象徵，誰能夠決定政治中心的存續？

### 第七卷《鳳翔風雨》｜901—903

**研究問題：** 當政治中心成為不同權力集團競逐的對象，制度本身是否還能限制掌權者？

**主要研究組別：** 秩序組、認知組、競存組。

**對話位置：**
- 卷中，政治人物與權力集團之間的關係出現轉變時。
- 卷末，討論權力是否仍然受到制度約束。

**階段觀察：**

研究者發現，制度並非完全不存在，而是制度的解釋權、執行權與實際受益者可能已經分離。

不同政治人物仍會使用既有制度語言來證明自身行為的合理性，但制度是否能真正約束權力，則需要從實際結果判斷。

研究者不能只依據最後的勝負，反推某一方在當時必然具有較高的合理性。

**下一階段問題：**

當舊政權的政治中心無法再維持原有秩序，新的權力形式是否能夠建立更穩定的治理結構？

### 第八卷《長安秋暮》｜904—907

**研究問題：** 一個王朝的結束，究竟是政治名義的改變，還是長期制度與社會關係轉變的結果？

**主要研究組別：** 紀錄組、秩序組、學習組。

**對話位置：**
- 卷末，唐朝政治名義終結之後。
- 可安排一段較長的實驗室對話，作為上冊與下冊的轉折。

**階段觀察：**

研究者不能將王朝終結簡化成某一個人的決定或某一場政治事件。

在王朝正式結束以前，中央與地方的關係、財政與行政能力、政治認同、地方權力及社會生活，早已經歷長期變化。

紀錄組可以確認王朝名義終結的時間，卻不能僅憑這個時間點判斷整個社會何時開始改變。

上冊的研究階段至此結束，但人類社會並未停止運作。

**下一階段問題：**

當舊王朝消失，新的政權是否會自然形成？還是不同地區會依照各自的條件，發展出不同的政治秩序？

## 三、下冊《中原風雲》

### 第九卷《新梁舊局》｜907—912

**研究問題：** 當新政權取代舊王朝，權力更替是否代表原有政治結構已經改變？

**主要研究組別：** 秩序組、紀錄組、認知組。

**對話位置：**
- 卷首，作為下冊研究問題的重新設定。
- 卷中，觀察新政權如何處理舊有制度與地方勢力。
- 卷末，討論政權更替與制度變革是否一致。

**階段觀察：**

研究者開始比較政權名義與實際治理能力。

新的王朝可以建立新的政治象徵，但仍需要面對既有官僚、人員、地方勢力、財政制度與社會關係。

研究者不能預設新政權一定比舊政權更有效率，也不能只以後來是否延續來判斷其制度價值。

**下一階段問題：**

當不同權力中心各自建立政權，哪些因素會影響它們的延續能力？

### 第十卷《河東風起》｜913—923

**研究問題：** 一個具有自身政治傳統與組織基礎的區域，如何在長期競爭中形成不同於中原政權的發展路徑？

**主要研究組別：** 競存組、秩序組、學習組。

**對話位置：**
- 卷中，河東政權的政治與組織特徵逐漸清晰時。
- 卷末，討論區域性政權的適應能力。

**階段觀察：**

研究者開始將河東視為具有自身條件的政治區域，而不是單純的中原政權競爭者。

地理位置、人口組成、政治傳統、組織結構與外部關係，都可能影響其發展方式。

研究者需要避免把某一種政治組織的成功，直接解釋成其他地區也應採取相同模式。

**下一階段問題：**

當區域性政權取得更大的政治影響力，它能否將原有組織模式轉化為更廣泛的治理制度？

### 第十一卷《唐旗未穩》｜923—926

**研究問題：** 一個新建立的王朝，如何處理自身政治正統、原有組織與被納入的不同區域？

**主要研究組別：** 秩序組、認知組、共存組。

**對話位置：**
- 卷中，新政權建立並開始整合不同區域時。
- 卷末，討論政權建立與政權穩定之間的差距。

**階段觀察：**

研究者注意到，建立政權與維持政權是兩種不同的能力。

政治正統可以提供名義上的共同基礎，但不同區域原有的利益、組織與社會關係，不會因為政權建立而立即消失。

新政權必須持續處理地方治理、人員任用、資源分配與政治信任。

**下一階段問題：**

當新政權開始進入相對穩定的治理階段，制度是否能逐漸脫離個別統治者的能力？

### 第十二卷《明宗治世》｜926—933

**研究問題：** 一個政權能否在統治者更替與政治環境變化之下，維持相對穩定的行政運作？

**主要研究組別：** 秩序組、學習組、共存組。

**對話位置：**
- 卷中，治理措施逐漸展開並產生社會影響時。
- 卷末，討論治理成效與制度持續性的差異。

**階段觀察：**

研究者開始觀察到，治理成效不能只從統治者的個人能力判斷。

政策是否能持續執行，取決於行政組織、官員能力、地方合作、財政條件及社會承受程度。

短期穩定也不必然代表制度已經建立長期自我修正能力。

**下一階段問題：**

當一段相對穩定的治理時期結束，政權能否依靠既有制度處理權力交接與政治衝突？

### 第十三卷《後唐風雨》｜934—936

**研究問題：** 當政權的延續過度依賴統治者與核心權力集團，權力交接會產生什麼影響？

**主要研究組別：** 秩序組、認知組、競存組。

**對話位置：**
- 卷中，權力交接與政治衝突逐漸加劇時。
- 卷末，討論制度是否具有承受統治者更替的能力。

**階段觀察：**

研究者開始區分統治者個人能力、核心集團的合作，以及制度本身的穩定性。

當權力交接缺乏可被各方接受的程序，原本維持政權運作的合作關係便可能迅速瓦解。

但研究者也必須注意，權力衝突並非單一制度缺陷所能完全解釋，還涉及人際關係、利益分配與當時的政治環境。

**下一階段問題：**

當一個政權結束，新的政權是否會延續舊有制度，還是重新建立自己的政治秩序？

### 第十四卷《北地易主》｜937—947

**研究問題：** 當政治中心更替，地方與區域社會如何適應新的統治者與政治制度？

**主要研究組別：** 秩序組、共存組、競存組。

**對話位置：**
- 卷中，北方政權變化與區域秩序重新調整時。
- 卷末，討論政權更替對不同區域造成的差異。

**階段觀察：**

研究者開始注意到，同一場政治更替，對不同地區可能產生完全不同的影響。

有些地方可能迅速接受新的行政安排，有些地方則需要經過長期協商、衝突與利益重組。

政治中心的更替，不代表所有地方都在同一時間完成制度轉換。

**下一階段問題：**

當中原政權不斷更替，南方諸國是否能在不同的政治環境下，建立具有自身特色的長期秩序？

### 第十五卷《五代餘聲》｜948—960

**研究問題：** 當不同區域長期維持各自的政治秩序，它們是否會發展出不同的治理模式與社會文化？

**主要研究組別：** 共存組、創造組、學習組、紀錄組。

**對話位置：**
- 卷中，南方諸國的政治、經濟與文化發展呈現不同面貌時。
- 卷末，討論多種區域秩序並存的意義。

**階段觀察：**

研究者開始將南方諸國視為具有自身發展歷程的政治與社會系統。

不同政權的治理方式、經濟基礎、文化活動、對外貿易與地方社會，可能形成各自的特色。

不能僅以最後是否被中原政權統一，判斷這些政權在其存在期間的歷史價值。

研究者也需要注意，政治上的弱勢不代表文化或經濟上的落後，政治上的延續也不代表所有社會問題都已解決。

**下一階段問題：**

當某個政權逐漸取得更大的整合能力，其他區域會如何回應？統一又會帶來哪些新的治理問題？

### 第十六卷《天下未定》｜961—979

**研究問題：** 當一個政權逐漸擴大控制範圍，政治統一是否等於社會秩序、制度與認同的全面整合？

**主要研究組別：** 秩序組、競存組、共存組、紀錄組、學習組。

**對話位置：**
- 卷中，統一進程逐漸改變不同區域的政治關係時。
- 卷末，北漢結束、十國時代告一段落之後，安排本系列最後一次較完整的實驗室討論。

**階段觀察：**

研究者可以確認，政治上的統一能夠改變政權之間的關係，也能重新建立更大範圍的行政與資源配置體系。

但政治統一並不代表各地的制度、文化、利益與生活方式立即一致。

統一之後仍然需要治理，治理之後仍然需要調整。原本存在於不同政權之間的差異，可能轉化為新政權內部的治理問題。

研究者也必須重新檢查最初的研究假設：人類社會是否真的只能透過一個中央權力維持秩序？不同區域的長期並存，是否曾經產生其他可行的發展方式？

本卷結束時，不應由研究者宣布實驗成功或失敗。北宋建立與北漢結束，是人類歷史中的一個階段性結果，不是所有問題的最終答案。

**下一階段問題：**

如果政治統一只是社會發展的一種階段，而不是歷史的終點，那麼人類是否能在更長的時間尺度中，學會處理權力、合作、差異與共同生活？

## 四、跨卷實驗室支線管理

### 1. 研究問題的連續性

| 卷次 | 核心研究方向 | 研究問題的推進 |
|---|---|---|
| 1 | 制度失效 | 制度存在是否代表制度有效？ |
| 2 | 危機擴散 | 局部問題如何跨區域連鎖？ |
| 3 | 社會重組 | 人們如何重新建立生活秩序？ |
| 4 | 制度復原 | 機構恢復是否等於功能恢復？ |
| 5 | 地方競爭 | 地方權力如何形成長期關係？ |
| 6 | 中央失序 | 政治名義與實際控制是否分離？ |
| 7 | 權力約束 | 制度能否限制掌權者？ |
| 8 | 王朝終結 | 政權結束是否代表社會秩序終結？ |
| 9 | 新政權 | 政權更替是否等於制度改變？ |
| 10 | 區域發展 | 區域條件如何影響政權發展？ |
| 11 | 政權整合 | 建立王朝是否等於建立穩定治理？ |
| 12 | 治理持續 | 制度能否超越統治者個人能力？ |
| 13 | 權力交接 | 制度能否承受統治者更替？ |
| 14 | 區域適應 | 政權更替如何影響地方社會？ |
| 15 | 多元秩序 | 不同區域能否形成不同發展模式？ |
| 16 | 政治統一 | 統一是否等於全面整合？ |

### 2. 研究組別出場原則

研究組別不必依照固定順序輪流出場。

同一個研究問題可以由不同組別提出不同觀察角度。例如：

- 秩序組關心制度是否仍能運作。
- 共存組關心人們是否仍能合作。
- 競存組關心不同群體如何適應環境。
- 紀錄組關心研究者究竟掌握了哪些證據。
- 學習組關心人們是否從經驗中修正行為。

不同組別的觀察可能互相補充，也可能產生矛盾。矛盾不必立即解決。

### 3. 實驗室對話的寫作限制

- 不使用「研究者 A／B」、「研究員甲／乙」等代號。
- 不以固定問答格式呈現研究者。
- 研究者的聲音應透過思考方式、用語、研究立場與對話脈絡自然區分。
- 不讓研究者直接背誦歷史事件。
- 不讓研究者在歷史事件尚未發生時預測其結果。
- 不將研究者的假設寫成作者的歷史結論。
- 不擅自增加實驗室設備、控制者、文明或其他上層設定。
- 不任意改動實驗參數，也不讓研究者隨意暫停、倒轉或改寫人類世界。
