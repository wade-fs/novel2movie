# 《長安秋暮》／《中原風雲》人物關係網與政治互動管理

## 一、文件目的

本文件用於管理 875—979 年間，唐朝末期、五代十國及宋初人物之間的政治關係、軍政依附、親族承繼、派系變化與跨政權互動。

本文件不是人物名冊，也不是忠奸分類表，而是追蹤：

1. 人物如何建立關係。
2. 關係如何因權力、利益、制度與局勢而改變。
3. 人物如何在不同政權之間轉換位置。
4. 一個人物的選擇如何影響其他人物及地方社會。
5. 同一組人物如何跨越多卷，保持年齡、經歷、立場與關係的連續性。

核心原則：

**人物關係不是固定標籤，而是隨時間變動的歷史事實。**

---

## 二、關係分類

每一組人物關係，必須標明關係性質與有效時間。

### 2.1 政治關係

| 關係類型 | 說明 |
|---|---|
| 君臣 | 君主與臣僚之間的制度關係 |
| 主從 | 軍事首領與部屬、依附者 |
| 藩屬 | 地方政權對中央或強權的名義承認 |
| 聯盟 | 因共同利益形成的暫時合作 |
| 對立 | 政治目標、權力分配或生存利益衝突 |
| 代理 | 代表他人或政權執行政治、軍事任務 |
| 挾制 | 一方實際控制另一方的決策空間 |

### 2.2 軍事與地緣關係

| 關係類型 | 說明 |
|---|---|
| 同鎮 | 同一藩鎮或軍事集團 |
| 鄰鎮 | 地理相鄰，可能合作或衝突 |
| 依附 | 地方勢力接受較強勢力保護 |
| 交戰 | 曾發生直接軍事衝突 |
| 借道 | 因交通、補給或外交需要取得通行 |
| 邊境互動 | 與契丹、河東、北方政權等往來 |

### 2.3 親族與婚姻關係

| 關係類型 | 說明 |
|---|---|
| 父子／母子 | 直系親屬 |
| 兄弟 | 同父母或異母兄弟 |
| 姻親 | 因婚姻形成的政治關係 |
| 收養 | 養子、義子等關係 |
| 繼承 | 因血緣、收養或政治安排形成的承繼 |

注意：五代軍政集團常透過收養、賜姓、婚姻與義親關係建立政治網絡。不可將義子直接寫成親生子，也不可將名義上的親族關係等同於實際血緣。

### 2.4 私人關係

| 關係類型 | 說明 |
|---|---|
| 師友 | 學習、交遊或共同經歷 |
| 舊識 | 早年相識，後來立場可能不同 |
| 恩主 | 曾提供庇護、資源或提拔 |
| 仇怨 | 有具體事件形成的私人衝突 |
| 合作者 | 因特定事務建立合作 |
| 間接關係 | 透過第三者、家族或地方網絡產生聯繫 |

私人關係必須有史料或合理推演依據，不可為了讓人物相遇而任意建立。

## 三、核心政治網絡

### 3.1 唐廷與宦官集團

主要人物：

- 唐僖宗李儇
- 唐昭宗李曄
- 唐哀帝李柷
- 田令孜
- 楊復恭
- 劉季述
- 韓全誨
- 鳳翔李茂貞
- 朱溫

#### 關係主線

【史實骨架】

唐末中央權力逐步受到宦官、藩鎮與軍事強人牽制。宦官集團並非始終一致，宮廷內部亦有不同派系與利益。

【合理推演】

小說應呈現不同時期宦官集團與皇帝、禁軍、外鎮之間的利益交換，不宜將所有宦官寫成同一個組織、同一種立場。

#### 重要關係變化

| 時期 | 關係變化 | 敘事重點 |
|---|---|---|
| 875—880 | 田令孜與僖宗關係密切 | 皇帝依賴宦官處理政務與軍事 |
| 880—884 | 僖宗出奔與返京 | 朝廷流亡期間的權力依附 |
| 884—888 | 田令孜失勢 | 宦官與藩鎮之間的責任與利益衝突 |
| 888—895 | 昭宗試圖重整皇權 | 皇帝、宦官與地方軍鎮的角力 |
| 896—903 | 宮廷內部衝突加劇 | 宦官與外鎮勢力相互利用 |
| 904—907 | 朱溫控制朝廷 | 皇帝與中央官僚的自主空間逐步消失 |

#### 校核事項

- 田令孜與楊復恭不可混為同一派系。
- 劉季述事件須依時間與史料核對。
- 韓全誨與李茂貞的關係須呈現其政治背景。
- 朱溫對宦官的處置，須放在其控制中央政權的過程中理解。

### 3.2 朱溫與後梁政治網絡

主要人物：

- 朱溫
- 朱友裕
- 朱友珪
- 朱友貞
- 張全義
- 敬翔
- 李振
- 王彥章
- 龐師古
- 朱友謙

#### 關係主線

【史實骨架】

朱溫從黃巢軍中轉投唐廷，逐步取得軍事與政治地位，最後控制唐廷並建立後梁。

後梁政權建立後，朱氏宗室與軍政重臣之間的權力安排，成為政權穩定的重要問題。

【合理推演】

朱溫集團內部不應被寫成單純的父子繼承故事，而應同時呈現：

- 宗室繼承順位。
- 軍事將領的實際力量。
- 文臣的政治建議。
- 皇帝對地方軍鎮的控制能力。
- 朱溫晚年的健康與決策狀態。

#### 關係變化

| 時期 | 關係變化 | 敘事重點 |
|---|---|---|
| 875—884 | 朱溫加入黃巢勢力，後歸唐 | 政治選擇與個人前途 |
| 884—900 | 朱溫逐步擴張 | 軍事依附轉化為政治權力 |
| 901—907 | 朱溫控制朝廷 | 唐廷官員與朱氏集團的重新定位 |
| 907—912 | 後梁建立與內部繼承 | 宗室、重臣與軍隊的權力關係 |
| 912 | 朱溫死亡 | 繼承危機與政權內耗 |

#### 校核事項

- 朱友珪弒父及其後的政變過程須依史料核對。
- 朱友貞取得帝位的政治過程不可簡化成單純的兄弟爭位。
- 張全義的地方治理與後梁政治關係須保留。
- 敬翔、李振等人的政治角色應有所區別。

### 3.3 河東李氏與後唐政治網絡

主要人物：

- 李克用
- 李存勖
- 李嗣源
- 李存審
- 周德威
- 郭崇韜
- 朱友謙
- 石敬瑭
- 李從珂

#### 關係主線

【史實骨架】

河東集團以李克用為核心，逐步形成具有軍事、家族與地方治理特徵的政治力量。

李存勖繼承其父的政治與軍事基礎，最終滅後梁、建立後唐。

後唐建立後，原有河東軍事集團與新政權官僚體系之間產生新的權力問題。

#### 重要關係變化

| 時期 | 關係變化 | 敘事重點 |
|---|---|---|
| 875—884 | 李克用崛起 | 河東軍事勢力形成 |
| 885—908 | 李克用與朱溫長期對立 | 兩大勢力的競爭 |
| 908—923 | 李存勖繼承並擴張 | 父子承繼與新一代將領 |
| 923—926 | 後唐建立 | 河東舊部與中央新體制的磨合 |
| 926—933 | 李嗣源即位 | 軍事功臣與皇權的重新平衡 |
| 934—936 | 李從珂與石敬瑭衝突 | 後唐內部權力結構崩解 |

#### 特別注意

- 李嗣源不是李克用的親生兒子，須明確標示其收養與軍事依附關係。
- 李從珂與後唐宗室的關係須依史實核對。
- 石敬瑭與後唐皇室、軍事集團的關係有其歷史脈絡，不可寫成突然背叛。
- 郭崇韜之死須呈現後唐建立後的政治環境，而不只是一場宮廷陰謀。
- 李存勖晚年的統治變化，須兼顧其個人選擇、宮廷環境與軍政制度問題。

### 3.4 契丹與北方政治網絡

主要人物：

- 耶律阿保機
- 耶律德光
- 石敬瑭
- 劉知遠
- 郭威
- 柴榮
- 劉崇
- 劉承鈞

#### 關係主線

【史實骨架】

契丹與中原政權的關係不只是戰爭，也包括外交、貿易、盟約、冊立、人口流動與政治承認。

石敬瑭向契丹求援及其後的割地、稱臣安排，是五代政治秩序的重要轉折。

#### 關係變化

| 時期 | 關係變化 | 敘事重點 |
|---|---|---|
| 907—926 | 契丹勢力逐步擴張 | 北方政治環境變化 |
| 936 | 石敬瑭向契丹求援 | 政權建立與外交代價 |
| 936—947 | 後晉與契丹關係 | 名義臣屬與實際政治利益 |
| 947 | 契丹進入中原，後晉滅亡 | 占領、治理與撤退 |
| 947—951 | 後漢建立 | 北方秩序重新組合 |
| 951—979 | 北漢依靠契丹維持政權 | 地緣依附與生存選擇 |

#### 校核事項

- 契丹自身的政權建構與內部發展必須獨立呈現。
- 耶律阿保機與耶律德光不可只作為中原政權的外部威脅。
- 石敬瑭與契丹的關係須呈現當時的政治計算及後續影響。
- 北漢與契丹的關係不是單純的上下級關係。

### 3.5 後漢、後周與宋初政治網絡

主要人物：

- 劉知遠
- 劉承祐
- 郭威
- 柴榮
- 趙匡胤
- 趙光義
- 韓通
- 王朴
- 范質
- 趙普

#### 關係主線

【史實骨架】

後漢建立後，皇帝與軍事重臣之間的權力關係並不穩定。郭威建立後周，柴榮進一步整頓政務與軍政體系。

趙匡胤透過後周軍政體系取得地位，最後建立宋朝。

【合理推演】

這一階段應著重描寫制度承接與人事延續，不應將宋朝建立寫成所有人物早已安排好的必然結果。

#### 關係變化

| 時期 | 關係變化 | 敘事重點 |
|---|---|---|
| 947—948 | 劉知遠建立後漢 | 後晉滅亡後的權力重組 |
| 948—950 | 劉承祐即位 | 皇帝與軍事重臣之間的張力 |
| 951—954 | 郭威建立後周 | 後漢舊臣與新政權的整合 |
| 954—959 | 柴榮即位 | 政務改革與軍政整頓 |
| 959—960 | 柴榮去世，趙匡胤崛起 | 繼承問題與軍隊政治 |
| 960—976 | 宋初政權建立 | 新皇權與舊官僚、舊軍人的整合 |
| 976—979 | 趙光義即位，北漢滅亡 | 宋朝統一進程與北方局勢 |

#### 校核事項

- 趙匡胤在後周時期的官職、軍職與人際關係須逐年核對。
- 陳橋兵變須區分史實、後世敘述與小說推演。
- 韓通之死不可只作為情節轉折，應呈現其身分與政治處境。
- 柴榮的改革應保留其自身的歷史目標，不應只當作趙匡胤的前奏。

## 四、南方諸國人物網絡

南方政權不是中原歷史的附屬篇章。各政權有自身的統治結構、經濟基礎、外交策略與地方社會。

### 4.1 吳與南唐

主要人物：

- 楊行密
- 徐溫
- 徐知誥／李昪
- 李璟
- 李煜

#### 關係主線

【史實骨架】

楊行密建立的吳政權，經徐溫掌握實際權力，再由徐知誥取得政權，建立南唐。

南唐的政治發展與中原五代政權並非單向從屬，而是存在外交、經濟、軍事與文化互動。

#### 關係變化

| 時期 | 關係變化 | 敘事重點 |
|---|---|---|
| 875—905 | 楊行密崛起 | 淮南地方勢力形成 |
| 905—927 | 徐溫掌權 | 吳政權內部的權力轉移 |
| 927—937 | 徐知誥逐步取得權力 | 政權承繼與合法性 |
| 937—943 | 李昪建立南唐 | 新政權的制度安排 |
| 943—961 | 李璟統治 | 南唐擴張、財政與外交 |
| 961—975 | 李煜統治 | 南唐後期政治與亡國 |
| 975—978 | 李煜降宋後 | 南唐舊臣與地方社會的變化 |

#### 校核事項

- 徐溫與徐知誥的收養關係須明確。
- 李昪建立南唐的合法性敘事，須兼顧其政治安排。
- 李璟時期的戰爭、財政與國力變化，須避免只用結果倒推原因。
- 李煜不能只以亡國君主的身分出場。

- 吳越的水利、農業、商業與城市發展。
- 錢俶納土歸宋的政治考量與地方影響。

## 五、跨政權人物關係管理

本系列有大量人物經歷多個政權，必須建立跨卷追蹤表。

| 人物 | 初始位置 | 政權變動 | 關係變化 | 最後位置 |
|---|---|---|---|---|
| 朱溫 | 唐末軍事人物 | 後梁建立 | 從唐廷藩鎮成為皇帝 | 912 年死亡 |

## 六、人物關係變化的寫作規則

### 6.1 不可把後來的立場提前

人物在某個年份尚不知道未來的政權更替，也不知道自己將成為某一政權的敵人或臣屬。

例如：

- 朱溫早期歸唐時，不應以後梁皇帝的視角描寫。
- 李存勖早年仍須面對父親留下的政治與軍事局勢。
- 石敬瑭在後唐時期的選擇，不能直接用後世對割地稱臣的評價取代當時的處境。
- 趙匡胤在後周時期，不應被寫成早已注定建立宋朝的人物。

### 6.2 不可將政權名稱當成人物的固定身分

人物可能經歷唐、後梁、後唐、後晉、後漢、後周與宋等不同政權。

必須記錄：

- 當時的官職。
- 當時的效忠對象。
- 實際控制的資源。
- 政治關係的變化。
- 人物是否主動轉換立場。
- 是否只是被新政權接收或重新任用。

### 6.3 不可將親族關係簡化成政治關係

父子、兄弟、收養與婚姻關係，不代表政治立場必然一致。

尤其五代時期，親族承繼與軍事權力常常互相牽制。

### 6.4 不可將合作關係視為永久同盟

合作可能源自：

- 共同敵人。
- 地理安全。
- 貿易利益。
- 皇位承繼。
- 軍事援助。
- 暫時的政治需要。

當上述條件改變，原有關係也可能改變。

## 七、關係網校核表

每次新增人物或改動章節時，至少檢查以下項目：

| 校核項目 | 檢查內容 |
|---|---|
| 年齡 | 當年是否符合人物年齡與人生階段 |
| 親族 | 血緣、收養、婚姻是否正確 |
| 官職 | 當時是否已任該職 |
| 政權 | 當時所屬政權是否正確 |
| 主從 | 是否存在史料支持的依附關係 |
| 派系 | 是否把不同時期的派系混為一談 |
| 地理 | 人物是否可能在該地活動 |
| 交往 | 是否有合理的相遇與通信條件 |
| 利益 | 關係變化是否具有政治或生活原因 |
| 後見之明 | 是否不小心使用了人物當時尚不知道的資訊 |

## 八、關係資料的證據標記

所有關係必須標記證據層級：

- 【史實骨架】：正史、實錄、碑誌、文集等有明確記載。
- 【合理推演】：由任官、地理、親族、事件與政治環境推導。
- 【小說虛構】：為敘事需要創作的私人交往、對話、通信或人物關係。

若某項關係尚未查證，不可直接寫成確定史實，應標記：

**【待核】**

若不同史料記載不一致，應保留差異，不可任意選擇最符合小說情節的版本。

## 十、正式寫作前的驗收標準

本文件完成後，必須能夠回答：

1. 一個人物從初次出場到死亡，經歷了哪些政治關係變化？
2. 同一個人物跨越不同政權時，是否保留了合理的履歷與立場？
3. 一個政權的建立或滅亡，對其官員、將領、家族與地方勢力造成什麼影響？
4. 南方諸國的人物是否具有獨立的政治與生活脈絡？
5. 人物之間的相遇、通信、合作與衝突是否符合年代與地理條件？
6. 是否把後世評價誤當成當時人物的認知？
7. 是否將史實、推演與虛構清楚區分？

**最終原則：人物關係網的目的不是把所有人連成一張漂亮的圖，而是確保每個人在歷史變動中，都有自己的位置、選擇、利益與代價。**
