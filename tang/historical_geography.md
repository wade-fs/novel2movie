# 《長安秋暮》／《中原風雲》歷史地理與社會空間設定

## 一、文件目的

本文件建立 875—979 年間的歷史地理基礎，供小說分卷、人物移動、政權興亡、地方治理與日常生活描寫使用。

本系列不以戰場地形或軍事部署為主要描寫對象，而是以地理如何影響政治、經濟、交通、人口流動與普通人的生活為核心。

地理不只是故事發生的背景，而是影響歷史發展的條件之一。

主要研究範圍：

1. 唐末中央政治核心與關中地區。
2. 河東、河北與北方邊境。
3. 河南、山東與淮河流域。
4. 江淮與長江中下游。
5. 巴蜀與西南地區。
6. 湖南、荊南與長江中游。
7. 福建與東南沿海。
8. 嶺南與南海交通。
9. 契丹及北方草原地區。

## 二、基本地理原則

### 2.1 使用當時地名

小說正文以當時使用的州、府、縣、道、鎮等名稱為主。

現代地名僅用於作者查閱與地理定位，不應直接代替歷史地名。

例如：

| 歷史地名 | 現代地理參照 | 注意事項 |
|---|---|---|
| 長安 | 今西安一帶 | 唐末政治中心 |
| 洛陽 | 今河南洛陽 | 唐末及五代重要都城 |
| 汴州／汴京 | 今開封一帶 | 五代後梁、後晉、後漢、後周及北宋的重要政治中心 |
| 太原 | 今山西太原一帶 | 河東政治與軍事中心 |
| 魏州 | 今河北邯鄲大名一帶 | 河北重要軍鎮 |
| 幽州 | 今北京一帶 | 北方邊境重鎮 |
| 揚州 | 今江蘇揚州 | 淮南經濟與交通中心 |
| 金陵 | 今南京 | 南唐重要都城 |
| 杭州 | 今浙江杭州 | 吳越政治中心 |
| 福州 | 今福建福州 | 閩政權重要中心 |
| 廣州 | 今廣東廣州 | 南漢政治與海上貿易中心 |
| 成都 | 今四川成都 | 前蜀、後蜀政治中心 |

以上為定位參照，不代表各時期行政區劃完全一致。

### 2.2 行政區劃必須分期核對

唐末、五代與宋初的州縣名稱、隸屬關係與行政地位並非固定不變。

每一卷開始前，應核對該卷所涉及地區在當時的：

- 州縣名稱。
- 行政隸屬。
- 節度使轄區。
- 軍鎮控制範圍。
- 政權實際管轄情況。
- 地方官職與軍政權力。

不可將後來的行政區劃直接套用到早期年代。

### 2.3 名義疆域與實際控制區域必須分開

五代十國期間，政權疆域常有名義與實際控制不一致的情況。

地圖與敘述應分別記錄：

- 名義上的領土主張。
- 實際能徵稅、任官與維持治安的地區。
- 地方勢力自行控制的地區。
- 需要依賴盟友或軍事力量才能維持的地區。

不得因某政權自稱皇帝或建立國號，就認定其已有效控制所有宣稱疆域。

## 三、第一地理區：關中與唐廷核心

### 3.1 長安

【史實骨架】

長安是唐朝政治、官僚與文化中心。黃巢起事期間，長安的陷落與唐廷出奔，象徵中央政權控制能力的重大衰退。

【小說敘事功能】

長安不應只作為皇帝與官員活動的宮廷舞台。

必須呈現：

- 宮城、皇城與坊市的空間差異。
- 官僚、軍人、商人、工匠與平民的生活。
- 城門、道路、坊市與官署的日常秩序。
- 戰亂、徵發與人口流動造成的生活變化。
- 唐廷離開後，長安居民面對的政治與經濟變化。

### 3.2 關中平原

關中地區是唐朝政治核心，其地理條件與周邊交通，長期影響中央政權的穩定。

需要研究：

- 渭水流域。
- 關中農業與糧食供應。
- 長安周邊州縣。
- 通往洛陽、河東與蜀地的交通。
- 關中與外部糧食來源的依賴關係。

【合理推演】

中央政權失去對關中周邊交通與糧食供應的控制後，長安即使仍保有政治象徵，也可能逐漸失去實際治理能力。

### 3.3 鳳翔與關中西部

鳳翔是唐末政治的重要地區，李茂貞等地方勢力與朝廷的關係，影響昭宗時期的政治局勢。

敘事應呈現：

- 鳳翔與長安的交通。
- 地方軍事勢力與中央官僚的互動。
- 地方徵稅與糧食供應。
- 朝廷在地方軍事力量面前的實際處境。

## 四、第二地理區：河東、河北與北方

### 4.1 河東

核心地點：太原。

【史實骨架】

河東是李克用、李存勖政治與軍事力量的重要根據地，地理位置使其與中原、河北及北方草原勢力密切互動。

敘事重點：

- 太原城及其周邊生活。
- 汾河流域。
- 山西盆地與山地交通。
- 河東與河北的往來。
- 河東與契丹的關係。
- 地方軍政體系如何影響百姓生活。

【合理推演】

河東的地理條件使其具有一定的防禦優勢，但也受到糧食、交通與人口供應限制。

不能將河東寫成完全封閉、自給自足的軍事基地。

### 4.2 河北

重要地區：

- 魏博。
- 成德。
- 幽州。
- 滄州。
- 相州。
- 邢州。
- 洺州。

【史實骨架】

河北藩鎮長期具有高度地方自主性。唐末至五代，河北地區的政治歸屬與軍政勢力不斷變動。

敘事重點：

- 藩鎮與中央的關係。
- 地方軍政首領的承繼。
- 城鎮商業與農業。
- 地方士人、豪族與軍事勢力。
- 河北與河東、中原及契丹的互動。

### 4.3 幽州與北方邊境

幽州是中原政權與北方草原勢力往來的重要區域。

需要研究：

- 幽州的城鎮與行政結構。
- 契丹勢力南下的地理通道。
- 邊境貿易與物資交換。
- 馬匹、牲畜與農產品流通。
- 邊境居民的生活與身分變化。

### 4.4 契丹地區

契丹不是單純的中原邊境外部力量，而是有自身政治、社會與經濟發展的政權。

敘事應包含：

- 契丹政治中心的發展。
- 部族與部落聯盟。
- 首領權力與繼承。
- 遊牧、農業及其他生產方式。
- 與中原的外交與貿易。
- 契丹統治者對中原政權的認識與政策。

【合理推演】

契丹與中原之間的往來，應呈現雙方對彼此政治制度、物資需求與外交秩序的理解，而非單純的文明衝突。

## 五、第三地理區：中原與淮河流域

### 5.1 汴州與汴京

【史實骨架】

汴州在五代時期逐漸成為中原政權的重要政治中心，後梁定都於此，後晉、後漢、後周與宋亦以此地為重要都城。

敘事重點：

- 黃河與汴水交通。
- 汴州城內的官署、商業與居民生活。
- 糧食運輸與漕運。
- 都城人口與市場。
- 政權更替對官員、商人與平民的影響。

### 5.2 洛陽

洛陽在唐末與五代仍具有重要政治地位。

需要呈現：

- 唐廷遷都後的政治意義。
- 洛陽與汴州之間的交通。
- 城市人口與官僚活動。
- 政權更替後的城市功能變化。
- 舊都城與新政治中心之間的關係。

### 5.3 河南與山東

重要地區：

- 汴州。
- 宋州。
- 亳州。
- 徐州。
- 鄆州。
- 青州。
- 濮州。
- 滑州。

敘事重點：

- 農業生產與土地控制。
- 地方軍鎮。
- 黃河水患與河道變化。
- 商業與交通。
- 徵稅、徵兵與地方秩序。

### 5.4 淮河流域

淮河流域連接中原、江淮與長江下游，是五代時期重要的政治與經濟交界區域。

需要研究：

- 淮河及支流交通。
- 渡口與水運。
- 揚州、楚州、壽州等地的政治地位。
- 吳、南唐與中原政權之間的往來。
- 農業與水利。
- 戰亂造成的遷徙與市場變化。

【合理推演】

淮河不只是政權邊界，也是一條生活與商業往來的通道。居民可能在政治歸屬改變後，仍維持原有的親族、商業與地方聯繫。

## 六、第四地理區：江淮與長江下游

### 6.1 揚州

【史實骨架】

揚州是唐末至五代重要的經濟與交通中心，也是吳政權的重要政治區域。

敘事重點：

- 城市商業與市場。
- 淮河、長江與運河交通。
- 鹽業與財政。
- 商人、船戶與手工業者。
- 吳政權的地方治理。

### 6.2 金陵

【史實骨架】

金陵是南唐的重要政治中心。

需要呈現：

- 都城官僚與宮廷生活。
- 長江交通。
- 南唐與吳越、楚、後蜀及中原政權的關係。
- 城市文化與士人活動。
- 財政與物資供應。

### 6.3 潤州與常州

長江下游的重要交通與地方行政區域。

敘事重點：

- 江南水網。
- 城鎮間的舟船交通。
- 農業、手工業與市場。
- 吳與南唐政權更替對地方社會的影響。

### 6.4 杭州與兩浙

【史實骨架】

杭州是吳越的重要政治中心。兩浙地區的農業、水利、商業與城市發展，是吳越政權長期維持的重要基礎。

敘事重點：

- 錢氏政權的地方治理。
- 太湖流域與錢塘江流域。
- 水利工程。
- 農業與稻作。
- 海塘、港口與沿海交通。
- 城市商業與手工業。
- 吳越與中原政權的外交。

## 七、第五地理區：巴蜀與西南

### 7.1 成都平原

【史實骨架】

成都平原是前蜀、後蜀的重要政治與經濟核心。

敘事重點：

- 成都城。
- 平原農業與水利。
- 地方官僚與士人。
- 商業與手工業。
- 蜀地與中原的交通。
- 蜀地政權更替後的人事與地方秩序。

### 7.2 劍門與蜀道

蜀道是連接巴蜀與關中、漢中及中原的重要交通系統。

需要研究：

- 劍門關。
- 棧道。
- 山區驛站。
- 交通與糧食運輸。
- 商旅與官員往來。
- 地方居民的交通限制。

不得將蜀道簡化成只有軍隊能夠通過的道路。

### 7.3 漢中與山南地區

漢中及山南地區連接關中、巴蜀與荊楚。

敘事重點：

- 山區交通。
- 地方行政與軍鎮。
- 農業及物資運輸。
- 蜀地政權與中原政權的接觸。
- 人口流動與地方依附。

### 7.4 巴蜀政權更替

應分別呈現：

- 王建建立前蜀。
- 前蜀王氏政權內部變化。
- 後唐滅前蜀。
- 孟知祥建立後蜀。
- 孟昶時期的地方治理。
- 宋滅後蜀後的社會承接。

不能把前蜀、後蜀當作同一政權的簡單延續。

## 八、第六地理區：湖南、荊南與長江中游

### 8.1 長沙與湖南

【史實骨架】

湖南是楚政權的重要基礎區域，具有自身的農業、交通與地方政治條件。

敘事重點：

- 長沙城市生活。
- 湘江水運。
- 洞庭湖流域。
- 農業與地方市場。
- 馬氏政權的地方治理。
- 楚政權內部的繼承問題。

### 8.2 江陵與荊南

江陵位於長江中游交通要道，荊南政權的政治價值與地理位置密切相關。

敘事重點：

- 長江水運。
- 江陵城鎮與市場。
- 荊南與周邊政權的外交。
- 商旅、船戶與地方居民。
- 高氏政權的生存策略。

### 8.3 洞庭湖與鄱陽湖

兩湖流域不應只作為地圖上的水域標記。

需要研究：

- 湖泊與河流交通。
- 漁業及農業。
- 水患與水利。
- 港口、渡口與聚落。
- 湖區居民與地方政權的關係。

## 九、第七地理區：福建與東南沿海

### 9.1 福州

【史實骨架】

福州是閩政權的重要政治中心。

敘事重點：

- 閩政權的地方行政。
- 城市商業。
- 沿海交通。
- 宗室與地方勢力。
- 福州與建州等地的政治關係。

### 9.2 建州與福建內陸

福建山地地形複雜，沿海與內陸的交通、經濟及地方政治可能存在差異。

需要研究：

- 山區道路。
- 河谷聚落。
- 農業與茶葉等地方物產。
- 地方豪族。
- 沿海港口與內陸市場的聯繫。

### 9.3 閩政權的地理限制

【合理推演】

福建地形使地方政權具有一定的區域獨立性，但也增加內部交通與行政整合的難度。

小說應呈現：

- 政令如何傳達。
- 地方官員如何往來。
- 物資如何進出。
- 沿海與內陸如何互相依賴。
- 宗室內鬥如何影響地方秩序。

## 十、第八地理區：嶺南與南海

### 10.1 廣州

【史實骨架】

廣州是南漢的重要政治中心，也是唐末至五代重要的海上貿易城市。

敘事重點：

- 城市市場。
- 港口與海上交通。
- 外來商人。
- 香料、珠寶、陶瓷及其他貿易物資。
- 南漢宮廷與地方官僚。
- 海上貿易與財政收入。

### 10.2 嶺南內陸

需要研究：

- 珠江水系。
- 西江、北江與東江交通。
- 山地與河谷聚落。
- 農業與地方物產。
- 廣州與內陸州縣的行政聯繫。
- 地方族群與市場互動。

### 10.3 南海交通

南海不是單純的小說背景，而是南漢與周邊世界接觸的重要空間。

敘事重點：

- 海上航線。
- 港口與商船。
- 季風與航行季節。
- 外來商人及貨物。
- 海上貿易的管理與稅收。
- 沿海居民的生活。

【合理推演】

海上貿易受季風、航行技術、港口管理與政治環境影響。不可讓船隻在沒有合理時間與航線條件下任意往返。

## 十一、交通系統

### 11.1 陸路

主要陸路交通包括：

- 長安至洛陽。
- 洛陽至汴州。
- 汴州至太原。
- 太原至河北。
- 長安至漢中。
- 漢中至成都。
- 汴州至淮河流域。
- 河北至幽州。

每一條路線都應建立：

- 起點與終點。
- 中途主要州縣。
- 山川與渡口。
- 驛站及交通條件。
- 一般旅人與官方人員的差異。
- 正常季節與特殊天候下的行程差異。

### 11.2 水路

主要水路包括：

- 黃河。
- 汴水及相關運河系統。
- 淮河。
- 長江。
- 大運河。
- 湘江。
- 贛江。
- 閩江。
- 珠江水系。

水路描寫應注意：

- 水位季節變化。
- 船隻種類與載運能力。
- 逆流與順流差異。
- 渡口與港口。
- 水運稅收與管理。
- 船戶、纖夫與商人的生活。

### 11.3 海路

海路以東南沿海、廣州及南海交通為主。

需要核對：

- 港口位置。
- 季風航行條件。
- 海上航行時間。
- 船隻種類。
- 主要貿易貨物。
- 與海外商人的接觸方式。

## 十二、人物移動與旅行時間管理

所有重要人物的跨區移動，都必須經過交通合理性檢查。

### 12.1 移動記錄格式

每次人物移動，應記錄：

| 欄位 | 內容 |
|---|---|
| 人物 | 移動者 |
| 出發地 | 當時歷史地名 |
| 目的地 | 當時歷史地名 |
| 出發時間 | 年、月或季節 |
| 抵達時間 | 年、月或季節 |
| 交通方式 | 陸路、水路、海路 |
| 主要路線 | 中途州縣與交通節點 |
| 移動原因 | 任官、避亂、外交、商業、家族等 |
| 證據層級 | 史實骨架、合理推演、小說虛構 |
| 待核事項 | 史料或路線尚待查證之處 |

### 12.2 不可任意安排人物相遇

若兩個人物在不同地區活動，必須有合理的：

- 會面地點。
- 交通時間。
- 政治任務。
- 書信或使者往來。
- 中間人或共同關係。

不能只因兩人都屬於同一政權，就假設他們曾經見面。

### 12.3 旅行時間不可使用現代交通直覺

人物移動速度須考慮：

- 步行、騎馬、車輛或舟船。
- 官方驛傳與私人旅行的差異。
- 地形與道路狀況。
- 季節、雨雪與洪水。
- 戰亂與地方治安。
- 身分、財力與隨行人數。

尚未查證的行程時間，標記【待核】，不可假裝精確。

## 十四、地理與政權興亡的關係

地理條件不是政權興亡的唯一原因，但會影響政權的選擇與能力。

### 14.1 中原政權

關鍵條件：

- 黃河流域的農業與人口。
- 汴州、洛陽等交通樞紐。
- 對河北、河東與淮河地區的控制。
- 糧食運輸與地方徵稅。

### 14.2 河東政權

關鍵條件：

- 太原地理位置。
- 山地防禦。
- 河北與契丹方向的交通。
- 糧食與人口供應。
- 對中原的進出通道。

### 14.3 南方政權

關鍵條件：

- 長江與大運河交通。
- 水利與農業。
- 城市商業。
- 地方士人與官僚體系。
- 海上貿易。
- 各政權之間的地理阻隔與往來。

### 14.4 北漢

關鍵條件：

- 太原及河東北部地理環境。
- 與契丹的交通及外交。
- 對外糧食供應。
- 周邊政權的壓力。
- 地方社會對長期軍事化的承受能力。

## 十八、最終驗收標準

本文件完成後，應能回答：

1. 人物在某年某月是否可能出現在某地？
2. 人物從甲地到乙地，是否有合理路線與時間？
3. 某地在當時究竟由誰實際控制？
4. 政權更替對地方居民造成哪些具體影響？
5. 南方諸國是否擁有自己的地理、經濟與社會敘事？
6. 地理條件如何影響政權的選擇，而非決定政權的命運？
7. 讀者能否從人物的生活與移動，理解當時的空間與世界？

**最終原則：地理不是人物移動的背景板，而是歷史人物每天必須面對的真實限制。**
