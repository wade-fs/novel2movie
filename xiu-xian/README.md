# **《求理與歷劫》修煉體系總綱（階段整理版）**

## **一、修煉體系的基本架構**

本世界的修煉體系分成兩個層次：

1. **入門資格：煉骨、煉氣。**  
2. **正式境界：知身、離欲、無我、斷緣、超時、入道。**

煉骨與煉氣不屬於正式修煉境界，也不需要歷劫。它們是判定一個人是否已經成為修仙者的標準。

真正涉及存在本質轉換、需要歷劫的，是後面的六個正式境界。

## **二、入門階段：煉骨與煉氣**

### **1\. 煉骨**

煉骨的目的，是鍛煉身體、改善健康。

它屬於修仙入門的基礎，不是正式境界，也不涉及歷劫。

### **2\. 煉氣**

煉氣的關鍵，是修煉者能夠吸納天地之氣，以此滋養自身，進而不必依靠吃喝維持生命。

它同樣不屬於正式境界，也不涉及歷劫。

### **3\. 入門資格的意義**

煉骨、煉氣的作用，是建立修仙者的基本條件，而不是決定修仙者已經達到哪個境界。

一個人即使完成煉骨、煉氣，也可以停留在這個階段，繼續過自己的生活。

他不必追求更高境界，也不會因為已經成為修仙者，就被迫歷劫。

---

## **三、修煉的最高原則**

### **1\. 修煉的本質：存在的轉換**

修煉的本質，是**把一種存在，換成另一種存在**。

佛家講「放下」，道家講「轉化」。兩者結合，便是放下某種原有的存在，同時轉化出另一種存在。

越往高處，被換掉的東西越接近「自己」，所付出的代價也越深。

因此：

**強大，本來就是「缺了些什麼」的結果。**

修煉不是單純累積力量，而是以自身原有的某些部分作為代價，換取新的存在形式與能力。

### **2\. 六大境界的核心轉換**

| 境界 | 換掉的東西 | 得到的東西 |
| ----- | ----- | ----- |
| 知身 | 對身體的依賴 | 氣 |
| 離欲 | 貪與懼，也就是感知被扭曲的源頭 | 真正的感知 |
| 無我 | 「我是唯一」 | 化身 |
| 斷緣 | 人與人的牽繫 | 無跡，可推算過去與未來 |
| 超時 | 壽元 | 時間操控 |
| 入道 | 「人」本身 | 與一法則同步 |

以上六境是正式修煉境界，不包含煉骨、煉氣。

## **四、六大境界的定位與規則**

### **第一境：知身**

**定位：修仙的第一課。**

知身境可以類比傳統修仙小說中的築基境，以便理解它在修煉體系中的位置，但這只是類比，不能直接套用其他作品的築基設定。

知身境是六大境界的起點，也是修仙者第一次真正以生命承擔歷劫代價的階段。

* 核心轉換：對身體的依賴轉換為氣。  
* 歷劫數量：四劫。  
* 修為變化：每渡過一劫，修為便有所提升。  
* 境界突破：四劫全部渡過，才能突破至下一境界，也就是離欲境。  
* 量化方式：不以數值指標區分知身境內的修為。  
* 歷劫失敗：必定身死道消。

知身境不需要量化，不代表修為沒有差異。修煉者的進展，可以透過渡過的劫數表達。

知身境與其他五境最重要的差別，在於歷劫失敗的後果：**知身境是唯一一個歷劫失敗必定身死道消的境界。**

### **第二境：離欲**

**核心轉換：放下貪與懼，換取真正的感知。**

離欲境的「神」指感知能力。

貪與懼會扭曲一個人對世界的感知。當修煉者逐漸放下這些扭曲來源，便能看得更真。

離欲境有兩個獨立的衡量方向：

1. \*\*範圍：\*\*感知能延伸多遠，取決於「神」的多寡。  
2. \*\*平緩度／清晰度：\*\*感知隨距離衰減的曲線有多平緩，取決於離欲的深度，也就是貪與懼放下得有多徹底。

感知不是固定半徑內清楚、半徑外完全不可見的遊戲式範圍，而是一條隨距離逐漸衰減的清晰度曲線。

* 近處最清楚，越遠越淡。  
* 修為越高，曲線越平、延伸越長。  
* 距離越遠，感知仍會衰減。  
* 不存在無限遠的感知，也沒有一條硬性的範圍邊界。

感知深度可以透過細節呈現：

* 初入：能辨認遠處有人，但看不清是誰。  
* 更深：能看清對方的神色與動作。  
* 更深一層：能察覺呼吸起伏、手指細微動作。  
* 極深：遠處景象如在眼前，甚至能看出對方尚未說出口的遲疑。

**代價與限制：**

1. 看得越清楚，越容易被察覺。感知是雙向的，窺視別人，也可能被別人窺視。  
2. 神離開本體，身體便可能無人照看。感知越遠、維持越久，本體的風險就越高。  
3. 離欲只感知「此刻」正在發生的事情。  
4. 對過去與未來的推算，屬於斷緣境，而非離欲境。

### **第三境：無我**

**核心轉換：放下「我是唯一」，換取化身。**

* 核心之質：化身。  
* 數量：無上限。  
* 代價：「我」的濃度。

無我境的能力與代價，都圍繞「我」的概念展開。化身的數量沒有上限，但化身能力的擴展，必須與「我」的濃度及其代價一併理解。

具體量化指標與細節，仍以原始設定為準。

### **第四境：斷緣**

**核心轉換：放下人與人的牽繫，換取無跡。**

* 核心之質：無跡。  
* 能力：推算過去與未來。  
* 量化方式：相對推算距離，也就是對過去與未來各能推算多遠。

斷緣的推算屬於另一種能力，不能與離欲境對當下的感知混為一談。

離欲看的是此刻；斷緣處理的是過去與未來。

### **第五境：超時**

**核心轉換：付出壽元，換取時間操控。**

* 核心之質：時間。  
* 能力：加速自身。  
* 加速倍數：無上限。  
* 代價：壽元。  
* 延伸規則：氣場範圍內的少量物件，可以被視為自身的一部分。

超時境的壽元，不能只理解為剩餘壽命的數值，而要理解為生命從生到死所經歷的整條行程。

加速意味著讓這條行程更快走過。

因此：

* 對幼苗而言，加速表現為成長與成熟。  
* 對老樹而言，加速表現為衰敗與枯死。  
* 對人而言，加速既可能帶來修為與見識的增長，也會使身體更快衰老。

催熟靈藥也有代價：靈藥更快長成，剩餘壽元也會減少。因此，藥性與壽命之間存在取捨。

藥齡應以藥物實際經歷的行程計算，而非單看世間日曆。若世間一日、域內千日，藥物便實際經歷了千日的行程。

### **第六境：入道**

**核心轉換：放下「人」本身，換取與一法則同步。**

* 核心之質：與一法則同步。  
* 類型：大道與小道。  
* 重要能力：時之域。  
* 主要代價：維持差速本身，以及逆向時之域所消耗的「人的部分」。

#### **時之域**

時之域分為兩個方向，兩者皆可作用於一定範圍，但成本結構不同。

**順向：吸，內慢外快。**

* 維持成本低。  
* 屬於入道者的常態用法。  
* 作用是放慢域內事物的行程，可用於保存、延緩衰老，以及讓傷者停止惡化。

**逆向：推，內快外慢。**

* 維持成本高。  
* 能用得起、維持得久的人較少。  
* 屬於殺手鐧，而不是日常能力。  
* 除了氣之外，還會付出「人」的部分。

兩個方向的共同規則是：範圍越大，成本越高。

#### **壽元與時之域的共同規則**

生命有生命的行程；器物、土地等無生命之物，也有自己的「壽」，可理解為耐久。

* 人付出成長與衰老。  
* 植物付出生長與枯榮。  
* 器物付出耐久，例如劍鏽、衣爛、田地逐漸貧瘠。

時之域內的每個存在，各自承擔自己的行程變化。

入道者自身付出的，則是維持差速本身；成本取決於速率差與領域大小，而不是領域內有多少物件。

#### **入道的方向性代價**

* 順向（吸）：主要消耗氣，成本較低。  
* 逆向（推）：消耗氣，也會逐漸消磨「人」的部分。

逆向維持得越久，記憶、情感與人際牽繫便可能越淡。這條代價直接連接入道境最核心的轉換：失去作為「人」的身份。

## **五、求理與歷劫的分界**

### **1\. 應對與求理**

是否進入歷劫，不取決於一個人的學問高低，也不取決於他想成為什麼樣的人，而取決於他是否真正開始追求事物背後的原理。

\*\*應對：\*\*問的是「怎麼活下去」。

例如覓食、逃荒、尋找水源，都是對既有環境作出反應。即使最後餓死，也不因此自動構成歷劫。

\*\*求理：\*\*問的是「為什麼會這樣」。

例如追問為什麼不下雨、災荒如何形成、能否改變造成災荒的機制，以及如何讓這種事情不再發生。

這才可能進入求理，並引來歷劫。

這條分界不看學問高低：

* 不識字的農夫追問天為什麼不下雨，也可能是在求理。  
* 博學之人只是背誦典籍、尋找力量，卻從不追問為什麼，仍可能只是在應對。

這套觀念可以與「格物致知」及屈原《天問》形成思想上的呼應。

### **2\. 動機不決定是否歷劫**

好奇、不甘、野心、仇恨、慈悲，都可以成為一個人開始求索的動機。

但動機本身不會引來劫。

例如，想拯救更多人只是願望；真正開始研究如何救人、追問災難的原因與機制，才進入求理。

動機影響劫的樣貌，累積的因果則會影響歷劫的難易。

### **3\. 劫會長成問題的形狀**

歷劫不是單純的雷擊，也不是外在發放的試煉通知。

一個人真正開始追求某項原理時，劫便可能在他尚未察覺的情況下展開，並以他所追問的問題為核心。

例如，追問災荒的人，可能必須面對飢餓、絕源及生存困境。

因此，歷劫既與修煉者所求的問題有關，也可能影響他後續的道路。

### **4\. 捷徑不能取代求理**

單純追求力量、背誦方法或模仿別人的修煉方式，若沒有真正追問原理，就不能以此取代求理。

沒有真正求索，便沒有相應的歷劫，也就不能靠單純累積方法直接突破境界。

### **5\. 實踐是真理的必要條件**

本體系的重要思想是：

**只有實踐的才是真理，沒實踐的都叫空談。**

理解一套理論，不代表真正取得了它所代表的真理。

如果一個人聲稱理解某種規則，卻無法承擔或實現這種理解所要求的轉變，就不能單憑理論宣稱自己已經真正求得真理。

求理不等於與天道對抗，也不一定要改變世界；重點是弄懂事物的原理，並真正實踐所求。

## **六、目前已確認的結構性原則**

1. 煉骨與煉氣是入門標準，不是正式境界。  
2. 正式境界共有六個：知身、離欲、無我、斷緣、超時、入道。  
3. 知身境有四劫，每渡一劫，修為便提升；四劫完成後突破至離欲境。  
4. 知身境不設量化指標，是六境中唯一歷劫失敗必定身死道消的境界。  
5. 其他五境各有量化方式，但量化的對象與形式不必相同。  
6. 修煉的核心不是累積力量，而是以某種存在作為代價，換取另一種存在。  
7. 求理與應對的分界，在於是否真正追問事物背後的原理。  
8. 動機不決定是否歷劫；求索的內容會影響劫的形狀。  
9. 實踐是真正取得真理的必要條件。  
10. 境界越高，所付出的代價越接近「人」本身；入道境尤其如此。

## **七、尚待補齊的內容**

以下項目目前不能只靠這份整理確定，應等待原始設定或後續討論：

* 知身四劫各自的名稱、內容與具體變化。  
* 離欲、無我、斷緣、超時、入道各自的劫數與歷劫細則。  
* 除知身以外，各境量化指標的完整定義及數值。  
* 無我境「我」的濃度如何衡量，以及化身數量與代價之間的關係。  
* 斷緣境對過去、未來的推算規則與限制。  
* 超時境加速自身的具體作用條件。  
* 入道境大道與小道的區別，以及各自與法則同步的方式。  
* 六境各自歷劫失敗的完整後果。  
* 各境的突破判定、外在可觀察的「驗」，以及修煉者如何認識自身已經突破。

以上內容以目前已確認的規則為基礎，不將尚未確認的細節當成既定設定。
