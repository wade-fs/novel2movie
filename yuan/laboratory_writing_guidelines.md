# laboratory_writing_guidelines.md
# 外星實驗室敘事嵌入與 AI Agent 執行規範

**文件用途：** 指導 AI Agent 將外星實驗室敘事嵌入既有及未來的歷史小說  
**適用範圍：** 元末明初、宋末、唐末、五代至宋初、明末至康熙、清末及後續歷史作品  
**核心原則：** 人類歷史是正文，外星實驗室是隱藏的第二故事線。

---

# 一、專案總體目標

本專案是一系列以中國歷史為背景的歷史小說，透過真實歷史人物、制度、政治變遷、社會生活及虛構人物，呈現不同時代的文明發展。

在既有歷史小說之外，加入一條跨越不同朝代、長期持續的外星實驗室敘事線。

外星研究者以人類文明為觀察對象，透過不同研究組的觀察、假說、討論、實驗及結果分析，逐步理解人類社會的運作方式。

這條敘事線有自己的劇情、人物關係、研究方向及發展歷程。

它不是歷史小說的附屬解說，也不是單純提供讀者額外知識的旁白。

**最終目標：讓讀者在閱讀歷史小說的同時，也能逐漸拼湊出外星研究者自己的故事。**

# 二、兩個世界的基本設定

## 2.1 人類世界

人類世界是歷史小說的主要敘事空間。

必須遵循原有歷史小說的設定：

- 以史實為骨架。
- 以合理推演補足歷史記載不足之處。
- 以小說虛構人物及情節串聯歷史。
- 重視人物、制度、地理、社會及日常生活。
- 不因外星實驗室的存在而改變歷史事件。

人類世界有自己的時間、空間、因果關係及歷史發展。

## 2.2 外星實驗室

外星實驗室是另一個維度的研究空間。

其存在方式與人類世界不同，不能直接套用人類對時間、空間、物理環境及科技設備的理解。

外星研究者觀察人類，如同人類觀察螞蟻。

人類可能看見一個腳印突然出現，又突然消失，卻無法理解腳印的來源、形成過程及背後的存在。

同樣地，人類無法完整理解外星研究者的存在。

因此：

- 不需要詳細描寫外星世界。
- 不需要解釋外星科技如何運作。
- 不需要設定複雜的時間參數。
- 不需要描述研究設備的規格與操作方式。
- 不需要讓人類與外星研究者建立直接交流。
- 不應將人類世界簡化為普通的電腦遊戲或虛擬實境。

外星世界的設定以維持敘事一致性為主，不以科幻世界觀的完整技術解釋為目標。

# 三、外星研究組設定

## 3.1 研究組的性質

外星實驗室由多個研究組共同參與人類文明研究。

研究組代表不同的研究方向，而不是不同的外星種族或文明。

研究組可以對同一現象提出不同假說，也可以因為研究成果而改變原有觀點。

研究組之間不預設正派、反派或善惡立場。

## 3.2 研究方向

研究方向以專案既有的 `laboratory.md` 為準。

目前討論過的研究方向包括：

- 秩序：研究群體規則、制度、權力及秩序形成。
- 學習：研究知識傳遞、經驗累積及群體學習。
- 共存：研究不同群體如何維持共同生活。
- 競存：研究資源競爭、利益衝突及群體生存。
- 認知：研究人類如何理解世界、建立信念及形成判斷。
- 紀錄：研究資訊保存、傳播及歷史記憶。
- 創造：研究人類如何產生新制度、新技術及新觀念。
- 干預：研究外部影響對群體行為及文明發展的作用。

以上是既有討論中的方向，不代表必須全部採用，也不代表最終研究組數量已經確定。

**AI Agent 不得自行新增、刪除或重定義研究組。**

如需調整，必須先檢查總體設定文件。

## 3.3 研究組的互動

研究者可以：

1. 提出研究假說。
2. 質疑其他研究組的結論。
3. 提出不同解釋。
4. 承認原先判斷錯誤。
5. 根據新的觀察修正研究方向。
6. 對其他研究組的研究成果提出疑問。
7. 因長期觀察結果而產生新的研究問題。

研究者不應永遠正確。

研究者之間的意見分歧，是實驗室故事的重要來源。

# 四、實驗室敘事的基本原則

## 4.1 實驗室不是歷史解說員

禁止將實驗室對話寫成歷史知識補充。

不應出現：

- 對讀者解釋某位皇帝的生平。
- 說明某場戰爭的歷史經過。
- 直接講解某個王朝為何滅亡。
- 重述人類世界正文已經描述的事件。
- 直接替歷史人物評定功過。

研究者應該討論的是觀察到的現象，以及這些現象對既有研究假說造成的影響。

例如：

不適當：

「泰定帝死後，倒剌沙封鎖消息，造成元廷政治危機。」

適當：

「我發現負責維持這套系統的人，正在破壞這套系統。」

前者是歷史解說，後者是研究者對現象的觀察。

## 4.2 研究者不能全知

研究者只能依照其觀測能力及已取得的資料進行判斷。

不得任意取得人類世界中未曾觀察到的資訊。

不得因為作者知道歷史結果，就讓研究者提前知道。

研究者可以：

- 誤解人類行為。
- 將相關事件誤判為因果關係。
- 提出錯誤假說。
- 忽略重要因素。
- 對人類行為產生不合理的推論。
- 在後續觀察中發現原先的錯誤。

研究者的知識應該隨著觀察逐步累積。

## 4.3 不要擾亂外星實驗室參數

研究者的討論必須符合既有實驗室設定。

不得為了製造劇情而任意改變：

- 研究條件。
- 觀察規則。
- 研究組的職責。
- 實驗室與人類世界的關係。
- 已經建立的研究成果。

尤其不得為了配合某段歷史劇情，突然增加新的科技能力或觀測能力。

如有必要調整設定，先提出修訂建議，不得直接寫入正文。

# 五、實驗室對話寫作規範

## 5.1 位置

原則上將實驗室對話放在每章正文之前。

建議格式：

第一章　章名

【實驗室觀測紀錄】

研究者對話。

---

人類世界正文開始。

如此可以讓讀者在進入歷史場景之前，先接觸另一個觀察角度。

如某章的敘事結構有特殊需求，可以調整位置，但不得任意打斷歷史正文。

## 5.2 長度

每章原則上最多安排一段實驗室對話。

建議長度為 80～180 個中文字，視內容需要調整。

不得為了達到字數而增加無意義對話。

部分章節可以只有一兩句。

部分章節可以完全沒有實驗室對話。

不要求每章平均分配研究者的發言。

## 5.3 對話風格

實驗室對話應具有以下特色：

- 簡短。
- 冷靜。
- 理性。
- 帶有研究及實驗討論的語感。
- 偶爾出現疑問、質疑及意見分歧。
- 不刻意煽情。
- 不使用過多修辭。
- 不寫成哲學演講。
- 不寫成科幻電影式的技術對話。

應讓讀者感覺自己正在旁聽一群研究者討論一項長期實驗。

## 5.4 不要過度依賴對話

研究者不需要每次都完整解釋自己的想法。

允許：

- 一問一答。
- 短暫爭論。
- 一個研究者提出疑問，另一個不予回答。
- 對話中斷。
- 研究者承認目前沒有答案。

有時候，留下問題比給出答案更有價值。

## 5.5 研究者稱呼

目前使用「觀測節點〇〇一」作為研究者或觀測端的識別方式。

其他研究者的稱呼與識別方式，以 `laboratory.md` 為準。

不得擅自為所有研究者建立人類姓名、性別、外貌及人格設定。

除非總體設定有明確要求，否則不需要讓讀者知道研究者長什麼樣子。

# 六、每章的實驗室敘事設計方法

AI Agent 必須先理解歷史章節，再設計實驗室對話。

不得只根據章名或歷史事件名稱直接生成。

每章依照以下程序執行。

## 步驟一：閱讀完整章節

確認：

- 時間。
- 地點。
- 主要人物。
- 人物的身分與處境。
- 主要事件。
- 社會及制度背景。
- 本章對全書的作用。
- 與前後章節的關係。

## 步驟二：找出研究觀察點

從本章歷史內容中，找出適合研究者討論的現象。

例如：

- 制度與實際執行的落差。
- 權力與規則的衝突。
- 個人選擇與群體利益。
- 資訊傳遞與資訊封鎖。
- 社會秩序與暴力。
- 人類對未知事件的反應。
- 信念與現實的衝突。
- 群體合作與群體分裂。
- 人類對自身行為的理解。

研究觀察點不必是本章最大的歷史事件。

有時候，一個基層人物的日常行為，比皇帝的政治決策更值得研究。

## 步驟三：確認研究組

判斷哪個研究組最適合提出觀察。

可以由一個研究組主導，也可以由兩個研究組進行不同角度的討論。

不得為了讓所有研究組都有戲份而強行安排。

## 步驟四：建立對話的研究目的

每段對話至少應具備以下一種作用：

1. 提出新的研究問題。
2. 建立新的研究假說。
3. 質疑既有假說。
4. 修正先前結論。
5. 呈現研究組之間的分歧。
6. 累積長期研究成果。
7. 埋下後續研究的伏筆。

如果一段對話完全沒有上述作用，就不應安排。

## 步驟五：撰寫對話

依照本文件的長度、語氣及觀測限制完成。

不得將歷史章節內容直接改寫成研究者的摘要。

## 步驟六：檢查連續性

完成後必須檢查：

- 是否與前一章的實驗室劇情銜接？
- 是否與同一卷前面的研究假說一致？
- 是否與前幾卷的研究成果衝突？
- 是否提前揭露尚未觀察到的資訊？
- 是否擅自增加研究者的能力？
- 是否為了配合歷史結果而讓研究者突然變得全知？

# 七、跨作品的實驗室長期劇情

## 7.1 實驗室故事必須連續

外星實驗室不是每一本書重新開始的獨立故事。

應建立跨作品的長期研究歷程。

同一研究組在元末提出的假說，可以在宋末受到新的挑戰；在唐末觀察到的現象，也可以讓研究者重新檢視過去的結論。

研究者必須保留先前的研究成果及錯誤判斷。

## 7.2 歷史作品與研究主題

各作品的研究主題可以有不同側重。

目前可作為初步參考：

| 歷史作品 | 可觀察的研究問題 |
|---|---|
| 元末明初 | 舊秩序崩潰與新秩序形成 |
| 宋末 | 信念、忠誠、選擇與群體延續 |
| 唐末《長安秋暮》 | 中央權威、制度失效與地方秩序 |
| 五代《中原風雲》 | 政權競爭、反覆統合與秩序重建 |
| 明末至康熙 | 政權競爭、疆域整合與海疆秩序 |
| 清末《天下易主》 | 傳統文明與外部世界的衝擊 |

以上只是研究方向，不是每本書的固定命題。

研究問題可以跨越多個朝代，也可以在不同作品中反覆出現。

## 7.3 不要讓研究者過早得到答案

例如：

元末研究者認為制度可以維持秩序。

但他們觀察到制度被權力破壞。

宋末研究者可能認為信念可以維持群體。

但後續觀察發現，即使信念堅定，也未必能改變歷史結果。

唐末研究者可能進一步發現，制度、權力、信念都不是單獨決定文明發展的因素。

研究者的理解必須逐步形成，而不是作者預先安排好一套答案，再讓研究者照著念。

# 八、既有小說的回溯嵌入規範

本專案包含已經完成或已經規劃完成的歷史小說。

AI Agent 必須採用回溯嵌入方式。

## 8.1 不修改原始歷史正文

禁止：

- 改寫原有歷史正文。
- 刪除原有段落。
- 更改人物設定。
- 更改歷史事件。
- 為了外星人對話而改變章節結構。
- 擅自補充歷史情節。

實驗室內容只能作為新增的獨立區塊。

## 8.2 先完成章節分析，再撰寫對話

每章必須獨立判斷是否適合加入實驗室內容。

不應因為章節數量很多，就機械式地每章配置一段對話。

## 8.3 不要把所有歷史事件都轉化為研究問題

研究者不必對每一場戰爭、每一位皇帝及每一項政策發表意見。

應優先選擇能夠累積長期研究成果的現象。

## 8.4 尊重作品原有的情感

歷史正文中的人物遭遇、親情、離別、死亡、理想及遺憾，都是小說的重要組成。

研究者不應以冷漠的分析語氣嘲諷人類，也不應將人物的痛苦簡化成研究數據。

研究者可以不理解人類的情感，但不能讓這種不理解破壞小說本身的情感表現。

# 九、AI Agent 工作流程與交付文件

每次執行一卷或一批章節時，依照以下流程工作。

## 9.1 第一階段：讀取資料

必須先讀取：

1. `laboratory.md`
2. `laboratory_timeline.md`（如已建立）
3. 所屬作品的總綱。
4. 所屬作品的分卷規劃。
5. 本卷的完整章節內容。
6. 已完成的實驗室章節配置及前卷紀錄。

不得在未讀取既有設定前直接撰寫。

## 9.2 第二階段：建立章節配置表

每章先建立以下資料：

| 欄位 | 說明 |
|---|---|
| 章節 | 原有章節編號及名稱 |
| 歷史主題 | 本章主要歷史內容 |
| 觀察現象 | 值得研究的現象 |
| 研究組 | 主要參與研究的組別 |
| 研究問題 | 本章希望提出的問題 |
| 前後銜接 | 與實驗室前後劇情的關係 |
| 是否安排對話 | 是／否 |
| 對話位置 | 原則上章首 |

## 9.3 第三階段：撰寫實驗室對話

依照章節配置表完成所有預定對話。

必須保留原始章節正文。

建議採取新增區塊的方式，不直接覆寫原始檔案。

## 9.4 第四階段：建立實驗室章節紀錄

每卷建立一份：

`laboratory_volume_map.md`

內容至少包括：

- 本卷研究主題。
- 各章對話配置。
- 各研究組參與情況。
- 新增研究假說。
- 被推翻或修正的假說。
- 尚未解決的問題。
- 與下一卷的銜接。
- 跨作品的連續性影響。

## 9.5 第五階段：驗收

每卷完成後進行以下檢查：

- [ ] 原有歷史正文沒有被修改。
- [ ] 實驗室設定符合 `laboratory.md`。
- [ ] 研究組沒有被擅自增刪。
- [ ] 研究者沒有取得不合理的全知能力。
- [ ] 對話沒有變成歷史解說。
- [ ] 對話沒有過度冗長。
- [ ] 每段對話都有研究上的意義。
- [ ] 各章對話具有連續性。
- [ ] 各卷研究主線能夠持續發展。
- [ ] 沒有破壞歷史小說原有的情感及敘事節奏。

# 十、第一章示範：元末《上都煙塵》

本章作為 AI Agent 的初始校準範例。

**觀察對象：** 元代驛傳制度及其基層運作。

**研究主題：** 秩序。

**主要觀察現象：**

- 人類建立了完整的驛傳制度。
- 驛站人員依照規則執行職務。
- 上層權力在非常時期繞過制度。
- 制度執行者反而成為制度破壞的承受者。
- 基層人員在制度失效時，轉而保護自身及家人。

**研究問題：**

制度與控制是否為相同的概念？

**校準示範：**

【實驗室觀測紀錄】

「我發現一個現象。」

「說。」

「這個物種建立了一套非常龐大的資訊傳遞系統。道路、驛站、馬匹、人員、文書，每一個環節都有規則。」

「所以？」

「理論上，只要其中一個環節發生問題，其他環節應該能夠維持運作。」

「你確定？」

「目前的觀測資料是這樣。」

「那你看看現在。」

「傳遞中斷了？」

「不只是傳遞。你注意到沒有，負責維持這套系統的人，正在破壞這套系統。」

「這不合理。」

「為什麼？」

「如果他們依靠這套系統維持自己的統治，為什麼要親手破壞它？」

「也許，他們認為自己現在最需要的不是系統。」

「那是什麼？」

「控制。」

本範例僅供掌握敘事風格，不得機械式套用到其他章節。

# 十一、禁止事項總表

AI Agent 不得：

1. 把外星人寫成人類外貌、思維及情感的簡單翻版。
2. 為外星世界編造不必要的科技細節。
3. 把人類世界寫成普通虛擬遊戲。
4. 讓研究者直接知道所有歷史真相。
5. 讓研究者成為歷史事件的旁白解說員。
6. 為了外星故事修改歷史正文。
7. 為了湊字數而增加對話。
8. 每章都強迫安排同樣的對話形式。
9. 讓所有研究者永遠持有正確答案。
10. 把研究組設定成善惡對立的陣營。
11. 任意改變既有研究假說及實驗條件。
12. 為了製造戲劇性而讓研究者突然獲得新的觀測能力。
13. 讓實驗室故事搶走人類世界的敘事主體地位。
14. 擅自替尚未確定的研究組、研究者及實驗項目建立永久設定。

# 十二、最終創作理念

本專案不是在歷史小說中加入科幻元素。

而是在歷史小說之外，建立另一個持續發展的觀察視角。

人類在自己的世界裡生活、選擇、爭鬥、建立制度、創造文明，也承受歷史帶來的結果。

外星研究者則從另一個維度觀察這一切。

他們有自己的知識、假說、研究方法，也有自己的盲點。

他們可能觀察了人類數百年，仍然無法理解某些看似簡單的行為。

他們可能認為自己已經理解人類，卻在下一個歷史階段發現原先的理論完全不適用。

**不要急著讓外星人理解人類。**

**也不要急著讓讀者理解外星人。**

讓兩個世界各自發展，讓讀者在長期閱讀中，慢慢發現兩者之間的關係。

最重要的是：

**歷史照常發生，實驗持續進行。**
