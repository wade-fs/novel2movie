# 第三百二十章　分水知寒

至正十八年（1358）臘月，太湖西南，西山石公山下水網港汊。

太湖三萬六千頃，萬頃碧波在冬日的薄霧中宛如一面泛著幽藍光澤的古銅鏡。然而，在石公山南側這片原本水流暢通的湖灣裡，景象卻顯得異常逼仄與零亂。

一排排用粗大毛竹和生生夯入湖底的柳木樁連綿數里，將清澈的湖水硬生生隔斷成一塊塊死寂的方格。新築的泥壩橫七豎八地攔截在原本通航的水道之上，壩上插著一面面繡著「大元江浙行省平章張」、「太尉府參政李」字樣的大紅官旗。

在泥壩邊緣的一艘小烏篷船頭，五十八歲的老船工**柳知白**，正迎著刺骨的湖風，緩緩蹲下身子。

他穿著一身補丁摞補丁的粗布青襖，腰間用麻繩緊緊繫著那把陪伴了他四十年的包漿老骨尺。

柳知白伸出枯瘦粗糙、滿是裂口的大手，將那把磨損得邊角發圓的老骨尺垂直插進了泥壩下方的一道水竇之中。

「尺入三分，水流一寸……」

柳知白手指撫摸著尺身那道被太湖水浸泡了幾十年的刻痕，眉頭緊緊鎖成了一個疙瘩。

他又拔出骨尺，將指尖浸在冰冷的湖水裡，隨後把沾著水草的指尖送入口中，輕輕抿了抿。

「苦……澀……泥沙沉底，水氣已死。」

柳知白緩緩吐出一口白氣，轉過身，看著身後坐在船艙裡的一位六十多歲的太湖老漁翁。

老漁翁穿著破蓑衣，眼角掛著渾濁的淚水，手裡握著一張空空如也的破漁網，指著四周那些插滿官旗的泥壩，帶著哭腔悲憤地罵道：

「柳老哥！您是打小在水裡泡大的老水龍，您給評評這個理！這太湖自古是天下百姓的水，春秋時夫差和勾踐打仗，也沒說把太湖給圍起來當自個兒的私田！可自打去年張士誠當了元朝的大太尉，他那四弟張士信和平江城裡那幫將軍大人們，簡直像瘋了一樣！」

老漁翁狠狠把破網摔在船板上，泣不成聲：

「他們帶著成千上萬的兵卒，強佔了西山和東山三萬多畝活水湖灣！填土築壩、圍湖造田，全圈成他們張家將官的私家莊園！生生把太湖洩洪分流的七十二條水汊堵死了三十多條！咱們這些打魚為生的漁戶，如今連下網的地方都沒有！前天俺那二小子划著小船想從泥壩口借道打兩條鰱魚，硬是被張平章莊子上的惡奴用鳥銃轟爛了船底，差點淹死在湖裡啊！」

坐在柳知白身旁的養子柳小栓（時年十九歲）氣得滿臉通紅，抓起船槳罵道：

「阿爹！去年張士誠在大堂受封太尉的時候，阿爹還替他們公證了海運漕運水契！這張士信太不是東西了，這不是把老百姓往死路上逼嗎？！」

柳知白沒有說話。

他緩緩站起身，從懷裡摸出一卷發黃發脆的手繪羊皮古卷——那是他歷經三十年、走遍長江沿線每一處水脈親手繪製的《萬里長江水脈秘圖》。

柳知白用粗糙的拇指，在圖卷上的太湖區域重重劃過：

太湖東面是吳江、平江，北接常州，西鄰宜興；長江與太湖水系犬牙交錯，乃江南百萬生民的血脈命根！

「老弟啊，」柳知白望著眼前被泥壩截斷的死水，語氣沉重如鉛：

「水有水性，人有人道。水是活的，必須奔流不息、疏導分洪，方能滋養萬物！若是人心貪婪，仗著刀兵將天底下的活水圈成自家的死水塘，老天爺是一定要降罪的！」

柳知白指向平江府的方向，冷冷說道：

「張士誠這幫鹽丁起義，原本靠的是淮南十八條扁擔同仇敵愾的一腔熱血。可進了蘇州花花世界，短短兩年，他們便學起了蒙古王公那一套最下作的手段！圈圍湖田、阻斷水道、強佔民產、貪得無厭！這太湖的水被他們堵死了，老百姓對他們的那顆心，也就徹底堵死了！」

「那……那西邊呢？」老漁翁抹了抹眼淚，疑惑地問道，「柳老哥，俺聽往來常州的運糧船家說，西邊常州和金陵那邊，如今可是朱元璋的地盤……朱元璋難道就不圈地？」

聽到「朱元璋」這三個字，柳知白原本陰鬱的眼眸深處，驟然亮起了一道奇異的亮光。

他收起羊皮圖卷，將包漿老骨尺重新插回腰帶，指著太湖西北面的常州與鎮江方向，聲音沉靜而悠遠：

「朱元璋？上個月老夫剛從常州東壩和金陵秦淮河過來。」

柳知白嘴角泛起一抹由衷的敬佩與嘆服：

「在常州，朱元璋手底下的湯和大將軍，帶著三萬軍民冒著嚴寒，生生把淤塞了三十年的宜興荊溪和常州運河全挖通了！在金陵，徐達和常遇春的大軍一邊操練，一邊在紫金山下開渠築塘、興修水利！朱元璋頒下嚴令：凡有官兵將領敢圈佔民田一畝、堵塞水利一道者，立斬不赦！」

柳知白眼中閃爍著深邃的智慧，語氣中帶著洞悉歷史興亡的磅礴力量：

「老弟，這天底下的江山社稷，就跟老夫手裡這把老骨尺量水一模一樣！什麼叫王道？疏川導滯、使百萬生民有飯吃、有活路，這就叫王道！什麼叫霸道自取滅亡？截流自肥、與民爭利、自塞活路，這就叫自掘墳墓！」

柳知白深長地吸了一口刺骨的太湖冬風，望著太湖兩端截然不同的命運，擲地有聲地吐出了十個大字：

**「平江之水已死，金陵之水方生！」**

老漁翁與柳小栓聽得心頭劇震，呆呆地望著西方常州的天空。

「阿爹，」柳小栓低聲問道，「那咱們接下來往哪走？」

柳知白解開小船纜繩，用竹篙在泥壩前輕輕一點，小船順著未被堵死的一道狹窄清流，悠悠向西滑去：

「去處州，去浙東！朱元璋剛打下了婺州金華，前鋒胡大海正揮戈逼進處州！那裡的麗水甌江，還有許多未解的水道等著咱們去丈量！這天下的水，就要迎來它真正的主人了！」

太湖的微瀾在夕陽下漸漸暗去。

那一葉孤舟，帶著一把古老的骨尺與看透興亡的睿智，在冰冷的湖水深處，朝著那片充滿生機的王道之地，從容破浪前行。

### 【工作紀錄】
- **【史實骨架】**：《明史·張士誠傳》、《蘇州府志》及《太湖水利志》載：張士誠受封元朝太尉後，其弟張士信、部將李伯昇等將領在蘇州太湖周邊大肆圈佔湖田、築壩建私莊水榭，導致太湖排洪水道淤塞滯澀、漁民生計艱難、水系生態遭到嚴重破壞；而朱元璋在應天、太平、常州大力興修水利、疏浚河道、推行軍民屯田（「興修水利、保境足食」），二者在基層治理與民生生態上形成極端鮮明的反差。
- **【待核事項】**：柳知白時年58歲（生於1300年），作為貫穿全書民間科技與水脈視角的靈魂人物，其在太湖西山石公山測水為小說精準設定之情節線索。
- **【合理推演】**：透過老船工柳知白以老骨尺插水測流水質的微觀動作，將張士誠政權腐化墮落投射到太湖生態與漁民生計的具體矛盾上；借柳知白之口提煉出「平江之水已死，金陵之水方生」的宏大歷史讖語，深刻揭示兩大江南割據政權背後的民心向背根本分水嶺。
- **【小說虛構】**：太湖石公山泥壩插太尉府官旗；老漁翁哭訴張平章惡奴鳥銃擊沉漁船；柳知白以骨尺插水竇嘗水草苦澀；道出「平江水死金陵水生」名言並乘烏篷船西去處州。
- **【連續性變更】**：
  - **柳知白**：58歲，完成太湖水脈考察，洞悉張氏必亡，攜養子柳小栓轉往浙東甌江水系。
  - **張士誠集團**：圈佔太湖良田湖灣，將領私慾膨脹，基層民怨徹底沸騰。
  - **保住什麼**：張士信等平江貴冑保住了眼前的私莊湖田利益。
  - **失去什麼**：徹底失去了太湖沿岸數萬漁戶與農民的民心支持。
  - **哪些變成日常**：太湖私設關卡泥壩、漁民艱難求生、平江將官私莊連綿，成為太湖動盪日常。
  - **章末狀態變化**：太湖水脈已滯；而在此時的浙東南崇山峻嶺之中，朱元璋麾下的名將胡大海與黑面跛足名士孫炎，已經冒著漫天風雪，殺向了浙東重鎮——處州！
- **【後續銜接】**：第321章將視角轉向浙江處州麗水，胡大海、耿再成與名士孫炎夜襲古樓洞大破石抹宜孫克處州，朱元璋任孫炎為處州總制，孫炎城頭遠眺南田山尋訪劉基（〈處州烽火〉）。
